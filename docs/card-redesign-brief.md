# 卡片重做：设计纲要（2026-09-23 逐项问定）

这份文档是**用户逐条拍过的决定**，动代码前先看它。三条轴：卡面工艺、卡框、3D。

## 一、风格主线（总纲）

**分层：低档真实印刷、高档幻想光效。** 低档要"看得懂"（像一张真印刷卡），高档要"有惊喜"（数字卡才有的光效）。
「正交」不等于低档也会有幻想光效 —— 光效强度由等级给：收藏档的流光/星屑/全息通道一律为 0，
往上逐级长出来。这条与现有 `RANK_3D` 的口径一致，继续沿用。

## 二、卡面工艺：8 种

**保留 4 种（光系）**：星芒全息、全息、烫银、星屑。
**新设计 4 种（印刷系）**：凸印压痕、珠光纸、烫金箔、墨染。

| 工艺 | 纹样 | 材质 | 与谁最容易混 → 靠什么拉开 |
|---|---|---|---|
| 星芒全息 | 几何星芒（六/八芒） | 彩虹衍射，**只在线内出彩虹** | vs 全息：有图案 / 无图案 |
| 全息 | 无图案 | 大面积彩虹箔，整体随角度变色 | vs 烫银：会彩虹 / 不彩虹 |
| 烫银 | 细斜纹（弱） | 镜面银，冷白高光，**不彩虹** | vs 烫金：冷银 / 暖金 |
| 星屑 | 大小不一的点 + 少量十字星光 | 深底上发亮的点状发光，**无面** | vs 星芒：点 / 几何线 |
| 凸印压痕 | 沿画面轮廓的压痕（无独立图案） | 纸白，**只改光不改色**，左上高光右下阴影 | 唯一的"零颜色"工艺 |
| 珠光纸 | 细密横向丝光 | 暖白珠光，随角度**微**变色，带纸纹颗粒 | vs 全息：弱一个量级、偏暖白 |
| 烫金箔 | 云纹/缠枝等传统纹样 | 暖黄金属，边缘锐利闪光，**不彩虹** | vs 烫银：暖 / 冷 |
| 墨染 | 水墨晕染（边缘羽化、浓淡不匀） | 冷灰黑、亚光、纸纹吸墨 | 唯一的"暗面"工艺 |

- **工艺与等级正交**：工艺管纹样与材质，等级管框与光效强度。同一种工艺在收藏档是"素面印刷"，在传世档才满力。
- **叠加：1 主 + 最多 1 副**；副工艺只出纹样层、不出材质与框；**只有传世与奇迹**能有副工艺。
- **墙上 205px 必须可辨**：同一副纹样、**两级强度** —— 卡小的时候按显示尺寸放大线宽与对比，弹层回归细腻。
  同一份参数、不维护两套图形。

## 三、卡框：全档同一副框

同宽、同角饰、同徽记位置，**几何完全一致**。等级只靠两处：

1. **材质色阶（金属系）**：纸白 → 赤铜 → 白银 → 黄金 → 黑金 → 幻彩。
2. **徽记**的分级：六档曲线的徽记沿用（圆 → 星形线 → 双纽线 → 内摆线 → 玫瑰线 → 蝴蝶）。

**物理卡边（左上受光/右下背光）与内衬线保留** —— 那是"这是一张实物卡"的两条关键线索。

## 四、3D 卡

四块全要，按贵贱分阶段：

1. **能转的真卡**（现有基础，保留）。
2. **工艺纹样真的做进 3D 表面**：前提**已满足**（2026-09-25 查清）。「高度图改了没反应」是旧实验的**方法错**：它把图案写进了 `public/` 里的构建产物，而页面服务自 hugo 开发服务器（从 `assets/` 现渲染），改的是一个没人服务的副本；同一个 0.055 格线图案写进源码后是卡面内 **5.99 / 14.65% 像素**（判读为「表面压出格状起伏」，无撕裂）。机制、读数与坑记在 `assets/js/card-3d.js` 里 `parallax()` 那段注释、`lab/README.md`「3D 卡效果的量测口径」与 `docs/pending.md`。**方向也已定**（2026-09-25 样张轮）：纹样要「有结点、有线宽变化、有边框」的规整格（掐丝格那一版判读最好），均匀细网格禁入（读成数字 moiré），高斯软脊读成「糊」；默认幅度 ≈0.11、上限 ≈0.15，且加法要留头寸防削顶。详表见 `docs/pending.md` 的「候选样张轮」。**已落管线**（2026-09-25）：`reliefPattern`（YAML 单一事实源）+ `tools/cards/make-depth.py` 的图案层（`--pattern auto|none|<kind>`，叠在滤波之后）—— **烫金箔/烫银（缠枝卷草）、珠光纸（帘纹）、凸印压痕（硬菱格）四档已上**，三轮 1:1 判读判「可定档」；**星屑夜天/星芒全息/墨染三档先关掉**（星点落在脸上、射线穿过手臂、飞白读成扫描线 —— 瓶颈是手上只有「高度代理 + 皮肤掩码」两张网，认不出主体；要接得先引分割模型，或把那三个家族的形态重做）。`foil`（默认兜底档）不配纹样。详表见 `docs/pending.md` 的「落地轮」。
3. **展示台**：卡悬浮 + 背景压暗 + 投影 + 景深。
4. **分层浮起**：
   - 基础（全部档位）：**2 层**（主体 + 背景），转到侧面/背面**自动收平** —— 保住实卡手感。
   - **只有传世与奇迹**有触发方式：点一下进入"层离"（更多层、各自视差），并与**奇迹的显形合成一个动作**。
   - 纪律：层越多越像"盒子里的景"，所以基础档只做 2 层，多的那部分必须由用户主动触发。

**先出设计稿（纹样与卡框的静态样张）→ 用户拍 → 再动代码。**
样张要带**双尺寸对照**（205px 墙 / 弹层尺度），因为"墙上可辨"是硬要求。


## 八、样张 v1 的实测结论（2026-09-23）

样张：`lab/redesign/sheet1.html`（截图 `lab/结果/collreview/sheet1-full.png`），8 种工艺 × 两种尺寸 + 6 档框材质。

**成立的两条技术路线：**

1. **凸印压痕不能靠画面本身做**（用原画做掩膜会把人洗成白模）。正确做法是**由深度图算"高度场梯度"**：
   `lab/工具/bevelmap.py` —— 法线与左上方光源做 Lambert 得受光图、再做一次高次幂得脊线镜面图，
   两张灰图分别用 `soft-light`（受光，改光不改色）与 `screen`（镜面）叠在画面上。**画面颜色完整保留，压痕沿人物本身的起伏走**。
   代价：每张卡多两张小灰图（可按需求生成 webp，约 10~20KB/张）。
2. **烫金箔的金属感来自渐变本身，不要靠 mask**：把金渐变直接烘进云纹 SVG 的 stroke（`linearGradient` + 多个 stop 做明暗交替），
   再用一道斜向镜面 `screen` 扫过 —— 比"渐变层 + mask"稳得多。

**v1 暴露的问题（要修）：**

- **205px 下凸印压痕与珠光纸分不开** —— 两者都"保留原色 + 轻微纹理"。修法（走两级强度那条机制）：
  珠光在墙上**整体偏暖**（可见的暖白偏色），凸印在墙上**给主体加一层接触阴影/明暗包边**，让两者的"视觉签名"在小尺寸下就不同。
- 墨染在小尺寸下最可辨（黑团），烫金次之（暖金云纹）；光系 4 种待同样做"视觉签名"检查。


## 九、纹样路线 v2：CSS 矢量平铺 → 生成纹样板（2026-09-23）

用户反馈：**有图形的工艺（烫金箔 / 墨染 / 星芒全息 / 星屑）"太生硬"**。根子在两处：矢量线稿边缘硬、粗细一致；平铺 = 等距重复，一眼就是壁纸。

**改法：把纹样从 CSS 矢量平铺改成"生成出来的整张纹样板"**（`lab/工具/mkpatterns.py` → `lab/redesign/plates/*.webp`）：

- 每块板**只做一张、全库共用**（不随卡数增长，4 块板合计约 0.3~0.6 MB）；做成整张而不是 tile，从根上消灭接缝与等距重复。
- 生硬靠三件事治：**不规则**（位置/大小/旋转随机）、**化边**（羽化 + 分形噪声做轮廓与断续）、**密度不均**（成团分布，不是均匀撒）。
- 墨染用分形噪声当晕染、烫金用随机卷云曲线 + 箔的断续、星芒/星屑用稀疏随机 + 柔光。

A/B 判读结果（`lab/结果/collreview/sheet2-ab.jpg`）：**烫金箔、星芒全息、星屑三对 v2 都成立**（更自然、没糊、没盖住画面）；
磨金箔 v2 偏含蓄，可再提一点存在感。

**墨染 v2 仍不到位**（明显比 v1 好，但还是"数字噪点/罩层"，不是水墨）。下一版的修法（三条，按重要性）：

1. **用深度图做主体避让遮罩** —— 墨只落在背景区域，脸/手/裙摆保持干净。深度图本来就有（主体亮、背景暗），反相即可当遮罩。
2. **降颗粒**：现在 fbm 直接阈值化 → 盐缩噪点感；改成低频团块决定"墨在哪"、高频只负责轮廓的轻微扰动。
3. **水痕边**：用「膨胀 − 原图」做出一圈略深的水痕边，比现在的碎边更像纸上吸墨。


## 十、墨染定稿与两条通用设计规则（2026-09-23）

用户反馈"墨染还是有点脏"。查清了"脏"的三个来源，逐个消掉：

1. **高频阈值化的分形噪声 = 盐缩颗粒** → 改成低频团块定浓淡、高频只做轻微扰动。
2. **模糊填充出来的软边 = 灰雾罩层** → 改成「沿路径盖章」的笔触（`bez` + `brush`：粗细随行笔起伏、两端收尖、
   干笔处断开），收尾只糊 1.3px，浓心用 `(w-0.05)*1.75` 快切到纯黑。
3. **暗墨压在白裙上，一定读成脏** —— 这条是最关键的：墨只走灰底背景，一笔都不压白裙。

**两条通用规则（对 8 种工艺都适用）：**

- **暗部元素不要压在高调主体上**：白裙/白发上任何深色都读成污渍。工艺的深色成分要有"避让"或只落在中间调的背景上。
- **两级强度不只是"放大对比"，而是"减元素 + 加粗主线 + 抹掉细颗粒"**：细线和细颗粒在 205px 下会变成噪点，
  不是"更精致"。墙上版要**删掉最细的那一笔**（墨染的右上清笔在小尺寸会像划痕），主笔放大 15~20% 并轻度模糊。

**当前状态**：弹层尺度版**可定稿**；205px 墙上版按上面的适配也读得出来（`lab/结果/collreview/ink-final.jpg`、`ink-wall-adapt.jpg`）。


## 十一、光系四工艺与「靠材质分级」的实测结论（2026-09-23）

**一、光系四工艺在 205px 上还没解决（烫银最急）**

- **烫银过曝**：白裙白发被银光吃掉。根因是我把银写成了"白光带"。银是有暗面的金属 ——
  改成**中灰金属体（multiply）+ 窄亮边（screen，宽度 ~12%）+ 一道暗侧**，并加冷灰反射。已改，仍需再验。
- **星屑**：密集小点在 205px 下就是灰尘/噪点（细颗粒→噪点的规则再次应验）。已改成"少而大的火花 + 十字长臂"，
  大尺寸下成立，小尺寸仍偏弱，需要再加大少元素的比例。
- **星芒全息**：硬边白星在小尺寸读成"贴上去的贴纸"。修法：保留硬边、降不透明度、加虹彩边、允许被人物的光晕吃掉一部分。
- **全息**：偏白偏平，把人物的明暗压掉了 —— 要降强度，把体积感还给画面。

**二、「靠材质分级」在小尺寸不成立（这条最重要）**

实测：六档材质在 205px 下只能读出"不同"，读不出"高低"。亮度序列是 **高-低-高-中-低-高（纸白/赤铜/白银/黄金/黑金/幻彩）**，
不是单调的；色相冷暖交替。结论：**材质色阶必须重排成单调明度 + 递增彩度/光泽**，而且等级必须有**第二个在小尺寸看得见的通道**。

两条修法：

1. **材质色阶重排（单调明度 + 递增彩度）**：纸白(最亮、无光泽) → 珠银(次亮、柔光泽) → 黄金(中、金属) →
   赤铜(较暗、深金属) → 黑金(最暗 + 金线) → **幻彩（黑底幻彩流光：明度仍低、彩度最高）**。
   幻彩做成"暗底流光"而不是"亮彩虹"，这样六档的明度仍然是单调下降的。
2. **徽记必须在 205px 上看得见** —— 用户原本的方案里就有徽记（六档曲线：圆/星形线/双纽线/内摆线/玫瑰线/蝴蝶），
   但它要成为**小尺寸下真正承担分级的那一个通道**：够大、够对比、位置固定。样张 v1 根本没画徽记，这是缺口。


## 十二、色阶重排的实测：问题不在色阶，在**带宽**（2026-09-23）

重排后的六档（素纸→珠光→烫银→烫金→黑金→幻彩，明度相邻差 ≥10）在 205px 上实测**仍然排不出高低**。
原因不是我排得不够开：**205px 时框带只有约 7 个物理像素宽，一条 7px 的细带承载不了"材质色阶"** ——
相邻两档差 10 个明度值，落在 7px 宽的边上，人眼读不出来；反而"饱和度"会跳出来干扰判断。

**结论（重要）：靠材质色阶分级，在墙尺寸上不可行 —— 这是面积问题，不是配色问题。**
等级必须在墙上换到一个**有面积**的通道。四条候选：

| 通道 | 做法 | 代价 |
|---|---|---|
| A 框内缘等级色带 | 内地缘一圈 4~6px 的等级色带（整圈，像集换卡的 rarity strip） | 改框结构，但面积足够、规整、最耐读 |
| B 徽记单独扛 | 徽记放大到卡面 1/5 宽 + 金属压印感 + 固定角标 | 不动框；徽记要重画 |
| C 框整体加厚 | 框加厚到 6~8px，靠材质读档 | 改变卡片比例观感 |
| D 卡面底衬色调 | 低档补浅色衬、高档压暗角（大面积） | 会动到画面上的一切工艺 |

**徽记实测**：205px 下深色底托只有十多像素，圆/三尖/四尖/五尖/六瓣全被像素吃掉，读成"黑点/污渍"。
所以徽记若要在墙上承担分级，必须**放大 + 高对比**（或做成金属压印那种"实心徽记"而不是细线轮廓）。

**星屑 → 星闪（重做中）**：已从"点阵"改成"四芒星闪（亮核 + 光臂渐隐）"，弹层尺度不再像灰尘；
但"串珠"的轨迹还没连起来（星点仍偏散），下一步补连续轨迹/拖尾与大小节奏。


## 十三、等级通道定了：一条色阶梯，两处同源（2026-09-23 实测通过）

**用户拍板：墙上用「框内缘一圈等级色带」承担等级信号，材质色阶保留（当弹层里的材质语言）。**

**关键教训（踩过两次）**：

1. 先试"材质色阶承担分级" → 205px 上框带只有 ~7px，承载不了，失败（见 §十二）。
2. 再试"材质色阶 + 另一套颜色的色带" → **两套色阶梯互相打架**，判读直接指出"看框和看色带得到的顺序不一致"，
   比只有一套还差。

**成立的做法：一条色阶梯，两处同源。**

- 色阶梯：**灰纸 → 青玉 → 蓝钢 → 紫金 → 黄金 → 幻彩**（色相逐档推进、彩度与"贵重感"递增）。
- **框材质 = 该档色的金属版**；**框内缘色带 = 该档色的纯色版**；两处同一个色，谁也不抢谁。
- **色带宽度随档递增**（2.4% → 5.4% 卡宽）：面积本身成为第二个单调通道。
- 素材：`lab/redesign/sheet1.html`（自包含样张），实拍 `lab/结果/collreview/v2-rank3.jpg`。

判读结论：**能一眼排出高低，双色冲突已解决，方案基本成立。** 顺手改掉的四条精修：蓝/紫拉开（蓝提亮、紫压深）、
黄金提纯（亮金 #f0cf76 + 深金 #a8760f，去掉土黄）、幻彩固定暗底（虹彩只做流光，避免像 RGB 故障／花屏）、
色带宽度递增从 3.0–4.2% 拉到 2.4–5.4%。

**还欠的两件（下一步）**：

1. **非颜色的冗余编码**：徽记要放大、形状差异要更大（色盲与小图都要能分档）—— 现在徽记在 205px 下仍偏小。
2. **全档多尺寸总校验**：六档 × 双尺寸 × 全部 8 种工艺混在同一条墙上，看整体是否和谐、有没有互相抢。


## 十四、边框花纹定案：单色压印「双细线」（2026-09-23 实测）

四个候选（素带 / 双细线 / 珠链 / 回纹）在同一档「秘藏·黄金」下双尺寸实测：

| 候选 | 205px | 弹层 | 是否抢等级色带 | 结论 |
|---|---|---|---|---|
| 素带 | 干净 | 干净 | 不抢 | 保底方案 |
| **双细线** | 仍读得出"内框"结构 | 精致、有层次 | 基本不抢 | **定案** |
| 珠链 | 珠子变小、读成断续噪点 | 有珠宝感 | 小尺寸略抢 | 否 |
| 回纹 | **糊成花边/噪带** | 华丽 | 最抢 | 否 |

**结论：边框花纹用「单色压印的双细线」**，与等级色带同色系、低对比、只做收边 —— 不新增色相，所以不构成第二个"等级声音"。
细密花纹（回纹、卷草、珠链）在 205px 一律变噪点，**要华丽只能放在弹层的第二档强度里**。这是"细密高频在小尺寸=噪点"这条规则的第三次应验。

## 十五、混排墙首过暴露的两件事（2026-09-23）

混排墙（8 工艺 × 6 档，205px）整体和谐度只给到 **4/10**，暴露两件：

1. **墨染在浅色卡面 + 205px 下读成污痕**（判读原话："像渲染错误、污痕、没擦干净的笔刷"）。
   由此得到一条新规则：**工艺要与卡面适配** —— 深色成分的工艺（墨染、黑金类）只适合**中低调**的卡面，
   浅色卡面上一律读成脏。这条单卡样张看不出来，必须有**工艺 × 卡面适配表**。
2. **同档相邻会出现"重复感"**：8 格排 6 档，必然有两档重复出现，重复的档挨在一起时就显得"没秩序"。
   这是**排布问题**（实际站点 57 张随机分布），但说明墙上要考虑**等级在排布上的分散**，不能让它扎堆。

**顺带**：徽记放到卡面 10.5% 仍然偏小（205px 下形状还是认不准），下一步要改"实心压印 + 高对比"，而不是继续放大细线轮廓。


## 十六、工艺 × 卡面适配表（2026-09-23 实测，205px）

按真实卡面明度挑三张（暗 37 / 中 197 / 亮 230），与 6 种工艺交叉排，205px 上逐格判读：

| 工艺 | 亮卡面 230 | 中 197 | 暗 37 | 适配 |
|---|---|---|---|---|
| 墨染 | **脏**（像漏墨） | **脏**（像咖啡渍） | **优秀**（像烟雾/云层） | **只适合暗卡** |
| 星闪 | 糊（白点在亮底显不出） | 糊（融成噪点） | 优秀（星光璀璨） | **只适合暗卡** |
| 烫金 | 正常 | 正常 | 最佳（黑底金字） | 暗卡主场，亮中可用 |
| 全息 | 略脏 | 正常 | 最佳 | 暗卡主场，亮中可用 |
| 凸印 | 好（光影清楚） | 好 | 偏平（缺对比） | **通用**，亮中更好 |
| 珠光 | 好（通透） | 正常 | **脏**（像划痕/水渍） | **只适合亮/中卡** |

**一句话：亮卡面配"微光与物理压印"（凸印、珠光）；暗卡面配"强对比与悬浮特效"（墨染、星闪、烫金、全息）。**
乱配在 205px 上一定"脏 / 糊 / 像坏了" —— 这也解释了混排墙里"墨染像污痕"那件事：不是墨染坏了，是**配错了卡面**。

落地含义（要动清单结构）：`data/home-cards.yaml` 每张卡要么按明度自动过滤可选工艺，要么在清单里显式声明**这张卡允许哪种工艺**；
`check-deck.mjs` 要新增一条守卫（工艺 × 明度适配）。**这条会在代码阶段改到清单与校验脚本，必须在设计阶段先定。**

## 二十二、边框花纹「复杂版」与等级标「去几何化」（2026-09-23）

### 花纹：L 型边框砖 + 四角角花 + 压印对偶
做法：同一条纹样在**相邻两边各画一遍**（L 型砖），平铺即得整圈连续纹样；线一律**压印对偶**（暗线 + 反向错位亮线，`translate(±0.75)`）→ 有雕琢感而不是平涂。四角另加角花（回纹方旋，四层 `no-repeat` 定角）。

四个候选实测（205 / 420 同一纹样两个尺度）：

| 候选 | 205px 墙 | 420px 弹层 |
|---|---|---|
| 双细线 | 最清楚，但不算"花纹" | 太素，像普通简约金框 |
| 回纹 | 偏密，读成花边噪带 | 硬朗、偏传统 |
| 卷草 | **糊成噪带**（细碎卷曲） | **最像精装卡/证书烫印** |
| **如意云纹** | **块面大、最抗缩**，仍读得出纹样 | 端庄、偏中式国风 |

**定案：墙上用如意云纹，弹层用卷草**。角花在 205px 只能看到"四角有装饰"的轮廓，读不出纹样 —— 这一点不能再要求更多。

### 等级标：统一底场 + 负形镂空（v3）
v1（几何图形）、v2（六枚各自设计的剪影）都被判"像六个各画各的小图标，不是纹章家族"。v3 的改法：

- **统一底场**：六档共用同一枚圆角盾（占满视图 92%）+ 内圈 0.80 缩放的家族花边；
- **图案全部改负形镂空**（`fill-rule=evenodd`，图案是"洞"不是"贴上去的形"）→ 家族感与对比度一起解决；
- **外形差异靠负形的质量分布拉开**：竖向 Y / 空三角 / 鸢尾 / 十字 / 星 / 横向翼；
- **两级强度**：墙上是核，弹层加镂空花边（判读同意的做法）。

**客观判据（黑白剪影测试，全填黑）**：32px、24px 六枚一眼分清；**20px 临界；16px 不分**。标在墙上的实际尺寸约 33px → **通过**。

判读结论：v3 相对 v2 是**方向正确的进步**（家族感、系统感明显增强），代价是个别符号辨识度下降。三条对比度修正已改（统一深色外轮廓、收藏档底场压深、奇迹档粉提饱和），**未复验**。

## 二十四、花纹「自然化」与等级标尺寸（2026-09-23 实测定案）

### 自然化的三个来源（不靠画细）
① **笔势收锋**：图案用**填充带**（起笔粗、收笔尖）而不是等宽描边；② **不等间距**：叶芽落点不规则、大小/角度各异；③ **非对称砖**：一块砖内左右不镜像 → 平铺出 period-2 节奏。

四候选实测（205 / 420）：

| 候选 | 205px | 420px | 自然度 |
|---|---|---|---|
| n-vine 藤蔓 | 有结构但机械 | 一眼看出平铺单元 | **最低** |
| n-branch 细枝 | **接近噪点** | 最像手绘枝芽 | 最高 |
| **n-ink 墨线** | **结构最清楚** | **最像手工压箔（高级）** | 高 |
| n-soft 柔云 | 糊成均匀亮带 | 柔但"平"，无笔势 | 中 |

**定案：墙上 n-ink（少而粗、高对比），弹层用同族加密版（更长更多笔触）。** 与"同款简单缩放"相比判读明确推荐**分尺寸独立调整**。

### 等级标尺寸（判读给出识别下限）
墙上 **12%（≈25px）**、弹层 **16%（≈67px）**；判读原话："约 20–25px 是徽章识别下限，再小就退化成小点"。9%（18px）已糊。

### 同轮实测的遗留项（未改）
**色带宽度差在 205px 区分度不足** —— 判读建议把六档宽度差**再拉大 10–15%**（现 2.4% → 5.4%）。这是当前唯一还开着的一处微调。


## 二十五、角花自然化（2026-09-23 实测定案）

用户反馈「卡框四个角的图案太生硬」。原角花是**方旋回纹**：直角、等宽、四角同一朝向 —— 三样都硬。

四个候选（卷草角 / 抽芽角 / 墨扫角 / 圆化方旋），共同改法：**填充带收锋 + 非对称（主枝 + 大小不等叶）+ 每角各自旋转 90° 朝内生长**（原来是同一张砖同朝向硬贴）。

| 候选 | 判读 |
|---|---|
| **c-scroll 卷草角** | **定案** —— "自然感、清洁度、可读性最平衡，明显软化了几何感" |
| c-bud 抽芽角 | 太细，420px 下像轻微划痕 |
| c-ink 墨扫角 | 毛糙边缘，易显脏/破损 |
| c-rounded 圆化方旋 | 干净但本质仍几何、机械 |

**已接进定稿样张**（`orn4 c-scroll`）。复验遗留：**浅色档（收藏/奇迹）的角花线在浅底上读成灰渍/掉色** —— 已加 `.card.m-strip-light .orn4 { filter:brightness(.74) contrast(1.4) }`，**未复验**。

**判读同轮再次点名色带宽度差**：六档宽度差在 205px 区分度不足，建议再拉大 10–15%（现 2.4% → 5.4%）。仍是唯一开着的微调项。


## 二十六、等级标移到卡背 + 色带宽度差拉大（2026-09-23 用户拍板）

### 等级标挪到卡背
正面去掉 `.mark`（正面已够忙：色带 + 花纹 + 角花），等级标改住卡背：**该档材质底 + 内衬框 + 居中等级标 + 底部档位文字**。定稿样张新增「卡背六档」两段（205 / 420）。

## 三十四、色带阶梯得拿「框深」换 + 色带必须带两条深色描边（2026-09-24 晚，1:1 实测定案）

判读点名两条：① **色带宽度递进感知不到**；② **色带与卡面融色**（灰融灰 / 蓝融蓝 / 白融白）。

**三条候选在同一张 206px 1:1 六档接触表 + 左边缘水平扫描线上对拍**（判读原话）：

| 做法 | 相邻差@206px | 判读 |
|---|---|---|
| 现状（框深 0.060w，阶梯 0.020–0.060，无色带描边） | 1.6px | 「不能一眼看出逐档递增，相邻档宽度差只有约 1px，需要仔细并排比对或测量才明显」 |
| 只加两条深色描边（框深与阶梯不动） | 1.6px | 同样排不出来 —— 描边治好了 ②，救不了 ① |
| **框深 0.075w + 阶梯 0.020–0.075 + 两条描边（采用）** | **2.3px** | 「能把六档正确排序」；最难分的是 rare–epic，legend–miracle 次之 |
| 框深 0.080w + 阶梯 0.020–0.080 + 两条描边 | 2.5px | 阶梯最清楚，但整墙对拍被判「边框占面积明显增大…像厚相框」，画面感被削弱 |

**定案**：框深 **0.060w → 0.075w**（画面内缩 12.3 → 15.4px@206px），色带阶梯
**0.020 / 0.031 / 0.042 / 0.053 / 0.064 / 0.075**（相邻差 0.011 卡宽 = 2.3px@206px = 4.6px@420px，
总幅 3.0x → 3.75x）。代价认清：画面每边小 3px。**这是唯一的办法** —— 框深 0.060w 时六档色带全挤在
0.060w 里，相邻差上限只有 ~0.010 卡宽（约 2px），怎么排都读不出来（§十二 的「这是面积问题」在
框深上同样成立）。

**色带的两条深色描边**（做法）：`.home-card-strip` 本体 = 深色衬底（`--strip-ink: rgba(11,8,15,.68)`，
结构件、六档同值）的整条环；`::before` = 该档纯色版色带（`inset: 1px` + 自己的 content-box 反相
mask，环厚 = `--rank-sw` − 1px）。衬底在色带内外各露 1px，于是色带的两条边被定住：外缘那条把它
与框材质分开（灰融灰 / 蓝融蓝），内缘那条贴在画面边上（白融白）。实测依据：不加描边时色带与框材质的
最大通道差只有 **30–44**（灰 vs 灰、蓝 vs 蓝），加了之后描边在两侧都是 1px 的 70 左右的深线。

先试过 `border` + 负 `outline-offset`（1:1 扫描线上完全正确，两条线各就各位），但 8× 放大下
outline 的拐角不跟 `border-radius` 缩半径、出现方角小方块/断口 —— 换成衬底 + 子层这条路，两层
走同一条 mask，圆角天然同心。**另一条坑**：`::before` 必须是「一圈」而不是「一整块」—— 只填满
衬底里圈的话，mask 会把它一直顶到画面边上，把衬底内缘那 1px 也盖掉（1:1 扫描线上就是这么发现的）。

**遗留（下一轮）**：① 收藏档那条灰带（`#84888f`）在浅画面上仍偏弱：扫描线上色带 132 对框材质 220
（差得不小），弱的是它与浅画面那一侧 —— 要不要把灰再压沉一档（例如 `#6d7280`）留待判读；② 8× 放大
下 1px 描边在圆角处仍是像素阶梯（3× 与 1:1 看不出来），未做专项修；③ 样张
（`lab/redesign/verify.html` / `sheet2-final.html`）尚未同步这三处数值，反推这一节请以 CSS 为准。
