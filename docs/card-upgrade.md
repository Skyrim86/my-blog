# 卡片全面升级：方案与分期（2026-09-23 提案，等你定方向）

> 起因：两轮取证后你给的判断是「不够好看和谐」，要求做一次全面升级（3D 卡面 / 边框 / 工艺）。
> 这份文档把「升级」拆成可量、可回滚的三条轴，每条轴先给现状数字，再给目标与落点。
> 取证工具与素材：`../../lab/结果/collreview/`（`README.md` 有全部读数）。

## 0. 三条轴现在各自的问题（都是量出来的）

| 轴 | 现状数字 | 结论 |
|---|---|---|
| **等级（框）** | 六档的框宽只有 2 / 2 / 2 / 2.5 / 3 / 2px，框环 8 / 8 / 8 / 9 / 9.5 / 6px；框环是固定配方 `rgba(255,255,255,.34)`，在 L76 的卡上比卡面亮 ~61、在 L227 的卡上只亮 ~9.5（6 倍差） | 低三档在 205px 下**读不出档次**；同一套框在明暗两端的读数差 6 倍 —— 「不像一套」的一半来自这里 |
| **工艺** | 16 种工艺的装饰层残差从 **10.7 到 73.0（6.8×）**：nacre 16.0 / silver 17.5 / silk 20.9 / … / holo-prism 40.2 / filigree 59.8；同种工艺内部散布也大（enamel σ11.8、filigree σ12.4） | 没有统一标尺：filigree 是 nacre 的 3.7 倍亮眼度，16 种里有一半在 205px 下「等于没做」 |
| **3D** | 卡面贴图 760px，弹层里卡的实际投影宽 ~1050 物理像素（DPR2）→ **放大 1.38×**；`RANK_3D` 的 20 条通道里，五条「脱离感」（wall/cast/lid/cone/drift）在收藏→秘藏**全是 0**，传世 0.70、奇迹 1.00 | 四档 3D 完全一样、高档突然全开（不是阶梯）；卡面糊是分辨率链问题，不是材质问题 |
| （横切）**卡面明度** | 63 张卡面平均明度 76 → 227，标准差 44；相邻格最大差 186 | 缩略扫视呈「补丁感」，见 `pending.md`「和谐性诊断」 |

一句话：**现在这套是「前四档几乎一样 + 后两档突然全开」，不是一条从低到高的连续梯度。** 这是「不够和谐」的结构性来源。

## 1. 轴 A：边框 v2

现状结构＝外沿（2~3px 近白线）+ 框环台面（8~9.5px 中性）+ 角饰（秘藏起）+ 内缩。
升级方向有三个（已在真实像素下出过预览：`lab/结果/collreview/frame-v2.png`）：

- **A 材质带**：外沿换成**本档既有的等级色**（#a9aeb9 / #a6dcb6 / #a8caf2 / #cbb4ef / #f4dba2 / 虹彩），下压一道中性发丝线。等级一眼可读，且框色成为整墙重复元素 → 帮助统一色相。风险：彩带在传世上会抢画面。
- **B 双发丝线**：外线中性（随卡面明度自适应）、内线细一号带等级色，中间留空。最克制、整墙最和谐；风险：205px 下细线发虚。
- **C 物理卡边**：1px 高光 + 1px 阴影模拟卡纸厚度，等级只靠内衬材质与角饰。最像实物；风险：等级更弱。

**推荐组合（判读独立给出的也是这个）**：全档铺 C 的物理卡边托底 → 低三档用 A 的材质色补辨识度（降饱和、收窄）→ 秘藏以上收成 B 的克制线条，把华丽度留给角饰与金光。这样「低档有材质、高档有做工」是连续的一条线。

落点：`assets/css/decks/21-card-deck.css` 的「等级」一节（令牌表 `--rank-frame/--rank-mat/--rank-band/--rank-line/--fret-*`）+ `.home-card-rank--*` 六条规则；新增令牌 `--ring-ink`（中性墨色，由卡面明度定）。

## 2. 轴 B：工艺 v2

1. **定标尺**：给每种工艺一个 0~1 的 `strength`，用它统一乘在各工艺的纹样不透明度/箔膜强度上，把 16 种的残差收进 **0.8~1.2** 的相对区间（现在是 6.8×）。分档维持现有口径：进阶工艺允许上限高 20%。
2. **可命名性**：16 种里凡是「在 205px 下说不出是什么材料」的，要么加强到说得出来，要么合并进最接近的族（此前已从 16 精简过一次，口径可复用）。
3. **验收**：`lab/工具/craftaudit.py` 复跑，看「工艺强度」列的极差与同族散布；同族 σ 目标 < 25%。

落点：`data/card-styles.yaml`（生成 `STYLE_3D` 与 CSS 工艺块，改一处即可两处同步）+ `21-card-deck.css` 的工艺一节。

## 3. 轴 C：3D 卡面

| 项 | 现状 | 升级 | 代价 |
|---|---|---|---|
| 贴图分辨率 | xl 760px，弹层里放大 **1.38×** | 加 1024px 档（DPR2 下约 1:1） | 63 张 ×约 +46 KB ≈ **+2.9 MB 产物**，整站 gzip 预算要从 11264 抬到 ~14336 |
| 档位连续化 | 五条「脱离感」在收藏→秘藏全是 0；`disp/sharp` 也是 0/0/0/0.12/0.26/0.35 | 六档沿单调曲线插值（0 → 满），并把 `check-deck.mjs` 的守卫从「单调不减」加一条「相邻档差不小于阈值」 | 改表 + 守卫，零字节 |
| 脱离感硬切 | 元素出框处被卡框硬切（`relief` 传世 2.40 / 奇迹 2.90） | 对 displaced 区域加边缘软化（或整体降一档 relief）；**先做同尺寸对拍定罪** | 一次对拍 + 小改 |
| 材质区分 | `STYLE_3D` 只有 foil/scale/tint/spec/relief/sparkle/edge 七项 | 补 `aniso`（各向异性，金属/玻璃的区别）与 `normalScale`（皱褶深度），让金 / 玻璃 / 纸在掠射角下分得更开 | 表 + shader 各一处 |
| 卡背 | 已按档位序号取值（`BACK_RING_*`） | 与正面同一套等级材质色 | 跟随轴 A |

## 4. 分期与回滚

| 期 | 内容 | 验收 | 回滚 |
|---|---|---|---|
| **S0** | 定方向（本文档三个问题） | 你拍板 | — |
| **S1** | 轴 A：物理卡边 + 自适应发丝线（先不动材质色） | 63 格实拍复跑，暗/亮两端「框可见度」差 < 2×；整墙左右对拍 | 单文件 CSS，一个 commit |
| **S2** | 轴 A 续：低档材质色 + 高档收线条 | 六档两两可分（独立判读通过） | 同上 |
| **S3** | 轴 B：工艺定标尺 | `craftaudit.py` 极差收进 0.8~1.2、同族 σ<25% | 只改 yaml + CSS 工艺一节 |
| **S4** | 轴 C：贴图档 1024 + 脱离感对拍 + 连续化 | canvas 采样 1:1；六档 fx 值成连续梯度 | 产物可重出；表可切片回退 |
| **S5** | 横切：明度分带归一（只收极端值，保高调卡） | p10/p90 收进 150~225，尖峰卡不再「黑洞/融底」 | 重出图，产物可回退 |

守卫同步：`scripts/check-deck.mjs`（六档令牌/3D 通道的完整性与单调性）、`scripts/check-cards.mjs`、体积预算脚本 —— 每期都过 `scripts/push-blog.sh` 的全套校验。
