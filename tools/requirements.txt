# 本仓库 Python 工具的依赖。**只在本地跑生成器时需要，不进 CI**（见 docs/architecture.md 第 6 节：
# action.yml 里只有 Hugo + Node，挂 Python 进 CI 要先加 actions/setup-python）。
#
# 用法（在仓库根目录）：
#   pip install -r tools/requirements.txt
#
# ---- 谁需要什么 ----
#   Pillow         tools/icons/make-icons.py、tools/covers/make-covers.py、
#                  tools/backgrounds/make-backgrounds.py、make-admin-bg.py、
#                  tools/cards/make-cards.py、tools/cards/make-depth.py
#    numpy         tools/backgrounds/make-backgrounds.py、make-mascot.py、make-mascot-left.py、
#                  tools/cards/make-cards.py、tools/cards/make-depth.py
#    opencv-python tools/backgrounds/make-mascot.py、make-mascot-left.py（白底抠图）
#    PyYAML        tools/cards/make-cards.py（读 data/home-cards.yaml）、
#                  tools/cards/make-depth.py（读同一份清单）、
#                  tools/course-import/import_course.py（读 data/math-branches.yaml，import 带兜底）、
#                  tools/wiki-publish/{publish,cards}.py
#    —— tools/course-import/import_course.py 除 YAML 外只用标准库
#
#   **不在本文件里的**：tools/cards/make-depth.py 还需要 torch / transformers / scipy，
#   那三项是 CUDA 级的重依赖（torch 的 wheel 接近 2 GB），单独写在
#   tools/cards/requirements-depth.txt —— 让「只想重生成一张图标」的人不必付这笔下载。
#
# 2026-09-18 立此文件前，这三项依赖完全没有声明：换一台机器想重生成图标或背景图，只能靠
# 读脚本的 import 反推版本。而仓库其余部分的锁版本纪律很严（Hugo 钉在 action.yml、所有 Action
# 钉到 commit SHA、KaTeX CSS/fonts 入库并做配对校验），唯独 Python 这一角是空的。
#
# 2026-09-20 补上 PyYAML：make-cards.py 无条件 `import yaml`，但它此前不在本文件里 —— 换台机器
# 跑卡片生成器会在第一行就 ImportError，而脚本头部注释里的用法只说了「用同一个解释器」。
# 前两项是**本机实测版本**（Python 3.11.15）；opencv-python 本机没安装，所以给的是区间而不是
# 精确钉 —— 等哪台机器真跑 make-mascot*.py 时，把 `pip freeze` 到的版本改成精确钉再提交。
Pillow==12.3.0
numpy==2.4.3
opencv-python>=4.10,<5
PyYAML==6.0.3
