新建内容

所有文件都由 scripts/new-content.sh 生成，front matter 来自 archetypes/，标签来自 data/taxonomy.yaml，不会出现手抄漂移。

拖入 .md 文件 先把上面的类型与目标目录选好，再把文件拖到这里：正文会替换骨架的占位正文，front matter 按文件里的值自动补全（缺的用骨架默认值）。 也可以点这里选择文件，或直接把文件拖到本面板任意位置。

勾选后仍可留空标签；新词会先写进词表再建内容，写入前会校验格式。

发布

走 scripts/push-blog.sh：先校验分支必须是 main → hugo --minify --gc 构建校验 → 提醒仍是草稿的内容与词表外的标签 → git add -A / commit / push → 显示 CI 状态。 构建失败会中止，不提交也不推送。
