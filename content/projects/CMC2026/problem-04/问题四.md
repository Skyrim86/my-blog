## 1 问题重述

在问题三的基础上，源中**混入未知数量、未知朝向的定向源**：定向源的辐射只覆盖"定向方向两侧各 $90^\circ$"（含边界），即一个**闭半平面**。其余条件（源数 $10\sim16$、频道 $1\sim20$ 互不重复、有效接收半径 $1000\sim1500$ m、机器狗自原点出发、初始频道 $1$、确保全部清除）与问题三相同；同样需给出检测与清除策略算法、演练并完成三次正式测试、按**表 1** 填报。

## 2 模型假设

1. **平面假设**（同问题三）。
2. **有界误差假设**：示向度误差 $\alpha_i\in[\theta_i\pm1^\circ]$，$\delta=1^\circ$。
3. **定向源的接收模型**：设源的定向方向为 $\varphi$（未知，接口不返回），则点 $p$ 能听到该源，当且仅当
$$\lVert p-G\rVert\le R_{\rm eff}\quad\text{且}\quad (p-G)\cdot u_\varphi\ge0,\qquad u_\varphi=(\cos\varphi,\sin\varphi). \tag{1}$$
覆盖角内信号均匀辐射、场强仅随距离衰减、与角度无关（附录 1），故式 (1) 中的距离条件与朝向条件**可分离**。
4. **`no_signal` 的三义**：`no_signal` 意味着"① 该频道无未清源，**或** ② 距离 $>R_{\rm eff}$，**或** ③ 该点不在源的覆盖半平面内"，三者不可区分。
5. **朝向未知的处理口径**：本章采用**最坏情况**（对每个位置要求"**所有**朝向都能被排除"），即给出**保证性**的排除结论。若改用"朝向边缘化"（假设朝向均匀随机）可排除更多区域、需要更少采样点，但**失去保证性**；本章不采用，并在 §5.7 说明差异。
6. **定向源的示向度仍指向源**：附录 2 关于示向度的定义不区分源的类型，故一旦听到，所得方位角即为指向源的真实方位（$\pm1^\circ$）。
7. **每频道至多一源**；同一地点误差固定。

## 4 问题分析

定向源带来的变化**只在"负信息"的解释上**：

1. **`no_signal` 的强度被削弱。** 问题三里一次 `no_signal` 直接排除一个 $1000$ m 圆盘。定向源下，落在这个圆盘里的源只要"背对"观测点就会给出 `no_signal`，因此**单个 `no_signal` 不排除任何位置**（§5.2 引理）。排除必须靠**多个观测点从不同方向"包围"**该位置（§5.3 定理）。
2. **采样密度必须提高。** 由 §5.4，内层格距需从 $\sqrt3\cdot1000$ m 收紧到 $\le1000$ m。
3. **采样范围必须外扩。** 位于圆域边界、朝向域外的源，其覆盖半平面几乎不含域内点，**任何域内观测都无法排除它**（§5.5 实测域内采样盲区 $46.3\%$）。必须把采样点布置到圆域外。
4. **定位与清除不变。** 由假设 6 与附录 2，示向度与朝向无关；`/clear` 只与距离（$\le20$ m）有关。故**一旦听到**，问题三的交会定位与两级清除链完全适用。**问题四的额外难度全部在检测与排除**，成本增量来自采样密度与范围。

**核心主线（三步）**：
$$\underbrace{\text{\textcircled{1} }no\_signal\text{ 的包围语义}}_{\text{引理 1}}\Rightarrow\underbrace{\text{\textcircled{2} 排除判据与采样构型}}_{\text{定理 3 + 表 2}}\Rightarrow\underbrace{\text{\textcircled{3} 定位清除复用问题三}}_{\text{定理 2(Q3)}}$$

## 5 模型的建立

### 5.1 定向源的接收模型

由式 (1)，固定频道 $k$、固定观测点 $p$，若得到 `no_signal`，则必有
$$\text{源不在 }G\text{ 处}\quad\text{或}\quad\lVert p-G\rVert>R_{\rm eff}\quad\text{或}\quad(p-G)\cdot u_\varphi<0. \tag{2}$$
观测点集 $S_k$ 就是所有给出 `no_signal` 的点。**注意 $S_k$ 不含给出 `direction` 的点**——给出示向度的点说明该处能听到源。

### 5.2 引理：单个 `no_signal` 不排除任何位置

> **引理 1**　对任意位置 $G$ 与任意单个 `no_signal` 观测点 $p$，存在某个定向方向 $\varphi$ 使 $p$ 落在 $G$ 的覆盖半平面外，从而"源在 $G$ 且定向方向为 $\varphi$"与"在 $p$ 处 `no_signal`"**完全相容**。

**证明.** 取 $u_\varphi$ 使 $(p-G)\cdot u_\varphi<0$。由于 $u_\varphi$ 可取任意方向，而 $p\ne G$（否则该点为 `near`），这样的 $\varphi$ 总存在（例如取 $u_\varphi$ 指向 $-(p-G)$ 方向）。代入式 (1) 即知在 $p$ 处听不到该源，与 `no_signal` 相容。$\blacksquare$

**推论**　定向源下，"某频道在若干点 `no_signal`" **不足以**判定该频道为空；排除必须依赖**包围**。

### 5.3 排除判据

> **定理 3（排除判据）**　设 $S_k$ 为频道 $k$ 的 `no_signal` 观测点集，对候选位置 $G$ 记 $Q(G)=S_k\cap B(G,1000)$。则
> $$G\ \text{可被保证排除}\iff \text{对每个定向方向 }\varphi,\ \exists p\in Q(G):\ (p-G)\cdot u_\varphi\ge0 \iff G\in\operatorname{conv}\big(Q(G)\big).$$

**证明.** 固定 $\varphi$。"方向 $\varphi$ 时在 $G$ 处的源探测不到"$\iff$ 对所有 $p\in Q(G)$ 有 $(p-G)\cdot u_\varphi<0$（距离 $\le1000$ 的点若在覆盖半平面内就必然被听到）$\iff Q(G)$ 严格落在过 $G$ 的开半平面 $\{(p-G)\cdot u_\varphi<0\}$ 内。于是
$$G\ \text{不能被排除}\iff\exists\varphi\ \text{使}\ \forall p\in Q(G):(p-G)\cdot u_\varphi<0\iff G\notin\operatorname{conv}(Q(G)),$$
最后一步是**分离超平面定理**（点 $G\notin$ 闭凸集 $\operatorname{conv}(Q(G))$ $\iff$ 存在方向 $u$ 使 $(p-G)\cdot u<0$ 对所有 $p\in Q(G)$ 成立）。$\blacksquare$

**可计算形式（最大角间隙判据）.** 记 $\theta_{\rm gap}(G)$ 为方位角集 $\{\angle(p-G):p\in Q(G)\}$ 排序后的**最大角间隙**，则
$$G\in\operatorname{conv}(Q(G))\iff\theta_{\rm gap}(G)\le180^\circ. \tag{3}$$
实现：把 $Q(G)$ 中各点的方位角排序求最大间隙，$O(\lvert S_k\rvert\log\lvert S_k\rvert)$。

**等价性数值验证**：300 组随机 $(S_k,G)$ 上，式 (3) 与"对 $720$ 个方向逐一检查式 (1)"的判定**零不一致**（`.review/q4_exclusion.py` A 节）。

> **与规划稿的两点差异**：① 定义域是 $Q(G)=S_k\cap B(G,1000)$，**距离截断不可省**（只有 $1000$ m 内的观测点才"本应听到"）；② 判据是**闭**凸包（$\theta_{\rm gap}=180^\circ$ 的中点型构型也满足，此时 $G$ 落在凸包边界上仍可排除）。

### 5.4 内层采样：格距 $\le1000$ m 的充分性

设内层观测点为六边形（三角）格，格距 $s$。对**远离圆域边界**的 $G$：

- 若 $G$ 落在格点上，其 $1000$ m 内有 $6$ 个距离为 $s$ 的邻居，方位角间隔 $60^\circ$，最大角间隙 $120^\circ<180^\circ$ $\Rightarrow$ 可排除；
- 若 $G$ 落在三格点中心，有 $3$ 个距离 $s/\sqrt3$ 的邻居，方位角间隔 $120^\circ$，最大角间隙 $120^\circ<180^\circ$ $\Rightarrow$ 可排除。

故**只要 $s\le1000$ m，内层即保证排除**（因为邻居距离 $s\le1000$ 才落在 $B(G,1000)$ 内）。取 $s=900$ m 留 $100$ m 余量。这正是"格距由 $\sqrt3\cdot1000$ 收紧到 $1000$"的由来——**包围**比**覆盖**苛刻：覆盖只需"最近邻 $\le1000$"（$s\le\sqrt3\cdot1000$），包围还需邻居**方位角分散**。

### 5.5 域外包围环：必要性与参数

**（1）只用域内采样必然有盲区.** 取内层六边形格（$s=950$ m、最大半径 $1740$ m，$13$ 点）作域内采样，在圆域内 $40$ m 网格上逐点判定式 (3)（`.review/q4_exclusion.py` C 节）：

> $6361$ 个检验点中**不可排除 $2944$ 个 = $46.3\%$**；典型盲区点位于圆域边界（如 $(0,-1800)$）。

**机理**：位于边界、朝向域外的源，其覆盖半平面几乎不含域内点，故任何域内 `no_signal` 都无法包围它。**必须域外采样。**

### 5.6 定位与清除：与问题三完全通用

- **定位**：由假设 6，`direction` 给出的示向度仍指向源。故一旦听到，直接用问题三 §5.3 的两视线交会（丢弃交会角 $\le2\delta$ 的视线对）与无框半平面交。
- **清除**：`/clear` 成功仅与距离（$\le20$ m）有关、**与覆盖角无关**，故问题三 §5.4 的两级清除链（$c_1$ 复测 + 垂直视线偏移 $100$ m 复测，二级半径 $\le2.7$ m）**原样适用**。
- **唯一差异**：定向源下"在 $c_1$ 复测"时可能因源背对 $c_1$ 而得到 `no_signal`。此时该次复测不产生视线，应改为**在 $c_1$ 附近绕一圈取一个能听到的点**（算法步骤 8 的兜底）；数值上这一情形仅占少数，且可由 §5.4 的射线兜底清除保证收敛。

### 5.7 朝向口径的取舍

| 口径 | 判据 | 采样需求 | 性质 |
|---|---|---|---|
| **最坏情况（本章采用）** | $G\in\operatorname{conv}(S_k\cap B(G,1000))$ | 内层 $s\le1000$ + 外环 | **保证性**：对所有朝向都被排除 |
| 朝向边缘化 | 按朝向先验加权后排除 | 可显著减少点（外环可省） | 仅统计意义，**不保证** |

本章取最坏情况，因为题面要求"**确保**全部清除"；论文中已明确写出该口径，二者可排除的区域不同。

## 6 算法设计与复杂度

### 6.1 主算法

```
算法 Q4：含定向源的搜索—定位—清除
输入 : Ω、频道集 K、采样构型 P4 = 内层六边形格(s=900, R≤1650) ∪ 外环(R=1900, 12 点)
输出 : 清除记录、虚拟时间

 1  构造巡回路径 tour ← NN(P4) + 2-opt，起点 = 原点
 2  noSig[k] ← ∅（频道 k 的 no_signal 观测点集）；cleared ← ∅
 3  FOR p IN tour:
 4      FOR k IN 尚未定论 的频道:
 5          (res, svd) ← /measure(p, k)
 6          IF res = near:      /clear(p,k); cleared ← cleared ∪ {k}
 7          ELIF res = direction: dets[k] ← dets[k] ∪ {(p,svd)}
 8          ELSE:               noSig[k] ← noSig[k] ∪ {p}     # 负信息记账
 9  巡回结束：对每个 k
10      IF dets[k] ≠ ∅:            转入清源流程（问题三 §5.4）
11      ELIF 用式(3)判定 "Ω 内所有 G 均可排除":  k 判空      # 包围判据
12      ELSE:                      加密采样（内层减半格距 / 外环加点）后重判
13  WHILE 待清频道: 调用问题三的两级清除链 + 射线兜底
14  /exit
```

### 6.2 复杂度

| 环节 | 复杂度 | 说明 |
|---|---|---|
| 巡回规划 | $O(m^3)$ | $m=25$，秒级 |
| 逐点检测 | 上界 $25\times20=500$ 次；自适应后平均 $\approx$ 见 §7 | 与问题三同一机制 |
| 逐频道判空 | $O(\lvert S_k\rvert\log\lvert S_k\rvert)$ / 每个检验点 | 实际只对网格检验点抽样判定 |
| **总虚拟时间** | 由**移动距离**主导（25 点巡回） | 见 §7 |

## 8 结论

1. **定向源改变了"负信息"的强度**：`no_signal` 有三种不可区分的原因，**单个 `no_signal` 不排除任何位置**（引理 1）；排除必须依赖**包围**。
2. **排除判据（定理 3）**：$G$ 可被保证排除 $\iff G\in\operatorname{conv}(S_k\cap B(G,1000))$，可计算形式为**最大角间隙 $\le180^\circ$**（与逐方向检查等价，数值零不一致）。
3. **采样必须"变密 + 外扩"**：内层六边形格格距 $\le1000$ m（取 $900$ m）；仅用域内采样在圆域边界留下 $46.3\%$ 盲区，**必须域外采样**；外环半径的**甜点区为 $1900\sim2000$ m**（更远反而重现盲区）。
4. **推荐构型**：内层 $s=900$ m、$R_{\rm lat}=1650$ m（$13$ 点）+ 外环 $R_{\rm out}=1900$ m、$12$ 点，共 **$25$ 点**，$20$ m 网格零盲区。
5. **定位与清除完全复用问题三**：示向度与朝向无关、`/clear` 与朝向无关，故两级清除链原样适用；**问题四的额外难度全部在检测与排除**。
6. **实测**：平均定位清除时间约 $665$ s，比保底基线快 $4.2$ 倍，$100$ 个种子全部 $100\%$ 清除，并消除了基线在定向源上的漏检。

## 9 理论依据与文献支撑

**（1）分离超平面定理.** 定理 3 的核心是"点不属于闭凸集 $\iff$ 存在分离超平面"，这是凸分析的经典结论（文献 [1] 第 11 章）。它把"对所有朝向都存在探测点"这一**连续量词**的判定，化归为一个**凸包/最大角间隙**的有限计算。

**（2）定向传感器网络的覆盖与包围.** 定向传感器（摄像机、定向天线）的覆盖判定与"目标是否被包围"在传感器网络领域有大量研究：单点覆盖不足以判定，需要**多方向覆盖**（barrier coverage / $k$-coverage 的对偶问题）。本章的定理 3 正是这一类判据在"闭半平面视场"下的精确形式（文献 [20,21]）。**注**：该两条文献的书目信息本机无法联网核实，已在 `参考论文/README.md` 标注【待核对】；本章结论**不依赖**它们（定理 3 已自证）。

**（3）搜索论.** 把 `no_signal` 解释为"对（位置, 朝向）联合假设的部分削弱"，与最优搜索论中"负信息即假设剪除"的框架一致（文献 [21]）；本章取**最坏朝向**（而非边缘化），对应鲁棒/悲观推断（文献 [3]）。

```python
# -*- coding: utf-8 -*-
"""问题四策略核心（摘自 dog_plan.py）。无 numpy 依赖。"""
import math

ARENA, D2R, DELTA, DETECT_R = 1800.0, math.pi / 180.0, 1.0, 1000.0


def hex_lattice(s, Rmax):
    """六边形（三角）格，格距 s，保留 ‖p‖ <= Rmax 的点。"""
    pts = []
    ny = int(Rmax / (s * math.sqrt(3) / 2)) + 2
    nx = int(Rmax / s) + 2
    for j in range(-ny, ny + 1):
        y = j * s * math.sqrt(3) / 2
        for i in range(-nx, nx + 1):
            x = i * s + (j % 2) * s / 2
            if math.hypot(x, y) <= Rmax:
                pts.append((x, y))
    return pts


def q4_points(s=900.0, Rlat=1650.0, Rout=1900.0, nout=12):
    """内层六边形格 + 域外包围环；20 m 网格复核零盲区（表 3）。"""
    pts = hex_lattice(s, Rlat)
    for i in range(nout):
        a = 2 * math.pi * i / nout
        pts.append((Rout * math.cos(a), Rout * math.sin(a)))
    return pts


def excludable(no_sig_pts, G):
    """定理 3 的可计算形式：G ∈ conv(no_sig_pts ∩ B(G,1000)) <=> 最大角间隙 <= 180°。"""
    Q = [(p[0] - G[0], p[1] - G[1]) for p in no_sig_pts
         if math.hypot(p[0] - G[0], p[1] - G[1]) <= DETECT_R + 1e-9]
    if len(Q) < 2:
        return False
    ang = sorted(math.atan2(q[1], q[0]) for q in Q)
    gaps = [ang[i + 1] - ang[i] for i in range(len(ang) - 1)]
    gaps.append(ang[0] + 2 * math.pi - ang[-1])
    return max(gaps) <= math.pi + 1e-12
```
