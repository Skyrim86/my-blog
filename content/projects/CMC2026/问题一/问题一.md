## 1 问题重述

已知目标区域中某干扰源关于若干检测点的示向度，要求：

1. 给出采用**交会定位法**计算该干扰源**多边形定位区域直径**（即区域内任意两点之间距离的最大值）的算法；
2. 回答：**以该定位区域直径为直径的圆能否覆盖此定位区域**。

依附录 2，示向度定义为：在检测点处测得的、使场强最大的接收天线方向的方位角，即 $x$ 轴正向逆时针旋转至"检测点指向干扰源"向量方向的角度，取值范围 $[0^\circ,360^\circ)$。由于环境影响与测向精度所限，示向度与真实方位角之间存在误差；在目标区域全局范围内，**误差落在 $[-1^\circ,1^\circ]$ 内**，且**同一地点的电磁环境固定，重复检测不改变该误差**。图 2 给出两检测点 $S_1,S_2$ 交会的情形：两条实线为测得示向度方向，实线与相邻虚线夹角均为 $1^\circ$，由四条误差边界线围成的四边形即**定位区域**。

由此可见：**一条示向度给出的不是一个点，而是一个角约束**；定位区域是这些角约束的公共部分。这正是本问的几何本质。

## 2 模型假设

1. **平面假设**：由附录 2(7)，忽略测向机与干扰源的高度差，测向机与所有干扰源位于同一平面，问题为二维几何问题。
2. **有界误差假设**：真实方位角 $\alpha_i$ 与示向度 $\theta_i$ 之差满足 $|\alpha_i-\theta_i|\le 1^\circ$，即
   $$\alpha_i\in[\theta_i-1^\circ,\ \theta_i+1^\circ].$$
   本假设**不依赖误差的分布形式，也不依赖各检测点误差之间的独立性**（题面明确同一地点误差固定、不同地点才呈现统计规律）。这是本问采用"集合隶属"视角的根据。
3. **同一源假设**：所有示向度来自同一个干扰源。
4. **几何约束仅由方向决定（主模型）**：**主模型**的定位区域仅由示向度方向及其 $\pm1^\circ$ 误差带决定，即附录 2 图 2 所定义的区域；有效接收半径 $[1000,1500]$ m 与目标圆域半径 $1800$ m 不进入主模型，而是作为**物理先验约束**单独构造区域 $R_c$ 处理（见 5.2 第二块）。本文的全部定理（有界性、直径、覆盖判据）均针对主模型的 $R$；$R_c$ 需**重新计算**直径与覆盖性，不能沿用 $R$ 的结论。
5. 忽略数值舍入；算法在实数域上讨论。

## 4 问题分析

本问要解决三个层层递进的子问题：

1. **如何把示向度写成几何约束？** 一个检测点的示向度只给出"源在该方向上"的射线，误差带把射线放宽为一个夹角 $2^\circ$ 的角形区域（楔形）。多个检测点给出多个楔形，它们的交集才是源的可能位置集合，即定位区域。
2. **如何由定位区域求直径？** 楔形是两个半平面的交，有限个楔形之交是凸多边形；凸多边形的直径必在其顶点对处取得，故只需在有限个顶点上求最大距离。
3. **直径圆能否覆盖定位区域？** 这是"一个由直径决定的圆"与"区域"的包含关系问题。直觉上"直径的两端点决定了区域的最大跨度，所以半径为 $D/2$ 的圆应当够用"是**错误**的：圆是中心对称的，而区域可以是不对称的（例如钝角/直角三角形），此时区域会从直径圆"鼓"出去。因此需给出严格判据与最坏情况界。

此外必须处理两类退化：**观测矛盾（区域为空）**与**区域无界（无法定位）**。二者在数学上是独立的，不能混为一谈。

**核心主线（五步）.** 本问的解答归结为一条主链：

$$\underbrace{\text{\textcircled{1} 误差楔形 }W_i}_{\text{式(1)}}\Longrightarrow\underbrace{\text{\textcircled{2} 定位区域 }R=\textstyle\bigcap_iW_i}_{\text{凸多边形}}\Longrightarrow\underbrace{\text{\textcircled{3} 空集/无界/有界判定}}_{\text{定理 1}}\Longrightarrow\underbrace{\text{\textcircled{4} 直径 }D=\max_{p,q\in R}\lVert p-q\rVert}_{\text{定理 2}}\Longrightarrow\underbrace{\text{\textcircled{5} Thales 判据判覆盖}}_{\text{定理 3}}$$

①②③④⑤ 全部针对**主模型 $R$**（严格按题目/附录 2 图 2 定义）。**物理约束 $R_c$**（目标圆域、有效接收半径）是此主链之外的**独立修正层**：必须对 $R_c$ 重新求直径、重新判覆盖，**不能沿用 $R$ 的结论**（见 §5.2 第二块与勘误 C17）。

## 5 模型的建立

### 5.1 示向度的角约束与楔形模型

对检测点 $S_i$，其示向度误差边界方向为

$$\beta_i^-=\theta_i-1^\circ,\qquad \beta_i^+=\theta_i+1^\circ .$$

记 $\operatorname{rot}(v,\gamma)$ 为把向量 $v$ 逆时针旋转 $\gamma$。定义两条边界的内法向

$$n_i^-=\operatorname{rot}\big((\cos\beta_i^-,\sin\beta_i^-),+90^\circ\big)=(-\sin\beta_i^-,\ \cos\beta_i^-),$$
$$n_i^+=\operatorname{rot}\big((\cos\beta_i^+,\sin\beta_i^+),-90^\circ\big)=(\ \sin\beta_i^+,\ -\cos\beta_i^+).$$

第 $i$ 个检测点给出的**楔形**为

$$W_i=\{p\in\mathbb R^2:\ n_i^-\!\cdot(p-S_i)\ge 0,\ \ n_i^+\!\cdot(p-S_i)\ge 0\}. \tag{1}$$

式 (1) 表明 $W_i$ 是**两个半平面之交**，是一个以 $S_i$ 为顶点、张开 $2^\circ$ 的闭凸锥的平移。于是**定位区域**为

$$R=\bigcap_{i=1}^{n}W_i=\bigcap_{i=1}^{n}\{p:\ n_i^-\!\cdot(p-S_i)\ge0,\ n_i^+\!\cdot(p-S_i)\ge0\}, \tag{2}$$

即 $2n$ 个半平面之交。由凸集的交仍是凸集，得

> **性质 1**　$R$ 是闭凸集；当 $R$ 有界且非空时，它是顶点数 $h\le 2n$ 的凸多边形。

特别地，两检测点 $(n=2)$ 时 $R$ 是四条边界线围成的四边形（附录 2 图 2 的红色区域），这正是题目所定义的交会定位区域；$n$ 更大时 $R$ 是更一般的凸多边形。

### 5.2 定位区域：主模型与物理约束模型

**第一块：主模型 $R$（严格按题目/附录 2 图 2 定义，本文主体）.** 主模型只使用示向度方向及其 $\pm1^\circ$ 误差带，不含任何物理先验；本文的全部定理（有界性、直径、覆盖判据）都针对它。$R=\bigcap_iW_i$ 是 $2n$ 个半平面之交，由性质 1 为闭凸集，有界非空时是 $h\le2n$ 的凸多边形——这正是题面所称的"多边形定位区域"。

**锥的回收锥。** $W_i$ 是"以 $S_i$ 为顶点、方向区间 $[\beta_i^-,\beta_i^+]=[\theta_i-1^\circ,\theta_i+1^\circ]$ 的闭凸锥"的平移。它的**回收锥**（recession cone，即使得 $x+td\in W_i,\ \forall t\ge0$ 的方向 $d$ 的集合）就是这个锥本身：

$$\operatorname{rec}(W_i)=C_i=\Big\{t(\cos\varphi,\sin\varphi):\ t\ge0,\ \varphi\in[\theta_i-1^\circ,\theta_i+1^\circ]\Big\}. \tag{3}$$

**第二块：物理约束模型 $R_c$（单独定义、独立求解，不继承主模型结论）.** 题面另给出两条先验，二者都是**凸约束**，可把主模型 $R$ 进一步缩小为

$$\boxed{\ R_c=R\cap B(O,1800)\cap\bigcap_i B(S_i,1500)\ }\tag{3'}$$

即：**目标圆域**——源在以原点为心、半径 $1800$ m 的闭圆盘 $B(O,1800)$ 内；**有效接收半径**——在 $S_i$ 处能测得示向度说明源到 $S_i$ 的距离不超过其有效接收半径，而后者上界为 $1500$ m。二者加入后 $R_c\subseteq R$，故

$$\operatorname{diam}(R_c)\ \le\ \operatorname{diam}(R)\quad(\text{直径是"保守上界"}).$$

交后仍是凸紧集，但边界一般由若干直线段与至多一段圆弧组成。此时：**直径**仍可沿边界求极值（直线段的顶点，以及两端点均为"圆弧—直线"交点的圆弧段上的极值点）；**覆盖判定**要注意，定理 3 的"只需在顶点检验"不再直接成立（凸二次函数 $g$ 在圆弧边界上可能于内点取极大），需在圆弧段上补求 $\max g$（单变量问题，比较临界点与端点即可）。工程上亦可把圆盘换成内接正 $k$ 边形（$k$ 足够大），则退化为纯多边形问题，误差可估计。

题面所问为"**多边形**定位区域"的直径，故**主模型取 $R=\bigcap_iW_i$**（凸多边形，定理 1–4 全程适用）；物理约束 $R_c$ 作为独立的第二块单独求解（见 §6.1 步骤 12），其直径与覆盖性由 $R_c$ 自身（顶点与圆弧段）重新计算。

**注意（勘误 C17）**：上述"加入约束只会使 $R$ 变小、直径是保守上界"对**直径**成立，但**覆盖结论并不随之单调**——区域缩小后直径与直径圆同时改变。随机复算（$n=2$、满足 $\|S_i-G\|\le1500$ 的物理相容构型 $3948$ 组）显示，叠加接收半径约束后约 $3.60\%$ 的构型覆盖结论由"覆盖"翻为"不覆盖"。故必须对**同一个** $R$ 计算 $D,a,b$ 并作覆盖判定，不可把纯角约束下的覆盖结论直接搬到加约束后的区域。

### 5.3 有界性与空集的判别

**（1）无界的充要判据。**

> **定理 1**　设 $R=\bigcap_{i=1}^n W_i$。
> (i) 若 $R=\varnothing$，则 $R$ 有界。
> (ii) 若 $R\ne\varnothing$，则
> $$R\ \text{无界}\iff \bigcap_{i=1}^{n}[\theta_i-1^\circ,\ \theta_i+1^\circ]\ne\varnothing. \tag{4}$$

**证明.** 对非空闭凸集族，回收锥满足
$$\operatorname{rec}\Big(\bigcap_i W_i\Big)=\bigcap_i\operatorname{rec}(W_i)$$
（凸分析基本结论，见文献 [1] 第 8 章"回收锥"）。由式 (3)，$\operatorname{rec}(W_i)=C_i$，故
$$\operatorname{rec}(R)=\bigcap_{i=1}^n C_i .$$
非空闭凸集 $R$ 无界当且仅当其回收锥非平凡，即 $\operatorname{rec}(R)\ne\{0\}$。而由 $C_i$ 的定义，$\bigcap_i C_i\ne\{0\}$ 当且仅当存在一个方向 $\varphi$ 同时属于所有区间 $[\theta_i-1^\circ,\theta_i+1^\circ]$，即式 (4) 右端成立。$\blacksquare$

**（2）判据的可计算形式。** 记各示向度在圆周上的最小包含弧长为
$$\ell_{\min}=360^\circ-\max_{1\le i\le n}\big((\theta_{(i+1)}-\theta_{(i)})\bmod 360^\circ\big),$$
其中 $\theta_{(1)}\le\cdots\le\theta_{(n)}$ 为 $\{\theta_i\bmod360^\circ\}$ 的升序排列（含首尾环绕）。则

$$\bigcap_{i=1}^{n}[\theta_i-1^\circ,\theta_i+1^\circ]\ne\varnothing\iff \ell_{\min}\le 2^\circ. \tag{5}$$

其含义是：所有示向度若能塞进一段 $2^\circ$ 的弧内，则所有误差带有一个公共方向，定位区域沿该方向无限延伸。

**（3）$n=2$ 的推论。** 两检测点的情形最为常用：

> **推论 1**　$n=2$ 时，$R$ 无界（在 $R\ne\varnothing$ 的前提下）$\iff d_{\mathrm{circ}}(\theta_1,\theta_2)\le 2^\circ$；$d_{\mathrm{circ}}(\theta_1,\theta_2)>2^\circ$ 时 $R$ 必有界。

**（4）空集与无界的独立性。** "区域为空"与"区域无界"是两个独立判据。

**（非空性命题，修订）** 若 $\ell_{\min}<2\delta$，则由式 (5) 区间之交含一个非退化弧，可取**同时落在各区间内部**的公共方向 $u=(\cos\varphi,\sin\varphi)$（即 $|\varphi-\theta_i|<\delta$ 对所有 $i$ 成立，留有余量）。取 $p_t=S_1+tu\ (t>0)$，对每个 $i$ 有
$$\angle(p_t-S_i,\,u)=\arctan\frac{\lvert (S_1-S_i)\times u\rvert}{t+(S_1-S_i)\cdot u}\longrightarrow0\qquad(t\to\infty),$$
故存在 $T$ 使 $t\ge T$ 时 $p_t\in W_i\ (i=1,\dots,n)$，即 $R\ne\varnothing$；再结合定理 1 得 $R$ 非空且无界。

**注意（等号处命题不成立，见勘误 C6）** 当 $\ell_{\min}=2\delta$ 时区间之交退化为**单个公共方向** $\varphi$，它落在某些区间的**端点**上，上述"留有余量"的论证失效：$R$ 可能为空。反例：$S_1=(0,0),\ \theta_1=0^\circ$ 与 $S_2=(1000,100),\ \theta_2=2^\circ$（$\delta=1^\circ$）。两区间 $[-1^\circ,1^\circ]$ 与 $[1^\circ,3^\circ]$ 之交为 $\{1^\circ\}$，$\ell_{\min}=2^\circ$，但 $W_2$ 内任一点相对 $S_1$ 的方位角恒 $>1^\circ$：$W_2$ 的边界射线过 $S_2$、方向 $1^\circ$，与 $W_1$ 的边界射线**平行而不重合**，而 $S_2$ 位于错误一侧，故 $W_1\cap W_2=\varnothing$（复算 $R=\varnothing$）。临界几何：临界线为过 $S_1$、方向 $1^\circ$ 的射线，$S_2=(1000,y_0)$ 时 $y_0^*=1000\tan1^\circ=17.455$ m；$y_0<y_0^*$ 时区域非空无界，$y_0>y_0^*$ 时区域为空。于是：

> **命题（修正版）**　$\ell_{\min}<2\delta\Rightarrow R$ 非空且无界；$\ell_{\min}=2\delta\Rightarrow R$ **或为空、或无界**（两种结局皆可实现），必须由半平面交判定，无界判据不能替代空集判定。

**对算法无影响**：§6.1 的算法先做半平面交（步骤 2–4），故上述反例会被正确判为"空集（观测矛盾）"；本条修正的是辅助命题的表述，而非算法。

反之，$R$ 为空**并不要求**无界。例如取 $S_1=(0,0),\ \theta_1=0^\circ$ 与 $S_2=(1000,0),\ \theta_2=90^\circ$：两误差带 $[-1^\circ,1^\circ]$ 与 $[89^\circ,91^\circ]$ 无交，$\ell_{\min}=90^\circ>2^\circ$，但定位区域**非空有界**（复算为三角形，$D=17.4630$ m，观测并不矛盾）。

**例（背向观测导致空集）** 取 $S_1=(0,0),\ \theta_1=180^\circ$ 与 $S_2=(1000,0),\ \theta_2=0^\circ$，即两检测点各自朝外侧观测。此时两误差带 $[179^\circ,181^\circ]$ 与 $[-1^\circ,1^\circ]$ 无交，$\ell_{\min}=180^\circ>2^\circ$——若用"无界判据"将误判为"有界"，而半平面交实为**空集**（复算 $R=\varnothing$）。这说明**无界判据不能替代空集判别**。

因此算法必须**先做半平面交得到（可能为空的）$R$，再判定是否有界**。

**（5）边界等号的严格性。** 当 $\ell_{\min}=2^\circ$（如 $\lvert\theta_1-\theta_2\rvert_{\mathrm{circ}}=2^\circ$）时，两楔形仅共享**一个公共方向**（注意：共享的是方向，两条边界射线一般**平行且不重合**；仅当 $S_2$ 恰落在该方向过 $S_1$ 的射线上时才重合为一条射线）。由定理 1(ii)，若区域非空则**无界**（直径 $=+\infty$），而非"刚好有界"；但如 §5.3(4) 所示，此等号处区域也可能为空，故必须由半平面交先行判定。本地复核（检测点取 $S_1=(0,0),\ \theta_1=0^\circ$，$S_2=(1000,0)$，$\theta_2=\Delta\theta$）如表 1。

|---|---|---|---|---|---|---|---|

| 情形 | 判据 | 结论 |
|---|---|---|

| 有界 | 半平面交非空且 $\ell_{\min}>2^\circ$ | 存在有限直径 $D$，可定位 |

### 5.4 直径的刻画

**定理 2**　设 $R$ 为非空紧凸多边形，$\operatorname{vert}(R)$ 为其顶点集，则

$$\operatorname{diam}(R)=\max_{u,v\in R}\lVert u-v\rVert=\max_{u,v\in\operatorname{vert}(R)}\lVert u-v\rVert,\qquad
D=\max_{u,v\in\operatorname{vert}(R)}\lVert u-v\rVert. \tag{6}$$

**证明.** 映射 $f(u,v)=\lVert u-v\rVert$ 是仿射映射 $(u,v)\mapsto u-v$ 与范数（凸函数）的复合，故在凸集 $R\times R$ 上凸。紧凸集上的凸函数最大值必在极点取得；而 $R\times R$ 的极点集正是 $\operatorname{vert}(R)\times\operatorname{vert}(R)$。$\blacksquare$

由 $h\le2n$，式 (6) 把连续的极大化问题化归为有限个顶点对的枚举，复杂度 $O(h^2)$；对凸多边形亦可使用旋转卡壳（rotating calipers）在 $O(h)$ 内完成（文献 [11]）。

### 5.5 以定位区域直径为直径的圆的覆盖性

**主判据（第一判据，定理 3）.** 设 $a,b$ 为 $R$ 的直径点对，则

$$\boxed{\ \text{直径圆覆盖 }R\iff \max_{p\in R}\,(p-a)\cdot(p-b)\le0\ }$$

本文以该 **Thales 判据**为覆盖性的**主判据**。理由：它是充要条件，且只需在 $R$ 的有限个顶点上检验（定理 3），是最直接、最稳健的判定。最小包围圆 $R^*$ 与 Jung 界只作**辅助刻画与最坏界**（§5.5(3)），不进入主判定——因为 $R^*\ge D/2$ 恒成立、仅当 $R^*=D/2$ 时直径圆才覆盖，用它判定绕远且易误解。

下面：(1) 反例说明"**一般不能覆盖**"；(2) 证明 Thales 主判据；(3) 给辅助刻画与最坏界；(4) 给出 $n=2$ 的数值现象。

**（1）一般不能覆盖——反例。**

取三角形区域 $T$，顶点为 $(0,0),(1,0),(0.5,0.7)$；其直径点对为 $(0,0)$ 与 $(1,0)$，$D=1$。以其中点 $(0.5,0)$ 为圆心、$D/2=0.5$ 为半径的圆，到第三个顶点 $(0.5,0.7)$ 的距离为 $0.7>0.5$，故该顶点落在直径圆之外，**覆盖失败**。经本地计算，该三角形的真实最小包围圆半径为 $R^*=0.528571>0.5$（外接圆解析式 $abc/4K$ 与暴力枚举 MEC 两法一致），Thales 检验 $\max_{p\in\operatorname{vert}(T)}g(p)=0.24>0$。

该反例并非抽象构造，**可由三个检测点的楔形交实现**：取

| $i$ | $S_i$ | $\theta_i$ |
|---|---|---|
| 1 | $(-200,\ 0)$ | $1.0000^\circ$ |
| 2 | $(-116.2476,\ -162.7467)$ | $53.4623^\circ$ |
| 3 | $(-115.7476,\ 163.4467)$ | $304.5377^\circ$ |

其楔形交复算为三角形 $(0.000138,0),(1.000139,0),(0.500138,0.700000)$，
$$D=1.00000041,\qquad R^*=0.5285715,\qquad \max g=0.2399994>0,$$
即**复现上述反例**：与理想三角形的最大顶点偏差为 $1.4\times10^{-4}$ m（由示向度只给到 4 位小数所致；示向度给足位数即可精确复现）。

为使反例与题面的物理条件相容（并使各距离落在题面标称的 $[1000,1500]$ m 区间内），把上述构型整体放大 $k=5$ 倍并平移，即 $S_i^{(5)}=5S_i+(497.5,-1.75)$ m（**注**：原始构型的检测点距源约 $200$ m，已满足 $\|G-S_i\|\le R_{\rm eff}\le1500$ m——有效接收半径是**上界**，更近只会信号更强且 $200\gg5$ m 不会返回 `near`，故放大并非必需，仅为使距离落入标称区间）（勘误 C16）。放大后的构型如下：

| $i$ | $S_i^{(5)}$ / m | $\theta_i$ |
|---|---|---|
| 1 | $(-502.500,\ -1.750)$ | $1.0000^\circ$ |
| 2 | $(-83.738,\ -815.484)$ | $53.4623^\circ$ |
| 3 | $(-81.238,\ 815.484)$ | $304.5377^\circ$ |

复算得定位区域为三角形（顶点 $(497.5007,-1.7500),(502.5007,-1.7500),(500.0007,1.7500)$），
$$D=5.000002\ \text{m},\qquad R^*=2.642858\ \text{m}>D/2,\qquad \max g=5.999985>0,$$
**直径圆仍不能覆盖**。此时检测点到源的距离约为 $1001\sim1003$ m（落在有效接收半径 $[1000,1500]$ m 内），全部点坐标绝对值不超过 $815.5$ m（位于半径 $1800$ m 的目标圆域内）。故**该反例在本题的物理约束下同样成立**。

**（2）主判据的证明（Thales 定理）。**

由 Thales 定理，以线段 $ab$ 为直径的圆（闭圆盘）恰为

$$\mathcal D_{ab}=\{p:\ (p-a)\cdot(p-b)\le 0\}, \tag{7}$$

因为 $(p-a)\cdot(p-b)=\lVert p-c\rVert^2-\lVert a-b\rVert^2/4$，$c=(a+b)/2$，故 (7) 等价于 $\lVert p-c\rVert\le D/2$。于是

> **定理 3**　以 $R$ 的直径点对 $(a,b)$ 为直径的圆覆盖 $R$，当且仅当
> $$\max_{p\in R}\ g(p)\le0,\qquad g(p):=(p-a)\cdot(p-b). \tag{8}$$

**证明.** 式 (7) 给出等价性。$g$ 的 Hessian 为 $2I\succ0$，故 $g$ 为凸二次函数；凸函数在凸紧集上的最大值在极点取得，因此式 (8) 只需在 $R$ 的顶点上检验：
$$\max_{p\in R}g(p)=\max_{p\in\operatorname{vert}(R)}g(p). \qquad\blacksquare$$

定理 3 把"圆是否覆盖区域"化为**有限个顶点的符号检验**（因 $g(a)=g(b)=0$ 恒成立，实际只需检验其余顶点），是最直接、最稳健的判据。本地在随机有界凸多边形上比较"顶点检验"与最小包围圆刻画 $R^*=D/2$，判定完全一致（见 7 实验 4 ③）。

**（3）辅助刻画与最坏界（最小包围圆与 Jung 定理）。** 本小节是**辅助性**的：给出覆盖判据的等价刻画与最坏情况上界，不替代定理 3 的主判据地位。

> **定理 4**　设 $R^*$ 为 $R$ 的最小包围圆半径，$D$ 为其直径。则
> $$R^*\ge D/2, \tag{9}$$
> 且**直径圆覆盖 $R\iff R^*=D/2$**。

**证明.** 直径点对 $a,b\in R$ 满足 $\lVert a-b\rVert=D$，任何覆盖 $R$ 的圆的半径至少为 $D/2$，故 $R^*\ge D/2$。若 $R^*=D/2$，则半径 $D/2$ 的最小包围圆唯一，其必为以某直径点对为直径的圆（因 $a,b$ 必在该圆上且对径），故直径圆覆盖 $R$；反之若直径圆覆盖 $R$，则 $R^*\le D/2$，结合 (9) 得 $R^*=D/2$。$\blacksquare$

**Jung 定理**（文献 [6]）给出最坏情况上界：平面内直径 $D$ 的集合必被半径不超过 $D/\sqrt3$ 的圆覆盖，等边三角形取等。故一旦直径圆不够用，**所需覆盖圆的直径最坏为**

$$2R^*\le \frac{2D}{\sqrt3}\approx1.1547\,D. \tag{10}$$

当 $2R^*>D$ 时，工程上应直接采用**最小包围圆**（Welzl 算法，期望 $O(h)$，文献 [7]）作为覆盖圆，其半径 $R^*$ 即所需最小半径。

**（4）$n=2$ 的数值现象（非概率结论）。** 对 $n=2$ 的楔形交区域，数值上可以给出比 Jung 定理（$R^*\le D/\sqrt3$）紧得多的经验规律（**以下为随机构型的数值现象，依赖采样方式，不作为一般性概率结论**）。记楔形半角宽为 $\delta$（本题 $\delta=1^\circ=0.017453$ rad）。$6.0\times10^4$ 组随机构型加 25 次爬山式对抗搜索得到
$$\max\frac{R^*}{D}=0.500294,$$
且数值上呈现一条干净的量级规律
$$\frac{R^*}{D}\ \le\ \frac12+\delta_{\mathrm{rad}}^{2},\qquad \frac{R^*}{D}-\frac12\ \approx\ 0.95\,\delta_{\mathrm{rad}}^{2}. \tag{11}$$
式 (11) 是**数值观察到的量级规律**（尚未给出解析证明；$6.0\times10^4$ 组随机加对抗搜索在 $\delta\le8^\circ$ 内未发现反例），在 $\delta\lesssim16^\circ$ 的范围内它比 Jung 界 $1/\sqrt3$ 更紧。表 2 给出不同 $\delta$ 下的检验：$\delta=1^\circ$ 时上界为 $0.500305$，实测最坏 $0.500290$，二者仅差 $1.5\times10^{-5}$，**近于取等**。

- $R^*/D>1/2$ 虽然幅度极小，但**确实会发生**。$n=2$ 的 $5879$ 组有界随机构型中 $R^*>D/2$（即直径圆严格不能覆盖）的比例为 $0.95\%$（另一组"指向同一未知点 + 误差"的 $3.94\times10^4$ 组构型为 $1.18\%$），超出幅度不超过 $0.06\%$。**这些比例是随机构型的数值实验现象，依赖采样方式，不构成一般性概率结论。**
- 两楔形交的区域一般**不是平行四边形**：只有当 $\theta_2-\theta_1\equiv0\ (\mathrm{mod}\ 180^\circ)$ 时，四边形的两对边才分别落在平行的两对边界线上（例如 $\Delta\theta=180^\circ$ 时退化为菱形，属严格平行四边形），此**充分**情形下 $R^*/D=1/2$。但须注意：**$R^*/D=1/2$ 的充要条件是"直径圆覆盖 $R$"（定理 4），平行四边形只是充分族而非必要**——本文实验 6 的四边形（相邻边不平行，非平行四边形）即取到 $R^*/D=0.5$；随机搜索中 $R^*/D=0.5$ 的构型也普遍不是平行四边形。一般情况下 $R^*/D\ge1/2$，且区域可能退化为三角形（$n=2$ 的随机有界构型中约占 $1.4\%$）。（勘误 C13）

因此**理论上应以定理 3/4 的判据为准，不能默认 $R^*=D/2$**；当 $n\ge3$ 时反例（1）表明覆盖可以明显失败，且失效比例随 $n$ 迅速上升（见表 3）。

## 6 算法设计与复杂度

### 6.1 主算法

```
算法 Q1：交会定位区域直径与覆盖判定
输入 : 检测点 S_i 与示向度 θ_i, i = 1..n; 误差界 δ = 1°
输出 : 定位区域顶点集 V、直径 D 及点对 (a,b)、覆盖结论、最小包围圆半径 R*

 1  对每个 i: 由式(1) 生成两个半平面 (S_i, n_i^-), (S_i, n_i^+)
 2  R ← 半平面交(所有 2n 个半平面)            # 用大框裁剪或增量法
 3  若 R = ∅:                                 # 空集优先判定
 4      返回 "观测矛盾（非同源/误差超界/误测漏测）"
 5  若 最小包含弧长 ℓ_min(θ_1..θ_n) ≤ 2δ:     # 定理 1
 6      返回 "无界，D = +∞，不可定位"
 7  V ← R 的顶点集                            # h ≤ 2n
 8  (a,b), D ← 直径(V)                        # 枚举 O(h^2) 或旋转卡壳 O(h)
 9  cover ← [ max_{p∈V} (p-a)·(p-b) ≤ 0 ]     # 定理 3（主判据）
10  (c, R*) ← 最小包围圆(V)                    # Welzl（辅助/实际覆盖圆）
11  若需物理约束: R_c ← R ∩ B(O,1800) ∩ ∩_i B(S_i,1500)      # §5.2 第二块
12      对 R_c 重算 D_c 与覆盖（直线段顶点 + 圆弧段补求 max g）；结论不继承 R
13  返回 V, D, (a,b), cover, R*（启用约束时另返回 R_c, D_c）
```

### 6.2 关键子程序

- **半平面交**：$n$ 较小时，用 Sutherland–Hodgman 逐条裁剪一个大框（初始为包围所有 $S_i$ 的矩形），每次裁剪 $O(m)$，总 $O(n^2)$；也可对半平面按极角排序后用增量法，期望 $O(n\log n)$（文献 [5]）。**数值注意（勘误 C14）**：固定大小的框在 $\ell_{\min}\to2\delta$ 附近会失效——此时区域尺度按 $D\sim L\sin2\delta/(2\varepsilon)$（$\varepsilon=\ell_{\min}-2\delta$）无界增长。当 $\varepsilon$ 小到使真实区域超出框时，有界侧的直径会被**截断低估**，$\ell_{\min}$ 略小于 $2\delta$ 的非空无界区域甚至会被**误判为空集**（复算：$S_1=(0,0),\theta_1=0^\circ$、$S_2=(1000,0)$，框半宽 $10^6$ 时 $\Delta\theta=2.0005^\circ$ 给 $D=9.992\times10^5$ 而真值 $2\times10^6$；$\Delta\theta=1.999^\circ$ 返回空集而真域最近点距原点 $4.73\times10^6$ m）。**建议**：优先采用无框的"边界线两两求交 + 全约束可行性筛选"枚举顶点；若保留大框，则令框尺寸随 $\varepsilon$ 自适应，并对 $\ell_{\min}<2\delta$ 直接由定理判无界。本问已报告的全部数值（$D\le2\times10^4\ll10^6$）不受影响。
- **直径**：$h\le2n$ 很小，直接枚举 $\binom h2$ 个顶点对即可（$O(h^2)$，实现最简）；如需体现算法素养，用旋转卡壳 $O(h)$（文献 [11]）。
- **最小包围圆**：Welzl 随机增量算法，期望 $O(h)$；本问题 $h\le2n$，亦可暴力枚举所有点对与点三元组（$O(h^4)$，$h$ 小时足够）。
- **最小包含弧长** $\ell_{\min}$：对 $\{\theta_i\bmod360^\circ\}$ 排序求最大间隙，再补弧，$O(n\log n)$。

### 6.3 复杂度

设 $n$ 为检测点数，$h\le2n$ 为区域顶点数。半平面交 $O(n\log n)$（增量）或 $O(n^2)$（大框裁剪），直径 $O(h)$（旋转卡壳）或 $O(h^2)$，最小包围圆期望 $O(h)$。故总体为
$$O(n\log n)\ \text{（推荐）}\quad\text{或}\quad O(n^2)\ \text{（最简实现）}.$$

### 6.4 退化情形处理

| 退化情形 | 现象 | 处理 |
|---|---|---|
| $n=1$ | 单个楔形，无界 | $\ell_{\min}=0\le2^\circ$，返回"不可定位" |
| $n\ge2$，$\ell_{\min}\le2^\circ$ | 区域无界 | 直径记 $+\infty$，返回"不可定位" |
| 观测矛盾 | 区域为空 | 返回"观测矛盾"（非同源，或误差超界，或误测/漏测），检查数据 |
| $\ell_{\min}=2^\circ$ | 共享一个公共方向（边界射线一般平行不重合） | **须先由半平面交判空/非空**：非空则按定理 1 判无界（严格用 $>$）；可能为空（见 §5.3(4) 反例） |
| 顶点共线/重合 | $h<3$ 或出现重复顶点 | 去重、去共线点 |
| **区域退化为点/线段** | $h=1$ 或 $h=2$（区域非空） | **不可判为空集**：空集只能由半平面交为空判定；$h\le2$ 时按线段/点处理（$D$ 为线段长或 $0$，此时直径圆自动覆盖，覆盖判定恒为真） |
| 大框裁剪残留/截断 | 区域贴住或超出裁剪框 | **勘误 C14**：固定框在 $\ell_{\min}\to2\delta$ 时会截断直径或把非空域误判为空。以解析判据定理 1 为准；优先改用无框"边界线求交+可行性筛选"，或令框尺寸随 $\varepsilon=\ell_{\min}-2\delta$ 自适应 |

## 8 结论

本问的结论按**四层递进**给出，另附一条数值现象（非概率结论）：

1. **第一层（几何约束）**：示向度 $\theta_i$ 与有界误差 $\pm1^\circ$ 给出一个夹角 $2^\circ$ 的凸锥——楔形 $W_i$（式 (1)）；**主模型**定位区域是诸楔形之交 $R=\bigcap_iW_i$，为凸多边形（$h\le2n$）。
2. **第二层（直径）**：$R$ 为凸多边形，其直径 $D=\max_{p,q\in R}\lVert p-q\rVert$ 由顶点对给出（定理 2）。算法流程见 §6.1，复杂度 $O(n\log n)\sim O(n^2)$，并给出空集/无界/有界三种定论与退化处理。
3. **第三层（覆盖判据，主判据）**：设 $a,b$ 为直径点对，**直径圆覆盖 $R$ 的充要条件是 Thales 判据**
   $$\max_{p\in R}\,(p-a)\cdot(p-b)\le0$$
   （定理 3，只需在顶点检验）。因此**直径圆一般不能覆盖定位区域**——反例（三角形 $(0,0),(1,0),(0.5,0.7)$，$D=1$）中直径圆漏掉一个顶点，且该反例可由三检测点的楔形交实现（复现精度 $1.4\times10^{-4}$ m）。**最小包围圆 $R^*$ 与 Jung 界只作辅助刻画与最坏界**（$R^*\ge D/2$ 恒成立；覆盖失败时 $2R^*\le2D/\sqrt3\approx1.1547D$）；需要实际覆盖圆时取 $R^*$（Welzl）。
4. **第四层（物理约束）**：目标圆域 $B(O,1800)$ 与有效接收半径 $\bigcap_iB(S_i,1500)$ 构成**独立的物理约束区域** $R_c=R\cap B(O,1800)\cap\bigcap_iB(S_i,1500)$（§5.2 第二块），**必须对 $R_c$ 重新计算直径与覆盖性**——加约束后覆盖结论并不单调（物理相容的两点构型中约 $3.60\%$ 由"覆盖"翻为"不覆盖"），**不可直接沿用主模型 $R$ 的结论**。
5. **数值现象（非概率结论）**：随机模拟显示，$n=2$ 时绝大多数构型 $R^*/D\le\frac12+\delta_{\mathrm{rad}}^{2}=0.500305$（实测最坏 $0.500294$），但覆盖**并非恒成立**；$n\ge3$ 时失效比例随 $n$ 呈上升趋势（$n=3,4,5$ 约 $14\%,23\%,28\%$，见表 3）。这些比例是**随机构型的实验现象**，依赖采样方式，不作为一般性概率结论；实际判定一律以第三层的 Thales 判据为准。

## 9 理论依据与文献支撑

**（1）集合隶属（有界误差）估计。** 本问把示向度误差视为**有界不确定性**而非随机变量：真实方位角必落在测得值 $\pm1^\circ$ 内，故真源必属于所有楔形的交 $R$。"真源 $\in R$"是一个**确定性保证**，不依赖误差的分布形态，也不依赖各检测点误差的独立性（即使相邻地点误差高度相关仍成立），这正是集合隶属/有界误差估计框架的优点（文献 [3,4]）。由此可得三条直接可用的推论：同一地点重复检测不缩小 $R$（题面明确同点误差固定），故降低不确定域**必须改变检测点**；两点过近时两楔形几乎重合，$R$ 几乎不缩小；保证性与误差相关性无关，故不存在"区域虚假收缩"的风险。基于协方差的 GDOP/最小二乘（文献 [8,9]）给出的是**平均意义**下的精度，可作为辅助判据，但不能替代本问的保证性结论。

**（2）计算几何。** 定位区域是半平面交，其顶点数不超过 $2n$；凸多边形直径由顶点对决定，可用枚举或旋转卡壳求解；覆盖问题归结为 Thales 圆与凸集的包含，最坏情况由 Jung 定理给出上界，实际最小覆盖圆由 Welzl 算法求得。这些均为计算几何的经典结论（文献 [1,2,5,6,7,10]）。

## 附录 A　核心算法伪代码

**A.1 Thales 覆盖判定**

```
函数 THALES_COVER(V, a, b):        # V 为区域顶点；g(a)=g(b)=0 恒成立
    g_o ← -∞                        # 故只需检验除直径点对外的顶点
    for p in V, p ∉ {a, b}:
        g_o ← max(g_o, dot(p-a, p-b))
    return (g_o ≤ 0), g_o           # 真(=覆盖), 其余顶点最大 g
```

**A.2 最小包含弧长**

```
函数 MIN_ARC(thetas):              # thetas: 示向度(度)
    t ← sort([θ mod 360 for θ in thetas])
    max_gap ← max( (t[(i+1) mod n] - t[i]) mod 360 for i in 0..n-1 )
    return 360 - max_gap           # ≤ 2° 判为无界
```

## 附录 B　Python 参考实现

> 依赖：`numpy`。以下代码与第 7 节实验一致，可直接运行复现。B.1 为主算法，B.2 为补充实验（表 2、表 3、§5.5(1) 的放大反例）。

**B.1 主算法**

```python
# -*- coding: utf-8 -*-
import math
import numpy as np

EPS = 1e-9
D2R = math.pi / 180.0


def wedge_halfplanes(S, theta_deg, half=1.0):
    """楔形 W = 顶点 S、示向度 theta_deg、左右各 half 度。
    返回两个半平面 (q, n)，含义 n·(p-q) >= 0。"""
    S = np.asarray(S, float)
    a1 = (theta_deg - half) * D2R
    a2 = (theta_deg + half) * D2R
    n1 = np.array([-math.sin(a1), math.cos(a1)])   # 下边界内法向
    n2 = np.array([math.sin(a2), -math.cos(a2)])   # 上边界内法向
    return [(S, n1), (S, n2)]


def clip(poly, q, n):
    """Sutherland-Hodgman: 用半平面 n·(p-q) >= 0 裁剪凸多边形。
    poly 顶点数可为 1 或 2（退化的点/线段），凸裁剪不会使顶点数回升。"""
    if len(poly) == 0:
        return []
    out, m = [], len(poly)
    for i in range(m):
        A, B = poly[i], poly[(i + 1) % m]
        da = float(np.dot(n, A - q)); db = float(np.dot(n, B - q))
        ina, inb = da >= -EPS, db >= -EPS
        if ina:
            out.append(A)
        if ina != inb:
            out.append(A + (da / (da - db)) * (B - A))
    return out


def build_region(dets, box_half=1.0e6):
    """dets: [(S, theta_deg), ...] -> 顶点列表(逆时针)。
    返回 [] 表示**空集**（观测矛盾）；返回 1 或 2 个顶点表示区域退化为点/线段。
    空集只能由"半平面交为空"判定，不可由无界判据代替（见 5.3(4)）。

    注意（勘误 C14）：固定框 box_half 在 lmin -> 2*delta 附近会失效——
    真实直径 D ~ L*sin(2*delta)/(2*eps), eps = lmin-2*delta，
    eps 足够小时区域超出框：有界侧直径被截断低估，lmin 略小于 2*delta
    的非空无界域会被误判为空集。生产实现建议改用无框的"边界线两两求交
    + 全约束可行性筛选"，或按 eps 自适应放大 box_half。"""
    box = [np.array([-box_half, -box_half]), np.array([box_half, -box_half]),
           np.array([box_half, box_half]), np.array([-box_half, box_half])]
    poly = box
    for S, th in dets:
        for q, n in wedge_halfplanes(S, th):
            poly = clip(poly, q, n)
            if len(poly) == 0:
                return []
    res = []
    for p in poly:                    # 去重（含退化情形产生的重复顶点）
        if not res or np.linalg.norm(p - res[-1]) > 1e-7:
            res.append(p)
    while len(res) >= 2 and np.linalg.norm(res[0] - res[-1]) <= 1e-7:
        res.pop()
    return res


def min_arc(thetas):
    """所有示向度在圆周上的最小包含弧长 ℓ_min，式 (5)。"""
    ts = sorted(t % 360.0 for t in thetas)
    n = len(ts)
    if n <= 1:
        return 0.0
    max_gap = max((ts[(i + 1) % n] - ts[i]) % 360.0 for i in range(n))
    return 360.0 - max_gap


def region_unbounded(thetas, half=1.0):
    """定理 1 的解析判据：方向区间在圆周上有公共点 <=> 无界。"""
    ts = sorted(t % 360.0 for t in thetas)
    if len(ts) <= 1:
        return True
    return min_arc(ts) <= 2 * half + 1e-9


def diameter(V):
    """凸多边形直径 = 顶点对最大距离。"""
    best, pair = 0.0, (0, 0)
    for i in range(len(V)):
        for j in range(i + 1, len(V)):
            d = float(np.linalg.norm(V[i] - V[j]))
            if d > best:
                best, pair = d, (i, j)
    return best, pair


def circum(a, b, c):
    ax, ay = a; bx, by = b; cx, cy = c
    d = 2 * (ax * (by - cy) + bx * (cy - ay) + cx * (ay - by))
    if abs(d) < 1e-14:
        return None, None
    ux = ((ax**2 + ay**2)*(by - cy) + (bx**2 + by**2)*(cy - ay) + (cx**2 + cy**2)*(ay - by)) / d
    uy = ((ax**2 + ay**2)*(cx - bx) + (bx**2 + by**2)*(ax - cx) + (cx**2 + cy**2)*(bx - ax)) / d
    c0 = np.array([ux, uy])
    return c0, float(np.linalg.norm(a - c0))


def mec(V):
    """最小包围圆（暴力：点对 + 点三元组）；单点退化为半径 0。"""
    pts = [np.asarray(p, float) for p in V]
    if len(pts) == 0:
        return None, 0.0
    if len(pts) == 1:
        return pts[0], 0.0
    bestr, bestc = 1e18, None

    def ok(c, r):
        return all(np.linalg.norm(p - c) <= r + 1e-7 for p in pts)

    for i in range(len(pts)):
        for j in range(i + 1, len(pts)):
            c = (pts[i] + pts[j]) / 2
            r = float(np.linalg.norm(pts[i] - pts[j]) / 2)
            if r < bestr and ok(c, r):
                bestr, bestc = r, c
    for i in range(len(pts)):
        for j in range(i + 1, len(pts)):
            for k in range(j + 1, len(pts)):
                c, r = circum(pts[i], pts[j], pts[k])
                if c is not None and r < bestr and ok(c, r):
                    bestr, bestc = r, c
    return bestc, bestr


def solve_question1(dets):
    """主算法 Q1。"""
    V = build_region(dets)
    if len(V) == 0:                                  # 空集优先判定
        return {"status": "inconsistent", "msg": "观测矛盾（非同源/误差超界/误测漏测）",
                "lmin": min_arc([t for _, t in dets])}
    if region_unbounded([t for _, t in dets]):       # 定理 1
        return {"status": "unbounded", "msg": "直径 = +∞，不可定位",
                "lmin": min_arc([t for _, t in dets])}
    D, (ia, ib) = diameter(V)                        # 式 (6)
    a, b = V[ia], V[ib]
    g_all = [float(np.dot(p - a, p - b)) for p in V]
    # g(a) = g(b) = 0 恒成立，不构成覆盖证据；故只报"其余顶点"的最大值
    g_other = max([g for k, g in enumerate(g_all) if k not in (ia, ib)] or [-np.inf])
    c, Rstar = mec(V)
    return {"status": "bounded", "vertices": V, "D": D, "pair": (a, b),
            "covered": g_other <= 1e-9 * max(1.0, D * D),
            "gmax_others": g_other, "gmax": max(g_all),
            "Rstar": Rstar, "MEC_center": c, "Jung": D / math.sqrt(3),
            "degenerate": len(V) < 3}
```

def solve_with_half(dets, half):

def scan_delta(half, N=60000, seed=2026):

def coverage_by_n(N=6000, seed=7):

    res = {n: dict(tot=0, cov=0, mx=0.0) for n in (2, 3, 4, 5)}

            G = np.array([rng.uniform(-1200, 1200), rng.uniform(-1200, 1200)])
