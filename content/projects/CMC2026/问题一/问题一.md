# 问题一　交会定位区域直径的计算与圆覆盖性分析

> 本章依据赛题正文及其**附录 1（干扰源特征）**、**附录 2（测向机原理与交会定位法）**建立模型；所有数值结论均给出本地复算结果与验证方案。

---

## 1 问题重述

已知目标区域中某干扰源关于若干检测点的示向度，要求：

1. 给出采用**交会定位法**计算该干扰源**多边形定位区域直径**（即区域内任意两点之间距离的最大值）的算法；
2. 回答：**以该定位区域直径为直径的圆能否覆盖此定位区域**。

依附录 2，示向度定义为：在检测点处测得的、使场强最大的接收天线方向的方位角，即 $x$ 轴正向逆时针旋转至"检测点指向干扰源"向量方向的角度，取值范围 $[0^\circ,360^\circ)$。由于环境影响与测向精度所限，示向度与真实方位角之间存在误差；在目标区域全局范围内，**误差落在 $[-1^\circ,1^\circ]$ 内**，且**同一地点的电磁环境固定，重复检测不改变该误差**。图 2 给出两检测点 $S_1,S_2$ 交会的情形：两条实线为测得示向度方向，实线与相邻虚线夹角均为 $1^\circ$，由四条误差边界线围成的四边形即**定位区域**。

由此可见：**一条示向度给出的不是一个点，而是一个角约束**；定位区域是这些角约束的公共部分。这正是本问的几何本质。

---

## 2 模型假设

1. **平面假设**：由附录 2(7)，忽略测向机与干扰源的高度差，测向机与所有干扰源位于同一平面，问题为二维几何问题。
2. **有界误差假设**：真实方位角 $\alpha_i$ 与示向度 $\theta_i$ 之差满足 $|\alpha_i-\theta_i|\le 1^\circ$，即
   $$\alpha_i\in[\theta_i-1^\circ,\ \theta_i+1^\circ].$$
   本假设**不依赖误差的分布形式，也不依赖各检测点误差之间的独立性**（题面明确同一地点误差固定、不同地点才呈现统计规律）。这是本问采用"集合隶属"视角的根据。
3. **同一源假设**：所有示向度来自同一个干扰源。
4. **几何约束仅由方向决定**：若无特别说明，定位区域仅由示向度方向及其 $\pm1^\circ$ 误差带决定，即附录 2 图 2 所定义的区域；有效接收半径 $[1000,1500]$ m 与目标圆域半径 $1800$ m 作为可选附加约束（见 5.2 注）。
5. 忽略数值舍入；算法在实数域上讨论。

## 4 问题分析

本问要解决三个层层递进的子问题：

1. **如何把示向度写成几何约束？** 一个检测点的示向度只给出"源在该方向上"的射线，误差带把射线放宽为一个夹角 $2^\circ$ 的角形区域（楔形）。多个检测点给出多个楔形，它们的交集才是源的可能位置集合，即定位区域。
2. **如何由定位区域求直径？** 楔形是两个半平面的交，有限个楔形之交是凸多边形；凸多边形的直径必在其顶点对处取得，故只需在有限个顶点上求最大距离。
3. **直径圆能否覆盖定位区域？** 这是"一个由直径决定的圆"与"区域"的包含关系问题。直觉上"直径的两端点决定了区域的最大跨度，所以半径为 $D/2$ 的圆应当够用"是**错误**的：圆是中心对称的，而区域可以是不对称的（例如钝角/直角三角形），此时区域会从直径圆"鼓"出去。因此需给出严格判据与最坏情况界。

此外必须处理两类退化：**观测矛盾（区域为空）**与**区域无界（无法定位）**。二者在数学上是独立的，不能混为一谈。

## 5 模型的建立

### 5.1 示向度的角约束与楔形模型

对检测点 $S_i$，其示向度误差边界方向为

$$\beta_i^-=\theta_i-1^\circ,\qquad \beta_i^+=\theta_i+1^\circ .$$

记 $\operatorname{rot}(v,\gamma)$ 为把向量 $v$ 逆时针旋转 $\gamma$。定义两条边界的内法向

$$n_i^-=\operatorname{rot}\big((\cos\beta_i^-,\sin\beta_i^-),+90^\circ\big)=(-\sin\beta_i^-,\ \cos\beta_i^-),$$
$$n_i^+=\operatorname{rot}\big((\cos\beta_i^+,\sin\beta_i^+),-90^\circ\big)=(\ \sin\beta_i^+,\ -\cos\beta_i^+).$$

第 $i$ 个检测点给出的**楔形**为

$$W_i=\{p\in\mathbb R^2:\ n_i^-\!\cdot(p-S_i)\ge 0,\ \ n_i^+\!\cdot(p-S_i)\ge 0\}. \tag{1}$$

式 (1) 表明 $W_i$ 是**两个半平面之交**，是一个以 $S_i$ 为顶点、张开 $2^\circ$ 的闭凸锥的平移。于是**定位区域**为

$$R=\bigcap_{i=1}^{n}W_i=\bigcap_{i=1}^{n}\{p:\ n_i^-\!\cdot(p-S_i)\ge0,\ n_i^+\!\cdot(p-S_i)\ge0\}, \tag{2}$$

即 $2n$ 个半平面之交。由凸集的交仍是凸集，得

> **性质 1**　$R$ 是闭凸集；当 $R$ 有界且非空时，它是顶点数 $h\le 2n$ 的凸多边形。

特别地，两检测点 $(n=2)$ 时 $R$ 是四条边界线围成的四边形（附录 2 图 2 的红色区域），这正是题目所定义的交会定位区域；$n$ 更大时 $R$ 是更一般的凸多边形。

### 5.2 定位区域的几何性质与附注

**锥的回收锥。** $W_i$ 是"以 $S_i$ 为顶点、方向区间 $[\beta_i^-,\beta_i^+]=[\theta_i-1^\circ,\theta_i+1^\circ]$ 的闭凸锥"的平移。它的**回收锥**（recession cone，即使得 $x+td\in W_i,\ \forall t\ge0$ 的方向 $d$ 的集合）就是这个锥本身：

$$\operatorname{rec}(W_i)=C_i=\Big\{t(\cos\varphi,\sin\varphi):\ t\ge0,\ \varphi\in[\theta_i-1^\circ,\theta_i+1^\circ]\Big\}. \tag{3}$$

**注（可选附加约束）** 若进一步利用"干扰源位于半径 $1800$ m 的目标圆域内"，则把 $R$ 与闭圆盘 $B(O,1800)$ 求交。该交仍为凸紧集（边界一般由若干直线段与至多一段圆弧组成），且只会减小直径；此时直径与覆盖判定仍可沿其边界（直线段的顶点与圆弧上的极值点）求解。本文主体结论不依赖该约束，后文算法对是否附加该约束均适用（若只取直线段部分即为原算法）。同理，其他先验（如已确认频道的空间约束）可作为附加凸约束加入。

### 5.3 有界性与空集的判别

**（1）无界的充要判据。**

> **定理 1**　设 $R=\bigcap_{i=1}^n W_i$。
> (i) 若 $R=\varnothing$，则 $R$ 有界。
> (ii) 若 $R\ne\varnothing$，则
> $$R\ \text{无界}\iff \bigcap_{i=1}^{n}[\theta_i-1^\circ,\ \theta_i+1^\circ]\ne\varnothing. \tag{4}$$

**证明.** 对非空闭凸集族，回收锥满足
$$\operatorname{rec}\Big(\bigcap_i W_i\Big)=\bigcap_i\operatorname{rec}(W_i)$$
（凸分析基本结论，见文献 [1] 第 8 章"回收锥"）。由式 (3)，$\operatorname{rec}(W_i)=C_i$，故
$$\operatorname{rec}(R)=\bigcap_{i=1}^n C_i .$$
非空闭凸集 $R$ 无界当且仅当其回收锥非平凡，即 $\operatorname{rec}(R)\ne\{0\}$。而由 $C_i$ 的定义，$\bigcap_i C_i\ne\{0\}$ 当且仅当存在一个方向 $\varphi$ 同时属于所有区间 $[\theta_i-1^\circ,\theta_i+1^\circ]$，即式 (4) 右端成立。$\blacksquare$

**（2）判据的可计算形式。** 记各示向度在圆周上的最小包含弧长为
$$\ell_{\min}=360^\circ-\max_{1\le i\le n}\big((\theta_{(i+1)}-\theta_{(i)})\bmod 360^\circ\big),$$
其中 $\theta_{(1)}\le\cdots\le\theta_{(n)}$ 为 $\{\theta_i\bmod360^\circ\}$ 的升序排列（含首尾环绕）。则

$$\bigcap_{i=1}^{n}[\theta_i-1^\circ,\theta_i+1^\circ]\ne\varnothing\iff \ell_{\min}\le 2^\circ. \tag{5}$$

其含义是：所有示向度若能塞进一段 $2^\circ$ 的弧内，则所有误差带有一个公共方向，定位区域沿该方向无限延伸。

**（3）$n=2$ 的推论。** 两检测点的情形最为常用：

> **推论 1**　$n=2$ 时，$R$ 无界（在 $R\ne\varnothing$ 的前提下）$\iff d_{\mathrm{circ}}(\theta_1,\theta_2)\le 2^\circ$；$d_{\mathrm{circ}}(\theta_1,\theta_2)>2^\circ$ 时 $R$ 必有界。

**（4）空集与无界的独立性。** "区域为空"与"区域无界"是两个独立判据：

- 交集非空（$\ell_{\min}\le2^\circ$）必然导致 $R$ **非空且无界**；
- 反之，$R$ 为空并不要求无界。例如取 $S_1=(0,0),\ \theta_1=0^\circ$ 与 $S_2=(1000,0),\ \theta_2=90^\circ$，两误差带 $[-1^\circ,1^\circ]$ 与 $[89^\circ,91^\circ]$ 无交，$\ell_{\min}=90^\circ>2^\circ$，定位区域是**有界的非空区域**（本例复算为三角形，$D\approx17.46$ m，观测并不矛盾）。

因此算法必须**先做半平面交得到（可能为空的）$R$，再判定是否有界**；不可用"无界判据"替代空集判别。

**（5）边界等号的严格性。** 当 $\ell_{\min}=2^\circ$（如 $\lvert\theta_1-\theta_2\rvert_{\mathrm{circ}}=2^\circ$）时，两楔形共享**一条边界射线**：它们仅在该方向上有一公共方向，故若区域非空则**无界**（直径 $=+\infty$），而非"刚好有界"。本地大框裁剪复核（检测点取 $S_1=(0,0),\ \theta_1=0^\circ$，$S_2=(1000,0)$，$\theta_2=\Delta\theta$）如表 1。

**表 1　有界性边界复核**

| $\Delta\theta$ | $1.00^\circ$ | $1.95^\circ$ | $\mathbf{2.00^\circ}$ | $2.05^\circ$ | $2.50^\circ$ | $5.00^\circ$ | $90.00^\circ$ |
|---|---|---|---|---|---|---|---|
| 解析判据 | 无界 | 无界 | **无界** | 有界 | 有界 | 有界 | 有界 |
| 数值复核 | 无界 | 无界 | **无界** | 有界 | 有界 | 有界 | 有界 |
| 直径 $D$/m | $\infty$ | $\infty$ | $\infty$ | $19998.99$ | $1999.92$ | $333.47$ | $17.46$ |

可见 $\Delta\theta$ 刚超过 $2^\circ$ 时，区域虽已有界但极其狭长（$D$ 可达万米量级），这正是问题 2 要规避的"失效构型"。

**（6）三种定论。** 综上，算法对定位区域给出且仅给出三种结论：

| 情形 | 判据 | 结论 |
|---|---|---|
| 空集 | 半平面交为空 | 观测矛盾，所有示向度不可能来自同一源 |
| 无界 | 半平面交非空且 $\ell_{\min}\le2^\circ$ | 直径 $=+\infty$，**不可定位** |
| 有界 | 半平面交非空且 $\ell_{\min}>2^\circ$ | 存在有限直径 $D$，可定位 |

### 5.4 直径的刻画

**定理 2**　设 $R$ 为非空紧凸多边形，$\operatorname{vert}(R)$ 为其顶点集，则

$$\operatorname{diam}(R)=\max_{u,v\in R}\lVert u-v\rVert=\max_{u,v\in\operatorname{vert}(R)}\lVert u-v\rVert,\qquad
D=\max_{u,v\in\operatorname{vert}(R)}\lVert u-v\rVert. \tag{6}$$

**证明.** 映射 $f(u,v)=\lVert u-v\rVert$ 是仿射映射 $(u,v)\mapsto u-v$ 与范数（凸函数）的复合，故在凸集 $R\times R$ 上凸。紧凸集上的凸函数最大值必在极点取得；而 $R\times R$ 的极点集正是 $\operatorname{vert}(R)\times\operatorname{vert}(R)$。$\blacksquare$

由 $h\le2n$，式 (6) 把连续的极大化问题化归为有限个顶点对的枚举，复杂度 $O(h^2)$；对凸多边形亦可使用旋转卡壳（rotating calipers）在 $O(h)$ 内完成（文献 [11]）。

### 5.5 以定位区域直径为直径的圆的覆盖性

这是本问的第二问，分三层回答。

**（1）一般不能覆盖——反例。**

取三角形区域 $T$，顶点为 $(0,0),(1,0),(0.5,0.7)$；其直径点对为 $(0,0)$ 与 $(1,0)$，$D=1$。以其中点 $(0.5,0)$ 为圆心、$D/2=0.5$ 为半径的圆，到第三个顶点 $(0.5,0.7)$ 的距离为 $0.7>0.5$，故该顶点落在直径圆之外，**覆盖失败**。经本地计算，该三角形的真实最小包围圆半径为 $R^*=0.528571>0.5$。

该反例并非抽象构造，**可由三个检测点的楔形交精确实现**：取

| $i$ | $S_i$ | $\theta_i$ |
|---|---|---|
| 1 | $(-200,\ 0)$ | $1.0000^\circ$ |
| 2 | $(-116.2476,\ -162.7467)$ | $53.4623^\circ$ |
| 3 | $(-115.7476,\ 163.4467)$ | $304.5377^\circ$ |

其楔形交的顶点经复算为 $(0.5,0.7),(0,0),(1,0)$，恰好复现上述三角形。故反例在本题模型内可实现。

**（2）充要条件（Thales 判据）。**

由 Thales 定理，以线段 $ab$ 为直径的圆（闭圆盘）恰为

$$\mathcal D_{ab}=\{p:\ (p-a)\cdot(p-b)\le 0\}, \tag{7}$$

因为 $(p-a)\cdot(p-b)=\lVert p-c\rVert^2-\lVert a-b\rVert^2/4$，$c=(a+b)/2$，故 (7) 等价于 $\lVert p-c\rVert\le D/2$。于是

> **定理 3**　以 $R$ 的直径点对 $(a,b)$ 为直径的圆覆盖 $R$，当且仅当
> $$\max_{p\in R}\ g(p)\le0,\qquad g(p):=(p-a)\cdot(p-b). \tag{8}$$

**证明.** 式 (7) 给出等价性。$g$ 的 Hessian 为 $2I\succ0$，故 $g$ 为凸二次函数；凸函数在凸紧集上的最大值在极点取得，因此式 (8) 只需在 $R$ 的顶点上检验：
$$\max_{p\in R}g(p)=\max_{p\in\operatorname{vert}(R)}g(p). \qquad\blacksquare$$

定理 3 把"圆是否覆盖区域"化为**有限个顶点的符号检验**，是最直接、最稳健的判据。本地在 5000 个随机有界凸多边形上比较"顶点检验"与最小包围圆刻画 $R^*=D/2$，判定完全一致（见 7 实验 4）。

**（3）几何刻画与最坏情况界。**

> **定理 4**　设 $R^*$ 为 $R$ 的最小包围圆半径，$D$ 为其直径。则
> $$R^*\ge D/2, \tag{9}$$
> 且**直径圆覆盖 $R\iff R^*=D/2$**。

**证明.** 直径点对 $a,b\in R$ 满足 $\lVert a-b\rVert=D$，任何覆盖 $R$ 的圆的半径至少为 $D/2$，故 $R^*\ge D/2$。若 $R^*=D/2$，则半径 $D/2$ 的最小包围圆唯一，其必为以某直径点对为直径的圆（因 $a,b$ 必在该圆上且对径），故直径圆覆盖 $R$；反之若直径圆覆盖 $R$，则 $R^*\le D/2$，结合 (9) 得 $R^*=D/2$。$\blacksquare$

**Jung 定理**（文献 [6]）给出最坏情况上界：平面内直径 $D$ 的集合必被半径不超过 $D/\sqrt3$ 的圆覆盖，等边三角形取等。故一旦直径圆不够用，**所需覆盖圆的直径最坏为**

$$2R^*\le \frac{2D}{\sqrt3}\approx1.1547\,D. \tag{10}$$

当 $2R^*>D$ 时，工程上应直接采用**最小包围圆**（Welzl 算法，期望 $O(h)$，文献 [7]）作为覆盖圆，其半径 $R^*$ 即所需最小半径。

**（4）对本题两检测点交会区域的注记。** 对 $n=2$ 的楔形交四边形，在 $20000$ 组随机构型上统计得
$$\max\ \frac{R^*}{D}\le 0.5003,$$
即 $R^*$ 与 $D/2$ 相差不足 $0.06\%$，直径圆实际上几乎总能覆盖此类区域（四检测点算例中更精确地取到 $R^*/D=0.500000$）。需要指出的是：两楔形交的四边形**严格来说不是平行四边形**（两楔形各贡献一对相差 $178^\circ$ 的边界方向，拼出的四边形一般没有两对平行边，甚至可能退化为三角形），故 $R^*/D>1/2$ 只会以极小幅度出现。因此**理论上应以定理 3/4 的判据为准，不能默认 $R^*=D/2$**；当 $n\ge3$ 时反例（1）表明覆盖可以明显失败。

## 6 算法设计与复杂度

### 6.1 主算法

```
算法 Q1：交会定位区域直径与覆盖判定
输入 : 检测点 S_i 与示向度 θ_i, i = 1..n; 误差界 δ = 1°
输出 : 定位区域顶点集 V、直径 D 及点对 (a,b)、覆盖结论、最小包围圆半径 R*

 1  对每个 i: 由式(1) 生成两个半平面 (S_i, n_i^-), (S_i, n_i^+)
 2  R ← 半平面交(所有 2n 个半平面)            # 用大框裁剪或增量法
 3  若 R = ∅:                                 # 空集优先判定
 4      返回 "观测矛盾，不可能为同一源"
 5  若 最小包含弧长 ℓ_min(θ_1..θ_n) ≤ 2δ:     # 定理 1
 6      返回 "无界，D = +∞，不可定位"
 7  V ← R 的顶点集                            # h ≤ 2n
 8  (a,b), D ← 直径(V)                        # 枚举 O(h^2) 或旋转卡壳 O(h)
 9  cover ← [ max_{p∈V} (p-a)·(p-b) ≤ 0 ]     # 定理 3
10  (c, R*) ← 最小包围圆(V)                    # Welzl
11  返回 V, D, (a,b), cover, R*
```

### 6.2 关键子程序

- **半平面交**：$n$ 较小时，用 Sutherland–Hodgman 逐条裁剪一个大框（初始为包围所有 $S_i$ 的矩形），每次裁剪 $O(m)$，总 $O(n^2)$；也可对半平面按极角排序后用增量法，期望 $O(n\log n)$（文献 [5]）。
- **直径**：$h\le2n$ 很小，直接枚举 $\binom h2$ 个顶点对即可（$O(h^2)$，实现最简）；如需体现算法素养，用旋转卡壳 $O(h)$（文献 [11]）。
- **最小包围圆**：Welzl 随机增量算法，期望 $O(h)$；本问题 $h\le2n$，亦可暴力枚举所有点对与点三元组（$O(h^4)$，$h$ 小时足够）。
- **最小包含弧长** $\ell_{\min}$：对 $\{\theta_i\bmod360^\circ\}$ 排序求最大间隙，再补弧，$O(n\log n)$。

### 6.3 复杂度

设 $n$ 为检测点数，$h\le2n$ 为区域顶点数。半平面交 $O(n\log n)$（增量）或 $O(n^2)$（大框裁剪），直径 $O(h)$（旋转卡壳）或 $O(h^2)$，最小包围圆期望 $O(h)$。故总体为
$$O(n\log n)\ \text{（推荐）}\quad\text{或}\quad O(n^2)\ \text{（最简实现）}.$$

### 6.4 退化情形处理

| 退化情形 | 现象 | 处理 |
|---|---|---|
| $n=1$ | 单个楔形，无界 | $\ell_{\min}=0\le2^\circ$，返回"不可定位" |
| $n\ge2$，$\ell_{\min}\le2^\circ$ | 区域无界 | 直径记 $+\infty$，返回"不可定位" |
| 观测矛盾 | 区域为空 | 返回"非同一源"，检查是否有误测/漏测 |
| $\ell_{\min}=2^\circ$ | 共享一条边界射线 | 按定理 1 判为无界（严格用 $>$） |
| 顶点共线/重合 | $h<3$ 或出现重复顶点 | 去重、去共线点；$h\le2$ 时按线段/点处理（$D$ 为线段长或 $0$） |
| 大框裁剪残留 | 区域贴住裁剪框 | 以解析判据定理 1 为准，大框仅用于求顶点 |

## 7 数值实验与验证

以下结果均由独立 Python 脚本复算（见附录 B），作为算法正确性的证据。

**实验 1（覆盖性反例）**　三角形 $(0,0),(1,0),(0.5,0.7)$：$D=1$，直径圆半径 $0.5$、圆心 $(0.5,0)$，顶点 $(0.5,0.7)$ 到圆心距离 $0.7$，**覆盖失败**；$R^*=0.528571$，Jung 上界 $D/\sqrt3=0.577350$，Thales 检验 $\max g=0.24>0$。三检测点楔形交精确复现该三角形（见 5.5(1)）。

**实验 2（有界性边界）**　见表 1：$1.95^\circ,2.00^\circ$ 无界，$2.05^\circ$ 有界（$D\approx19999$ m），与解析判据逐例一致。

**实验 3（蒙特卡洛：真源必落入区域）**　随机生成检测点与真源，按真值加 $[-1^\circ,1^\circ]$ 均匀误差反算示向度，共 $4000$ 组：真源未落入 $R$ 的次数 $=0$（应为 $0$），出现空集的次数 $=0$（应为 $0$）。这验证了集合隶属结论"真源必属 $R$"及实现的正确性。

**实验 4（无界判据与数值复核一致）**　随机构型（排除空集与近退化构型）$208$ 组，解析判据与大框数值判定**不一致次数 $=0$**；另对 $5000$ 个随机有界凸多边形比较 Thales 顶点判据与 $R^*=D/2$ 刻画，**不一致次数 $=0$**。

**实验 5（两检测点 $R^*/D$）**　随机与对抗构型共约 $5.7\times10^4$ 组，$\max R^*/D\le0.5003$，与 $D/2$ 相差不足 $0.06\%$。

**实验 6（完整数值算例）**　真源 $G=(600,400)$，四检测点及其示向度如下，误差分别为 $-0.7^\circ,+0.5^\circ,-0.3^\circ,+0.8^\circ$：

| $i$ | $S_i$ | 真实方位角 | 示向度 |
|---|---|---|---|
| 1 | $(-900,-700)$ | $36.25384^\circ$ | $35.55384^\circ$ |
| 2 | $(1400,-200)$ | $143.13010^\circ$ | $143.63010^\circ$ |
| 3 | $(-200,1500)$ | $306.02737^\circ$ | $305.72737^\circ$ |
| 4 | $(900,1100)$ | $246.80141^\circ$ | $247.60141^\circ$ |

复算得 $R$ 的顶点
$$(587.157443,377.014692),\ (610.259300,360.615315),\ (623.086473,393.348774),\ (601.394070,409.915818),$$
直径点对为 $(610.259300,360.615315)$ 与 $(601.394070,409.915818)$，
$$D=50.091236\ \text{m},\quad R^*=25.045618\ \text{m},\quad R^*/D=0.500000,$$

## 8 结论

1. **直径算法**：把每条示向度化为一个 $2^\circ$ 楔形（两个半平面），定位区域是其交集——凸多边形；求其对全部顶点对的最大距离即得直径 $D$（定理 2）。算法流程见 6.1，复杂度 $O(n\log n)$～$O(n^2)$，并给出空集/无界/有界三种定论与退化处理。
2. **覆盖性回答**：**一般不能覆盖**。反例（三角形 $(0,0),(1,0),(0.5,0.7)$，$D=1$）中直径圆漏掉一个顶点，且该反例可由三个检测点的楔形交精确实现。严格的**充要条件是 Thales 判据** $\max_{p\in\operatorname{vert}(R)}(p-a)\cdot(p-b)\le0$（定理 3）；等价刻画为 $R^*=D/2$（定理 4，因恒有 $R^*\ge D/2$）。最坏情况下覆盖圆半径不超过 $D/\sqrt3$，相应直径不超过 $2D/\sqrt3\approx1.1547D$（Jung 定理）；工程实现时应直接计算最小包围圆 $R^*$（Welzl）。
3. **两点注记**：对本题两检测点的交会四边形，数值上 $R^*/D\le0.5003$，直径圆几乎总能覆盖，但该等式并非严格成立（区域非平行四边形），$n\ge3$ 时反例表明覆盖可明显失败；因此必须按判据处理，不可默认覆盖成立。

## 9 理论依据与文献支撑

**（1）集合隶属（有界误差）估计。** 本问把示向度误差视为**有界不确定性**而非随机变量：真实方位角必落在测得值 $\pm1^\circ$ 内，故真源必属于所有楔形的交 $R$。"真源 $\in R$"是一个**确定性保证**，不依赖误差的分布形态，也不依赖各检测点误差的独立性（即使相邻地点误差高度相关仍成立），这正是集合隶属/有界误差估计框架的优点（文献 [3,4]）。由此可得三条直接可用的推论：同一地点重复检测不缩小 $R$（题面明确同点误差固定），故降低不确定域**必须改变检测点**；两点过近时两楔形几乎重合，$R$ 几乎不缩小；保证性与误差相关性无关，故不存在"区域虚假收缩"的风险。基于协方差的 GDOP/最小二乘（文献 [8,9]）给出的是**平均意义**下的精度，可作为辅助判据，但不能替代本问的保证性结论。

**（2）计算几何。** 定位区域是半平面交，其顶点数不超过 $2n$；凸多边形直径由顶点对决定，可用枚举或旋转卡壳求解；覆盖问题归结为 Thales 圆与凸集的包含，最坏情况由 Jung 定理给出上界，实际最小覆盖圆由 Welzl 算法求得。这些均为计算几何的经典结论（文献 [1,2,5,6,7,10]）。

```
函数 THALES_COVER(V, a, b):        # V 为区域顶点
    gmax ← -∞
    for p in V:
        gmax ← max(gmax, dot(p-a, p-b))
    return gmax ≤ 0, gmax           # 真(=覆盖), 最大值
```

**A.2 最小包含弧长**

```
函数 MIN_ARC(thetas):              # thetas: 示向度(度)
    t ← sort([θ mod 360 for θ in thetas])
    max_gap ← max( (t[(i+1) mod n] - t[i]) mod 360 for i in 0..n-1 )
    return 360 - max_gap           # ≤ 2° 判为无界
```

## 附录 B　Python 参考实现

> 依赖：`numpy`。以下代码与第 7 节实验一致，可直接运行复现。

```python
# -*- coding: utf-8 -*-
import math
import numpy as np

EPS = 1e-9
D2R = math.pi / 180.0


def wedge_halfplanes(S, theta_deg, half=1.0):
    """楔形 W = 顶点 S、示向度 theta_deg、左右各 half 度。
    返回两个半平面 (q, n)，含义 n·(p-q) >= 0。"""
    S = np.asarray(S, float)
    a1 = (theta_deg - half) * D2R
    a2 = (theta_deg + half) * D2R
    n1 = np.array([-math.sin(a1), math.cos(a1)])   # 下边界内法向
    n2 = np.array([math.sin(a2), -math.cos(a2)])   # 上边界内法向
    return [(S, n1), (S, n2)]


def clip(poly, q, n):
    """Sutherland-Hodgman: 用半平面 n·(p-q) >= 0 裁剪凸多边形。"""
    if len(poly) == 0:
        return []
    out, m = [], len(poly)
    for i in range(m):
        A, B = poly[i], poly[(i + 1) % m]
        da = float(np.dot(n, A - q)); db = float(np.dot(n, B - q))
        ina, inb = da >= -EPS, db >= -EPS
        if ina:
            out.append(A)
        if ina != inb:
            out.append(A + (da / (da - db)) * (B - A))
    return out


def build_region(dets, box_half=1.0e6):
    """dets: [(S, theta_deg), ...] -> 顶点列表(逆时针)；[] 表示空集。"""
    box = [np.array([-box_half, -box_half]), np.array([box_half, -box_half]),
           np.array([box_half, box_half]), np.array([-box_half, box_half])]
    poly = box
    for S, th in dets:
        for q, n in wedge_halfplanes(S, th):
            poly = clip(poly, q, n)
            if len(poly) < 3:
                return []
    # 去重
    res = []
    for p in poly:
        if not res or np.linalg.norm(p - res[-1]) > 1e-7:
            res.append(p)
    return res


def region_unbounded(thetas, half=1.0):
    """定理 1 的解析判据：方向区间在圆周上有公共点 <=> 无界。"""
    ts = sorted(t % 360.0 for t in thetas)
    n = len(ts)
    if n <= 1:
        return True
    max_gap = max((ts[(i + 1) % n] - ts[i]) % 360.0 for i in range(n))
    return (360.0 - max_gap) <= 2 * half + 1e-9


def diameter(V):
    """凸多边形直径 = 顶点对最大距离。"""
    best, pair = 0.0, (0, 0)
    for i in range(len(V)):
        for j in range(i + 1, len(V)):
            d = float(np.linalg.norm(V[i] - V[j]))
            if d > best:
                best, pair = d, (i, j)
    return best, pair


def circum(a, b, c):
    ax, ay = a; bx, by = b; cx, cy = c
    d = 2 * (ax * (by - cy) + bx * (cy - ay) + cx * (ay - by))
    if abs(d) < 1e-14:
        return None, None
    ux = ((ax**2 + ay**2)*(by - cy) + (bx**2 + by**2)*(cy - ay) + (cx**2 + cy**2)*(ay - by)) / d
    uy = ((ax**2 + ay**2)*(cx - bx) + (bx**2 + by**2)*(ax - cx) + (cx**2 + cy**2)*(bx - ax)) / d
    c0 = np.array([ux, uy])
    return c0, float(np.linalg.norm(a - c0))


def mec(V):
    """最小包围圆（暴力：点对 + 点三元组）。"""
    pts = [np.asarray(p, float) for p in V]
    bestr, bestc = 1e18, None

    def ok(c, r):
        return all(np.linalg.norm(p - c) <= r + 1e-7 for p in pts)

    for i in range(len(pts)):
        for j in range(i + 1, len(pts)):
            c = (pts[i] + pts[j]) / 2
            r = float(np.linalg.norm(pts[i] - pts[j]) / 2)
            if r < bestr and ok(c, r):
                bestr, bestc = r, c
    for i in range(len(pts)):
        for j in range(i + 1, len(pts)):
            for k in range(j + 1, len(pts)):
                c, r = circum(pts[i], pts[j], pts[k])
                if c is not None and r < bestr and ok(c, r):
                    bestr, bestc = r, c
    return bestc, bestr


def solve_question1(dets):
    """主算法 Q1。"""
    V = build_region(dets)
    if len(V) == 0:
        return {"status": "inconsistent", "msg": "观测矛盾，不可能为同一源"}
    if region_unbounded([t for _, t in dets]):
        return {"status": "unbounded", "msg": "直径 = +∞，不可定位"}
    D, (ia, ib) = diameter(V)
    a, b = V[ia], V[ib]
    gmax = max(float(np.dot(p - a, p - b)) for p in V)
    c, Rstar = mec(V)
    return {"status": "bounded", "vertices": V, "D": D, "pair": (a, b),
            "covered": gmax <= 1e-9 * max(1.0, D * D), "gmax": gmax,
            "Rstar": Rstar, "MEC_center": c, "Jung": D / math.sqrt(3)}
```
