## 1 问题重述

已知目标区域中某干扰源关于若干检测点的示向度，要求解决两件事：第一，给出采用**交会定位法**计算该干扰源**多边形定位区域直径**（即区域内任意两点之间距离的最大值）的算法；第二，回答**以该定位区域直径为直径的圆能否覆盖此定位区域**。

依附录 2，示向度定义为：在检测点处测得的、使场强最大的接收天线方向的方位角，即 $x$ 轴正向逆时针旋转至"检测点指向干扰源"向量方向的角度，取值范围 $[0^\circ,360^\circ)$。由于环境影响与测向精度所限，示向度与真实方位角之间存在误差；在目标区域全局范围内，**误差落在 $\pm1^\circ$ 内**，且**同一地点的电磁环境固定，重复检测不改变该误差**。附录 2 图 2 给出两检测点交会的情形：两条实线为测得示向度方向，实线与相邻虚线夹角均为 $1^\circ$，由四条误差边界线围成的四边形即**定位区域**。

由此可见：**一条示向度给出的不是一个点，而是一个角约束**；定位区域是这些角约束的公共部分。这正是本问的几何本质。据此，本问的求解不是"求两条射线的交点"这类解方程问题，而是"求一族角度约束的公共位置集合、再在该集合上求最大跨度与其外接圆包含关系"的几何问题。

## 2 模型假设

1. **平面假设**：由附录 2(7)，忽略测向机与干扰源的高度差，测向机与所有干扰源位于同一平面，问题为二维几何问题。
2. **有界误差假设**：真实方位角 $\alpha_i$ 与示向度 $\theta_i$ 之差的绝对值不超过楔形半角宽 $\delta$（本题 $\delta=1^\circ$）。本假设**不依赖误差的分布形式，也不依赖各检测点误差之间的独立性**（题面明确同一地点误差固定、不同地点才呈现统计规律）。这是本问采用"集合隶属"视角的根据。
3. **同一源假设**：所有示向度来自同一个干扰源。
4. **几何约束仅由方向决定（主模型）**：**主模型**的定位区域仅由示向度方向及其 $\pm1^\circ$ 误差带决定，即附录 2 图 2 所定义的区域；有效接收半径 $[1000,1500]$ m 与目标圆域半径 $1800$ m 不进入主模型，而是作为**物理先验约束**单独构造区域 $R_c$ 处理（见 §5.2）。本文的全部定理（有界性、直径、覆盖判据）均针对主模型的 $R$；$R_c$ 需**重新计算**直径与覆盖性，不能沿用 $R$ 的结论。
5. 忽略数值舍入；算法在实数域上讨论。

## 4 问题分析

本问要解决三个层层递进的子问题。

**第一，如何把示向度写成几何约束？** 一个检测点的示向度只给出"源在该方向上"的射线，误差带把射线放宽为一个夹角 $2^\circ$ 的角形区域（楔形）。多个检测点给出多个楔形，它们的交集才是源的可能位置集合，即定位区域。**第二，如何由定位区域求直径？** 楔形是两个半平面的交，有限个楔形之交是凸多边形；凸多边形的直径必在其顶点对处取得，故只需在有限个顶点上求最大距离。**第三，直径圆能否覆盖定位区域？** 这是"一个由直径决定的圆"与"区域"的包含关系问题。直觉上"直径的两端点决定了区域的最大跨度，所以半径为 $D/2$ 的圆应当够用"是**错误**的：圆是中心对称的，而区域可以是不对称的（例如钝角或直角三角形），此时区域会从直径圆"鼓"出去。因此需给出严格判据与最坏情况界。

此外必须处理两类退化：**观测矛盾（区域为空）**与**区域无界（无法定位）**。二者在数学上是独立的，不能混为一谈——空集判定只能由半平面交本身给出，无界判据不能替代它（§5.3 给出两个方向的算例）。

**核心主线（五步）.** 本问的解答归结为一条主链：先由误差带写出楔形 $W_i$（式 (1)）；再取诸楔形之交得到定位区域 $R$（凸多边形）；然后做空集、无界、有界的三分判定（定理 1）；再在顶点对上求直径 $D$（定理 2）；最后用 Thales 判据判定直径圆的覆盖性（定理 3）。

这五步全部针对**主模型 $R$**（严格按题目与附录 2 图 2 定义）。**物理约束 $R_c$**（目标圆域、有效接收半径）是此主链之外的**独立修正层**：必须对 $R_c$ 重新求直径、重新判覆盖，**不能沿用 $R$ 的结论**（见 §5.2 与定理 3 之后的覆盖性转移讨论）。

从算法设计角度看，问题一的难点不在优化而在**稳健性**：区域尺度会随观测几何的退化而无界增长（§5.3 表 1 给出 $\Delta\theta$ 刚超过 $2^\circ$ 时直径可达万米量级的算例），任何依赖"预先给定一个大框"的实现都会在临界构型上失效。因此本文的算法一律采用**无框**的区域顶点枚举，其合法性由性质 2 保证。

## 5 模型的建立

### 5.1 示向度的角约束与楔形模型

对检测点 $S_i$，其示向度误差的两条边界方向为 $\beta_i^-$ 与 $\beta_i^+$，各自的内法向为 $n_i^-$ 与 $n_i^+$（定义见《问题一_公式.md》"误差边界方向与内法向"条）。第 $i$ 个检测点给出的**楔形** $W_i$ 由这两个半平面之交定义，即式 (1)；它是一个以 $S_i$ 为顶点、张开 $2\delta$ 的闭凸锥的平移。于是**定位区域** $R$ 为全部楔形之交，即 $2n$ 个半平面之交，见式 (2)。

由凸集的交仍是凸集，得**性质 1**：设 $\delta\in(0^\circ,90^\circ)$（本题 $\delta=1^\circ$），$R$ 是闭凸集；当 $R$ 有界且非空时，它是顶点数 $h\le 2n$ 的凸多边形（前提 $\delta<90^\circ$ 的必要性见《问题一_公式.md》性质 1）。

**性质 2（顶点存在性）** 是整个算法实现的基石：设 $\delta\in(0^\circ,90^\circ)$（本题 $\delta=1^\circ$），则 $R\ne\varnothing$ 当且仅当"由边界线两两求交、再经全部约束可行性筛选"得到的候选点集非空。因此**空集判定可以只靠顶点枚举完成，不需要任何裁剪框**；该结论的完整证明（含前提的必要性）见《问题一_小证明.md》§1 与《问题一_公式.md》性质 2。性质 2 的价值在于：它把"$R$ 是否为空"这个原先需要**预先给定裁剪框**才能回答的问题，变成一个**无尺度**的有限枚举问题，从结构上消除了"固定大框在 $\ell_{\min}\to2\delta$ 附近截断直径或误判空集"的风险——具体失效对照见 §6.2 与 §6.4，附录 B.1 的实现即按此改写。

特别地，两检测点（$n=2$）时 $R$ 在一般位置为四条边界线围成的四边形（这正是题目与附录 2 图 2 所定义的交会定位区域），但**可退化为三角形**（§5.5(1) 的物理相容反例与 §5.3(4) 的 $D=17.463$ 例即三角形）；$n$ 更大时 $R$ 是更一般的凸多边形。

### 5.2 定位区域：主模型与物理约束模型

**第一块：主模型 $R$（严格按题目与附录 2 图 2 定义，本文主体）.** 主模型只使用示向度方向及其 $\pm1^\circ$ 误差带，不含任何物理先验；本文的全部定理（有界性、直径、覆盖判据）都针对它。$R$ 是 $2n$ 个半平面之交，由性质 1 为闭凸集，有界非空时是 $h\le2n$ 的凸多边形——这正是题面所称的"多边形定位区域"。每个楔形的回收锥就是该楔形锥本身（式 (3)），它张角 $2\delta<180^\circ$、不含直线，这正是性质 2 中"尖锥"论断的来源，也是定理 1 中无界判据的出发点。

**第二块：物理约束模型 $R_c$（单独定义、独立求解，不继承主模型结论）.** 题面另给出两条先验，二者都是**凸约束**，可把主模型 $R$ 进一步缩小为式 (3′) 所示的 $R_c$：**目标圆域**——源在以原点为心、半径 $1800$ m 的闭圆盘内；**有效接收半径**——在 $S_i$ 处能测得示向度说明源到 $S_i$ 的距离不超过其有效接收半径，而后者上界为 $1500$ m。二者加入后 $R_c\subseteq R$，故 $\operatorname{diam}(R_c)\le\operatorname{diam}(R)$，即**主模型的直径是加约束后直径的保守上界**。交后仍是凸紧集。

其边界由**若干直线段（楔形边界线的片段）与若干圆弧段（圆盘边界上的片段）**组成；参与裁剪的圆盘共 $n+1$ 个（目标圆域 $1$ 个加每个检测点的有效接收圆盘 $n$ 个），**圆弧段数的上界是 $n+1$**，而不是"至多一段"。该上界的两层论证（$n$ 个检测圆盘借楔顶角窗各至多一段；目标圆域单独论证）见《问题一_小证明.md》§7，且该上界不能再收紧。取 $n=2$、两检测点**相向**观测的构型 $S_1=(-800,0)$、$\theta_1=0^\circ$ 与 $S_2=(800,0)$、$\theta_2=180^\circ$ 即为反例：此时 $R$ 是连接两检测点的细长透镜（$D=1600$ m），$B(S_1,1500)$ 削去远端尖角、$B(S_2,1500)$ 削去近端尖角，$R_c$ 边界上出现**两段来自不同圆盘的圆弧**。

由此带来两点实现上的注意。**其一，直径**仍可沿边界求极值（直线段的顶点；以及圆弧段上的极值点，其端点既可能是"圆弧—直线"交点，也可能是**两段圆弧的交点**）。**其二，覆盖判定**要注意，定理 3 的"只需在顶点检验"不再直接成立（凸二次函数 $g$ 在圆弧边界上可能于内点取极大），需在圆弧段上补求 $g$ 的极大值（单变量问题，比较临界点与端点即可）。工程上亦可把圆盘换成内接正 $k$ 边形（$k$ 足够大），则退化为纯多边形问题，误差可估计。

**关于有效接收半径的下界.** 题面把有效接收半径写成区间 $[1000,1500]$ m。本节只把**上界** $1500$ m 写成凸约束；下界 $1000$ m 的含义是"源不会比 $1000$ m 更近"，对应从 $R_c$ 中挖去各检测点的 $1000$ m 圆盘内部。**该约束非凸**：取 $S_1=(0,0)$，点 $A=(1200,0)$ 与点 $B=(0,1200)$ 都满足到 $S_1$ 的距离不小于 $1000$ m，但其中点 $(600,600)$ 距 $S_1$ 为 $848.5$ m，小于 $1000$ m，故可行集对凸组合不封闭。因此：① 若把下界并入，$R_c$ 将失去凸性，定理 2、定理 3 的"极值在顶点取得"不再适用，需改用一般非凸可行性判定；② 本题并不需要这一步——**只取上界得到的区域更大**，据它作覆盖判定是**保守**的（若大区域都能被直径圆覆盖，小区域自然也能）。故正文按"只取上界"处理，并把这一保守性作为口径在结论中注明。

题面所问为"**多边形**定位区域"的直径，故**主模型取 $R$**（凸多边形，定理 1–4 全程适用）；物理约束 $R_c$ 作为独立的第二块单独求解（见 §6.1 算法第 11–12 步），其直径与覆盖性由 $R_c$ 自身（顶点与圆弧段）重新计算。

**覆盖结论不可从主模型直接搬到物理约束模型.** "加入约束只会使 $R$ 变小、直径是保守上界"这句话对**直径**成立，但**覆盖结论并不随之单调**——区域缩小后直径与直径圆同时改变。随机复算（$n=2$、满足各检测点到源距离不超过 $1500$ m 的物理相容构型 $3948$ 组）显示，叠加接收半径约束后约 $3.60\%$ 的构型覆盖结论由"覆盖"翻为"不覆盖"。故必须对**同一个**区域计算直径点对与直径并作覆盖判定，不可把纯角约束下的覆盖结论直接搬到加约束后的区域。

### 5.3 有界性与空集的判别

**（1）无界的充要判据.** 设 $R=\bigcap_i W_i$。**定理 1** 断言：若 $R=\varnothing$，则 $R$ 有界；若 $R\ne\varnothing$，则 $R$ 无界当且仅当各示向度误差区间（即 $\theta_i\pm\delta$）在方向上存在公共点，见式 (4)。定理的证明建立在回收锥与交集的交换律上（见《问题一_小证明.md》§2）。

**（2）判据的可计算形式.** 把各示向度按模 $360^\circ$ 排序、求最大间隙再补弧，得**最小包含弧长** $\ell_{\min}$，见式 (5)。于是式 (4) 右端的条件等价于 $\ell_{\min}\le2\delta$。其含义是：所有示向度若能塞进一段 $2^\circ$ 的弧内，则所有误差带有一个公共方向，定位区域沿该方向无限延伸。

**（3）$n=2$ 的推论.** 两检测点的情形最为常用。**推论 1** 断言：$n=2$ 时，在 $R\ne\varnothing$ 的前提下，$R$ 无界当且仅当两示向度的圆周角距离 $d_{\mathrm{circ}}(\theta_1,\theta_2)\le2\delta$；当该距离大于 $2\delta$ 时 $R$ 必有界。符号口径上，$d_{\mathrm{circ}}$ 为 §3 定义的圆周角距离，$\ell_{\min}$ 为式 (5) 的最小包含弧长；$n=2$ 时二者等价，均为 $\ell_{\min}=d_{\mathrm{circ}}(\theta_1,\theta_2)$，全文按此换算，不再混用。

**（4）空集与无界的独立性.** "区域为空"与"区域无界"是两个独立判据。

先看无界侧的非空性条件。**非空性命题（修订版）** 的表述是：$\ell_{\min}<2\delta$ 时 $R$ 非空且无界；而 $\ell_{\min}=2\delta$ 时 $R$ **或为空、或无界**（两种结局皆可实现），必须由半平面交判定。严格不等式的论证思路是：区间之交通含一个非退化弧，可取同时落在各区间内部的公共方向 $u$，再沿 $u$ 从 $S_1$ 出发向远处取点 $p_t=S_1+tu$，则 $p_t$ 相对各 $S_i$ 的方位角随 $t\to\infty$ 趋于 $u$ 的方向，故充分远处必落入每个楔形（详见《问题一_小证明.md》§6）。

**等号处命题不成立**：当 $\ell_{\min}=2\delta$ 时区间之交退化为**单个公共方向**，它落在某些区间的**端点**上，"留有余量"的论证失效，$R$ 可能为空。反例：$S_1=(0,0)$、$\theta_1=0^\circ$ 与 $S_2=(1000,100)$、$\theta_2=2^\circ$（$\delta=1^\circ$）。两误差区间 $[-1^\circ,1^\circ]$ 与 $[1^\circ,3^\circ]$ 之交为单点 $1^\circ$，$\ell_{\min}=2^\circ$，但 $W_2$ 内任一点相对 $S_1$ 的方位角恒大于 $1^\circ$：$W_2$ 的边界射线过 $S_2$、方向 $1^\circ$，与 $W_1$ 的边界射线**平行而不重合**，而 $S_2$ 位于错误一侧，故 $W_1\cap W_2=\varnothing$（复算 $R=\varnothing$）。该构型的临界几何是：临界线为过 $S_1$、方向 $1^\circ$ 的射线，$S_2=(1000,y_0)$ 时临界值 $y_0^*=1000\tan1^\circ=17.455$ m；$y_0<y_0^*$ 时区域非空无界，$y_0>y_0^*$ 时区域为空。

**对算法无影响**：§6.1 的算法先做半平面交（第 2–4 步），故上述反例会被正确判为"空集（观测矛盾）"；本条修正的是辅助命题的表述，而非算法。

反之，$\ell_{\min}>2\delta$ 只保证有界，并不保证 $R$ 非空。例如取 $S_1=(0,0)$、$\theta_1=0^\circ$ 与 $S_2=(1000,0)$、$\theta_2=90^\circ$：两误差带 $[-1^\circ,1^\circ]$ 与 $[89^\circ,91^\circ]$ 无交，$\ell_{\min}=90^\circ>2^\circ$，但定位区域**非空有界**（复算为三角形，$D=17.4630$ m，观测并不矛盾）。此例说明"$\ell_{\min}>2^\circ$"不能被当成"$R=\varnothing$"的依据。

更有甚者，**$R$ 为空并不要求无界**：取 $S_1=(0,0)$、$\theta_1=180^\circ$ 与 $S_2=(1000,0)$、$\theta_2=0^\circ$，即两检测点各自朝外侧观测（背向观测）。此时两误差带 $[179^\circ,181^\circ]$ 与 $[-1^\circ,1^\circ]$ 无交，$\ell_{\min}=180^\circ>2^\circ$——若用"无界判据"将误判为"有界"，而半平面交实为**空集**（复算 $R=\varnothing$）。该例正是"$R$ 为空却落在有界侧"的情形，说明**无界判据不能替代空集判别**。

因此算法必须**先做半平面交得到（可能为空的）$R$，再判定是否有界**。

**（5）边界等号的严格性.** 当 $\ell_{\min}=2^\circ$（如两示向度圆周角距离为 $2^\circ$）时，两楔形仅共享**一个公共方向**（注意：共享的是方向，两条边界射线一般**平行且不重合**；仅当 $S_2$ 恰落在该方向过 $S_1$ 的射线上时才重合为一条射线）。由定理 1(ii)，若区域非空则**无界**（直径记为 $+\infty$），而非"刚好有界"；但如上文所示，此等号处区域也可能为空，故必须由半平面交先行判定。本地复核（检测点取 $S_1=(0,0)$、$\theta_1=0^\circ$，$S_2=(1000,0)$、$\theta_2=\Delta\theta$）如表 1。

|---|---|---|---|---|---|---|---|

**（6）三种定论.** 综上，算法对定位区域给出且仅给出三种结论：

| 情形 | 判据 | 结论 |
|---|---|---|
| 空集 | 半平面交为空 | 观测矛盾（可能非同源，或误差超出 $\pm1^\circ$，或误测/漏测） |

| 有界 | 半平面交非空且 $\ell_{\min}>2^\circ$ | 存在有限直径 $D$，可定位 |

### 5.4 直径的刻画

**定理 2** 断言：设 $R$ 为非空紧凸多边形，则其直径等于其顶点集上的最大点对距离，即式 (6)。证明见《问题一_小证明.md》§3：距离映射是仿射映射与凸范数的复合，因而是凸函数，紧凸集上的凸函数最大值必在极点取得，而 $R\times R$ 的极点集正是 $\operatorname{vert}(R)\times\operatorname{vert}(R)$。

由 $h\le2n$，式 (6) 把连续的极大化问题化归为有限个顶点对的枚举，复杂度 $O(h^2)$；对凸多边形亦可使用旋转卡壳（rotating calipers）在 $O(h)$ 内完成（文献 [11]）。

### 5.5 以定位区域直径为直径的圆的覆盖性

**主判据（第一判据，定理 3）.** 设 $a,b$ 为 $R$ 的直径点对，则**直径圆覆盖 $R$ 当且仅当 Thales 判据成立**，即 $g$ 在 $R$ 上的最大值不超过零，见式 (7)、式 (8)。

本文以该 **Thales 判据**为覆盖性的**主判据**。理由：它是充要条件，且只需在 $R$ 的有限个顶点上检验（定理 3），是最直接、最稳健的判定。最小包围圆 $R^*$ 与 Jung 界只作**辅助刻画与最坏界**（见下文第 (3) 点），不进入主判定——因为 $R^*\ge D/2$ 恒成立、仅当 $R^*=D/2$ 时直径圆才覆盖，用它判定绕远且易误解。

下面依次给出：一般不能覆盖的反例、主判据的证明要点、辅助刻画与最坏界、以及 $n=2$ 的数值现象。

**（1）一般不能覆盖——反例.** 取三角形区域，顶点为 $(0,0),(1,0),(0.5,0.7)$；其直径点对为 $(0,0)$ 与 $(1,0)$，$D=1$。以其中点 $(0.5,0)$ 为圆心、$D/2=0.5$ 为半径的圆，到第三个顶点 $(0.5,0.7)$ 的距离为 $0.7>0.5$，故该顶点落在直径圆之外，**覆盖失败**。经本地计算，该三角形的真实最小包围圆半径为 $R^*=0.528571>0.5$（外接圆解析式 $abc/4K$ 与暴力枚举最小包围圆两法一致），Thales 检验得 $\max_{p\in\operatorname{vert}(T)}g(p)=0.24>0$。

该反例并非抽象构造，**可由三个检测点的楔形交实现**：

| $i$ | $S_i$ | $\theta_i$ |
|---|---|---|
| 1 | $(-200,\ 0)$ | $1.0000^\circ$ |
| 2 | $(-116.2476,\ -162.7467)$ | $53.4623^\circ$ |
| 3 | $(-115.7476,\ 163.4467)$ | $304.5377^\circ$ |

其楔形交复算为三角形 $(0.000138,0),(1.000139,0),(0.500138,0.700000)$，得 $D=1.00000041$、$R^*=0.5285715$、$\max g=0.2399994>0$，即**复现上述反例**；与理想三角形的最大顶点偏差为 $1.4\times10^{-4}$ m，由示向度只给到 4 位小数所致（示向度给足位数即可精确复现）。

为使反例与题面的物理条件相容（并使各距离落在题面标称的 $[1000,1500]$ m 区间内），把上述构型整体放大 $k=5$ 倍并平移，即各检测点按 $S_i^{(5)}=5S_i+(497.5,-1.75)$ m 变换。**注**：原始构型的检测点距源约 $200$ m，已满足"检测点到源距离不超过有效接收半径上界 $1500$ m"——有效接收半径是**上界**，更近只会信号更强且 $200\gg5$ m 不会返回近距离信号过强，故放大并非物理必需，仅为使距离落入题面标称区间。放大后的构型如下：

| $i$ | $S_i^{(5)}$ / m | $\theta_i$ |
|---|---|---|
| 1 | $(-502.500,\ -1.750)$ | $1.0000^\circ$ |
| 2 | $(-83.738,\ -815.484)$ | $53.4623^\circ$ |
| 3 | $(-81.238,\ 815.484)$ | $304.5377^\circ$ |

复算得定位区域为三角形（顶点 $(497.5007,-1.7500),(502.5007,-1.7500),(500.0007,1.7500)$），得 $D=5.000002$ m、$R^*=2.642858$ m（大于 $D/2$）、$\max g=5.999985>0$，**直径圆仍不能覆盖**。此时检测点到源的距离约为 $1001\sim1003$ m（落在有效接收半径 $[1000,1500]$ m 内），全部点坐标绝对值不超过 $815.5$ m（位于半径 $1800$ m 的目标圆域内）。故**该反例在本题的物理约束下同样成立**。

**（2）主判据的证明要点.** 由 Thales 定理，以线段 $ab$ 为直径的闭圆盘恰由 $g(p)\le0$ 刻画，即式 (7)；其推导只需把 $g(p)$ 配方为点 $p$ 到线段中点的距离平方减去 $D^2/4$，见《问题一_小证明.md》§6（一）。于是得到**定理 3**：以 $R$ 的直径点对 $(a,b)$ 为直径的圆覆盖 $R$，当且仅当 $g$ 在 $R$ 上的最大值不超过零，见式 (8)。证明的要点是 $g$ 的 Hessian 为正定阵 $2I$，故 $g$ 为凸二次函数，凸函数在凸紧集上的最大值在极点取得，因此式 (8) 只需在 $R$ 的顶点上检验（详见《问题一_小证明.md》§4）。

定理 3 把"圆是否覆盖区域"化为**有限个顶点的符号检验**（**报告时排除直径点对**，因 $g(a)=g(b)=0$ 恒成立；这只是报告口径，不是判据成立的必要条件，且直径点对不唯一时结论与取哪一对无关——两条注见《问题一_公式.md》定理 3），是最直接、最稳健的判据。本地在随机有界凸多边形上比较"顶点检验"与最小包围圆刻画 $R^*=D/2$，判定完全一致（见 §7 实验 4③）。

**（3）辅助刻画与最坏界（最小包围圆与 Jung 定理）.** 本小节是**辅助性**的：给出覆盖判据的等价刻画与最坏情况上界，不替代定理 3 的主判据地位。

**定理 4** 断言：设 $R^*$ 为 $R$ 的最小包围圆半径、$D$ 为其直径，则 $R^*\ge D/2$（式 (9)），且**直径圆覆盖 $R$ 当且仅当 $R^*=D/2$**。证明见《问题一_小证明.md》§5。

**Jung 定理**（文献 [6]）给出最坏情况上界：平面内直径 $D$ 的集合必被半径不超过 $D/\sqrt3$ 的圆覆盖，等边三角形取等。故一旦直径圆不够用，**所需覆盖圆的直径最坏为 $2D/\sqrt3\approx1.1547D$**，见式 (10)。当 $2R^*>D$ 时，工程上应直接采用**最小包围圆**（Welzl 算法，期望 $O(h)$，文献 [7]）作为覆盖圆，其半径 $R^*$ 即所需最小半径。

**（4）$n=2$ 的数值现象（非概率结论）.** 对 $n=2$ 的楔形交区域，数值上可以给出比 Jung 定理（$R^*\le D/\sqrt3$）紧得多的经验规律（**以下为数值现象：主证据是 $(\varphi,\alpha)$ 二参数全扫，另有两套采样交叉核对；依赖采样与网格，不作为一般性概率结论**）。记楔形半角宽为 $\delta$（本题 $\delta=1^\circ=0.017453$ rad）。

需要先交代**数值口径**。$\sup R^*/D$ 的**主证据**是二参数空间全扫：由**相似与旋转不变性**，该上确界只依赖公共方向 $\varphi$ 与两视线交会角 $\alpha$，于是问题化为 $(\varphi,\alpha)$ 的**二参数问题**，对其全扫并局部加密（`.review/q1_sup_scan.py`，2026-09-12 新增）。$\delta=1^\circ$ 时得 $\sup R^*/D=0.5002942$（在 $\varphi\approx46.3^\circ$、$\alpha\approx90.035^\circ$ 附近），**小于**上界 $\frac12+\delta_{\mathrm{rad}}^{2}=0.5003046$，未发现反例。**表 2 口径**（示向度对齐同一未知点加均匀误差，纯随机 $6.0\times10^4$ 组，种子 `2026`，脚本 `.review/q1_audit.py` 与附录 B.2）在 $\delta=1^\circ$ 时得 $0.500290$，它是上述全扫值的**下偏样本**（低约 $4\times10^{-6}$）；**实验 5 口径**（同分布随机 $6.0\times10^4$ 组**再加 25 次爬山式对抗搜索**）得 $0.500294$，与全扫值一致。三者的差异属采样偏差而非矛盾；**全章统一以二维全扫值 $0.5002942$ 作为 $\sup R^*/D$ 的报告值**，并同时报出表 2 该行值 $0.500290$ 以保持表格可复现。

第一，$R^*/D>1/2$ 虽然幅度极小，但**确实会发生**。$n=2$ 的 $5879$ 组有界随机构型中 $R^*>D/2$（即直径圆严格不能覆盖）的比例为 $0.95\%$（二项标准误 $0.13\%$；另一组"指向同一未知点加误差"的 $3.94\times10^4$ 组构型为 $1.18\%$）。按报告值（$(\varphi,\alpha)$ 全扫值）$0.5002942$ 计，超出幅度为 $(0.5002942-0.5)/0.5=0.0588\%\approx0.06\%$；若按表 2 纯随机口径 $0.500290$ 则为 $0.058\%$——两种口径都不到 $0.06\%$。**这些比例是随机构型的数值实验现象，依赖采样方式，不构成一般性概率结论。**

第二，两楔形交的区域一般**不是平行四边形**：只有当两示向度之差同余于 $0\ (\mathrm{mod}\ 180^\circ)$ 时，四边形的两对边才分别落在平行的两对边界线上（例如示向度相差 $180^\circ$ 时退化为菱形，属严格平行四边形），此**充分**情形下 $R^*/D=1/2$。但须注意：**$R^*/D=1/2$ 的充要条件是"直径圆覆盖 $R$"（定理 4），平行四边形只是充分族而非必要**——本文实验 6 的四边形（相邻边不平行，非平行四边形）即取到 $R^*/D=0.5$；随机搜索中 $R^*/D=0.5$ 的构型也普遍不是平行四边形。一般情况下 $R^*/D\ge1/2$，且区域可能退化为三角形（$n=2$ 的随机有界构型中约占 $1.4\%$）。

因此**理论上应以定理 3、定理 4 的判据为准，不能默认 $R^*=D/2$**；当 $n\ge3$ 时上述反例表明覆盖可以明显失败，且失效比例随 $n$ 迅速上升（见表 3）。

## 6 算法设计与复杂度

### 6.1 主算法

```
算法 Q1：交会定位区域直径与覆盖判定
输入 : 检测点 S_i 与示向度 θ_i, i = 1..n; 误差界 δ = 1°
输出 : 定位区域顶点集 V、直径 D 及点对 (a,b)、覆盖结论、最小包围圆半径 R*

 1  对每个 i: 由式(1) 生成两个半平面 (S_i, n_i^-), (S_i, n_i^+)
 2  R ← 半平面交(所有 2n 个半平面)            # 无框：边界线两两求交 + 全约束筛选（性质 2）
 3  若 R = ∅:                                 # 空集优先判定
 4      返回 "观测矛盾（非同源/误差超界/误测漏测）"
 5  若 最小包含弧长 ℓ_min(θ_1..θ_n) ≤ 2δ:     # 定理 1
 6      返回 "无界，D = +∞，不可定位"
 7  V ← R 的顶点集                            # h ≤ 2n
 8  (a,b), D ← 直径(V)                        # 枚举 O(h^2) 或旋转卡壳 O(h)
 9  cover ← [ max_{p∈V} (p-a)·(p-b) ≤ 0 ]     # 定理 3（主判据）
10  (c, R*) ← 最小包围圆(V)                    # Welzl（辅助/实际覆盖圆）
11  若需物理约束: R_c ← R ∩ B(O,1800) ∩ ∩_i B(S_i,1500)      # §5.2 第二块
12      对 R_c 重算 D_c 与覆盖（直线段顶点 + 圆弧段补求 max g）；结论不继承 R
13  返回 V, D, (a,b), cover, R*（启用约束时另返回 R_c, D_c）
```

算法的结构要点有三：**空集优先**（第 2–4 步，先由半平面交判空，避免把观测矛盾误报为无界或某条直径）；**三分定论**（空集、无界、有界，分别对应第 3、5、7 步之后的三条出口）；**覆盖判定与辅助量分离**（第 9 步用 Thales 主判据给出覆盖结论，第 10 步的最小包围圆只作为"覆盖失败时该用什么圆"的辅助输出）。物理约束作为独立分支放在最后（第 11–12 步），强调对 $R_c$ 必须重算而不能沿用 $R$ 的结论。

### 6.2 关键子程序

- **半平面交**：**首选无框的"边界线两两求交 + 全约束可行性筛选"**。由性质 2，非空 $R$ 必有顶点，故只需枚举 $2n$ 条约束边界线的 $\binom{2n}{2}=O(n^2)$ 个交点并对每个交点做 $O(n)$ 的可行性筛选，即可**在不需要任何裁剪框的前提下**同时判空与得到顶点集，总复杂度 $O(n^3)$（$n$ 为个位数时极为廉价）。若只求更快，可对半平面按极角排序后用增量法，期望 $O(n\log n)$（文献 [5]），但增量法需要额外的退化处理。
  **为什么必须放弃固定大框**：区域尺度随 $\varepsilon=\ell_{\min}-2\delta$ 趋于零而无界增长（量级为 $D\sim L\sin2\delta/(2\varepsilon)$），$\varepsilon$ 足够小时真实区域必然超出任何固定框。复算（框半宽 $10^6$）：$\Delta\theta=2.0005^\circ$ 时大框给出 $D=9.992\times10^5$ 而真值为 $2\times10^6$（**截断低估一半**）；$\Delta\theta=1.999^\circ$ 时区域**真为无界**（$\ell_{\min}<2\delta$），大框却返回一个看似有界的 $D=9.992\times10^5$，**与定理 1 的无界判据直接冲突**。改用性质 2 的无框枚举后，这两种情形分别被正确判为"有界 $D=2\times10^6$"与"无界"，框依赖被彻底消除。本问已报告的全部数值（$D\le2\times10^4$）本不受影响，但实现层面已按无框重写。
- **直径**：$h\le2n$ 很小，直接枚举 $\binom h2$ 个顶点对即可（$O(h^2)$，实现最简）；如需体现算法素养，用旋转卡壳 $O(h)$（文献 [11]）。
- **最小包围圆**：Welzl 随机增量算法，期望 $O(h)$；本问题 $h\le2n$，亦可暴力枚举所有点对与点三元组（$O(h^4)$，$h$ 小时足够）。
- **最小包含弧长 $\ell_{\min}$**：对各示向度取模 $360^\circ$ 后排序求最大间隙，再补弧，$O(n\log n)$。

### 6.3 复杂度

设 $n$ 为检测点数，$h\le2n$ 为区域顶点数。三种实现路径的复杂度必须分开陈述：

| 实现路径 | 判空/顶点枚举 | 直径 | 最小包围圆 | 总体 |
|---|---|---|---|---|
| **无框"两两求交 + 全约束筛选"（本文推荐、附录 B 采用）** | $O(n^2)$ 交点 × $O(n)$ 筛选 $=O(n^3)$ | $O(h^2)$ 枚举或 $O(h)$ 旋转卡壳 | 期望 $O(h)$ | $O(n^3)$ |
| 增量法半平面交（极角排序，文献 [5]） | 期望 $O(n\log n)$ | $O(h)$ | 期望 $O(h)$ | $O(n\log n)$ |
| 固定大框逐条裁剪（仅作对照） | $O(n^2)$ | $O(h^2)$ | 期望 $O(h)$ | $O(n^2)$，但 $\ell_{\min}\to2\delta$ 时数值失效 |

即本文推荐的稳健实现为 $O(n^3)$（$n^2$ 个交点乘以每个 $O(n)$ 的可行性筛选），增量法为 $O(n\log n)$（需处理退化），大框裁剪为 $O(n^2)$ 但不推荐。这里必须强调：推荐路径的 $O(n^3)$ 不能被省略或与裁剪法混为一谈，否则易被误读为推荐方法与裁剪法同阶。本题 $n$ 为个位数（问题一为 $n=2\!-\!5$，问题三使用 $2$ 个检测点），$O(n^3)$ 的实际开销可忽略（一次调用为微秒量级），稳健性远比渐进阶重要。

### 6.4 退化情形处理

| 退化情形 | 现象 | 处理 |
|---|---|---|
| $n=1$ | 单个楔形，无界 | $\ell_{\min}=0\le2^\circ$，返回"不可定位" |
| $n\ge2$，$\ell_{\min}\le2^\circ$ | 区域无界 | 直径记 $+\infty$，返回"不可定位" |
| 观测矛盾 | 区域为空 | 返回"观测矛盾"（非同源，或误差超界，或误测/漏测），检查数据 |
| $\ell_{\min}=2^\circ$ | 共享一个公共方向（边界射线一般平行不重合） | **须先由半平面交判空/非空**：非空则按定理 1 判无界（严格用 $>$ 号）；可能为空（见 §5.3 反例） |
| 顶点共线/重合 | $h<3$ 或出现重复顶点 | 去重、去共线点 |
| **区域退化为点/线段** | $h=1$ 或 $h=2$（区域非空） | **不可判为空集**：空集只能由半平面交为空判定；$h\le2$ 时按线段/点处理（$D$ 为线段长或 $0$，此时直径圆自动覆盖，覆盖判定恒为真） |
| 大框裁剪残留/截断 | 区域贴住或超出裁剪框 | **已从实现中消除**：固定大框在 $\ell_{\min}\to2\delta$ 时会把有界域直径截断（$\Delta\theta=2.0005^\circ$ 低估一半）或给无界域返回假的有界直径（$\Delta\theta=1.999^\circ$）。现按性质 2 改用**无框"边界线两两求交 + 全约束筛选"**，不需要框、也不再依赖 $\varepsilon$；无界性一律由定理 1 的解析判据 $\ell_{\min}\le2\delta$ 判定 |

## 8 结论

本问的结论按**四层递进**给出，另附一条数值现象（非概率结论）。

1. **第一层（几何约束）**：示向度 $\theta_i$ 与有界误差 $\pm1^\circ$ 给出一个夹角 $2^\circ$ 的凸锥——楔形 $W_i$（式 (1)）；**主模型**定位区域是诸楔形之交 $R=\bigcap_iW_i$，为凸多边形（$h\le2n$）。
2. **第二层（直径）**：$R$ 为凸多边形，其直径 $D=\max_{p,q\in R}\lVert p-q\rVert$ 由顶点对给出（定理 2）。算法流程见 §6.1，推荐实现（无框"两两求交 + 全约束筛选"）的复杂度为 $O(n^3)$，即 $n^2$ 个约束交点乘以每个 $O(n)$ 的可行性筛选；本题 $n$ 为个位数，实际开销可忽略。算法同时给出空集/无界/有界三种定论与退化处理。
3. **第三层（覆盖判据，主判据）**：设 $a,b$ 为直径点对，**直径圆覆盖 $R$ 的充要条件是 Thales 判据** $g$ 在 $R$ 上处处非正（定理 3，只需在顶点检验；报告时排除直径点对，因 $g$ 在该点对处恒为 $0$，这是报告口径而非判据的必要条件，且直径点对不唯一时结论与取哪一对无关）。因此**直径圆一般不能覆盖定位区域**——反例（三角形 $(0,0),(1,0),(0.5,0.7)$，$D=1$）中直径圆漏掉一个顶点，且该反例可由三检测点的楔形交实现（复现精度 $1.4\times10^{-4}$ m）。**最小包围圆 $R^*$ 与 Jung 界只作辅助刻画与最坏界**（$R^*\ge D/2$ 恒成立；覆盖失败时所需覆盖圆的直径最坏为 $2D/\sqrt3\approx1.1547D$）；需要实际覆盖圆时取 $R^*$（Welzl）。
4. **第四层（物理约束）**：目标圆域 $B(O,1800)$ 与有效接收半径上界 $\bigcap_iB(S_i,1500)$ 构成**独立的物理约束区域** $R_c$（§5.2），**必须对 $R_c$ 重新计算直径与覆盖性**——加约束后覆盖结论并不单调（物理相容的两点构型中约 $3.60\%$ 由"覆盖"翻为"不覆盖"），**不可直接沿用主模型 $R$ 的结论**。有效接收半径的**下界**（源距不小于 $1000$ m）约束非凸，并入会破坏 $R_c$ 的凸性；正文按"只取上界"处理，所得区域更大、据此作覆盖判定是保守的，这一点已作为口径注明。
5. **数值现象（非概率结论）**：随机模拟显示，$n=2$ 时绝大多数构型 $R^*/D\le\frac12+\delta_{\mathrm{rad}}^{2}=0.5003046$（由 $(\varphi,\alpha)$ 二参数全扫得 $\sup R^*/D=0.5002942$，表 2 纯随机抽样 $0.500290$ 为其下偏样本），但覆盖**并非恒成立**；$n\ge3$ 时失效比例随 $n$ 呈上升趋势（$n=3,4,5$ 分别约 $14\%,23\%,28\%$，见表 3）。这些比例是**随机构型的实验现象**，依赖采样方式，不作为一般性概率结论；实际判定一律以第三层的 Thales 判据为准。

## 9 理论依据与文献支撑

**（1）集合隶属（有界误差）估计.** 本问把示向度误差视为**有界不确定性**而非随机变量：真实方位角必落在测得值 $\pm1^\circ$ 内，故真源必属于所有楔形之交 $R$。"真源属于 $R$"是一个**确定性保证**，不依赖误差的分布形态，也不依赖各检测点误差的独立性（即使相邻地点误差高度相关仍成立），这正是集合隶属/有界误差估计框架的优点（文献 [3,4]）。由此可得三条直接可用的推论：同一地点重复检测不缩小 $R$（题面明确同点误差固定），故降低不确定域**必须改变检测点**；两点过近时两楔形几乎重合，$R$ 几乎不缩小；保证性与误差相关性无关，故不存在"区域虚假收缩"的风险。基于协方差的 GDOP 与最小二乘（文献 [8,9]）给出的是**平均意义**下的精度，可作为辅助判据，但不能替代本问的保证性结论。

**（2）计算几何.** 定位区域是半平面交，其顶点数不超过 $2n$；凸多边形直径由顶点对决定，可用枚举或旋转卡壳求解；覆盖问题归结为 Thales 圆与凸集的包含关系，最坏情况由 Jung 定理给出上界，实际最小覆盖圆由 Welzl 算法求得。这些均为计算几何的经典结论（文献 [1,2,5,6,7,10]）。此外，把"回收锥为尖锥的多面体必有顶点"这一多面体基本事实用于**无框**判空（性质 2），是本问在实现层面避免框依赖的关键（文献 [1]）。

## 附录 A　核心算法伪代码

**A.1 Thales 覆盖判定**

```
函数 THALES_COVER(V, a, b):        # V 为区域顶点；g(a)=g(b)=0 恒成立
    g_o ← -∞                        # 故只需检验除直径点对外的顶点
    for p in V, p ∉ {a, b}:
        g_o ← max(g_o, dot(p-a, p-b))
    return (g_o ≤ 0), g_o           # 真(=覆盖), 其余顶点最大 g
```

**A.2 最小包含弧长**

```
函数 MIN_ARC(thetas):              # thetas: 示向度(度)
    t ← sort([θ mod 360 for θ in thetas])
    max_gap ← max( (t[(i+1) mod n] - t[i]) mod 360 for i in 0..n-1 )
    return 360 - max_gap           # ≤ 2° 判为无界
```

## 附录 B　Python 参考实现

> 依赖：`numpy`。以下代码与第 7 节实验一致，可直接运行复现。B.1 为主算法，B.2 为补充实验（表 2、表 3 与 §5.5(1) 的放大反例）。

**B.1 主算法**

```python
# -*- coding: utf-8 -*-
import math
import numpy as np

EPS = 1e-9
D2R = math.pi / 180.0


def wedge_halfplanes(S, theta_deg, half=1.0):
    """楔形 W = 顶点 S、示向度 theta_deg、左右各 half 度。
    返回两个半平面 (q, n)，含义 n·(p-q) >= 0。"""
    S = np.asarray(S, float)
    a1 = (theta_deg - half) * D2R
    a2 = (theta_deg + half) * D2R
    n1 = np.array([-math.sin(a1), math.cos(a1)])   # 下边界内法向
    n2 = np.array([math.sin(a2), -math.cos(a2)])   # 上边界内法向
    return [(S, n1), (S, n2)]


def clip(poly, q, n):
    """Sutherland-Hodgman: 用半平面 n·(p-q) >= 0 裁剪凸多边形。
    poly 顶点数可为 1 或 2（退化的点/线段），凸裁剪不会使顶点数回升。"""
    if len(poly) == 0:
        return []
    out, m = [], len(poly)
    for i in range(m):
        A, B = poly[i], poly[(i + 1) % m]
        da = float(np.dot(n, A - q)); db = float(np.dot(n, B - q))
        ina, inb = da >= -EPS, db >= -EPS
        if ina:
            out.append(A)
        if ina != inb:
            out.append(A + (da / (da - db)) * (B - A))
    return out


def build_region(dets, box_half=None):
    """dets: [(S, theta_deg), ...] -> 顶点列表（按极角排序）。
    返回 [] 表示**空集**（观测矛盾）；返回 1 或 2 个顶点表示区域退化为点/线段。

    实现（第四次修订：无框化，勘误 C14 由此从结构上消除）
    ---------------------------------------------------
    依据 §5.1 性质 2：每个楔形的回收锥张角 2δ<180°、不含直线，
    故 rec(R)=∩_i C_i 是**尖锥**，非空 R 必有顶点。于是
        R ≠ ∅  ⟺  "边界线两两求交 + 全约束可行性筛选"的候选点集非空。
    该判据**不需要任何裁剪框**，因此不再存在"固定大框在 lmin->2*delta
    附近截断直径或把非空域误判为空"的问题（旧实现 box_half=1e6 的缺陷）。
    空集只能由"半平面交为空"判定，不可由无界判据代替（见 5.3(4)）。
    box_half 仅为兼容旧签名保留，已不再使用。"""
    return region_vertices(dets)


def region_vertices(dets, half=1.0):
    """无框枚举 R 的顶点（性质 2）。返回 [] <=> R 为空集。"""
    hps = []
    for S, th in dets:
        hps.extend(wedge_halfplanes(S, th, half))
    # 相对容差：按坐标尺度缩放，避免绝对容差在 1e6 量级坐标上过紧（见 §6.2）
    scale = max(1.0, max(float(np.max(np.abs(np.asarray(S, float)))) for S, _ in dets))
    tol = 1e-9 * scale
    cand = []
    m = len(hps)
    for i in range(m):
        qi, ni = hps[i]
        for j in range(i + 1, m):
            qj, nj = hps[j]
            den = ni[0] * nj[1] - ni[1] * nj[0]
            if abs(den) <= 1e-12:
                continue                                   # 两边界平行
            bi, bj = float(np.dot(ni, qi)), float(np.dot(nj, qj))
            p = np.array([(bi * nj[1] - bj * ni[1]) / den,
                          (ni[0] * bj - nj[0] * bi) / den])  # Cramer 法则
            if all(float(np.dot(n, p - q)) >= -tol for q, n in hps):
                cand.append(p)                             # 可行 -> 必为顶点
    if not cand:
        return []
    uniq = []
    for p in cand:                                         # 去重（相对容差）
        if not any(float(np.linalg.norm(p - u)) <= 1e-6 * scale for u in uniq):
            uniq.append(p)
    c = np.mean(np.array(uniq), axis=0)                    # 按极角排序成凸多边形顶点序
    uniq.sort(key=lambda p: math.atan2(float(p[1] - c[1]), float(p[0] - c[0])))
    return uniq


def min_arc(thetas):
    """所有示向度在圆周上的最小包含弧长 ℓ_min，式 (5)。"""
    ts = sorted(t % 360.0 for t in thetas)
    n = len(ts)
    if n <= 1:
        return 0.0
    max_gap = max((ts[(i + 1) % n] - ts[i]) % 360.0 for i in range(n))
    return 360.0 - max_gap


def region_unbounded(thetas, half=1.0):
    """定理 1 的解析判据：方向区间在圆周上有公共点 <=> 无界。"""
    ts = sorted(t % 360.0 for t in thetas)
    if len(ts) <= 1:
        return True
    return min_arc(ts) <= 2 * half + 1e-9


def diameter(V):
    """凸多边形直径 = 顶点对最大距离。"""
    best, pair = 0.0, (0, 0)
    for i in range(len(V)):
        for j in range(i + 1, len(V)):
            d = float(np.linalg.norm(V[i] - V[j]))
            if d > best:
                best, pair = d, (i, j)
    return best, pair


def circum(a, b, c):
    ax, ay = a; bx, by = b; cx, cy = c
    d = 2 * (ax * (by - cy) + bx * (cy - ay) + cx * (ay - by))
    if abs(d) < 1e-14:
        return None, None
    ux = ((ax**2 + ay**2)*(by - cy) + (bx**2 + by**2)*(cy - ay) + (cx**2 + cy**2)*(ay - by)) / d
    uy = ((ax**2 + ay**2)*(cx - bx) + (bx**2 + by**2)*(ax - cx) + (cx**2 + cy**2)*(bx - ax)) / d
    c0 = np.array([ux, uy])
    return c0, float(np.linalg.norm(a - c0))


def mec(V):
    """最小包围圆（暴力：点对 + 点三元组）；单点退化为半径 0。"""
    pts = [np.asarray(p, float) for p in V]
    if len(pts) == 0:
        return None, 0.0
    if len(pts) == 1:
        return pts[0], 0.0
    bestr, bestc = 1e18, None

    def ok(c, r):
        return all(np.linalg.norm(p - c) <= r + 1e-7 for p in pts)

    for i in range(len(pts)):
        for j in range(i + 1, len(pts)):
            c = (pts[i] + pts[j]) / 2
            r = float(np.linalg.norm(pts[i] - pts[j]) / 2)
            if r < bestr and ok(c, r):
                bestr, bestc = r, c
    for i in range(len(pts)):
        for j in range(i + 1, len(pts)):
            for k in range(j + 1, len(pts)):
                c, r = circum(pts[i], pts[j], pts[k])
                if c is not None and r < bestr and ok(c, r):
                    bestr, bestc = r, c
    return bestc, bestr


def solve_question1(dets):
    """主算法 Q1。"""
    V = build_region(dets)
    if len(V) == 0:                                  # 空集优先判定
        return {"status": "inconsistent", "msg": "观测矛盾（非同源/误差超界/误测漏测）",
                "lmin": min_arc([t for _, t in dets])}
    if region_unbounded([t for _, t in dets]):       # 定理 1
        return {"status": "unbounded", "msg": "直径 = +∞，不可定位",
                "lmin": min_arc([t for _, t in dets])}
    D, (ia, ib) = diameter(V)                        # 式 (6)
    a, b = V[ia], V[ib]
    g_all = [float(np.dot(p - a, p - b)) for p in V]
    # g(a) = g(b) = 0 恒成立，不构成覆盖证据；故只报"其余顶点"的最大值
    g_other = max([g for k, g in enumerate(g_all) if k not in (ia, ib)] or [-np.inf])
    c, Rstar = mec(V)
    return {"status": "bounded", "vertices": V, "D": D, "pair": (a, b),
            "covered": g_other <= 1e-9 * max(1.0, D * D),
            "gmax_others": g_other, "gmax": max(g_all),
            "Rstar": Rstar, "MEC_center": c, "Jung": D / math.sqrt(3),
            "degenerate": len(V) < 3}
```

import math
import numpy as np

D2R = math.pi / 180.0


def solve_with_half(dets, half):
    """与 solve_question1 同流程，但允许自定义楔形半角 half（表 2 的 δ 扫描）。
    注：此处**故意保留**大框裁剪，以便与表 2 的历史结果（种子 2026）逐位对齐；
    正式实现请用 B.1 的无框 region_vertices（勘误 C14）。"""
    poly = [np.array([-1e6, -1e6]), np.array([1e6, -1e6]),
            np.array([1e6, 1e6]), np.array([-1e6, 1e6])]
    for S, th in dets:
        for q, n in wedge_halfplanes(S, th, half):
            poly = clip(poly, q, n)
            if len(poly) == 0:
                return None
    if region_unbounded([t for _, t in dets], half):
        return None
    D, (ia, ib) = diameter(poly)
    c, R = mec(poly)
    return D, R

    res = {n: dict(tot=0, cov=0, mx=0.0) for n in (2, 3, 4, 5)}

            G = np.array([rng.uniform(-1200, 1200), rng.uniform(-1200, 1200)])
