# 问题二　第二个检测点的选择策略与候选区域

> 本章依据赛题正文及其**附录 1（干扰源特征）**、**附录 2（测向机原理与交会定位法）**建立模型；所有数值结论均给出本地复算结果与验证方案。
>
> **方法主线**：一次示向度给出的不是源的位置，而是"一条射线 + 一个距离区间"。因此第二点的选择是一个**在保证必然能听到源的前提下、最小化定位区域直径期望**的二维最优实验设计问题。本文用$\mathbb E[D]$作主指标、$\operatorname{tr}\Sigma$作辅指标，给出**透镜形候选区域**与**最优设计**，并以解析式 + 精确半平面交 + Monte Carlo 三重验证。

---

## 1 问题重述

已知某**全向**干扰源在一个检测点 $S_1$ 处测得的示向度 $\theta_1$，要求：(1) 给出**第二个检测点 $S_2$ 的选择策略**，以获得关于该源较好的定位效果；(2) 给出 $S_2$ 的**候选区域**。

可用信息与约束（附录 1、2）：

1. 示向度误差落在 $[-1^\circ,1^\circ]$，**同一地点误差固定**，故同点重复检测不能提高精度，必须换点；
2. 源的有效接收半径 $R_{\rm eff}\in[1000,1500]$ m，**具体值未知**——保证性推理只能用下界 $1000$ m（"必然听到"）与上界 $1500$ m（"已听到则不超过它"）；
3. 目标区域为半径 $1800$ m 的圆域；
4. 检测需停止移动、耗时 $5$ s，频道切换 $1$ s，移动速度 $5$ m/s（第二点的**路程代价**由此决定）；
5. 测向机距离源 $\le5$ m 且处于覆盖角内时不返回示向度（返回 `near`），故"得到示向度"蕴含 $r_1>5$ m。

---

## 2 模型假设

1. **平面假设**（附录 2(7)）：测向机与源同平面，问题为二维几何。
2. **有界误差假设**：$\alpha_i\in[\theta_i-1^\circ,\theta_i+1^\circ]$，$\delta=1^\circ$；不假设误差分布与独立性（同问题一）。
3. **全向源假设**：源有效覆盖角 $360^\circ$，故只要距离 $\le R_{\rm eff}$ 就必被听到——这是"保证接收"约束成立的根据（问题 4 的定向源不满足）。
4. **先验假设**：在得到"距离 $r_1$ 处有源"这一信息后，对 $r_1$ 取先验。本文给出三种先验以检验稳健性：
   - $r_1\sim U(5,1500)$（**基准**：只要区间信息，不作分布假设）；
   - $r_1\sim U(200,1500)$（**稳健对照**：排除过近的源）；
   - $r_1$ 密度 $\propto r_1$（**面积均匀先验**：若源在圆域内面密度均匀，则落在 $[r,r+dr]$ 的概率 $\propto r\,dr$）。
5. **设计目标假设**：以定位区域直径为质量指标（与问题一的"定位区域"一致）；期望对**真源位置**与**两次示向度误差**取（双重期望，见 5.5）。
6. **示向度方向约定**：$\theta_1$ 定义 $+x$ 方向；$S_2$ 用相对 $S_1$ 的极坐标 $(\rho,\psi)$ 表示（$\psi$ 为相对 $\theta_1$ 的偏角，$|\psi|\le180^\circ$）。

## 4 问题分析

选第二点要做三件事，缺一不可：

1. **把"好"量化。** 本问的产物是"定位区域"，故最自然的指标是定位区域**直径 $D$**（问题一已建立其算法与几何）；同时给出统计指标 $\operatorname{tr}\Sigma$（GDOP，文献 [8,9]）作为对照。两者一个保证型、一个平均型。
2. **保证第二点能听到源。** 否则测不到示向度，设计落空。由于 $R_{\rm eff}\ge1000$ m 而具体值未知，唯一可保证的条件是 $\|S_2-G\|\le1000$ m **对所有可能的 $G$ 成立**。这给出了候选区域的形状。
3. **在源位置未知下做鲁棒化。** 若 $r_1$ 已知，最优 $S_2$ 就是源点本身（见 5.5）；因此本问的全部内容在于"$r_1$ 未知"下的**期望化/最坏化**与**接收保证**。

问题一的结论在此处的接口：$n=2$ 时定位区域是两楔形交（四边形或退化为三角形），其直径由问题一的算法给出；且当两示向度夹角 $\alpha\le2\delta$ 时区域无界（不可定位），这是搜索中必须排除的失败模式。

## 5 模型的建立

### 5.1 一次示向度后的可行集

在 $S_1$ 处得到示向度 $\theta_1$ 后，源必满足

$$G\in P:=\underbrace{W_1(\theta_1\pm\delta)}_{\text{角约束}}\ \cap\ \underbrace{B(S_1,1500)}_{\text{已听到}}\ \cap\ \underbrace{B(O,1800)}_{\text{目标圆域}},\qquad \|G-S_1\|>5\ \text{m}. \tag{1}$$

**性质 5.1**　$P$ 是**紧集**（有界闭集），但**一般不是凸集**——约束 $r_1>5$ 挖去了一个开圆盘。然而**候选区域** $\mathcal F$（见 5.3）必为闭凸集。

**证明（$P$ 的紧性与"非凸"）.** 紧性：$P\subseteq B(S_1,1500)$ 有界，且为闭集之交（去开圆盘后仍闭），故紧。非凸：取 $G_1=(-6,0),G_2=(6,0)$，二者距 $S_1$ 均为 $6>5$，但中点 $(0,0)$ 距 $S_1$ 为 $0<5$，不在 $P$ 中，故 $P$ 不凸。$\blacksquare$

**评注.** 因此**不能**对 $P$ 直接使用"凸函数极值在极点取得"的引理（该引理要求凸集）。正确处理有两条路：对 $S_2$ 用凸性（下证 $\mathcal F$ 凸），对 $G$ 用凸包外近似与子集内近似（见 5.3 命题 5.2）。$P$ 的边界由两条射线段（方向 $\theta_1\pm\delta$）、一段远弧（半径 $\min(1500,d_{\rm exit})$）与一段近弧（半径 $5$）组成。

### 5.2 质量指标

**（1）几何指标（主）.** 设两示向度决定定位区域 $R(\theta_1,\theta_2;S_1,S_2)$，其直径

$$D=\operatorname{diam}\big(W_1(\theta_1)\cap W_2(\theta_2)\big),$$

由问题一：$D$ 由顶点对最大距离给出；$\alpha\le2\delta$ 时 $D=+\infty$。

**（2）统计指标（辅）.** 测向定位的 Fisher 信息与位置协方差（Torrieri 形式，文献 [8]）

$$J=\frac{1}{\sigma_\theta^2}\Big(\frac{u_1u_1^{\mathsf T}}{r_1^2}+\frac{u_2u_2^{\mathsf T}}{r_2^2}\Big),\qquad
\operatorname{tr}\Sigma=\frac{\sigma_\theta^2(r_1^2+r_2^2)}{\sin^2\alpha},\qquad
\det\Sigma=\frac{\sigma_\theta^4\,r_1^2r_2^2}{\sin^2\alpha}, \tag{2}$$

$u_i$ 为与第 $i$ 条视线垂直的单位向量。**误差标准差**：题面给的是区间 $[-1^\circ,1^\circ]$ 而非标准差；按均匀分布应取

$$\sigma_\theta=\frac{2^\circ}{\sqrt{12}}=0.5774^\circ, \tag{3}$$

若误用 $\sigma_\theta=1^\circ$，一切协方差型结论会被放大约 $1.73$ 倍。若不作分布假设，则 (2) 式只作为**相对比较**的辅助量，主结论仍以 $D$ 为准。

### 5.3 保证接收约束与候选区域（透镜）

要求第二点**必然**能听到源：对先验支撑 $P$ 内的每个 $G$，

$$\|S_2-G\|\le1000\ \text{m}\qquad(\text{因 }R_{\rm eff}\ge1000). \tag{4}$$

**命题 5.2（可行域及其双边夹逼）.** 记 $\mathcal F=\{S_2:\|S_2-G\|\le1000\ \forall G\in P\}$，$u=(\cos\theta_1,\sin\theta_1)$，$Q=\operatorname{conv}(P)=W_1\cap B(S_1,1500)\cap B(O,1800)$。则 $\mathcal F$ 闭凸，且

$$\mathcal F_Q:=\bigcap_{G\in\operatorname{ext}(Q)}B(G,1000)\ \subseteq\ \mathcal F\ \subseteq\ \mathcal F_0:=B(S_1+5u,1000)\cap B(S_1+1500u,1000). \tag{4}$$

**证明.**
(i) **$\mathcal F$ 凸**：$h(S_2)=\max_{G\in P}\|S_2-G\|$ 是一族凸函数（关于 $S_2$）的最大值，故凸；$\mathcal F=\{h\le1000\}$ 是凸函数的下水平集，故闭凸。
(ii) **左包含**：$P\subseteq Q$，故"对 $Q$ 成立"强于"对 $P$ 成立"，得 $\{S_2:\forall G\in Q,\|S_2-G\|\le1000\}\subseteq\mathcal F$；又 $Q$ 凸紧，由问题一引理 A.2，$\max_{G\in Q}\|S_2-G\|=\max_{G\in\operatorname{ext}(Q)}\|S_2-G\|$，故对 $Q$ 的约束 $=$ 对 $\operatorname{ext}(Q)$ 的约束，即 $\mathcal F_Q\subseteq\mathcal F$。
(iii) **右包含**：$\{S_1+5u,\ S_1+1500u\}\subseteq P$，故对 $P$ 的约束弱于（交出去更大）对这两点的约束，即 $\mathcal F\subseteq\mathcal F_0$。$\blacksquare$

**评注.** 因 $P$ 不凸（性质 5.1），不能直接写 $\mathcal F=\bigcap_{\operatorname{ext}(P)}$。上式的**夹逼**才是严格可用的：$\mathcal F_Q$ 是**保守**（保证可听）的解析内近似，$\mathcal F_0$ 是**乐观**的外近似。

**推论 5.3（三个区域与数值几何）.** 取 $G=(5,0)$ 与 $(1500,0)$（中心射线上两点）得外近似 $\mathcal F_0$（"透镜"）；取凸包极点得内近似 $\mathcal F_Q$；真实 $\mathcal F$（$r_1\ge5$，密集采样）居中。数值几何：

| 区域 | 含义 | $x$ 范围 | $y$ 范围 | 可达 $|\psi|$ |
|---|---|---|---|---|
| $r_1\in[5,1500]$ | | | | |
| $\mathcal F_0$ | 外近似（中心线段两端） | $[500,1005]$ | $\pm664.3$ | $41.44^\circ$ |
| $\mathcal F$ | 真实可行域（数值） | $[500,1005]$ | $\pm642.8$ | $40.0^\circ$ |
| $\mathcal F_Q$ | 保守内近似（凸包极点，含 $S_1$） | $[\approx\!500,1000]$ | $\pm642.8$ | $40.0^\circ$ |
| $r_1\in[200,1500]$ | | | | |
| $\mathcal F_0$ | 外近似 | $[500,1200]$ | $\pm759.9$ | $41.80^\circ$ |

差异来自 $\pm1^\circ$ 扇形角点：远角点 $1500\angle\pm1^\circ$ 把远端的 $1000$ m 圆盘各平移约 $26$ m，使纵向半宽由 $664.3$ 降到 $642.8$ m；内近似额外含 $S_1$（凸包顶点），把 $x$ 上界压到 $1000$。

**关键结论**：最优设计 $(1000,38^\circ)$ 同时属于 $\mathcal F_Q\subset\mathcal F\subset\mathcal F_0$，**故无论采用哪一种口径，最优设计与结论都不变**；下文用 $\mathcal F_0$ 作解析、用 $\mathcal F$（或保守的 $\mathcal F_Q$）作校核。

**几何意义（可解释性）.**
- $\mathcal F_0$ 是"源可能线段的两个端点各 $1000$ m 圆之交"——一个**透镜**；
- 偏角接近 $\pm90^\circ$ 的侧方点**不在可行域内**（$\psi=90^\circ$ 时 $x\approx0$，而透镜要求 $x\ge500$）：把第二点放在 $S_1$ 正侧方通常**根本听不到源**，这不是次优而是不可行；
- 这正是"为什么最优设计是前方偏一点"的**可行性**根源。

### 5.4 定位区域直径的解析近似

两楔形交在一般位置是四边形。记源处两视线夹角（交会角）为 $\alpha$，则由正弦定理与楔形张角 $2\delta$，四边形两组对边长度分别为

$$a\approx\frac{2r_1\tan\delta}{\sin\alpha},\qquad b\approx\frac{2r_2\tan\delta}{\sin\alpha},$$

对角线与夹角关系给出

$$\boxed{\ D\ \approx\ \frac{2\tan\delta}{\sin\alpha}\sqrt{r_1^2+r_2^2+2r_1r_2|\cos\alpha|}\ }\tag{6}$$

其中 $r_2^2=r_1^2+\rho^2-2r_1\rho\cos\psi$，$\alpha=d_{\rm circ}(\theta_1,\theta_2)$。

**适用范围（重要）.** 式 (6) 是**平行四边形近似**，在区域为四边形时精度很高（$40$ 组随机构型：相对误差中位 $0.036\%$、均值 $0.20\%$、最大 $1.73\%$）；但**当区域退化为三角形时失效**。例如设计 $(1003,38.25^\circ)$、$r_1=5$ m 时精确 $D=33.16$ m，而式 (6) 给 $56.34$ m（高估 $70\%$）。退化发生在源离 $S_1$ 很近（$S_1$ 本身成为区域顶点）等情形。**因此搜索与最终报告一律以精确半平面交的 $D$ 为准**，式 (6) 只用于快速定位与可解释性分析（见 §6 算法）。

### 5.5 优化模型与退化性

**（1）优化问题.**

$$\min_{\rho,\psi}\ \ J(\rho,\psi):=\mathbb E_{G,\varepsilon_1,\varepsilon_2}\big[D(\theta_1,\theta_2;S_1,S_2)\big]\qquad \text{s.t.}\quad S_2=(\rho,\psi)\in\mathcal F_0\ (\text{或}\ \mathcal F), \tag{7}$$

其中 $\theta_1,\theta_2$ 是**含误差的示向度**（$\theta_i=\alpha_i^{\rm true}+\varepsilon_i$，$\varepsilon_i\sim U(-\delta,\delta)$），$G$ 按先验分布。辅问题把 $D$ 换成 $\operatorname{tr}\Sigma$。

**（2）双重期望的必要性.** 实际定位区域由**测得值** $(\theta_1,\theta_2)$ 决定，而非真实方位角；误差一方面平移区域、一方面改变 $\alpha$ 从而改变区域尺寸。一阶意义上误差主要平移区域，但二阶效应使 $D$ 的期望略增（Monte Carlo：透镜最优设计下 $\mathbb E[D]$ 由名义 $63.6$ m 升至 $64.8$ m，约 $+2\%$）。严谨表述应写成双重期望（式 7）。

**（3）退化性（为什么必须鲁棒化）.** 若 $r_1$ 已知，则当 $S_2\to G$ 时 $r_2\to0$，区域随第二楔形收拢而趋于一点，$D\to0$，$\operatorname{tr}\Sigma$ 亦随之减小：**最优第二点就是源点本身**。因此本问的全部内容在于 $r_1$ 未知下的期望化/最坏化，以及"保证听到"的约束；这解释了为什么最优解不是某个固定的"几何构型"，而是"尽可能靠近源、同时满足必然可听"的位置——即透镜的**肩部**。

**（4）最坏情况.** 对鲁棒设计 $(\rho^*,\psi^*)$，沿先验支撑的最坏 $D$ 出现在 $r_1$ 接近上界 $1500$ m 处（交会角变小、区域拉长）。用精确直径复算（设计 $(1005,38^\circ)$）：

| $r_1$/m | 5 | 50 | 100 | 200 | 300 | 500 | 750 | 1000 | 1250 | 1500 |
|---|---|---|---|---|---|---|---|---|---|---|
| $D$/m | 33.4 | 54.8 | 52.6 | 48.5 | 44.8 | 38.8 | 35.2 | 50.0 | 79.0 | **121.9** |
| $R^*=D/2$/m | 16.7 | 27.4 | 26.3 | 24.3 | 22.4 | 19.4 | 17.6 | 25.0 | 39.5 | **61.0** |

即最坏 $D\le122$ m、$R^*\le61$ m（此数在问题 3 的单源清除保证链中使用）。

## 6 算法设计与复杂度

### 6.1 主算法

```
算法 Q2：第二个检测点的选择
输入 : S1, θ1, 误差界 δ=1°, 先验 (r1 的分布), 目标 (D 或 trΣ)
输出 : 最优设计 (ρ*, ψ*), 候选区域 F

 1  构造凸包 Q=conv(P) 的极点 ext(Q): S1、远弧端点 r_max∠(±δ) 等
 2  F_Q ← ∩_{G∈ext(Q)} B(G,1000)                # 保守内近似（命题5.2）
    F_0 ← B(S1+5u,1000) ∩ B(S1+1500u,1000)      # 外近似（透镜），u=(cosθ1,sinθ1)
    工作可行域取 F_0；用 F_Q 校核最优解（二者夹逼真实域 F）
 3  设 S2 = (ρ cosψ, ρ sinψ)，网格 (ρ,ψ)
 4  对每个网格点且 S2∈F_0:
 5      用解析式(6)快速估计 E[D](ρ,ψ) 或 E[trΣ]
 6  取解析最优 (ρ0,ψ0)，在其邻域用小步长网格
 7      用精确半平面交(问题一算法)重算 E[D]，得 (ρ*,ψ*)
 8  返回 (ρ*,ψ*), F_Q, F_0, 以及最坏 r1 下的 D_max、R*_max
```

### 6.2 关键子程序与复杂度

- **精确直径**：由"边界线两两求交 + 全约束可行性筛选"直接枚举两楔形交的顶点（含 $S_1$、$S_2$ 作顶点的三角形退化情形），$O(1)$；**不用大框裁剪**，避开问题一勘误 C14 的截断问题。
- **网格搜索**：解析式 $O(1)$/格点；精确细化只在最优邻域做，故总代价 $\approx$ 解析网格规模。本文网格 $\rho$ 步 $10$ m、$\psi$ 步 $1^\circ$，最优邻域细化到 $\rho$ 步 $5$ m、$\psi$ 步 $1^\circ$。
- **无界格点处理**：$\alpha\le2\delta$（即两示向度夹角过小）的格点目标记 $+\infty$ 并排除，全域搜索中约占 $4.4\%$。

## 7 数值实验与验证

所有结果由本地脚本复算（附录 B；解析式对精确半平面交、透镜对密集采样、含误差对 Monte Carlo 三条独立路径交叉验证）。

**实验 1（候选区域/透镜）**　式 (4) 的三重区域（外近似 $\mathcal F_0$、真实 $\mathcal F$、保守内近似 $\mathcal F_Q$）的数值几何见 §5.3 表：$\mathcal F_0$ 为 $x\in[500,1005]$、$y\in\pm664.3$、$|\psi|\le41.44^\circ$；真实 $\mathcal F$ 与内近似 $\mathcal F_Q$ 的 $y$ 半宽均为 $\pm642.8$、$|\psi|\le40.0^\circ$（$\mathcal F_Q$ 的 $x$ 上界为 $1000$）。**在保守内近似 $\mathcal F_Q$ 内重做优化，最优设计不变**（仍 $(1000,38^\circ)$，$\mathbb E[D]=55.63$ m）。

**实验 2（最优设计）**　三先验、两指标、考虑/不考虑接收约束的最优设计与目标值见表 2。解析式定位 + 精确直径细化。

|---|---|---|---|---|---|
| $r_1\sim U(5,1500)$ | $\mathbb E[D]$/m | $(1085,\ \pm39.0^\circ)$ | $55.13$ | $(1000,\ \pm38.0^\circ)$ | $55.63$ |

**实验 3（交会角随 $r_1$ 变化）**　设计 $(1003,38.25^\circ)$ 下：$r_1=200/1000/1500$ m 时交会角约 $133.4^\circ/71.1^\circ/41.1^\circ$。故"最优交会角 $\approx90^\circ$"**只在源距离处于先验中部时近似成立**，不能写成常数结论。

**实验 4（最坏情况）**　见 §5.5(4) 表：鲁棒设计的最坏 $D\le121.9$ m、$R^*\le61.0$ m（$r_1=1500$ m）。

**实验 5（对照：正侧方）**　把第二点放在正侧方（$\psi=90^\circ,\rho=1000$）：$U(5,1500)$ 下精确 $\mathbb E[D]=91.6$ m，面积密度 $\propto r_1$ 下 $119.3$ m；且在 $r_1=1500$ m 时 $r_2=1802.8$ m $>1500$ m，**不满足接收保证**。含误差 Monte Carlo 下其平均 $D=118.4$ m，而最优设计为 $64.8$ m，**差约 $1.83$ 倍**。

**实验 6（含误差 Monte Carlo，双重期望）**　真源按面积密度采样于 $P$，两次误差 $U(-1^\circ,1^\circ)$，$N=20000$：

| 设计 | 平均 $D$/m | 中位 $D$/m | $P_{90}$/m | 最大 $D$/m | 无界比例 |
|---|---|---|---|---|---|
| 透镜最优 $(1000,38^\circ)$ | 64.81 | 56.16 | 107.84 | 133.47 | 0.00% |
| 全域最优 $(1085,39^\circ)$ | 61.41 | 53.84 | 96.86 | 117.65 | 0.00% |
| $U(200,1500)$ 最优 $(1125,36^\circ)$ | 59.21 | 52.96 | 90.03 | 110.06 | 0.00% |

两个观察：**误差使 $\mathbb E[D]$ 相对名义值上浮约 $2\%$**；**全域最优在面积先验下略优于透镜最优**，但它对部分 $G$ 不满足接收保证（故仍推荐满足保证的透镜解）。

**实验 7（真源隶属）**　用含误差示向度构造两楔形交区域，检验真源是否落在其中：$5000$ 组**零违反**。这验证了集合隶属结论"真源必属 $R$"，同时校核实现。

**验证结论**：候选区域（透镜）与最优设计经解析、精确几何、含误差 Monte Carlo 三方一致；最优设计在 $S_1$ 前方 $\approx1000$ m、偏角 $\approx\pm38^\circ$；最坏情况 $D\le122$ m、$R^*\le61$ m；侧方方案既不可行（接收）又差约 $1.8$ 倍。

## 8 结论

1. **候选区域**：第二点应落在**透镜**
   $$\mathcal F_0=B\big(S_1+5u,1000\big)\cap B\big(S_1+1500u,1000\big),\qquad u=(\cos\theta_1,\sin\theta_1)$$
   （外近似；严格形式见命题 5.2 的夹逼 $\mathcal F_Q\subseteq\mathcal F\subseteq\mathcal F_0$，数值上真实域 $y$ 半宽 $664.3\to642.8$ m、$|\psi|$ 上限 $41.44^\circ\to40.0^\circ$）。其含义是：第二点必须同时落在"源最近可能位置"与"源最远可能位置"的 $1000$ m 内，才能**保证**听到源。最优设计 $(1000,38^\circ)$ 即使按最保守的 $\mathcal F_Q$ 也属可行，故结论稳健。**偏角接近 $\pm90^\circ$ 的侧方点不在候选区域内。**
2. **选择策略（最优设计）**：把第二点放在 $S_1$ 前方约 $1000\sim1125$ m、偏离示向度约 $\pm30^\circ\sim40^\circ$ 处（**透镜肩部**）。优先推荐满足接收保证的 $(\rho^*,\psi^*)\approx(1000\text{ m},\pm38^\circ)$，此时 $\mathbb E[D]\approx55.6$ m（$U(5,1500)$ 先验），最坏 $D\le122$ m、$R^*\le61$ m。
3. **方法要点**：$r_1$ 未知是本题的全部难点（$r_1$ 已知则最优第二点就是源点）；必须对 $G$ 与误差取双重期望；$\sigma_\theta$ 应取 $2^\circ/\sqrt{12}=0.5774^\circ$；$\alpha\le2\delta$ 的构型不可定位，搜索中排除。正侧方 $1000$ m 方案比最优方案差约 $1.8$ 倍，且不满足接收保证。

## 9 理论依据与文献支撑

**（1）最优实验设计.** 把"第二点放哪"写成在可行域上最小化$\mathbb E[D]$或$\operatorname{tr}\Sigma$，属于最优实验设计（文献 [15]）与测向定位精度分析（文献 [8,9]）的标准框架。本文主指标取几何直径 $D$（与本问"定位区域"一致），统计量 $\operatorname{tr}\Sigma$ 作为辅助，二者结论一致，互为印证。

**（2）凸集与极点.** 候选区域 $\mathcal F$ 闭凸（它是一族凸函数 $\|S_2-G\|$ 的最大值的下水平集）。其严格的解析夹逼为 $\mathcal F_Q\subseteq\mathcal F\subseteq\mathcal F_0$：内近似 $\mathcal F_Q$ 取凸包 $\operatorname{conv}(P)$ 的极点（凸紧集上凸函数最大值在极点取得，问题一引理 A.2），外近似 $\mathcal F_0$ 取 $P$ 内两点。**注意** $P$ 本身因约束 $r_1>5$ 而**不凸**，故不可写成 $\mathcal F=\bigcap_{G\in\operatorname{ext}(P)}$（详见《问题二剖析与证明》§5.1、§5.3）。

**（3）集合隶属.** "真源必落在两楔形交区域内"不依赖误差分布与独立性（文献 [3,4]），故设计目标的期望化只用于**优化**，而**保证性**（真源隶属、必然接收）是确定性的。

## 附录 B　Python 参考实现

> 依赖 `numpy`。以下为精简版；`q1_impl` 为问题一的主算法模块（楔形半平面、无框顶点、直径、最小包围圆）。

```python
# -*- coding: utf-8 -*-
import math
import numpy as np

D2R = math.pi / 180.0
DELTA = 1.0


def bearing(S, P):
    return math.degrees(math.atan2(P[1] - S[1], P[0] - S[0])) % 360.0


def dcirc(a, b):
    return abs((a - b + 180.0) % 360.0 - 180.0)


def line_inter(h1, h2):
    (q1, n1), (q2, n2) = h1, h2
    det = n1[0] * n2[1] - n1[1] * n2[0]
    if abs(det) < 1e-14:
        return None
    b1 = float(np.dot(n1, q1)); b2 = float(np.dot(n2, q2))
    return np.array([(b1 * n2[1] - b2 * n1[1]) / det, (n1[0] * b2 - n2[0] * b1) / det])


def feasible(p, H, tol=1e-6):
    return all(float(np.dot(n, p - q)) >= -tol for q, n in H)


def exact_diameter(S1, S2, th1, th2, half=DELTA, wedge_halfplanes=None):
    """两楔形交的精确直径（含三角形退化；无界返回 inf）。"""
    if dcirc(th1, th2) <= 2 * half + 1e-12:
        return float("inf")
    H1 = wedge_halfplanes(S1, th1, half)
    H2 = wedge_halfplanes(S2, th2, half)
    H = H1 + H2
    pts = []
    for h1 in H1:
        for h2 in H2:
            p = line_inter(h1, h2)
            if p is not None and feasible(p, H):
                pts.append(p)
    for ap in (S1, S2):
        if feasible(ap, H):
            pts.append(ap)
    uniq = []
    for p in pts:
        if not any(np.linalg.norm(p - u) < 1e-7 for u in uniq):
            uniq.append(p)
    if len(uniq) < 2:
        return 0.0
    P = np.array(uniq)
    return max(float(np.linalg.norm(P[i] - P[j]))
               for i in range(len(P)) for j in range(i + 1, len(P)))


def lens(rho, psi, rmin=5.0, rmax=1500.0, R=1000.0):
    p = np.array([rho * math.cos(psi * D2R), rho * math.sin(psi * D2R)])
    return (np.linalg.norm(p - np.array([rmin, 0.0])) <= R
            and np.linalg.norm(p - np.array([rmax, 0.0])) <= R)


def design_expected_D(prior="u5", rho=1000.0, psi=38.0, exact=True, wedge_halfplanes=None):
    r1s = np.arange(5.0, 1500.0 + 1e-9, 5.0)
    if prior == "u200":
        r1s = r1s[r1s >= 200.0]
    w = r1s.copy() if prior == "r1" else np.ones_like(r1s)
    w = w / w.sum()
    S1 = np.array([0.0, 0.0]); G0 = None
    S2 = np.array([rho * math.cos(psi * D2R), rho * math.sin(psi * D2R)])
    acc = 0.0
    for r1, wi in zip(r1s, w):
        G = np.array([r1, 0.0])
        th1 = bearing(S1, G); th2 = bearing(S2, G)
        if exact:
            d = exact_diameter(S1, S2, th1, th2, wedge_halfplanes=wedge_halfplanes)
        else:
            a = dcirc(th1, th2)
            if a <= 2 * DELTA:
                d = float("inf")
            else:
                r2 = float(np.linalg.norm(S2 - G))
                d = (2 * math.tan(DELTA * D2R) / math.sin(a * D2R)) * \
                    math.sqrt(r1 * r1 + r2 * r2 + 2 * r1 * r2 * abs(math.cos(a * D2R)))
        if not math.isfinite(d):
            return float("inf")
        acc += wi * d
    return acc
```
