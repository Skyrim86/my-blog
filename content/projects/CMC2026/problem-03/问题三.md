## 1 问题重述

全向干扰源共 $10\sim16$ 个，位置、频道（$1\sim20$ 且互不重复）、有效接收半径（$1000\sim1500$ m）均未知。机器狗从原点出发、初始频道 $1$，需在**确保全部清除**的前提下使时间越短越好；模拟器按"被清除源个数比例"与"平均定位清除时间（总时间 ÷ 被清除个数）"给出结果，并进行三次正式测试、按**表 1** 填报。

时间的计费口径（附录 2）：移动 $\lVert\Delta p\rVert/5$ s（$5$ m/s）；检测 $5$ s；频道切换 $1$ s（**仅** `/measure` 且频道变化时）；清除未发现 $3$ s、成功 $5$ s；`/enter`、`/exit` 不计时。**移动时间主导总时间**，故策略的核心是**减少无效行程**。

## 2 模型假设

1. **平面假设**：由附录 2(7)，测向机与干扰源同平面。
2. **有界误差假设**：示向度误差 $\alpha_i\in[\theta_i\pm1^\circ]$，$\delta=1^\circ$；不假设分布与独立性（同问题一）。
3. **全向源假设**：本方（问题三）所有源的有效覆盖角为 $360^\circ$，故"距离 $\le R_{\rm eff}$ 即必被听到"；因 $R_{\rm eff}\ge1000$ m 而具体值未知，**保证性推理只能用下界 $1000$ m**。
4. **每频道至多一源**（题面附录 1）：故某频道一旦清除即了结，某频道一旦被证明为空即永久排除。
5. **`no_signal` 的保守语义**：`no_signal` 只保证"源不在该点的 $1000$ m 内"，不保证更远。
6. **同一地点误差固定**（附录 2）：故重复检测同一点不能提高精度，必须换点。
7. 忽略数值舍入；通信按协议串行、每动作新 `request_id`。

## 4 问题分析

本问要在**源的位置、数量、频道、接收半径全部未知**的条件下做到"**一个不漏**"，且尽量快。三个子问题层层递进：

1. **如何在有限次检测下"证明"某频道没有源？** 这是本问最不同于直觉的地方：`no_signal` 只给出**负面证据**。由于 $R_{\rm eff}\ge1000$ m，一次 `no_signal` 排除了一个 $1000$ m 圆盘；要排除整个 $1800$ m 圆域，需要若干点的 $1000$ m 圆盘**覆盖**该圆域。这就是"覆盖巡视"的由来，也是保证性的唯一来源。
2. **如何定位并清除已发现的源？** 听到信号后，示向度给出一个 $\pm1^\circ$ 楔形约束（问题一）；两个不同地点的示向度即可交会出定位区域，再用**问题一**的直径/最小包围圆得到"必然包含源"的小区域，走到其中心清除。
3. **如何调度？** 覆盖点、第二示向度点、清除点三者若各跑一趟，行程会翻倍。故必须把它们**合并到同一条巡回路径**上（广义 TSP），并用"频道剪枝"把已了结的频道从测量集中永久移除。

**核心主线（四步）**：
$$\underbrace{\text{(1) 选覆盖构型}}_{\text{定理 1}}\Rightarrow\underbrace{\text{(2) 巡回 + 自适应按频道判空}}_{\text{算法 Q3}}\Rightarrow\underbrace{\text{(3) 两视线交会定位}}_{\text{问题一}}\Rightarrow\underbrace{\text{(4) 两级清除链}}_{\text{定理 2}}$$

**关于时间构成的预判（决定优化重点）**：由附录 2，检测 $5$ s/次、切换 $1$ s/次，而移动按 $5$ m/s 计。7 点构型的巡回行程约 $9.7$ km（约 $1933$ s），而全部检测（即使 7 点全扫）也只有 $833$ s。**故虚拟时间由移动主导，优化重点是"减少采样点数与行程"，而不是"减少检测次数"。** 这一预判在 §7.5 的消融实验中得到实测确认。

## 5 模型的建立

### 5.1 覆盖保证：采样构型与覆盖半径

**判据.** 设采样点集 $\mathcal P$，若
$$c(\mathcal P):=\max_{G\in\Omega}\ \min_{p\in\mathcal P}\lVert G-p\rVert\le1000\ \text{m}, \tag{1}$$
则**任何位置的源都会被至少一次检测到**（因为 $R_{\rm eff}\ge1000$），从而"在所有采样点都 `no_signal`"**等价于**"该频道无源"。这就把"证明没有源"化归为一个**纯几何的圆盘覆盖问题**。

**（1）构型族与最优环半径.** 取"原点 1 点 + 半径 $R$ 的正六边形环 6 点"（共 7 点）。由于 $\Omega$ 是圆盘（旋转对称），$c$ 只依赖 $R$。对 $\Omega$ 内 5 m 网格逐点实算（`.review/q3_config.py` A 节）得表 2。

**表 2　7 点构型的覆盖半径随环半径的变化（域内 5 m 网格实测）**

| 环半径 $R$/m | 1250 | 1350 | 1450 | **1550** | 1650 | 1700 | $\sqrt3\cdot1000=1732.05$ | 1750 |
|---|---|---|---|---|---|---|---|---|
| 覆盖半径 $c$/m | 951.5 | 923.9 | 906.6 | **900.0** | 952.0 | 981.1 | **1000.000** | 1010.3 |
| 余量 $1000-c$/m | 48.5 | 76.1 | 93.4 | **100.0** | 48.0 | 18.9 | **0.000** | $-10.3$ |

**结论（定理 1）**　$c(R)$ 在 $R^\dagger\approx1550$ m 处取极小值 $900.0$ m。两条约束在此平衡：格心约束要求 $R\lesssim\sqrt3\cdot1000$（六边形格覆盖半径 $R/\sqrt3$），域边界约束要求 $R\gtrsim1123$ m，二者在 $R\approx1550$ m 处相等。

> **与规划稿的差异**：规划稿把 $\sqrt3\cdot1000$ 当作 7 点的"最优值"并判断"恰好取等、必须加余量就得改 8 点"。**实际上收紧环半径反而扩大余量**：$R=1550$ m 时 7 点即带 **100 m 余量**，且环周长更短（$2\pi R$ 由 $10.9$ km 降到 $9.7$ km）。

**（2）点数与余量的权衡.** 对 $n$ 个环点联合优化 $R$（`.review/q3_config.py` B 节）：

**表 3　点数—余量—行程的权衡（中心 + $n$ 环点，5 m 网格）**

| 环点数 $n$ | 最优 $R$/m | 覆盖半径/m | 余量/m | 环周长/m | 环上最短行程/s |
|---|---|---|---|---|---|
| 5 | 1460 | 1058.0 | $-58.0$ | 9173 | 1760 |
| **6（共 7 点）** | **1550** | **900.0** | **100.0** | 9739 | 1933 |
| 7（共 8 点） | 1440 | 801.9 | 198.1 | 9048 | 1839 |
| 8（共 9 点） | 1370 | 745.3 | 254.7 | 8608 | 1780 |

（环上最短行程按"自原点出发、遍历全部环点、不闭合"计：$\big(R+2\pi R\frac{n-1}{n}\big)/5$。）

**结论**：**5 个环点不够**（最优也只有 $1058$ m 覆盖半径，无法保证）；**6 个环点是保证检测的最少点数**。本章取 **7 点构型（$R=1550$ m）为基准**（余量 100 m），并在 §7 中用 8 点构型（$R=1440$ m，余量 198 m，行程反而更短）作稳健对照。**注意"8 点余量更大且行程更短"这一反直觉现象**：环半径收缩带来的周长收益超过了点数增加的开销。

### 5.2 自适应按频道判空

**机制.** 为每个频道 $k$ 维护候选域 $S_k\subseteq\Omega$（初值 $\Omega$）。在点 $p$ 对该频道得到 `no_signal` 即执行
$$S_k\ \leftarrow\ S_k\setminus B(p,1000),\qquad S_k=\varnothing\ \Longrightarrow\ \text{频道 }k\text{ 无源}. \tag{2}$$
一旦在 $p$ 听到信号，该频道转入**清源流程**；此后它**不再需要任何覆盖测量**（因每频道至多一源）。

**为什么省时（理想化核算）.** 规划稿的时间账按"每点扫全部 20 频道"计（$7\times119=833$ s）。若"一旦听到即退出覆盖集"，则只有"从未听到"的频道需要在**全部**采样点上测完。按此理想化模型模拟 2000 局（源数 $10\sim16$、位置面均匀，`.review/q3_config.py` C 节）：

**表 4　检测预算的"理想化"对照（2000 局平均；假设"首次检出即退出覆盖集"）**

| 方案 | 平均检测次数/局 | 检测虚拟时间 | 相对 |
|---|---|---|---|
| 每点扫全部 20 频道（7 点） | 140 | 833 s | 基准 |
| 自适应按频道判空（理想化） | **42.2** | **247 s** | 省 70.4% |

> **重要修正（依实测消融，见 §7.5）**：上表是**理想化**上限——它假设"首次检出即可停止测量该频道"。**实际策略需要两条视线才能交会定位**，故被检出的频道还要在后续采样点上再测一次取第二示向度；且**判空频道无论如何都必须在全部 7 个点上测完**。因此**真实实现的节省远小于 70%**：实测动作数 $167.8\to146.7$（省 $12.6\%$），虚拟时间 $6180.8\to6119.6$ s（省 $1.0\%$）。原因是**检测时间只占虚拟时间约 $10\%$，总时间由移动距离主导**。上表仍保留，作为"检测环节本身能省多少"的理论刻画；论文中**不得**把 70% 当作总时间收益。

### 5.3 两视线交会定位与退化识别

**定位.** 对频道 $k$ 收集到两条以上视线 $\{(S_i,\theta_i)\}$ 后，取其楔形交（问题一的无框半平面交），得顶点集、直径 $D$、最小包围圆 $(c,R^*)$。真源必在该区域内（问题一的集合隶属结论），故 $\lVert c-G\rVert\le R^*$。

**退化识别（关键）.** 若某对视线满足 $d_{\rm circ}(\theta_i,\theta_j)\le2\delta$，则由问题一定理 1 该对给出的区域**无界**，交会定位失效。数值上这类构型会把"区域"拉成上万米的长条（实测：交会角 $2.1^\circ$ 时 $D=17043$ m、$R^*=8521$ m，估计误差达 $8054$ m）。**因此必须丢弃交会角 $\le2\delta$ 的视线对**，并在交会角过小时主动到"垂直视线方向"的新位置补测一条视线（见 §5.4 步骤 2）。

**第二示向度的零额外行程做法.** 覆盖巡回本身要依次经过全部采样点。若在 $p_1$ 听到频道 $k$，只需在巡回的**下一个采样点** $p_2$ 顺带测一次 $k$——$p_1,p_2$ 间距约 $1550$ m（同环相邻点），交会角良好，且这条移动本就是巡回的既有行程，**边际成本仅 $6$ s**。只有"在巡回最后一个点才听到"的频道需要专程补测（少数）。

### 5.4 单源清除链

清除的成功条件是 $\lVert p-G\rVert\le20$ m（与朝向无关）。故只要能把 $G$ 锁定到半径 $20$ m 内即**必然命中**。

> **定理 2（两级清除链的保证性）**　设一级定位的最小包围圆半径为 $R^*_1\le61.5$ m。走到其圆心 $c_1$ 复测一次得第 3 条视线，再在 $c_1$ 沿**垂直视线方向偏移 100 m** 处复测一次得第 4 条视线，则由四条视线交会所得区域满足 $R^*_2\le2.7$ m 且 $\lVert c_2-G\rVert\le2.0$ m $<20$ m，**走到 $c_2$ 清除必然命中**。

**数值验证**（`.review/q3_config.py` D 节，4000 局）：

**表 5　清源链的两种做法对比（4000 局实测）**

| 链 | 一级 $R^*_1$（中位/最大） | 二级 $R^*_2$（中位/最大） | $\lVert c_2-G\rVert$ 最大 | 能否保证清除 |
|---|---|---|---|---|
| 只在 $c_1$ 复测 1 次 | 23.6 / 65.9 m | 8.42 / **31.59 m** | — | **否**（$31.6>20$） |
| **$c_1$ 复测 + 垂直偏移 100 m 再测** | 23.5 / 64.9 m | **1.78** / **2.64 m** | **1.98 m** | **是** |

**为什么只测 $c_1$ 不行（证明思路）.** $c_1$ 落在区域内部，第 3 条视线的方向与原来两条**近似平行**（都指向 $G$），故新楔形只把区域削成一条细长条，在**纵向（视线方向）几乎不提供信息**，$R^*_2$ 仍有约 $R^*_1/2$ 量级；垂直偏移使第 3、4 条视线之间形成大交会角，才能同时约束纵向与横向。

按 $R^*_1$ 分档的实测上界：$R^*_1\in[0,15)/[15,30)/[30,50)/[50,70)$ 对应 $R^*_2\le1.76/2.03/2.39/2.64$ m。由问题二的最坏界（含误差 Monte Carlo 最坏 $D\le133$ m $\Rightarrow R^*_1\le66.7$ m），本链在**全先验范围内**保证清除，且对 $R^*_1$ 直到约 $225$ m 仍成立（3 倍余量）。

**动作序列**（典型）：巡回点测到信号（5 s）→ 下一点顺带复测（6 s）→ 走到 $c_1$ 清除／复测 → 垂直偏移 100 m 复测 → 走到 $c_2$ 清除。典型 **4 次检测 + 1 次清除**；若出现 `near` 或 $R^*_1\le20$ m 可直接就地清除。

**兜底（退化构型）**：若四视线后仍不能清除（交会角持续退化），依次启用 ①以最后估计为中心、**28 m 间距**的局部网格清除（$28$ m 间距保证任一格点距真实源 $\le14\sqrt2=19.8<20$ m），②沿**最优那条示向度射线**以 40 m 步长、横向 $0/\pm25$ m 的射线推进清除（源必在该射线上：$1500$ m 处横向偏差 $\le1500\tan1^\circ=26$ m）。两者均只依赖"`/clear` 与朝向无关、失败仅 3 s"，故对任何退化构型都收敛。

### 5.5 多源调度：巡回与清源合并

- **频道剪枝**（收益最大）：已清除或已判空的频道永久移出测量集。
- **巡回规划**：把"覆盖采样点"与"各源的清除点"统一为一条路径，用**最近邻 + 2-opt**（点数 $\lesssim30$，秒级求解）。
- **清源顺序**：每轮选"当前估计最近的待清频道"先清（降低空跑）。
- **终止条件**：每个频道"已清除"或"已证明为空"；若清除数达 $16$（源数上界）可立即 `/exit`。
- **评分口径（优先级）**：**先保证清除比例 $=1$，再最小化平均时间**。因指标是"总时间 ÷ 被清除个数"，少清一个源会"降低"平均值，故任何"为省时间而放弃难清源"的做法都判为不合格。

## 6 算法设计与复杂度

### 6.1 主算法

```
算法 Q3：全向源的搜索—定位—清除
输入 : 圆域 Ω、频道集 K={1..20}、覆盖构型 P（7 点，R=1550）
输出 : 全部源的清除记录、虚拟时间

 1  构造巡回路径 tour ← NN(P) + 2-opt，起点 = 原点
 2  状态：每个频道的视线集 dets[k] ← ∅；cleared ← ∅；empty ← ∅
 3  FOR p IN tour:                                  # 覆盖巡视（自适应）
 4      FOR k IN K \ (cleared ∪ empty ∪ {已取到2条良态视线者}):
 5          (res, svd) ← /measure(p, k)
 6          IF res = near: /clear(p,k); cleared ← cleared ∪ {k}
 7          ELIF res = direction: dets[k] ← dets[k] ∪ {(p, svd)}
 8          ELSE: (no_signal)  # S_k ← S_k \ B(p,1000)，仅作记账，判空在步骤 10
 9  巡回结束：对每个 k
10      IF dets[k] = ∅:  k 判空（因 c(P) ≤ 1000 m，覆盖成立）        # 保证性来源
11      ELIF 无良态视线对（交会角 > 2δ）: 到垂直方向补测一条视线
12  WHILE 存在待清频道:
13      k ← 估计位置离当前位置最近的待清频道
14      (c1,R*1) ← 由 dets[k] 作无框半平面交 → 最小包围圆
15      /clear(c1, k);  IF 成功: 记 cleared, CONTINUE
16      (res3,svd3) ← /measure(c1,k);  dets[k] ← dets[k] ∪ {(c1,svd3)}
17      c3 ← c1 + 100 · n̂(视线方向); (res4,svd4) ← /measure(c3,k)
18      dets[k] ← dets[k] ∪ {(c3,svd4)};  c2 ← 四视线交会的最小包围圆圆心
19      /clear(c2, k)
20      IF 仍失败: 局部 28 m 网格清除 → 沿最优射线推进清除（兜底）
21  /exit
```

### 6.2 复杂度

设采样点数 $m$（$m=7$ 或 $8$），频道数 $20$。

| 环节 | 复杂度 | 说明 |
|---|---|---|
| 巡回规划 | $O(m^3)$（2-opt 最坏） | $m\lesssim30$，秒级 |
| 覆盖检测次数 | $O(m\cdot20)$ 上界；自适应后平均 $\approx42$ 次 | 实测 |
| 单频道定位 | $O(1)$ | 视线数 $\le4$，半平面交 $O(n^3)$、$n\le4$ |
| 清源链 | $O(1)$ 次 `/clear` + 兜底有界 | 兜底封顶 120 次清除 |
| **总虚拟时间** | 由**移动距离**主导 | 见 §7 |

## 8 结论

1. **候选区域的"证明"问题化归为圆盘覆盖**：因 $R_{\rm eff}\ge1000$ m，"所有采样点都听不到"等价于"该频道的 $1000$ m 无信号圆盘覆盖整个圆域"。取**中心 + 6 环点（环半径 $1550$ m）**，覆盖半径 $900.0$ m（余量 $100$ m），是保证检测的**最少点数**构型；$\sqrt3\cdot1000$ m 只是零余量临界值。
2. **检测预算靠"自适应按频道判空"压缩，但其收益须与移动代价分开评估**：把"检测环节"单独看，自适应把检测次数由 $140$ 降到 $42.2$（理想化上限，省 $70.4\%$）；但在**完整策略**中实测只省 $1.0\%$ 虚拟时间（动作数省 $14.3\%$）——因为检测只占虚拟时间约 $10\%$，总时间由**移动距离**主导。因此本策略的主要收益来自**采样构型（覆盖率与余量）与巡回合并**。
3. **定位复用问题一**：两视线楔形交 + 无框半平面交得直径与最小包围圆；**必须丢弃交会角 $\le2\delta$ 的视线对**。
4. **清除靠"两级链"**：走到一级区域中心 $c_1$ 复测、再在**垂直视线方向偏移 100 m** 处复测，二级区域半径 $\le2.7$ m、圆心距真源 $\le2.0$ m，**必然命中**（清除半径 $20$ m）。
5. **调度把覆盖、第二示向度、清源合并为一条巡回**，并用频道剪枝；平均定位清除时间 $488.5$ s，比保底基线快 $5.6$ 倍，100 局清除比例 $100\%$。
6. **评分口径**：先保证清除比例 $=1$，再最小化平均时间。

## 9 理论依据与文献支撑

**（1）圆盘覆盖与格覆盖.** "用最少的等半径圆盘覆盖一个区域"是经典覆盖问题。**无界平面**上最省的格是六边形（三角）格，其覆盖半径为格距的 $1/\sqrt3$（文献 [16]）。本章的两点差异须强调：① 本题区域是**有界圆盘**，故最优环半径不是 $\sqrt3\cdot1000$ 而是 $1550$ m（§5.1）；② 我们用的是"1 个中心点 + 6 个环点"的**有限构型族**，而非无限格，其最优性由域内网格穷举验证（数值）。

**（2）覆盖路径规划与多目标调度.** 采样点的访问顺序是覆盖路径规划问题，把"覆盖点"与"源清除点"合并为一条路径则是广义 TSP；本章规模很小（点数 $\lesssim30$），最近邻 + 2-opt 已足够（文献 [17]–[20]）。

**（3）集合隶属与有界误差.** "真源必落在两楔形交区域内"是确定性的（问题一），故清源链的保证性是集合隶属意义上的**必然**，而非概率；`no_signal` 的保守语义（$R_{\rm eff}\ge1000$）同样是集合意义上的排除（文献 [3,4]）。

**（4）搜索论视角.** 把"候选域 + 负信息更新"写成 $S_k\leftarrow S_k\setminus B(p,1000)$ 并据此规划下一步采样点，与最优搜索论中"负信息即区域剪除"的思想一致（文献 [21]）。

## 附录 B　Python 参考实现

> 完整可运行程序见 `本地测试器/simulator/dog_plan.py`（策略）与 `batch_plan.py`（批量驱动）。下列为核心片段（**无 numpy 依赖**，以便在模拟器环境直接运行）。

```python
# -*- coding: utf-8 -*-
"""问题三策略核心（摘自 dog_plan.py）。完整版含通信、巡回与兜底。"""
import math

ARENA, D2R, DELTA = 1800.0, math.pi / 180.0, 1.0
DETECT_R, CLEAR_R = 1000.0, 20.0


def q3_points(R=1550.0):
    """中心 + 正六边形环（覆盖半径 900.0 m，余量 100 m）。"""
    pts = [(0.0, 0.0)]
    for i in range(6):
        a = 2 * math.pi * i / 6
        pts.append((R * math.cos(a), R * math.sin(a)))
    return pts


def wedge_halfplanes(S, theta_deg, half=DELTA):
    a1, a2 = (theta_deg - half) * D2R, (theta_deg + half) * D2R
    return [(S, (-math.sin(a1), math.cos(a1))), (S, (math.sin(a2), -math.cos(a2)))]


def dcirc(a, b):
    return abs((a - b + 180.0) % 360.0 - 180.0)


def region_stats(dets, tol_rel=1e-9):
    """无框半平面交：返回顶点 V、直径 D、最小包围圆半径 R* 与圆心 c。
    交会角 <= 2δ 的对必须在调用前剔除（否则区域无界）。"""
    hps = []
    for S, th in dets:
        hps.extend(wedge_halfplanes(S, th))
    scale = max(1.0, max(max(abs(s[0]), abs(s[1])) for s, _ in dets))
    tol = tol_rel * scale
    cand = []
    m = len(hps)
    for i in range(m):
        qi, ni = hps[i]
        for j in range(i + 1, m):
            qj, nj = hps[j]
            den = ni[0] * nj[1] - ni[1] * nj[0]
            if abs(den) <= 1e-12:
                continue
            bi = ni[0] * qi[0] + ni[1] * qi[1]
            bj = nj[0] * qj[0] + nj[1] * qj[1]
            p = ((bi * nj[1] - bj * ni[1]) / den, (ni[0] * bj - nj[0] * bi) / den)
            if all(n[0] * (p[0] - q[0]) + n[1] * (p[1] - q[1]) >= -tol for q, n in hps):
                cand.append(p)
    uniq = []
    for p in cand:
        if not any(math.hypot(p[0] - u[0], p[1] - u[1]) <= 1e-6 * scale for u in uniq):
            uniq.append(p)
    if len(uniq) < 2:
        return None
    D = max(math.hypot(uniq[i][0] - uniq[j][0], uniq[i][1] - uniq[j][1])
            for i in range(len(uniq)) for j in range(i + 1, len(uniq)))
    best_r, best_c = float("inf"), None

    def ok(c, r):
        return all(math.hypot(p[0] - c[0], p[1] - c[1]) <= r + 1e-7 for p in uniq)

    for i in range(len(uniq)):
        for j in range(i + 1, len(uniq)):
            c = ((uniq[i][0] + uniq[j][0]) / 2, (uniq[i][1] + uniq[j][1]) / 2)
            r = math.hypot(uniq[i][0] - uniq[j][0], uniq[i][1] - uniq[j][1]) / 2
            if r < best_r and ok(c, r):
                best_r, best_c = r, c
    for i in range(len(uniq)):
        for j in range(i + 1, len(uniq)):
            for k in range(j + 1, len(uniq)):
                a, b, cc = uniq[i], uniq[j], uniq[k]
                d = 2 * (a[0] * (b[1] - cc[1]) + b[0] * (cc[1] - a[1]) + cc[0] * (a[1] - b[1]))
                if abs(d) < 1e-14:
                    continue
                ux = ((a[0]**2 + a[1]**2) * (b[1] - cc[1]) + (b[0]**2 + b[1]**2) * (cc[1] - a[1])
                      + (cc[0]**2 + cc[1]**2) * (a[1] - b[1])) / d
                uy = ((a[0]**2 + a[1]**2) * (cc[0] - b[0]) + (b[0]**2 + b[1]**2) * (a[0] - cc[0])
                      + (cc[0]**2 + cc[1]**2) * (b[0] - a[0])) / d
                c = (ux, uy)
                r = math.hypot(a[0] - ux, a[1] - uy)
                if r < best_r and ok(c, r):
                    best_r, best_c = r, c
    return {"V": uniq, "D": D, "R": best_r, "c": best_c}


def good_pair(th1, th2):
    """交会角必须严格大于 2δ，否则该对给出的区域无界（问题一定理 1）。"""
    return dcirc(th1, th2) > 2 * DELTA


def tour_nn_2opt(points, start=(0.0, 0.0)):
    """最近邻 + 2-opt（点数 ≤ 30，秒级）。"""
    remaining, tour, cur = list(points), [], start
    while remaining:
        nxt = min(remaining, key=lambda p: math.hypot(p[0] - cur[0], p[1] - cur[1]))
        tour.append(nxt); remaining.remove(nxt); cur = nxt
    improved = True
    while improved:
        improved = False
        for i in range(len(tour) - 1):
            for j in range(i + 1, len(tour)):
                a = start if i == 0 else tour[i - 1]
                b, cc = tour[i], tour[j]
                d = tour[j + 1] if j + 1 < len(tour) else None
                old = math.hypot(b[0] - a[0], b[1] - a[1])
                if d:
                    old += math.hypot(d[0] - cc[0], d[1] - cc[1])
                new = math.hypot(cc[0] - a[0], cc[1] - a[1])
                if d:
                    new += math.hypot(d[0] - b[0], d[1] - b[1])
                if new < old - 1e-9:
                    tour[i:j + 1] = reversed(tour[i:j + 1]); improved = True
    return tour


def ray_march_clear(client, ch, dets, max_len=1500.0, step=40.0, budget=120):
    """退化构型的兜底：沿最优示向度射线推进清除（源必在该射线上）。"""
    if not dets:
        return False
    S, th = dets[0]
    u = (math.cos(th * D2R), math.sin(th * D2R))
    n = (-u[1], u[0])
    for i in range(int(max_len / step) + 1):
        for lat in (0.0, 25.0, -25.0):
            if budget <= 0:
                return False
            budget -= 1
            client.clear(S[0] + u[0] * i * step + n[0] * lat,
                         S[1] + u[1] * i * step + n[1] * lat, ch)
            if ch in client.cleared:
                return True
    return False
```
