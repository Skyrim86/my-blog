# 问题二　第二个检测点的选择策略与候选区域

> 本章依据赛题正文及其**附录 1（干扰源特征）**、**附录 2（测向机原理与交会定位法）**建立模型。
>
> 为保持正文连贯，本章只写**思想、建模过程、算法设计与实验**：全部公式与集合定义见《问题二_公式.md》，全部推导与小证明见《问题二_小证明.md》，验证口径、脚本对应与踩坑清单见《问题二_证明笔记.md》。

**方法主线。** 一次示向度给出的不是源的位置，而是"一条射线 + 一个距离区间"。于是策略分两层：(i) **理想几何**——若源距已知，最优是让两条视线正交（$\beta=90^\circ$）且第二点尽量靠近源；(ii) **鲁棒化**——源距未知时"正交"只是一个**族**（对每个可能的 $r$ 各有一个理想点），必须把第二点限制在**保证必然能听到源**的候选区域内（**透镜**），再最小化定位区域直径的期望。本章用 $\mathbb E[D]$ 作主指标、$\operatorname{tr}\Sigma$ 作辅指标，给出**透镜形候选区域**与**最优设计**，并以解析式 + 精确半平面交 + Monte Carlo 三重验证。

## 1 问题重述

已知某**全向**干扰源在一个检测点 $S_1$ 处测得的示向度 $\theta_1$，要求：(1) 给出**第二个检测点 $S_2$ 的选择策略**，以获得关于该源较好的定位效果；(2) 给出 $S_2$ 的**候选区域**。

可用信息与约束（附录 1、2）：

1. 示向度误差落在 $[-1^\circ,1^\circ]$，**同一地点误差固定**，故同点重复检测不能提高精度，必须换点；
2. 源的有效接收半径 $R_{\rm eff}\in[1000,1500]$ m，**具体值未知**——保证性推理只能用下界 $1000$ m（"必然听到"）与上界 $1500$ m（"已听到则不超过它"）；
3. 目标区域为半径 $1800$ m 的圆域；
4. 检测需停止移动、耗时 $5$ s，频道切换 $1$ s，移动速度 $5$ m/s（第二点的**路程代价**由此决定）；
5. 测向机距离源 $\le5$ m 且处于覆盖角内时不返回示向度（返回 `near`），故"得到示向度"蕴含 $r_1>5$ m。

## 2 模型假设

1. **平面假设**（附录 2(7)）：测向机与源同平面，问题为二维几何。
2. **有界误差假设**：示向度误差半界 $\delta=1^\circ$；不假设误差分布与独立性（同问题一）。
3. **全向源假设**：源有效覆盖角 $360^\circ$，故只要距离 $\le R_{\rm eff}$ 就必被听到——这是"保证接收"约束成立的根据（问题四的定向源不满足）。
4. **先验假设**：在得到"距离 $r_1$ 处有源"这一信息后，对 $r_1$ 取先验。本章给出三种先验以检验稳健性：
   - $r_1\sim U(5,1500)$（**基准**：只要区间信息，不作分布假设）；
   - $r_1\sim U(200,1500)$（**稳健对照**：排除过近的源）；
   - $r_1$ 密度 $\propto r_1$（**面积均匀先验**：若源在圆域内面密度均匀，则落在 $[r,r+dr]$ 的概率 $\propto r\,dr$）。
5. **设计目标假设**：以定位区域直径为质量指标（与问题一的"定位区域"一致）；期望对**真源位置**与**两次示向度误差**取（双重期望，见 5.5）。
6. **示向度方向约定**：$\theta_1$ 定义 $+x$ 方向；$S_2$ 用相对 $S_1$ 的极坐标 $(\rho,\psi)$ 表示（$\psi$ 为相对 $\theta_1$ 的偏角，$|\psi|\le180^\circ$）。

## 4 问题分析

选第二点要做三件事，缺一不可：

1. **把"好"量化。** 本问的产物是"定位区域"，故最自然的指标是定位区域**直径 $D$**（问题一已建立其算法与几何）；同时给出统计指标 $\operatorname{tr}\Sigma$（GDOP，文献 [8,9]）作为对照。两者一个保证型、一个平均型。
2. **保证第二点能听到源。** 否则测不到示向度，设计落空。由于 $R_{\rm eff}\ge1000$ m 而具体值未知，唯一可保证的条件是 $\|S_2-G\|\le1000$ m **对所有可能的 $G$ 成立**。这给出了候选区域的形状。
3. **在源位置未知下做鲁棒化。** 若 $r_1$ 已知，最优 $S_2$ 是"正交且尽量靠近源"（受 $r_2>5$ m 盲区限制，不能取 $S_2=G$；见 5.5(3)）；因此本问的全部内容在于"$r_1$ 未知"下的**期望化/最坏化**与**接收保证**。

问题一的结论在此处的接口：$n=2$ 时定位区域是两楔形交（四边形或退化为三角形），其直径由问题一的算法给出；且当两示向度夹角 $\alpha\le2\delta$ 时区域无界（不可定位），这是搜索中必须排除的失败模式。

## 5 模型的建立

### 5.1 一次示向度后的可行集

在 $S_1$ 处得到示向度 $\theta_1$ 后，源必同时满足三个条件：落在示向度张成的楔形内、已被听到故距离不超过接收半径上界 $1500$ m、位于半径 $1800$ m 的目标圆域内；又因"得到示向度"蕴含源不在 $5$ m 近距盲区内，故该集合还严格排除 $r_1\le5$ m 的部分。记这个可行集为 $P$（式 (1)，见《问题二_公式.md》§1）。

$P$ 的数学性质是后续一切论证的地基，其陈述如下（证明见《问题二_小证明.md》§1）：

- **有界**：$P$ 含于以 $S_1$ 为心、$1500$ m 为半径的圆内。
- **非闭**：约束 $r_1>5$ m 是**严格**的，$r_1=5$ m 弧上的点都是 $P$ 的聚点却不属于 $P$，故 $P$ 不含其全部聚点、不是闭集，因而也不是紧集；只有它的闭包 $\operatorname{cl}(P)$ 才是紧集。$\operatorname{cl}(P)$ 的边界由两条射线段（方向 $\theta_1\pm\delta$）、一段远弧（半径 $1500$ m、张角 $2\delta$）与一段近弧（半径 $5$ m、张角 $2\delta$）组成。
- **非凸，但非凸程度极浅**：取位于两边界射线附近、半径刚超过 $5$ m 的两点，其中点已落入被挖去的近距盲区，故 $P$ 不凸；但由于楔形只有 $2\delta=2^\circ$ 宽，$P$ 中任意两点的中点最多"陷入"盲区 $0.76$ mm，即**非凸深度的上界为 $5(1-\cos1^\circ)\approx0.76$ mm**。
- **$0.76$ mm 的定位（勿误用）**：$0.76$ mm 只说明"非凸缺口很薄"，**不能**据此推断"用 $\operatorname{conv}(P)$ 构造内近似无害"——$\operatorname{conv}(P)$ 与扇形环在 $5$ m 近弧的**角点邻域**可差约 $5$ m，而真正的内近似损失量级是**米**（$\mathcal F$ 与 $\mathcal F_Q$ 的 $y$ 半宽相差 $2.78$ m，由 $|S_2|\le1000$ m 造成）。内近似的正确依据不是凸包，而是"取一个包含 $\operatorname{cl}(P)$ 的凸紧集 $Q$、对 $Q$ 的极点施加约束"（见 5.3 命题 5.2）。

**评注。** 因此**不能**对 $P$ 直接使用"凸函数极值在极点取得"的引理（该引理要求凸紧集）。正确处理有两条路：对 $S_2$ 用凸性（下证 $\mathcal F$ 凸），对 $G$ 用一个含 $\operatorname{cl}(P)$ 的凸紧集 $Q$ 作内近似、并用极端的两个可能位置作外近似（见 5.3 命题 5.2）。另需注意两点：**保证接收约束要对 $\operatorname{cl}(P)$ 内的 $G$ 施加**——距离函数关于 $S_2$ 是凸的，其最大值在闭包上取到，故用 $\operatorname{cl}(P)$ 与用 $P$ 得到同一个 $\mathcal F$；目标圆域约束 $B(O,1800)$ 在 $S_1$ 为原点且 $1500<1800$ 时**冗余**（已被 $1500$ m 圆蕴含），不产生额外约束。

### 5.2 质量指标

**（1）几何指标（主）。** 设两示向度决定定位区域（两楔形之交），其直径记为 $D$，它等于该区域顶点的最大两两距离；由问题一的结论，当交会角 $\alpha\le2\delta$ 时区域无界、$D=+\infty$，这类构型不可定位、必须排除。

**（2）统计指标（辅）。** 测向定位的 Fisher 信息与位置协方差取 Torrieri 形式（文献 [8]），其中协方差的两个标量刻画分别为迹 $\operatorname{tr}\Sigma$ 与行列式 $\det\Sigma$（式 (2)，见《问题二_公式.md》§1）：二者均与交会角正弦的平方 $\sin^2\alpha$ 成反比，但**长度依赖不同**——$\operatorname{tr}\Sigma\propto r_1^2+r_2^2$（两视线长度的**平方和**），$\det\Sigma\propto r_1^2r_2^2$（两视线长度平方之**积**，不是平方和）。**单调性须限定条件**：在固定 $r_1$ 与交会角 $\alpha$ 时，$\operatorname{tr}\Sigma$ 与 $\det\Sigma$ 随 $r_2$ 严格递增（沿固定视线把第二点推远更差）；但作为 $S_2$ 的函数，$\alpha$ 也随之变化，故二者整体**并非单调**——最优设计是"$r_2$ 小"与"$\alpha$ 远离 $0^\circ/180^\circ$"的平衡。

**误差标准差。** 题面给的是区间 $[-1^\circ,1^\circ]$ 而非标准差；按均匀分布应取 $\sigma_\theta=0.5774^\circ$（式 (3)，见《问题二_公式.md》§1）。若误用 $\sigma_\theta=1^\circ$：$\sigma_\theta$ 与误差尺度放大约 $1.73$ 倍（$=\sqrt3$），而协方差型量（正比于 $\sigma_\theta^2$）的 $\operatorname{tr}\Sigma$、$\det\Sigma$ 放大约 $3.00$ 倍。若不作分布假设，则式 (2) 只作为**相对比较**的辅助量，主结论仍以 $D$ 为准。

### 5.3 保证接收约束与候选区域（透镜）

要求第二点**必然**能听到源，即对先验支撑内的每个 $G$，$S_2$ 到 $G$ 的距离不超过 $1000$ m（式 (4)，见《问题二_公式.md》§1）。

**命题 5.2（可行域及其双边夹逼，陈述）。** 记保证接收的可行域为 $\mathcal F$、$Q:=W_1\cap B(S_1,1500)\cap B(O,1800)$（凸紧集，且 $\operatorname{cl}(P)\subseteq Q$），则 $\mathcal F$ **闭凸**；并且有**双边夹逼**：以 $Q$ 的极点为约束的内近似 $\mathcal F_Q$ 含于 $\mathcal F$，而 $\mathcal F$ 又含于由源的两个极端可能位置（最近、最远）的 $1000$ m 圆之交构成的外近似 $\mathcal F_0$（式 (5)，见《问题二_公式.md》§2；证明见《问题二_小证明.md》§2）。三者依次为"保守可听""真实可行""乐观外放松"。**注意**：内近似取的是 $Q$ 的极点，不是 $\operatorname{conv}(P)$ 的极点——$S_1\in Q$ 但 $S_1\notin\operatorname{conv}(P)$，这决定了 $\lvert S_2\rvert\le1000$ 这一约束的归属。

关于内近似 $\mathcal F_Q$ 的极点，有三点必须写明：

- **$Q$ 的远弧是连续统极点。** $Q$ 的极点是"$S_1$（楔形顶点；$S_1\notin\operatorname{cl}(P)$，但 $S_1\in Q$）加上半径 $1500$ m 远弧上的**全部**点"，远弧上的每一点都是极点。故内近似的约束必须对整段远弧施加，**不能只取弧的两个端点**——只取端点得到的是**外**近似，方向恰好相反。数值上，对固定 $S_2$，远弧上的最远点必在弧的端点，因此整段弧与仅取两端点给出**同一个** $\mathcal F_Q$（复算：两者最大 $y$ 半宽均为 $648.247783$ m），但论证必须按整段弧书写。
- **约束 $\lvert S_2\rvert\le1000$ 只属于内近似。** 该约束来自 $Q$ 的极点 $S_1$，是**保守内近似** $\mathcal F_Q$ 独有的；**真实可行域 $\mathcal F$ 并不含它**——因为 $S_1\notin\operatorname{cl}(P)$，$\mathcal F$ 对近端的约束是"到源最近可能位置的距离不超过 $1000$ m"，相差 $5$ m 的平移。在 $\rho\approx1000$ m 处，这 $5$ m 恰好决定某个点是否可取，故本章凡标"属于 $\mathcal F$"者一律按到 $\operatorname{cl}(P)$ 的最大距离实算判定。
- **$\operatorname{cl}(P)$ 的极点与本题冗余性。** 按严格定义，$\operatorname{ext}(\operatorname{cl}(P))$ 只含远弧（$r=1500$ m）上的全部点与**内弧（$r=5$ m）的两个端点** $5\angle\pm1^\circ$；内弧的其余点都不是极点。命题 5.2 的夹逼不依赖 $\operatorname{ext}(\operatorname{cl}(P))$；内弧两端点的约束对本题参数**冗余**（$\mathcal F_Q$ 内点到该二点的距离上界为 $996.2<1000$ m），写明以备核。

**推论 5.3（三个区域与数值几何）。** 取源的两个极端可能位置即得外近似 $\mathcal F_0$（"透镜"）；取凸紧集 $Q$ 的极点（含 $S_1$ 与整段远弧）得内近似 $\mathcal F_Q$；真实 $\mathcal F$ 居中。数值几何（二分精度 $10^{-6}$ m，脚本见《问题二_证明笔记.md》§3）：

| 区域 | 含义 | $x$ 范围 | $y$ 半宽极大值 | 可达 $\lvert\psi\rvert$ |
|---|---|---|---|---|
| $r_1\in[5,1500]$ | | | | |
| $\mathcal F_0$ | 外近似（中心线段两端 $1000$ m 圆之交） | $[500.000000,\ 1005.000000]$ | $\pm664.261808$ | $41.436130525^\circ$ |

**关键结论：最优设计与口径无关。** 最优设计 $(1000,38^\circ)$ 同时属于 $\mathcal F_Q\subset\mathcal F\subset\mathcal F_0$，**故无论采用哪一种口径，最优设计与结论都不变**。需精确说明"边界"的归属：

- $\mathcal F_Q$ 在 $\psi=38^\circ$ 处的 $\rho$ 上界恰为 $1000.000$ m（由约束 $\lvert S_2\rvert\le1000$ m 决定），故 $(1000,38^\circ)$ 落在 **$\mathcal F_Q$ 的边界**上；
- 而 $\mathcal F_0$ 在同一方向的 $\rho$ 上界是 $1003.935$ m，$\mathcal F$ 为 $1003.880$ m——**都不是 $1000$ m**；
- 因此"最优点被**透镜**边界顶住"这一说法应读作"被**保守内近似 $\mathcal F_Q$** 的边界顶住"。$\mathcal F_0/\mathcal F$ 约束下的最优在 $\rho\approx1003.9$ m，其 $\mathbb E[D]=55.582$ m，与 $\rho=1000$ m 的 $55.629$ m **只差 $0.047$ m（$0.08\%$）**；而优化搜索的 $\rho$ 步长取 $10$ m，本来也只能取到 $1000$ m。故取 $\rho^*=1000$ m 是网格精度下的自然取值，且工程上无损。

下文用 $\mathcal F_0$ 作解析、用 $\mathcal F$（或保守的 $\mathcal F_Q$）作校核。

**几何意义（可解释性）。**

- $\mathcal F_0$ 是"源可能线段的两个端点各 $1000$ m 圆之交"——一个**透镜**；
- 偏角接近 $\pm90^\circ$ 的侧方点**不在可行域内**（$\psi=90^\circ$ 时 $x\approx0$，而透镜要求 $x\ge500$）：把第二点放在 $S_1$ 正侧方通常**根本听不到源**，这不是次优而是不可行；
- 这正是"为什么最优设计是前方偏一点"的**可行性**根源。

**与"朴素带状区域"的区别（重要）。** 一个常见做法是把候选区域取成"沿射线方向、半宽 $1000$ m 的带状矩形"。**它只是外放松，不是保证区域**：半宽只有在真实源恰好位于该处时才是到源的距离，源距未知时二者不等。反例：$S_2=(752.5,1000)$ 虽落在带宽边界上，但它到 $r_1=5$ m 的源、到 $r_1=1500$ m 的源均为 $1248.5$ m $>1000$ m，**两个都听不到**。正确的保证域是**透镜**（两端点 $1000$ m 圆之交）：半宽在中段约 $664$ m、向两端收敛到 $0$，与带状矩形的常数半宽有本质差别。

### 5.4 定位区域直径的解析近似

两楔形交在一般位置是四边形。记源处两视线夹角（交会角）为 $\alpha$，则由正弦定理与楔形张角 $2\delta$ 可写出四边形两组对边长度，再联合对角线与夹角关系，得到直径的一阶近似 $D\approx\frac{2\tan\delta}{\sin\alpha}\sqrt{r_1^2+r_2^2+2r_1r_2|\cos\alpha|}$（式 (6)，见《问题二_公式.md》§3），其中 $r_2$ 由 $r_1,\rho,\psi$ 的余弦定理给出，$\alpha$ 为两示向度的圆距离。

**适用范围（重要）。** 式 (6) 是**平行四边形近似**。在良态四边形处它很准，但误差分布是**双向重尾、且近退化处系统性低估**。对 $N=4\times10^4$ 组随机构型（采样 $r_1\in[50,1500]$ m、$\rho\in[400,1600]$ m、$\psi\in[5^\circ,60^\circ]$，剔除 $\alpha\le2\delta$ 与 $D_{\rm exact}\ge10^4$ m 的近退化构型）统计：相对误差中位 $+0.0305\%$、均值 $-0.214\%$、**最大正误差 $+68.37\%$、最大负误差 $-69.19\%$**；$|\varepsilon|$ 的 $90/99$ 分位为 $0.62\%/10.95\%$，$D_{\rm exact}$ 范围 $[14.11,\ 6490.21]$ m。按 $\alpha$ 分层可见低估随退化加剧：$\alpha\in[2.0,2.5)^\circ$ 中位 $-67.33\%$、$[2.5,3.0)^\circ$ $-49.67\%$、$[3.0,3.5)^\circ$ $-37.62\%$、$[10,20)^\circ$ $-1.62\%$、$[40,180)^\circ$ $+0.0305\%$；不设 $D<10^4$ m 门槛时最坏 $|\varepsilon|=86.04\%$（纯低估）。**当区域退化为三角形时失效**：设计 $(1003,38.25^\circ)$、$r_1=5$ m 时精确 $D=33.163357$ m，而式 (6) 给 $56.337088$ m（高估 $+69.88\%$）。退化发生在源离 $S_1$ 很近（$S_1$ 本身成为区域顶点）等情形。

> **事实性警示①**：式 (6) 只是一阶（平行四边形）近似，误差双向重尾（近退化处最大低估约 $-69\%$，含超长近退化区可达 $-86\%$；三角形退化处最大高估约 $+70\%$）。式 (6) **只能用于粗搜**（按估计值排序取前 $K$ 个候选），**必须**再用精确半平面交细化；**不得**用于"报告与最坏值"（见第 6 节算法）。复现命令见《问题二_证明笔记.md》§3。

### 5.5 优化模型与退化性

**（1）优化问题。** 目标是在候选区域（$\mathcal F_0$ 或更严的 $\mathcal F$）上最小化定位区域直径的期望，决策变量为 $S_2$ 的极坐标 $(\rho,\psi)$；期望对真源位置与两次示向度误差取，即**双重期望**（式 (7)，见《问题二_公式.md》§1）。辅问题把目标换成 $\operatorname{tr}\Sigma$。

**（2）双重期望的必要性。** 实际定位区域由**测得值**（含误差的示向度）决定，而非真实方位角；误差一方面平移区域、一方面改变交会角从而改变区域尺寸。**同先验、同设计**的对照（面积密度先验，见第 7 节表 3）显示误差的影响很小且**符号不定**：

| 设计 | 名义 $\mathbb E[D]$（源在轴上） | 含误差 MC 平均 $D$ | 相对差 |
|---|---|---|---|
| $(1000,38^\circ)$ | $64.91$ m | $64.71$ m（$N=4000$；表 3 同设计 $N=20000$ 给 $64.81$ m） | $-0.3\%$ |
| 正侧方 $(1000,90^\circ)$ | $119.3$ m | $118.35$ m | $-0.8\%$ |

机理上，误差只平移定位区域并轻微改变其尺寸。**正确结论是：$\mathbb E[\alpha]$ 基本不变（$=\alpha_{\rm true}$），误差不改变交会角的期望**（机理的论证见《问题二_证明笔记.md》§4 第 7 条）；含误差后的数值影响在 $\pm1\%$ 内、符号不定（表 3）。故用一阶（名义）目标做设计足够，但严谨表述仍应写成双重期望（式 (7)）。

**另需说明。** 设计优化阶段的期望只对 $r_1$ 取、且把源置于示向度轴线上（**一维先验**，第 2 节假设 4）；可行集 $P$ 的二维性（源还可偏离示向度 $\pm1^\circ$）由第 7 节表 3 的 Monte Carlo 校核。因 $\pm1^\circ$ 的角偏对 $r_2$ 与 $\alpha$ 的影响是二阶的，一维先验给出的设计对二维情形同样近似最优。

**（3）退化性（为什么必须鲁棒化）。** 已知 $r_1$ 时直径**不趋于 $0$**，其**真下确界**是 $r_1\sin\delta/\cos2\delta$（$r_1=1000$ m、$\delta=1^\circ$ 时为 $17.463044$ m，量级等价于 $r_1\tan\delta$）；若再计入"$S_2$ 处必须能测到示向度"即 $r_2>5$ m，则 $r_1=1000$ m 时的最小直径约 $22.5$ m。故**已知源距时的最优构型是"正交且尽量靠近源"**：$S_2\to G$（沿过 $G$ 且垂直于 $S_1G$ 的方向），$D$ 趋于上述下确界。结论不变：**最优第二点是正交且尽量靠近源**（受 $r_2>5$ m 盲区限制，只能尽量靠近而不能取 $S_2=G$）。几何上，楔形 $W_2$ 的顶点就在 $G$ 处，定位区域只能落在 $G$ 的**单侧**，可用横向宽度只有 $2\tan\delta\,r_1$ 的**一半**。

> **事实性警示④（下确界的量级，易错点）**：$D$ 的下确界是 $r_1\sin\delta/\cos2\delta$（$r_1=1000$ m 时 $17.463044$ m），**不是** $2\tan\delta\,r_1$（$34.910$ m）——后者是式 (6) 近似式在 $r_2\to0$ 处的产物，恰为真值的**两倍**。反例：$r_1=1000$ m、$S_2=1000\angle0.5^\circ$、$\theta_2$ 取真方位角时精确 $D=26.197$ m $<34.910$ m（推导与反例见《问题二_小证明.md》§3.2）。

因此本问的全部内容在于 $r_1$ 未知下的期望化/最坏化与"保证听到"的约束；这解释了为什么最优解不是某个固定的"几何构型"，而是"尽可能靠近源、同时满足必然可听"的位置——即透镜的**肩部**。（式 (6) 为平行四边形近似，退化情形以精确半平面交为准；$\beta=90^\circ$ 这一理想几何的进一步讨论见 5.6。）

**（4）最坏情况。** 对推荐设计 $(\rho^*,\psi^*)=(1000,38^\circ)$（属 $\mathcal F$ 与 $\mathcal F_Q$），沿先验支撑的最坏 $D$ 出现在 $r_1$ 接近上界 $1500$ m 处（交会角变小、区域拉长）。用精确直径复算（不含测向误差，即按真方位计算）：

| $r_1$/m | 5 | 50 | 100 | 200 | 300 | 500 | 750 | 1000 | 1250 | 1500 |
|---|---|---|---|---|---|---|---|---|---|---|
| $D$/m | 33.4 | 54.9 | 52.6 | 48.5 | 44.8 | 38.8 | 35.2 | 50.0 | 79.0 | **122.8** |
| $R^*=D/2$/m | 16.7 | 27.4 | 26.3 | 24.3 | 22.4 | 19.4 | 17.6 | 25.0 | 39.5 | **61.4** |

即 **最坏 $D\le123$ m、$R^*\le61.5$ m**（$r_1=1500$ m 处精确值 $D=122.815$ m、$R^*=61.408$ m）。此数在问题三的单源清除保证链中使用。

### 5.6 理想构型的思想与结论（正交几何解释层）

本小节是把"好"的理想形态讲清楚，用于解释最优设计为何落在透镜肩部，而**不承担推导**（完整推演见《问题二_公式.md》§3）。

**思想。** 对固定距离的两条视线，方位误差引起的位置误差按交会角正弦的倒数放大（bearings-only 定位的经典结论，文献 [8,9]）：交会角越接近直角越好。因此在**源距已知、两视线长度固定**的前提下，理想构型是两视线正交，且第二点尽量靠近源。

**结论一：正交条件是一族，不是一个点。** 在局部坐标下，"两视线正交"对**每个可能的源距** $r$ 各给出一个不同的理想第二点，它们分别落在**过 $G$（即距 $S_1$ 为 $r$ 的那一点）且垂直于 $S_1G$ 的直线**上（随 $G$ 变）；$h=0$ 的特例 $S_2=G$ 与 $r_2>5$ m 的盲区相悖，故正交族只作**解释层**、不作为可达设计。源距未知时"取正交"并不能确定 $S_2$；而且选错源距代价极大——数值上，对 $r_1=1000$ m 正交的点使 $\mathbb E[D]\approx167$ m，而对先验中段 $r_1\approx752$ m 正交的点仅 $\approx55.8$ m，后者已接近期望最优的 $55.6$ m。故"正交"是理解最优设计的**几何解释**，不能替代期望优化。

**结论二：正确做法是把正交条件约束到保证域内再取期望。** 即在整个透镜可行域上最小化 $\mathbb E[D]$。其解落在透镜肩部，并对先验**中段**的源近似正交（交会角随 $r_1$ 从约 $133^\circ$ 变到约 $41^\circ$，见第 7 节实验 3）；固定在错误的源距上会使 $\mathbb E[D]$ 差约 $3$ 倍（第 7 节实验 5′）。

**结论三：移动代价属问题三。** 若进一步考虑机器狗移动时间，可把目标写成"定位质量指标 + 移动时间"的加权和，第二项为路程除以速度。这属于问题三的调度目标；问题二只问"较好的定位效果"，故本章不并入。另需说明："$S_2$ 距原点不超过 $1800$ m"**并非题目约束**（机器狗坐标只受分量绝对值不超过 $2\times10^6$ m 的限制），此处仅作为可选的工程偏好。

## 6 算法设计与复杂度

### 6.1 主算法

```
算法 Q2：第二个检测点的选择
输入 : S1, θ1, 误差界 δ=1°, 先验 (r1 的分布), 目标 (D 或 trΣ)
输出 : 最优设计 (ρ*, ψ*), 候选区域 F

 1  构造凸紧集 Q = W1 ∩ B(S1,1500) ∩ B(O,1800) 的极点 ext(Q):
      S1、以及远弧 r_max∠φ 上的**全部** φ∈[-δ,δ]
      （Q ⊇ cl(P) 且凸紧；远弧是连续统，数值上其最远点必在弧端点，故可仅取 φ=±δ 实现）
 2  F_Q ← ∩_{G∈ext(Q)} B(G,1000)                # 保守内近似（命题5.2）
    F_0 ← B(S1+5u,1000) ∩ B(S1+1500u,1000)      # 外近似（透镜），u=(cosθ1,sinθ1)
    工作可行域取 F_0；用 F_Q 校核最优解（二者夹逼真实域 F）
 3  设 S2 = (ρ cosψ, ρ sinψ)，网格 (ρ,ψ)
 4  对每个网格点且 S2∈F_0:
 5      用解析式(6)**仅作粗搜**（排序取前 K 个候选）
 6  取解析最优 (ρ0,ψ0)，在其邻域用小步长网格
 7      用精确半平面交(问题一算法)重算 E[D]，得 (ρ*,ψ*)
 8  返回 (ρ*,ψ*), F_Q, F_0, 以及最坏 r1 下的 D_max、R*_max
```

算法分三阶段：**构造可行域**（步 1–2）→ **解析粗搜**（步 3–5）→ **精确细化**（步 6–7）。这样设计的理由是：可行域的形状决定了"哪些点根本不允许放"，必须先定下来；解析式虽在退化情形不可靠，但作为**粗定位**足够快；只有最优邻域才值得付精确半平面交的代价。

### 6.2 关键子程序与复杂度

- **精确直径**：由"边界线两两求交 + 全约束可行性筛选"直接枚举两楔形交的顶点（含 $S_1$、$S_2$ 作顶点的三角形退化情形），复杂度 $O(1)$；**不使用大框裁剪**，从而避开截断（无界域被误判为有界、或近退化域直径被低估）的隐患。
- **网格搜索**：解析式 $O(1)$/格点；精确细化只在最优邻域做，故总代价 $\approx$ 解析网格规模。本章网格取 $\rho$ 步 $10$ m、$\psi$ 步 $1^\circ$，最优邻域细化到 $\rho$ 步 $5$ m、$\psi$ 步 $1^\circ$。
- **无界格点处理**：$\alpha\le2\delta$（即两示向度夹角过小）的格点目标记 $+\infty$ 并排除，全域搜索中约占 $4.4\%$。

**实验 3（交会角随 $r_1$ 变化）**　设计 $(1003,38.25^\circ)$ 下：$r_1=200/1000/1500$ m 时交会角约 $133.4^\circ/71.1^\circ/41.1^\circ$。故"最优交会角 $\approx90^\circ$"**只在源距离处于先验中部时近似成立**，不能写成常数结论。

**实验 4（最坏情况）**　见 5.5(4) 节表：**推荐**设计 $(1000,38^\circ)$ 的最坏 $D\le122.8$ m、$R^*\le61.4$ m（$r_1=1500$ m，不含误差口径）。含误差的最坏由表 3 给出（约 $133$ m）。

**实验 5（对照：正侧方）**　把第二点放在正侧方（$\psi=90^\circ,\rho=1000$）：$U(5,1500)$ 下精确 $\mathbb E[D]=91.6$ m，面积密度 $\propto r_1$ 下 $119.3$ m；且在 $r_1=1500$ m 时 $r_2=1802.8$ m $>1500$ m，**不满足接收保证**。含误差 Monte Carlo 下其平均 $D=118.4$ m，而最优设计为 $64.8$ m，**差约 $1.83$ 倍**。

**实验 5′（正交几何对照，配合 5.6 节）**　把"$\beta=90^\circ$ 正交"落实到具体源距，与期望最优对照（$U(5,1500)$ 一维先验、精确半平面交）。表中对每个设计**逐点实算**判定其集合归属。

|---|---|---|---|---|---|---|---|

结论：正交几何若**固定在错误的 $r$** 上，期望直径可差约 $3$ 倍；把正交条件**约束到保证域、并按先验中段取期望**，才是最优策略——落在 $\mathcal F$ 边界上、对中段 $r_1$ 正交的点其 $\mathbb E[D]=55.90$ m，与期望最优的 $55.63$ m 几乎相同，这正是 $(1000,38^\circ)$ 附近的解。

**实验 6（含误差 Monte Carlo，双重期望）**　真源按**面积密度** $\propto r_1$ 采样于 $P$，两次误差 $U(-1^\circ,1^\circ)$，$N=20000$。

**实验 7（真源隶属）**　用含误差示向度构造两楔形交区域，检验真源是否落在其中：$5000$ 组**零违反**。这验证了集合隶属结论"真源必属定位区域"，同时校核实现。

**验证结论**：候选区域（透镜）与最优设计经解析、精确几何、含误差 Monte Carlo 三方一致；最优设计在 $S_1$ 前方 $\approx1000$ m、偏角 $\approx\pm38^\circ$；最坏情况 $D\le123$ m、$R^*\le61.5$ m（精确 $D=122.815$、$R^*=61.408$）；侧方方案既不可行（接收）又差约 $1.8$ 倍。

> **随机性结论的口径**：表 3 的各列数值及其"误差影响在 $\pm1\%$ 以内"的结论均为**数值实验现象，非客观概率**——它们由固定的 MC 样本产生，换随机种子或换先验会略变。

## 8 结论

1. **候选区域**：第二点应落在**透镜** $\mathcal F_0$（外近似；严格形式见命题 5.2 的夹逼 $\mathcal F_Q\subseteq\mathcal F\subseteq\mathcal F_0$，数值上真实域 $y$ 半宽 $664.261808\to651.027702$ m、$|\psi|$ 上限 $41.436130525^\circ\to40.436130525^\circ$，保守内近似 $\mathcal F_Q$ 再收到 $648.247783$ m / $40.409622109^\circ$）。其含义是：第二点必须同时落在"源最近可能位置"与"源最远可能位置"的 $1000$ m 内，才能**保证**听到源。最优设计 $(1000,38^\circ)$ 即使按最保守的 $\mathcal F_Q$ 也属可行，故结论稳健。**偏角接近 $\pm90^\circ$ 的侧方点不在候选区域内。**
2. **选择策略（最优设计）**：把第二点放在 $S_1$ 前方约 $1000\sim1125$ m、偏离示向度约 $\pm30^\circ\sim40^\circ$ 处（**透镜肩部**）。优先推荐满足接收保证的 $(\rho^*,\psi^*)\approx(1000\text{ m},\pm38^\circ)$，此时 $\mathbb E[D]\approx55.6$ m（$U(5,1500)$ 先验），最坏 $D\le122.8$ m、$R^*\le61.4$ m（$r_1=1500$ m，不含误差口径；含误差最坏约 $133$ m）。**几何解释（5.6 节）**：该点对先验**中段**的源近似正交（交会角随 $r_1$ 从 $133^\circ$ 变到 $41^\circ$）；"$\beta=90^\circ$ 正交"只在源距已知时才给出确定的最优，且是"一族"而非一点——固定在错误的 $r$ 上会使 $\mathbb E[D]$ 差约 $3$ 倍（第 7 节实验 5′）。
3. **方法要点**：$r_1$ 未知是本题的全部难点（$r_1$ 已知则最优第二点正交且尽量靠近源，真下确界 $r_1\sin\delta/\cos2\delta$，见 5.5(3)）；必须对 $G$ 与误差取双重期望；$\sigma_\theta$ 应取 $2^\circ/\sqrt{12}=0.5774^\circ$；$\alpha\le2\delta$ 的构型不可定位，搜索中排除。正侧方 $1000$ m 方案比最优方案差约 $1.8$ 倍，且不满足接收保证。

## 9 理论依据与文献支撑

**（1）最优实验设计。** 把"第二点放哪"写成在可行域上最小化 $\mathbb E[D]$ 或 $\operatorname{tr}\Sigma$，属于最优实验设计（文献 [15]）与测向定位精度分析（文献 [8,9]）的标准框架。本章主指标取几何直径 $D$（与本问"定位区域"一致），统计量 $\operatorname{tr}\Sigma$ 作为辅助，二者结论一致，互为印证。

**（2）凸集与极点。** 候选区域 $\mathcal F$ 闭凸（它是一族凸函数 $\|S_2-G\|$ 的最大值的下水平集）。其严格的解析夹逼为 $\mathcal F_Q\subseteq\mathcal F\subseteq\mathcal F_0$：内近似 $\mathcal F_Q$ 取**凸紧集** $Q=W_1\cap B(S_1,1500)\cap B(O,1800)$ 的极点（$\operatorname{cl}(P)\subseteq Q$；凸紧集上凸函数最大值在极点取得，问题一引理 A.2），外近似 $\mathcal F_0$ 取 $\operatorname{cl}(P)$ 内的两个极端点。**注意**：$P$ 因约束 $r_1>5$ m 严格而**非闭且不凸**（非凸深度仅 $0.76$ mm，见 5.1 节），且 $S_1\notin\operatorname{conv}(P)$、$S_1\in Q$，故**不能**写成"$Q=\operatorname{conv}(P)$"或"$\mathcal F$ 等于对 $P$（或 $\operatorname{conv}(P)$）的极点取交"；内近似的正确依据是 $\operatorname{cl}(P)\subseteq Q$ 与 $Q$ 凸紧，$\lvert S_2\rvert\le1000$ 这一约束来自 $Q$ 的极点 $S_1$。完整的极点分析与成员判定见 `main/问题二/问题二审查报告.md` §0–§1，本节的集合定义与命题陈述见《问题二_公式.md》§1–§2。

**（3）集合隶属。** "真源必落在两楔形交区域内"不依赖误差分布与独立性（文献 [3,4]），故设计目标的期望化只用于**优化**，而**保证性**（真源隶属、必然接收）是确定性的。

## 附录 B　Python 参考实现

> 依赖 `numpy`。以下为精简版；**它依赖问题一的 `wedge_halfplanes`（即问题一的楔形半平面生成函数，本模块不重复实现几何代码）**，调用精确直径函数时须将该函数传入 `wedge_halfplanes=` 参数。

```python
# -*- coding: utf-8 -*-
import math
import numpy as np

D2R = math.pi / 180.0
DELTA = 1.0


def bearing(S, P):
    return math.degrees(math.atan2(P[1] - S[1], P[0] - S[0])) % 360.0


def dcirc(a, b):
    return abs((a - b + 180.0) % 360.0 - 180.0)


def line_inter(h1, h2):
    (q1, n1), (q2, n2) = h1, h2
    det = n1[0] * n2[1] - n1[1] * n2[0]
    if abs(det) < 1e-14:
        return None
    b1 = float(np.dot(n1, q1)); b2 = float(np.dot(n2, q2))
    return np.array([(b1 * n2[1] - b2 * n1[1]) / det, (n1[0] * b2 - n2[0] * b1) / det])


def feasible(p, H, tol=1e-6):
    return all(float(np.dot(n, p - q)) >= -tol for q, n in H)


def exact_diameter(S1, S2, th1, th2, half=DELTA, wedge_halfplanes=None):
    """两楔形交的精确直径（含三角形退化；无界返回 inf）。"""
    if dcirc(th1, th2) <= 2 * half + 1e-12:
        return float("inf")
    H1 = wedge_halfplanes(S1, th1, half)
    H2 = wedge_halfplanes(S2, th2, half)
    H = H1 + H2
    pts = []
    for h1 in H1:
        for h2 in H2:
            p = line_inter(h1, h2)
            if p is not None and feasible(p, H):
                pts.append(p)
    for ap in (S1, S2):
        if feasible(ap, H):
            pts.append(ap)
    uniq = []
    for p in pts:
        if not any(np.linalg.norm(p - u) < 1e-7 for u in uniq):
            uniq.append(p)
    if len(uniq) < 2:
        return 0.0
    P = np.array(uniq)
    return max(float(np.linalg.norm(P[i] - P[j]))
               for i in range(len(P)) for j in range(i + 1, len(P)))


def lens(rho, psi, rmin=5.0, rmax=1500.0, R=1000.0):
    p = np.array([rho * math.cos(psi * D2R), rho * math.sin(psi * D2R)])
    return (np.linalg.norm(p - np.array([rmin, 0.0])) <= R
            and np.linalg.norm(p - np.array([rmax, 0.0])) <= R)


def design_expected_D(prior="u5", rho=1000.0, psi=38.0, exact=True, wedge_halfplanes=None):
    r1s = np.arange(5.0, 1500.0 + 1e-9, 5.0)
    if prior == "u200":
        r1s = r1s[r1s >= 200.0]
    w = r1s.copy() if prior == "r1" else np.ones_like(r1s)
    w = w / w.sum()
    S1 = np.array([0.0, 0.0]); G0 = None
    S2 = np.array([rho * math.cos(psi * D2R), rho * math.sin(psi * D2R)])
    acc = 0.0
    for r1, wi in zip(r1s, w):
        G = np.array([r1, 0.0])
        th1 = bearing(S1, G); th2 = bearing(S2, G)
        if exact:
            d = exact_diameter(S1, S2, th1, th2, wedge_halfplanes=wedge_halfplanes)
        else:
            a = dcirc(th1, th2)
            if a <= 2 * DELTA:
                d = float("inf")
            else:
                r2 = float(np.linalg.norm(S2 - G))
                d = (2 * math.tan(DELTA * D2R) / math.sin(a * D2R)) * \
                    math.sqrt(r1 * r1 + r2 * r2 + 2 * r1 * r2 * abs(math.cos(a * D2R)))
        if not math.isfinite(d):
            return float("inf")
        acc += wi * d
    return acc
```
