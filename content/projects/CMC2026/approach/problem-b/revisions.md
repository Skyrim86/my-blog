### 2 问题 1：定位区域直径与覆盖

**几何模型**：在 $S_i$ 测得示向度 $\theta_i$，真实方位角 ∈$[\theta_i-1^\circ,\theta_i+1^\circ]$ → 构成一个**角度楔形**（夹角 2°）；$n$ 个检测点的定位区域 = 所有楔形的**交集** = 由 $2n$ 个半平面围成的凸多边形。

**算法（半平面交 / LP-type，期望 $O(n\log n)$）**

1. 每个楔形写成 2 个半平面（射线左侧/右侧）；
2. 全部 $2n$ 个半平面求交 → 随机增量 LP 或按极角排序的增量算法；
3. 得凸多边形顶点集 $V$；
4. **边界情形必须讨论**：交集为空 → 观测互相矛盾（不可能是同一源）；交集无界 → 两楔形方向近平行，**直径 $=\infty$，判定"不可定位"**；
5. 直径：$|V|\le 2n$ 很小 → 直接 $O(|V|^2)$ 枚举最远点对即可（也可用旋转卡壳显专业度）。

**"以定位区域直径为直径的圆能否覆盖该区域？"**

- 一般**不能**。反例：三角形 $(0,0),(1,0),(0.5,0.7)$，直径 $d=1$，以最远点对中点为心、$d/2=0.5$ 为半径的圆不覆盖 $(0.5,0.7)$。
- 严格工具：**Jung 定理** —— 平面内直径 $d$ 的集合必被半径 $\le d/\sqrt3$ 的圆覆盖 → 所需圆直径可达 $2d/\sqrt3\approx1.155d$。
- 工程判据：用**最小包围圆**（Welzl 算法，期望 $O(n)$）算真实半径 $R^*$；则 $2R^*\le d$ ⇒ 可覆盖（以圆域最远点对中点为心即可）；否则须用 $2R^*$。
- 与交会角的关系：定位误差 $\propto \dfrac{d_1 \cdot \Delta\theta}{\sin\alpha}$（$\alpha$ 为交会角）→ $\alpha\to90^\circ$ 最准，$\alpha\to0^\circ/180^\circ$ 退化。
- 论文写法：不要只回答"能/不能"，给出**充要条件 + 反例 + 修正方案（最小包围圆）**。

### 3 问题 2：第二个检测点的选择策略

**要先把"好"量化**（至少给两个指标并权衡）：

- 几何：定位区域**直径 / 面积**期望最小；
- 统计：位置协方差 $\det/\mathrm{tr}$ 最小（GDOP），$\sigma_p^2\propto \dfrac{d_1^2\sigma_\theta^2}{\sin^2\alpha}$；
- 稳健：因为源位置未知 → 用 $\min_{S_2}\ \mathbb{E}_G[f]$，或 minimax（最小化最坏情形直径）。

**不确定性结构**：源在 $S_1$ 的射线上，距离受有效接收半径约束（$\le1500$ m 才有信号）；先验可取 $d_1\in[0,1500]$ 的均匀分布，或按面密度均匀推出 $\propto d_1$ 的径向密度（写清假设）。**约束**：$S_2$ 要能听到源，用下界保证 → $|S_2-G|\le1000$ m。

**优化模型**

$$\min_{S_2\in\text{目标圆}}\ \mathbb{E}_G\big[f(\text{定位区域})\big]\quad \text{s.t.}\ |S_2-G|\le1000\ \text{m}$$

求解：把 $S_2$ 参数化为相对 $S_1$ 的极坐标 $(\rho,\varphi)$，二维网格搜索（几十×几十）→ 画 $f$ 等值图，给出最优 $(\rho^*,\varphi^*)$。

**预期结论（可先推导再数值验证）**

- 最优交会角约 $\alpha^*\in[70^\circ,110^\circ]$（≈90° 附近）；
- $\rho^*$ 取"满足检测约束的最大可达距离"（≈1000–1500 m），因为基线越长、夹角越接近直角则误差椭圆越小；
- **候选区域**：以 $S_1$ 为圆心、半径 $\rho\in[\rho_{\min},1500]$ m 的**两个环形扇区**，方位角约 $\theta_1\pm90^\circ\pm\omega$（$\omega$ 由可接受交会角区间 $[60^\circ,120^\circ]$ 反推）；若 $S_1$ 靠近区域边界，退化为"域内可达弧段"，并给出修正规则。
- **验证**：Monte Carlo（采样 $10^4$ 个 $G$，加均匀误差 $\pm1^\circ$）比较候选点与随机点的平均定位直径，报告提升百分比；同时给出"同点重复检测不能降误差"的说明。

### 4 问题 3：全向源的多源搜索—定位—清除

**信息模型**

- 频道状态机：未知 / 已确认有源（含位置估计与不确定域）/ 已清除；活跃集 $A$（初始 $|A|$ 未知，上限 16）。
- 概率占用栅格（格边长 50–100 m）：$p_k(\text{cell})$ = 频道 $k$ 的源在该格的后验概率。
- 三类返回的信息价值：`direction`：射线 + ±1° → 楔形约束；`no_signal`：**对全向源，该点周围 1000 m 内不可能存在此频道的源** → 后验置零；`near`：$d\le5$ m → 直接 `/clear`。

**定位流程**：两点交会 → 定位四边形，取质心/内切圆中心作为点估计 → 判据"估计误差是否 < 20 m"；若为否，沿估计方位**逐步逼近**（前进—重测—修正），直至 `near` 或误差 <20 m，然后 `/clear`。若 `/clear` 返回 `no_target_in_range`，说明估计偏了或已被清除 → 回收证据、重估、稍后重试。

**调度（总时间最小，这是得分主战场）**

- **发现层（粗扫描）**：六边形网格/螺旋线。保证性结论：全向源可被半径 1000 m 内任意点听到 → 六边形覆盖要求格距 $s\le\sqrt3\times1000\approx1732$ m，覆盖半径 1800 m 的圆域**只需约 4–6 个采样点**（可写成命题并证明"每个源必被至少一点检测到"）。
- **频道剪枝**：全频道遍历成本 ≈ $20\times5+19\times1=119$ s/点 → 必须剪枝：已清除频道永久排除；只扫活跃集（≤16）；先扫"曾被听到"的频道。
- **路径**：跨域移动分钟级（1800 m ≈ 360 s）→ 对候选动作排序用最近邻 + 2-opt/Or-opt；或直接**贪心信息增益**：每步选 $\dfrac{\text{期望信息增益}}{\text{移动}+\text{检测时间}}$ 最大的动作。
- **动态重规划**：一旦某频道被定位，把它插入任务序列（最近邻插入）"顺路清除"。
- **终止条件**：所有活跃频道被清除，或对每个频道给出"已扫描覆盖证明"。
- **风险**：20 min 是真实时钟（含 HTTP 往返）→ 请求不能太慢；日志 <2 MB → 严禁高频轮询/死循环。

### 5 问题 4：混入定向源

**新增难点**：`no_signal` 不再等价于"1000 m 内无源"（可能是定向源背向）。

**建模选项**

- **类型判别**：对频道 $k$ 构造假设 $H_1$（有源，朝向未知，边缘化）与 $H_0$（无源），用不同方位的多次检测做似然比。实用判据：若在两点 $P,Q$ 都无信号，而另一点 $R$ 有信号，且 $|P-G|,|Q-G|<1000$ m ⇒ 判为**定向源**；再用"有/无信号"的方位转换点反推覆盖锥朝向（覆盖范围 ±90°）。
- **覆盖性保证（关键，与问题 3 的本质差别）**：全向情形靠距离覆盖即可；定向情形必须让检测点落在源的覆盖半平面内。策略：对每个未清除频道做**多方位逼近**（至少 3 个相隔 ≥90° 的方位向可疑子区靠近），或对可疑区域做"绕行环测"。
- **栅格更新方式改变**：无信号时不再置零，而按覆盖锥先验做部分削弱（Bayes 边缘化朝向）。
- **效率取舍**：先清全向源（收益确定），再对残余频道集中做多方位攻坚；对"判定为定向"的阈值、绕行半径等参数在演练中标定。

### 6 工程实施流程与风险（问题 3/4 共用）

1. 先写**离线几何内核**（楔形交、半平面交、直径、面积、最小包围圆）并单元测试（含退化/无界用例）。
2. 写**模拟器客户端**（HTTP+JSON，串行请求、`request_id` 规则、超时重试、日志落盘 CSV）。
3. 写**演练分析器**：从日志重构时间分解、路径可视化、未清除频道的失败原因归类 → 调参依据。
4. 演练 20–30 局（不同随机案例），报告成功率/平均时间/方差。
5. 正式测试 3 次（机会有限）：留足余量，建议 **9/13 15:30 前完成**；测前检查网络、时间同步（±60 s 内）、端口 2026、日志大小、程序无死循环。
6. **风险清单**：同点误差固定（系统性偏差）、定向源隐藏、`near` 分支漏判、估计误差 >20 m 导致反复空清（每次白花 3 s）、HTTP 故障、正式机会不可重复。

### 7 验证路径

- 问题 1：Monte Carlo —— 已知真值反算示向度（加 ±1° 均匀误差），检验真值落在计算定位区域内的比例应为 100%；并与暴力采样算得的直径交叉验证。
- 问题 2：Monte Carlo 比较"候选点 vs 随机点 vs 理论最优交会角"的定位直径分布；对 $S_1$ 在域内不同位置做鲁棒性测试。
- 问题 3/4：模拟器演练的成功率与平均时间；**消融实验**（去掉信息增益排序 / 去掉频道剪枝，看时间增加多少）以证明策略有效性；覆盖性定理给出网格间距与最小有效半径的解析关系。

### 8 成熟度 / 边界 / 置信度

| 方法 | 成熟度 | 边界 |
|---|---|---|
| 半平面交、凸包、旋转卡壳、最小包围圆（Welzl）、Jung 定理 | TRL 9（教科书级） | 需专门处理空集/无界退化 |

**置信度**

- 问题 1：**高**。
- 问题 2：**高**（结论形式稳健：≈90° 交会角 + 尽量长基线 + 环扇区候选域）。
- 问题 3 / 4：**中**。

## 4 附件带来的新增事实与相应修订

附件 1、附件 2 均无嵌入图片，全部内容为文本，以下事实此前无法从赛题正文获知。

| 新增事实 | 对策略的影响 |
|---|---|
| 只有 4 条指令（/enter、/measure、/clear、/exit）；**移动与切换频道没有独立指令**，由相邻两次合法动作的位置与频道参数推断 | 动作序列就是（位置，频道）序列；路径优化等同于位置序列优化，不需要额外的移动指令开销 |
| 虚拟时间公式：/measure = 移动距离/5 + 切换标志×1 + 5；/clear = 移动距离/5 + 3（未发现）或 +5（成功）；/enter 与 /exit 不耗时 | 单点全频道遍历 = 119 s；时间账可以精确写成公式 |
| /clear 的 `channel` 只是目标频道，**不切换测向机频道、不产生切换耗时**；只有合法 /measure 会更新当前频道 | 两次检测之间插入清除不会额外增加切换开销 |
| /clear 只在 20 m 内成功，且与覆盖角无关；未发现耗时 3 s、成功 5 s（光学 3 s + 激光 2 s） | 清除的几何判据是 $D\le40$ m；失败一次只花 3 s，但仍进入平均时间，应避免 |
| `near` 判据为"距离 ≤5 m 且在覆盖角内"，此时不返回 `svd_deg` | 得到示向度即说明 $r_1>5$ m，这成为问题 2 先验的可证明下界 |
| 每局存在**幂等记录上限**，超限返回 HTTP 429（数值未公布） | 动作次数存在隐藏上限，须在演练中实测；这是"约 200 条动作"之外唯一可能收紧预算的因素 |
