## 2.1 问题与基本思路

求方程的根，即寻找 `x*` 使 `f(x*) = 0`。除少数特殊方程外，没有求根公式，只能迭代逼近。

迭代法的一般形式：

```
给定初值 x₀，按 x_{k+1} = g(x_k) 产生序列 {x_k}
```

要回答三个问题：**收不收敛、收敛多快、什么时候停**。

## 2.2 二分法

**前提**：`f` 在 `[a, b]` 上连续且 `f(a)·f(b) < 0`（介值定理保证有根）。

每次取中点 `c = (a + b) / 2`，用 `f(c)` 的符号把含根区间缩小一半：

```
若 f(a)·f(c) < 0，则 b ← c；否则 a ← c
```

`n` 次迭代后区间长度为 `(b − a) / 2^n`，误差

```
|x_n − x*| ≤ (b − a) / 2^(n+1)
```

- **优点**：只要前提成立就一定收敛，误差有先验估计。
- **缺点**：收敛速度是**线性**的（每步误差减半），且无法求偶数重根。

## 2.3 不动点迭代与收敛条件

把 `f(x) = 0` 改写成 `x = g(x)`，再迭代 `x_{k+1} = g(x_k)`。

**收敛定理**：若 `g` 在 `[a, b]` 上满足

1. 对任意 `x ∈ [a, b]` 有 `g(x) ∈ [a, b]`（自映射）；
2. `g` 可导且存在 `L < 1` 使 `|g′(x)| ≤ L` 对一切 `x ∈ [a, b]` 成立（压缩），

则迭代对任意初值收敛到唯一不动点，且有误差估计

```
|x_k − x*| ≤ L^k / (1 − L) · |x₁ − x₀|
```

收敛速度由 `|g′(x*)|` 决定：`L` 越小越快。

## 2.4 牛顿法

取 `g(x) = x − f(x) / f′(x)`，得到牛顿迭代

```
x_{k+1} = x_k − f(x_k) / f′(x_k)
```

几何意义：用过点 `(x_k, f(x_k))` 的切线与 x 轴的交点作为下一次近似。

**收敛性**：在单根 `x*` 的邻域内 `f′ ≠ 0` 且 `f″` 连续时，牛顿法是**二阶收敛**的：

```
|x_{k+1} − x*| ≈ (|f″(x*)| / (2|f′(x*)|)) · |x_k − x*|²
```

**失效情形**：

- `f′(x_k) ≈ 0`（切线接近水平），迭代会跑到很远；
- 初值离根太远，可能不收敛或收敛到别的根；
- 重根处二阶收敛退化为线性收敛。

## 2.5 割线法

牛顿法每步要算导数。割线法改用差商代替导数：

```
x_{k+1} = x_k − f(x_k) · (x_k − x_{k−1}) / (f(x_k) − f(x_{k−1}))
```

只需两个初值、每步一次函数求值，收敛阶约为 **1.618**（黄金比），比二分法快、比牛顿法略慢，但省去了求导。

## 2.6 方法对比

| 方法 | 收敛阶 | 每步代价 | 需要导数 | 保证收敛 |
|---|---|---|---|---|
| 二分法 | 1（线性） | 1 次求值 | 否 | 是（需变号区间） |
| 不动点迭代 | 由 `g′` 决定 | 1 次求值 | 否 | 需压缩条件 |
| 牛顿法 | 2（单根） | 1 次求值 + 1 次求导 | 是 | 局部收敛 |
| 割线法 | ≈1.618 | 1 次求值 | 否 | 局部收敛 |

**实用策略**：先用二分法把区间缩到足够小、保证收敛，再切换到牛顿法或割线法快速收敛到底。

## 2.7 停机准则

常用三条，通常合起来用：

- `|x_{k+1} − x_k| < ε`——相邻两次迭代足够接近；
- `|f(x_{k+1})| < ε`——残差足够小；
- 迭代次数超过上限——防止死循环。

单看前两条都可能误判（例如函数很平坦时），所以加次数上限兜底。
