## 作业 2-1：二分法迭代次数

**题目** 用二分法求 `f(x) = x³ − x − 1 = 0` 在 `[1, 2]` 上的根，要使误差不超过 `10^−4`，至少需要迭代多少次？

**解**

二分法误差估计

```
|x_n − x*| ≤ (b − a) / 2^(n+1)
```

代入 `b − a = 1`，要求

```
1 / 2^(n+1) ≤ 10^−4
```

即 `2^(n+1) ≥ 10^4`，两边取对数

```
n + 1 ≥ 4 / lg2 ≈ 13.29
```

故 `n ≥ 12.29`，取 `n = 13` 次。

（注：`f(1) = −1 < 0`，`f(2) = 5 > 0`，满足变号前提。）

## 作业 2-2：牛顿法的收敛阶验证

**题目** 用牛顿法求 `√2`，即解 `f(x) = x² − 2 = 0`，取 `x₀ = 1`，写出迭代式并说明为什么收敛很快。

**解**

牛顿迭代式

```
x_{k+1} = x_k − (x_k² − 2) / (2 x_k) = (x_k + 2 / x_k) / 2
```

这是求平方根经典的巴比伦算法。前几步：

| k | x_k |
|---|---|
| 0 | 1 |
| 1 | 1.5 |
| 2 | 1.41666667 |
| 3 | 1.41421569 |
| 4 | 1.41421356 |

从第 3 步起已经精确到小数点后 8 位。

收敛快的理由：`x* = √2` 是单根，`f′(x*) = 2√2 ≠ 0`，`f″` 连续，满足牛顿法二阶收敛的条件，误差每步按平方缩减：

```
e_{k+1} ≈ (f″(x*) / (2 f′(x*))) · e_k² = (1 / (2√2)) · e_k²
```

`e₀ = 0.414` → `e₁ ≈ 0.0607` → `e₂ ≈ 0.0013` → `e₃ ≈ 6 × 10^−7`，与上表吻合。

## 作业 2-3：牛顿法失效的例子

**题目** 对 `f(x) = x³ − 2x + 2`，取 `x₀ = 0` 用牛顿法会发生什么？

**解**

牛顿迭代式

```
x_{k+1} = x_k − (x_k³ − 2x_k + 2) / (3x_k² − 2)
```

代入 `x₀ = 0`：`x₁ = 0 − 2 / (−2) = 1`。
代入 `x₁ = 1`：`x₂ = 1 − (1 − 2 + 2) / (3 − 2) = 1 − 1 = 0`。

于是序列在 `0` 与 `1` 之间**循环**，永远不收敛。原因是 `f′(0) = −2`、`f′(1) = 1` 都不为 0，但迭代恰好落在长度为 2 的周期上。

**结论**：牛顿法是局部收敛方法，初值选择不当会出现震荡甚至发散，实际实现必须设置迭代次数上限。
