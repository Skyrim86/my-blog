## 作业 1-1：有效数字与相对误差

**题目** 设精确值 `x = 3.1415926`，取近似值 `x* = 3.14`，求绝对误差、相对误差，并判断有几位有效数字。

**解**

绝对误差

```
|e| = |3.14 − 3.1415926| = 0.0015926 < 0.005 = 0.5 × 10^−2
```

相对误差

```
|ε| = 0.0015926 / 3.1415926 ≈ 5.07 × 10^−4
```

`3.14` 的百分位的半个单位是 `0.005`，绝对误差小于它，故从 3 开始的三位数字都是有效数字：**3 位有效数字**。

## 作业 1-2：灾难性抵消

**题目** 在双精度下计算 `y = √(x + 1) − √x`，其中 `x = 10^8`。分析直接计算的问题，并给出数值稳定的算法。

**解**

直接计算时 `√(10^8 + 1) ≈ 10000.0000499999`，而 `√(10^8) = 10000`，两者相减。前 5 位数字相同，相减后有效数字大量损失，相对误差被放大约

```
√(x + 1) / (√(x + 1) − √x) ≈ 2 × 10^4
```

倍。

改用有理化变形：

```
y = 1 / (√(x + 1) + √x)
```

此时分母是两个同号量相加，没有抵消，相对误差保持在 `u` 量级。代入 `x = 10^8`：

```
y ≈ 1 / 20000.00005 ≈ 5.0 × 10^−5
```

**结论**：等价变形消除了灾难性抵消，是处理此类问题的标准手法。

## 作业 1-3：浮点数模型

**题目** 证明对规格化浮点数，`fl(x) = x(1 + δ)` 中 `|δ| ≤ u = 2^−53`。

**解**

设 `x` 落在区间 `[2^e, 2^(e+1))` 内，该区间中相邻浮点数的间距为 `2^(e−52)`。舍入到最近浮点数，绝对误差不超过半个间距：

```
|fl(x) − x| ≤ 0.5 × 2^(e−52) = 2^(e−53)
```

于是

```
|δ| = |fl(x) − x| / |x| ≤ 2^(e−53) / 2^e = 2^−53 = u
```

得证。∎
