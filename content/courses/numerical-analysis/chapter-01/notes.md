## 1.1 误差的来源

记精确值为 `x`，近似值为 `x*`，则

- **绝对误差**：`e = x* − x`
- **相对误差**：`ε = (x* − x) / x`（`x ≠ 0`）

数值计算中的误差主要有四类：

1. **模型误差**——数学模型与实际问题之间的差距；
2. **观测误差**——输入数据本身不精确；
3. **截断误差**——用有限过程代替无限过程，例如用 Taylor 展开的前几项近似函数；
4. **舍入误差**——计算机用有限位数表示实数造成。

其中 3、4 两类是数值分析真正要控制的对象。

## 1.2 有效数字

若近似值的绝对误差不超过某一位的半个单位，则称该位及之前所有数字为**有效数字**。

有效数字与相对误差的关系：若近似值有 `n` 位有效数字，则

```
|ε| ≤ (1 / (2·a₁)) × 10^(−(n−1))
```

其中 `a₁` 是首位非零数字。这说明**有效数字位数直接给出相对误差的量级**——位数越多，相对误差越小。

注意：有效数字是相对概念，它衡量的是相对误差，而不是绝对误差。

## 1.3 浮点数与机器精度

IEEE 754 双精度（binary64）用 64 位表示一个数：

| 部分 | 位数 |
|---|---|
| 符号 | 1 |
| 阶码 | 11 |
| 尾数 | 52 |

规格化数的形式为

```
x = ±1.f × 2^e,      |e| ≤ 1023
```

52 位尾数对应约 15~16 位十进制有效数字。**机器精度**（unit roundoff）

```
u = 2^−53 ≈ 1.11 × 10^−16
```

是实数舍入到最近浮点数的相对误差上界：

```
fl(x) = x(1 + δ),     |δ| ≤ u
```

## 1.4 舍入误差与抵消

**灾难性抵消**：两个相近的数相减，会把各自的有效数字大量抵消，结果的相对误差被急剧放大。

例如用求根公式解 `x² + bx + c = 0`，当 `b² ≫ 4c` 时

```
x₁ = (−b + √(b² − 4c)) / 2
```

分子是两个几乎相等的数相减，有效数字损失严重。改用等价的

```
x₁ = 2c / (−b − √(b² − 4c))
```

即可避开相减，得到数值稳定的结果。

## 1.5 本章要点

- 误差分绝对/相对两类，数值分析更关心相对误差；
- 有效数字位数对应相对误差的量级；
- 浮点运算的基本模型 `fl(x) = x(1 + δ)`，`|δ| ≤ u`；
- 避免相近数相减，必要时做代数等价变形。
