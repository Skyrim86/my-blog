---
description: 打开本地博客管理页（新建/编辑内容、管理词表、查看改动、一键发布 + 内嵌预览）
---

启动本地管理页：

```bash
bash tools/admin/start.sh
```

约束：

- **用户想"一键打开、不碰命令行"时，告诉他双击仓库根目录的 `启动管理页.bat`**（或桌面快捷方式「博客管理页」）即可 —— 那是最省事的入口，不需要你代跑任何命令。它内部调用的就是下面这个脚本。
- `tools/admin/start.sh` 会 `exec node tools/admin/server.mjs`，是**阻塞进程，必须放到后台运行**（run_in_background），不要在前台等它结束。
- 启动后把 **http://127.0.0.1:1414/** 告诉用户，并说明：
  - 顶部三个页签是「新建 / 编辑 / 发布」，右侧是同屏预览（会自己带起 `hugo server`，已就绪后 iframe 会在保存后自动刷新）；
  - 「新建」页签的类型选择是两级：先选「文章 / 课程 / 项目」，再在第二行选具体类型（课程 ▸ 课程主页 / 章节 / 笔记 / 作业 / 实验，项目 ▸ 项目 / 子项目 / 项目文档）；
  - 「发布」页签走的是同一个 `scripts/push-blog.sh`（构建校验失败即中止，不提交不推送）；
  - 停止后台任务即关闭管理页，它启动的 hugo 预览也会一起关掉。
- 若 1414 端口被占用（提示 EADDRINUSE，多半是上一次没关），改用 `bash tools/admin/start.sh --port 1415`。
- 不需要为这件事探索仓库结构，也不需要额外起 `scripts/preview.sh`——管理页自带预览。
- 只在用户明确要求时再用 `--host 0.0.0.0`：那会把「能执行命令的页面」暴露到局域网，启动时会打印风险提示。
