期望与方差的运算法则（命题 1.1）

命题 期望与方差的运算法则 1.1 #

命题 设 X,YX,YX,Y 为随机变量（期望、方差均存在），a,b,c∈Ra,b,c\in\mathbb Ra,b,c∈R 为常数，则

E(aX+bY+c)=aEX+bEY+c,Var⁡(aX+b)=a2Var⁡(X), E(aX+bY+c)=aEX+bEY+c,\qquad \operatorname{Var}(aX+b)=a^2\operatorname{Var}(X), E(aX+bY+c)=aEX+bEY+c,Var(aX+b)=a2Var(X),Var⁡(X+Y)=Var⁡(X)+Var⁡(Y)+2Cov⁡(X,Y). \operatorname{Var}(X+Y)=\operatorname{Var}(X)+\operatorname{Var}(Y)+2\operatorname{Cov}(X,Y). Var(X+Y)=Var(X)+Var(Y)+2Cov(X,Y).
用途 回归里的估计量几乎都是 y1,…,yny_1,\dots,y_ny1​,…,yn​ 的线性组合，无偏性与方差全部由这两条公式推出。M1 §4 的每一行计算都在用这个引擎。
证明

证明 期望是积分（或求和），积分算子线性，故第一条成立。记 μX=EX\mu_X=EXμX​=EX，μY=EY\mu_Y=EYμY​=EY。由定义

Var⁡(aX+b)=E[(aX+b)−(aμX+b)]2=E[a2(X−μX)2]=a2Var⁡(X). \operatorname{Var}(aX+b)=E\big[(aX+b)-(a\mu_X+b)\big]^2=E\big[a^2(X-\mu_X)^2\big]=a^2\operatorname{Var}(X). Var(aX+b)=E[(aX+b)−(aμX​+b)]2=E[a2(X−μX​)2]=a2Var(X).

又 X+Y−μX−μY=(X−μX)+(Y−μY)X+Y-\mu_X-\mu_Y=(X-\mu_X)+(Y-\mu_Y)X+Y−μX​−μY​=(X−μX​)+(Y−μY​)，展开平方并取期望即得第三式。□\square□

注 方差公式对任意随机变量成立（不必独立、不必正态）。凡是用到"和的方差 = 方差之和"的地方，一律先查线性组合的方差公式的条件——独立不是默认前提。
