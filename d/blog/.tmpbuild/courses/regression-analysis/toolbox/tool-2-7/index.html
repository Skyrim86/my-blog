非中心卡方与二次型的期望（命题 2.7）

命题 非中心卡方与二次型的期望 2.7 #

命题 设 Y\mathbf YY 为随机向量，EY=μE\mathbf Y=\boldsymbol\muEY=μ，Cov⁡(Y)=Σ\operatorname{Cov}(\mathbf Y)=\SigmaCov(Y)=Σ，AAA 为对称常数矩阵，且 Y′AY\mathbf Y'A\mathbf YY′AY 可积，则

E[Y′AY]=tr⁡(AΣ)+μ′Aμ. E\big[\mathbf Y'A\mathbf Y\big]=\operatorname{tr}(A\Sigma)+\boldsymbol\mu'A\boldsymbol\mu. E[Y′AY]=tr(AΣ)+μ′Aμ.
用途 E(MSres)=σ2E(MS_{\rm res})=\sigma^2E(MSres​)=σ2 与 E(MSreg)=σ2+β12SxxE(MS_{\rm reg})=\sigma^2+\beta_1^2S_{xx}E(MSreg​)=σ2+β12​Sxx​ 是 FFF 检验的方向依据：原假设下两者期望相同，备择下差出 β12Sxx\beta_1^2S_{xx}β12​Sxx​——这个差（非中心参数 λ=β12Sxx/σ2\lambda=\beta_1^2S_{xx}/\sigma^2λ=β12​Sxx​/σ2）就是势的来源。
证明

证明 用迹的循环性 tr⁡(BC)=tr⁡(CB)\operatorname{tr}(BC)=\operatorname{tr}(CB)tr(BC)=tr(CB) 与"标量等于其迹"：

Y′AY=tr⁡(Y′AY)=tr⁡(AYY′), \mathbf Y'A\mathbf Y=\operatorname{tr}(\mathbf Y'A\mathbf Y)=\operatorname{tr}(A\mathbf Y\mathbf Y'), Y′AY=tr(Y′AY)=tr(AYY′),

取期望（期望与迹可交换，因迹是有限和），得 E[Y′AY]=tr⁡(A E(YY′))E[\mathbf Y'A\mathbf Y]=\operatorname{tr}\big(A\,E(\mathbf Y\mathbf Y')\big)E[Y′AY]=tr(AE(YY′))。又 E(YY′)=Σ+μμ′E(\mathbf Y\mathbf Y')=\Sigma+\boldsymbol\mu\boldsymbol\mu'E(YY′)=Σ+μμ′，故

E[Y′AY]=tr⁡(AΣ)+tr⁡(Aμμ′)=tr⁡(AΣ)+tr⁡(μ′Aμ)=tr⁡(AΣ)+μ′Aμ. □ E[\mathbf Y'A\mathbf Y]=\operatorname{tr}(A\Sigma)+\operatorname{tr}(A\boldsymbol\mu\boldsymbol\mu')=\operatorname{tr}(A\Sigma)+\operatorname{tr}(\boldsymbol\mu'A\boldsymbol\mu)=\operatorname{tr}(A\Sigma)+\boldsymbol\mu'A\boldsymbol\mu.\ \square E[Y′AY]=tr(AΣ)+tr(Aμμ′)=tr(AΣ)+tr(μ′Aμ)=tr(AΣ)+μ′Aμ. □

推论（χ2\chi^2χ2 的期望，由本条与幂等二次型的分布互相印证） Z∼N(0,In)\mathbf Z\sim N(\mathbf 0,I_n)Z∼N(0,In​)、AAA 幂等时 E[Z′AZ]=tr⁡(A)=rank⁡(A)E[\mathbf Z'A\mathbf Z]=\operatorname{tr}(A)=\operatorname{rank}(A)E[Z′AZ]=tr(A)=rank(A)，与卡方分布的 Eχr2=rE\chi^2_r=rEχr2​=r 一致。

命题（非中心卡方，F 检验的势用到） 若 Y∼Nn(μ,In)\mathbf Y\sim N_n(\boldsymbol\mu,I_n)Y∼Nn​(μ,In​)、AAA 对称幂等，则 Y′AY∼χr2(λ)\mathbf Y'A\mathbf Y\sim\chi^2_{r}(\lambda)Y′AY∼χr2​(λ)，非中心参数

λ=μ′Aμ=∥Aμ∥2, \lambda=\boldsymbol\mu'A\boldsymbol\mu=\|A\boldsymbol\mu\|^2, λ=μ′Aμ=∥Aμ∥2,

其期望为 r+λr+\lambdar+λ，且当且仅当 Aμ=0A\boldsymbol\mu=\mathbf 0Aμ=0 时退化为中心卡方 χr2\chi^2_rχr2​。

证明 沿用幂等二次型的分布的谱分解 A=PΛP′A=P\Lambda P'A=PΛP′，Λ=diag⁡(Ir,0)\Lambda=\operatorname{diag}(I_r,0)Λ=diag(Ir​,0)，令 U=P′Y∼Nn(P′μ,In)\mathbf U=P'\mathbf Y\sim N_n(P'\boldsymbol\mu,I_n)U=P′Y∼Nn​(P′μ,In​)，则 Y′AY=∑i=1rUi2\mathbf Y'A\mathbf Y=\sum_{i=1}^rU_i^2Y′AY=∑i=1r​Ui2​，其中 Ui∼N(νi,1)U_i\sim N(\nu_i,1)Ui​∼N(νi​,1) 独立，ν=P′μ\nu=P'\boldsymbol\muν=P′μ 的前 rrr 个分量。∑i=1rUi2\sum_{i=1}^r U_i^2∑i=1r​Ui2​ 的分布按定义即非中心卡方，非中心参数 ∑i≤rνi2=μ′PΛP′μ=μ′Aμ\sum_{i\le r}\nu_i^2=\boldsymbol\mu'P\Lambda P'\boldsymbol\mu=\boldsymbol\mu'A\boldsymbol\mu∑i≤r​νi2​=μ′PΛP′μ=μ′Aμ。又 EUi2=1+νi2E U_i^2=1+\nu_i^2EUi2​=1+νi2​（由期望与方差的运算法则），求和得 r+λr+\lambdar+λ。λ=0  ⟺  \lambda=0\iffλ=0⟺ 前 rrr 个 νi=0  ⟺  Aμ=PΛP′μ=0\nu_i=0\iff A\boldsymbol\mu=P\Lambda P'\boldsymbol\mu=0νi​=0⟺Aμ=PΛP′μ=0。□\square□
