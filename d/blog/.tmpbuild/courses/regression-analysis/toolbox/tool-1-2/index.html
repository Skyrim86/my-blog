条件期望、全期望律与全方差律（定义 1.2）

定义 条件期望、全期望律与全方差律 1.2 #

定义（条件期望） 给定 X=xX=xX=x，YYY 的条件分布（离散情形为条件概率质量函数，连续情形为条件密度）的均值称为条件期望，记 E(Y∣X=x)E(Y\mid X=x)E(Y∣X=x)。把 xxx 换回随机变量 XXX，得到随机变量 E(Y∣X)E(Y\mid X)E(Y∣X)。

命题（全期望律） E[E(Y∣X)]=E(Y)E\big[E(Y\mid X)\big]=E(Y)E[E(Y∣X)]=E(Y)。

命题（全方差律） Var⁡(Y)=E[Var⁡(Y∣X)]+Var⁡(E(Y∣X))\operatorname{Var}(Y)=E\big[\operatorname{Var}(Y\mid X)\big]+\operatorname{Var}\big(E(Y\mid X)\big)Var(Y)=E[Var(Y∣X)]+Var(E(Y∣X))。

用途 回归量 xxx 是随机变量时（M1 §16），β^1\hat\beta_1β^​1​ 的无条件均值与方差要先求条件矩再取期望——全期望律与全方差律就是这一步。
证明

证明 以离散情形写出，连续情形把求和换成积分，逐字相同。记 p(x)=P(X=x)p(x)=P(X=x)p(x)=P(X=x)。则

E[E(Y∣X)]=∑xE(Y∣X=x) p(x)=∑x∑yy p(y∣x)p(x)=∑yy∑xp(x,y)=E(Y). E\big[E(Y\mid X)\big]=\sum_x E(Y\mid X=x)\,p(x)=\sum_x\sum_y y\,p(y\mid x)p(x)=\sum_y y\sum_x p(x,y)=E(Y). E[E(Y∣X)]=x∑​E(Y∣X=x)p(x)=x∑​y∑​yp(y∣x)p(x)=y∑​yx∑​p(x,y)=E(Y).

再证全方差律。对每个 xxx，Var⁡(Y∣X=x)=E(Y2∣X=x)−(E(Y∣X=x))2\operatorname{Var}(Y\mid X=x)=E(Y^2\mid X=x)-\big(E(Y\mid X=x)\big)^2Var(Y∣X=x)=E(Y2∣X=x)−(E(Y∣X=x))2，故

E[Var⁡(Y∣X)]=E(Y2)−E[(E(Y∣X))2]. E[\operatorname{Var}(Y\mid X)]=E(Y^2)-E\big[(E(Y\mid X))^2\big]. E[Var(Y∣X)]=E(Y2)−E[(E(Y∣X))2].

又 Var⁡(E(Y∣X))=E[(E(Y∣X))2]−(E[E(Y∣X)])2=E[(E(Y∣X))2]−(EY)2\operatorname{Var}(E(Y\mid X))=E\big[(E(Y\mid X))^2\big]-\big(E[E(Y\mid X)]\big)^2=E\big[(E(Y\mid X))^2\big]-(EY)^2Var(E(Y∣X))=E[(E(Y∣X))2]−(E[E(Y∣X)])2=E[(E(Y∣X))2]−(EY)2。两式相加，−E[(E(Y∣X))2]-E[(E(Y\mid X))^2]−E[(E(Y∣X))2] 与 +E[(E(Y∣X))2]+E[(E(Y\mid X))^2]+E[(E(Y∣X))2] 相消，得 E(Y2)−(EY)2=Var⁡(Y)E(Y^2)-(EY)^2=\operatorname{Var}(Y)E(Y2)−(EY)2=Var(Y)。□\square□
