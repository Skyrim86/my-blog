线性估计类与 BLUE（定义 3.2）

定义 线性估计类与 BLUE 3.2 #

定义（线性估计） 设 θ\thetaθ 是模型参数（或参数的线性组合 θ=c′β\theta=c'\boldsymbol\betaθ=c′β）。若估计量可写成 θ^=∑i=1ndiyi\hat\theta=\sum_{i=1}^n d_iy_iθ^=∑i=1n​di​yi​（did_idi​ 只依赖已知的 xxx，不含未知参数），称 θ^\hat\thetaθ^ 为 θ\thetaθ 的线性估计。

定义（BLUE） 若 θ^\hat\thetaθ^ 线性、无偏，且对任何其他线性无偏估计 θ~\tilde\thetaθ~ 都有 Var⁡(θ^)≤Var⁡(θ~)\operatorname{Var}(\hat\theta)\le\operatorname{Var}(\tilde\theta)Var(θ^)≤Var(θ~)，称 θ^\hat\thetaθ^ 为 θ\thetaθ 的最优线性无偏估计量（Best Linear Unbiased Estimator）。

命题（类内最优点的唯一性） 若线性无偏估计类中存在方差最小者，则它（几乎必然）唯一。

用途 Gauss–Markov（M1 定理 4.3）说的是"线性无偏类内方差最小"。两个限定缺一不可：离开线性类，有偏估计完全可能赢——岭回归就是例子（M4）。
证明
