定义 极大似然估计 3.3 #

定义 设样本 y\mathbf yy 的联合密度（或质量函数）为 f(y;θ)f(\mathbf y;\theta)f(y;θ)，把它看作 θ\thetaθ 的函数称似然函数 L(θ;y)=f(y;θ)L(\theta;\mathbf y)=f(\mathbf y;\theta)L(θ;y)=f(y;θ)。极大似然估计（MLE） 是使 LLL 最大的 θ^MLE=arg⁡max⁡θL(θ;y)\hat\theta_{\rm MLE}=\arg\max_\theta L(\theta;\mathbf y)θ^MLE​=argmaxθ​L(θ;y)（等价地最大化 ℓ=ln⁡L\ell=\ln Lℓ=lnL）。若 ℓ\ellℓ 可微且最大值在内点，则 θ^\hat\thetaθ^ 满足得分方程 ∂ℓ/∂θ=0\partial\ell/\partial\theta=0∂ℓ/∂θ=0。

命题（不变性） 若 θ^\hat\thetaθ^ 是 θ\thetaθ 的 MLE，ggg 为任意函数，则 g(θ^)g(\hat\theta)g(θ^) 是 g(θ)g(\theta)g(θ) 的 MLE。
