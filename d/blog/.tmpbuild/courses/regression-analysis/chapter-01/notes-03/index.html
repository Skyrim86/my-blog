§12 两个应用案例#

§13 回归应用中的注意事项#

“回归结果能不能用"可以归纳为几条纪律。它们在技术上都对应后续模块的一个专门结论，这里只给出警告与出路。

13.1 适用范围与外推#

回归关系只在数据覆盖的范围内有根据。外推的危险不是计算错误，而是假设的失效：直线形式在观测区外没有支撑，且置信带与预测带向两侧张开的速度已经在提醒这件事（§9.5、§10.4）。

纪律：任何外推预测都必须能给出机理上的理由，否则只能称为"计算结果的延伸”，不能称为"预测"。

13.2 同方差假设与加权最小二乘#

OLS 对所有观测等权处理，其有效性（BLUE）建立于同方差假设 A2 之上。若真实误差方差随 xxx 变化（异方差），

  • β^\hat\betaβ^​ 仍然无偏（A1 未被破坏），
  • 但 se⁡(β^)\operatorname{se}(\hat\beta)se(β^​) 的计算失真，ttt 检验、置信区间的水平不再准确，
  • 效率上也不如加权最小二乘（WLS）：以 Var⁡(yi)\operatorname{Var}(y_i)Var(yi​) 的倒数为权。

异方差的诊断（残差图、正式检验）与修正（WLS、变换）属 M3 的内容。

13.3 异常点与强影响点#

同一组数据在不同异常点情形下，拟合结果可以差得很远。三类点必须区分（M3 §6 会给出量化指标）：

类型 特征 后果
离群点（outlier） yyy 方向远离其他点 拉高 RSSRSSRSS，抬高 σ^\hat\sigmaσ^，削弱所有检验
高杠杆点（high leverage） xxx 方向远离（xxx 的极端值） 对拟合线有"力矩"作用，即使 yyy 正常也能大幅改变 β^\hat\betaβ^​
强影响点（influential） 剔除后估计变化大 单个观测即可改变结论

纪律：不要盲目删除异常点。先判断是数据错误（记录/录入）、模型错误（漏了变量、形式不对），还是真实的重尾现象。删除只有在能给出独立理由时才可接受，且必须在报告中说明。

找异常点的第一步不是算指标，而是画图。残差图上肉眼可见的东西，比一屏诊断统计量更值得先看。

13.4 相关不等于因果#

有一个刺眼的例子：两个变量在机理上毫无因果联系，却能拟合出显著回归。原因是共同的趋势（时变、规模、季节）会让两个单调变化的序列表现出强相关，即所谓伪回归（spurious regression）。

三条判据（用回归谈因果的最低要求）：

  1. 时间先后：原因必须先于结果；
  2. 排除共同原因：是否存在同时驱动 xxx 与 yyy 的第三变量（混杂）——处理手段是多元回归中的"控制"（M2）、随机化实验或因果推断方法；
  3. 排除反向因果：y→xy\to xy→x 是否同样讲得通。

只用于预测时不需要因果性（§1.1）：只要关系在新数据上继续成立即可。芝加哥的降温例子把这条讲得很清楚——耗电量能预测气温，但不能调节气温。

13.5 其余风险清单#

  • 测量误差：yyy 的测量误差被并入 ϵ\epsilonϵ，只影响精度；xxx 的测量误差会使 β^1\hat\beta_1β^​1​ 向 000 收缩（衰减偏误，attenuation bias），且不随 nnn 增大而消失。
  • 模型形式：先画散点图。xxx 与 yyy 的关系是曲线时，直线拟合的 R2R^2R2 可能仍然可观，但残差图会暴露问题（M3）。
  • 样本量与设计：精度由 Var⁡(β^1)=σ2/Sxx\operatorname{Var}(\hat\beta_1)=\sigma^2/S_{xx}Var(β^​1​)=σ2/Sxx​ 决定，故增大 xxx 的变异范围与增加样本量同样重要；在区间两端取观测是最有效率的设计。
  • 多重比较：§9.5 注 9.9。
  • 报告规范：给出估计值、标准误或置信区间、样本量、Radj2R^2_{\rm adj}Radj2​、以及模型适用范围的明确陈述；只报 ppp 值是最低限度的做法。

14.4 与含截距模型的比较#

纪律

  1. 软件（如 R 的 lm(y ~ x + 0)）在无截距模型中报告的 Multiple R-squared 用的是 R02R_0^2R02​。不要用它比较两种模型——定义不同，比较无意义。

B.2 估计与推断的陷阱#

  1. 把残差当误差——eie_iei​ 是可算的统计量，ϵi\epsilon_iϵi​ 是不可观测的随机变量；eie_iei​ 之间有相关性（题 2.33），不能当作 iid 样本。（§2.3、§5.6）
  2. 把 A2 当成"独立"——A2 只要求不相关与同方差；独立是正态情形下的追加（§2.1）。
  3. 认为没有正态性就不能做 t 检验——无正态假设时 ttt 检验渐近成立（§15.4）。
  4. 把 ppp 值当作"H0H_0H0​ 为真的概率"——ppp 是"H0H_0H0​ 下观测到如此极端结果的概率"（§7.5）。
  5. 事后选择检验方向——看完 β^1\hat\beta_1β^​1​ 的符号再选单边，实际水平约翻倍（注 7.2）。
  6. 用 p<0.05p<0.05p<0.05 与 p>0.05p>0.05p>0.05 划断证据——ppp 是连续的证据度量；报 ppp 值而非"显著/不显著"的二元标签（§7.5）。
  7. 只看 ttt 比不看残差图——ttt 检验对模型形式完全沉默（§7.4 的四情形）。
  8. 把均值置信区间当作个体预测区间——前者不含 σ2\sigma^2σ2 项，宽度可差数倍（§10.1、例 10.5）。
  9. nnn 越大预测区间越窄到零——预测区间极限为 ±zα/2σ\pm z_{\alpha/2}\sigma±zα/2​σ，个体波动不可消除（命题 10.4）。
  10. 逐点置信区间当成同时置信带——先看数据再挑点会破坏覆盖率（注 9.9）。
  11. σ2\sigma^2σ2 的区间"看起来不宽"——n=20n=20n=20 时 σ2\sigma^2σ2 的 95% 区间跨度近 444 倍，σ^\hat\sigmaσ^ 的精度常被高估（§9.3）。
  12. 用 σ^\hat\sigmaσ^ 比较含截距与无截距模型时忽略自由度——n−1n-1n−1 与 n−2n-2n−2 不同（§14.4）。
  13. 外推当作预测——置信带/预测带张开就是代价的可视化（§9.5、§13.1）。
  14. β^1\hat\beta_1β^​1​ 显著就说明 xxx 是原因——显著性只说关联（§13.4）。
  15. 删除"碍事"的异常点——先判断是数据错误、模型错误还是真实重尾（§13.3、注 3.5）。

B.3 R2R^2R2 与拟合优度#

  1. R2R^2R2 高 = 模型好——§13.4 的伪回归是反例。
  2. R2R^2R2 高 = 模型充分——非线性关系的直线拟合也可能有高 R2R^2R2（§7.4、§11.4）。
  3. R2R^2R2 低 = 模型无用——§12.1 的医疗满意度案例 R2=0.43R^2=0.43R2=0.43 仍具决策价值。
  4. R2R^2R2 大 = 预测准——样本内变异分解与样本外预测精度是两件事（§11.4）。
  5. R2R^2R2 衡量斜率大小——R2R^2R2 无量纲、对单位不变（§11.4）。
  6. 用 R2R^2R2 比较不同模型——加变量必使 R2R^2R2 不减；Radj2R^2_{\rm adj}Radj2​ 稍好但也不是通用准则（§11.3、§11.4）。
  7. 用 R2R^2R2 比较含截距与过原点模型——定义不同，软件报告的是 R02R_0^2R02​（§14.4）。
  8. 认为 R2R^2R2 可以达到 111——同一 xxx 处有不同 yyy 重复观测时不可能（命题 11.6）。

B.4 Gauss–Markov 与最优性#

  1. 把 BLUE 说成"最好的估计"——限定在线性无偏类内（§4.4、线性估计与 BLUE）。
  2. 认为 OLS 在所有情形下都最优——异方差下 WLS 更有效（§13.2）；有偏估计可能有更小的 MSE（§4.4 讨论）。
  3. 认为 BLUE 需要正态——只需 A1、A2（§4.4）。
  4. 忘记"含截距"这一前提——残差和为零、分解式、R2R^2R2 定义都依赖它（注 3.5、注 8.2）。
  5. 在过原点模型里沿用 R2R^2R2 与 SSSSSS 分解——分解围绕原点而非均值（§14.3）。

B.5 数据与设计#

  1. 忽略 xxx 的变异范围——精度由 SxxS_{xx}Sxx​ 决定，两端取点最有效但牺牲曲率检验（§4.3、题 2.29）。
  2. 忽略测量误差的方向性——yyy 的误差只损精度，xxx 的误差使斜率向零收缩（§13.5）。
  3. 用 xxx 去"控制" yyy 却没有因果依据——控制需要因果，预测不需要（§1.1、§13.4）。
  4. 把随机设计与固定设计混用一套方差解释——无条件方差 E[σ2/Sxx]E[\sigma^2/S_{xx}]E[σ2/Sxx​] 大于条件方差（§16.2）。
  5. 对 nnn 小的非正态数据套用 tn−2t_{n-2}tn−2​ 临界值——考虑 bootstrap 或变换（§16.5）。

B.6 计算与实现#

  1. 用 ∑xi2−nxˉ2\sum x_i^2-n\bar x^2∑xi2​−nxˉ2 编程序——大数相减导致灾难性抵消，编程用中心化形式（§3.3）。
  2. 手抄 R 输出而不过问中间量——ttt 比 = 估计/标准误、F=t2F=t^2F=t2 、R2=SSreg/SSTR^2=SS_{\rm reg}/SS_{\rm T}R2=SSreg​/SST​ 这些恒等式应随手核对（§7.7、§8.7）。
  3. 盲信软件对无截距模型报的 Multiple R-squared——那是 R02R_0^2R02​（§14.4）。
