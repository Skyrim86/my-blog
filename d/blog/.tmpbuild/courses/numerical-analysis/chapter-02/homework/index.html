作业 2-3：牛顿法失效的例子#

题目 对 f(x)=x3−2x+2f(x) = x^3 - 2x + 2f(x)=x3−2x+2，取 x0=0x_0 = 0x0​=0 用牛顿法会发生什么？

解

牛顿迭代式

xk+1=xk−xk3−2xk+23xk2−2 x_{k+1} = x_k - \frac{x_k^3 - 2x_k + 2}{3x_k^2 - 2} xk+1​=xk​−3xk2​−2xk3​−2xk​+2​

代入 x0=0x_0 = 0x0​=0：x1=0−2−2=1x_1 = 0 - \dfrac{2}{-2} = 1x1​=0−−22​=1。

代入 x1=1x_1 = 1x1​=1：x2=1−1−2+23−2=1−1=0x_2 = 1 - \dfrac{1 - 2 + 2}{3 - 2} = 1 - 1 = 0x2​=1−3−21−2+2​=1−1=0。

于是序列在 000 与 111 之间循环，永远不收敛。原因是 f′(0)=−2f'(0) = -2f′(0)=−2、f′(1)=1f'(1) = 1f′(1)=1 都不为 000，但迭代恰好落在长度为 2 的周期上。

结论：牛顿法是局部收敛方法，初值选择不当会出现震荡甚至发散，实际实现必须设置迭代次数上限。
