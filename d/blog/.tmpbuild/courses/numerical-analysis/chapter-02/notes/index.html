2.1 问题与基本思路#

求方程的根，即寻找 x∗x^*x∗ 使 f(x∗)=0f(x^*) = 0f(x∗)=0。除少数特殊方程外没有求根公式，只能迭代逼近。

迭代法的一般形式：

xk+1=g(xk),k=0,1,2,… x_{k+1} = g(x_k), \qquad k = 0, 1, 2, \dots xk+1​=g(xk​),k=0,1,2,…

要回答三个问题：收不收敛、收敛多快、什么时候停。

2.2 二分法#

前提：fff 在 [a,b][a, b][a,b] 上连续且 f(a)⋅f(b)<0f(a) \cdot f(b) < 0f(a)⋅f(b)<0（介值定理保证有根）。

每次取中点 c=a+b2c = \dfrac{a+b}{2}c=2a+b​，用 f(c)f(c)f(c) 的符号把含根区间缩小一半：

f(a)⋅f(c)<0  ⟹  b←c,否则 a←c f(a) \cdot f(c) < 0 \implies b \leftarrow c, \qquad \text{否则 } a \leftarrow c f(a)⋅f(c)<0⟹b←c,否则 a←c

nnn 次迭代后区间长度为 b−a2n\dfrac{b-a}{2^n}2nb−a​，误差

∣xn−x∗∣≤b−a2n+1 |x_n - x^*| \le \frac{b-a}{2^{n+1}} ∣xn​−x∗∣≤2n+1b−a​
  • 优点：只要前提成立就一定收敛，误差有先验估计。
  • 缺点：收敛速度是线性的（每步误差减半），且无法求偶数重根。

2.3 不动点迭代与收敛条件#

把 f(x)=0f(x) = 0f(x)=0 改写成 x=g(x)x = g(x)x=g(x)，再迭代 xk+1=g(xk)x_{k+1} = g(x_k)xk+1​=g(xk​)。

收敛定理：若 ggg 在 [a,b][a, b][a,b] 上满足

  1. 对任意 x∈[a,b]x \in [a, b]x∈[a,b] 有 g(x)∈[a,b]g(x) \in [a, b]g(x)∈[a,b]（自映射）；
  2. ggg 可导且存在 L<1L < 1L<1 使 ∣g′(x)∣≤L|g'(x)| \le L∣g′(x)∣≤L 对一切 x∈[a,b]x \in [a, b]x∈[a,b] 成立（压缩），

则迭代对任意初值收敛到唯一不动点，且有误差估计

∣xk−x∗∣≤Lk1−L ∣x1−x0∣ |x_k - x^*| \le \frac{L^k}{1-L} \, |x_1 - x_0| ∣xk​−x∗∣≤1−LLk​∣x1​−x0​∣

收敛速度由 ∣g′(x∗)∣|g'(x^*)|∣g′(x∗)∣ 决定：LLL 越小越快。

2.4 牛顿法#

取 g(x)=x−f(x)f′(x)g(x) = x - \dfrac{f(x)}{f'(x)}g(x)=x−f′(x)f(x)​，得到牛顿迭代

xk+1=xk−f(xk)f′(xk) x_{k+1} = x_k - \frac{f(x_k)}{f'(x_k)} xk+1​=xk​−f′(xk​)f(xk​)​

几何意义：用过点 (xk,f(xk))\left(x_k, f(x_k)\right)(xk​,f(xk​)) 的切线与 xxx 轴的交点作为下一次近似。

收敛性：在单根 x∗x^*x∗ 的邻域内 f′≠0f' \ne 0f′=0 且 f′′f''f′′ 连续时，牛顿法是二阶收敛的：

∣xk+1−x∗∣≈∣f′′(x∗)∣2∣f′(x∗)∣ ∣xk−x∗∣2 |x_{k+1} - x^*| \approx \frac{|f''(x^*)|}{2|f'(x^*)|} \, |x_k - x^*|^2 ∣xk+1​−x∗∣≈2∣f′(x∗)∣∣f′′(x∗)∣​∣xk​−x∗∣2

失效情形：

  • f′(xk)≈0f'(x_k) \approx 0f′(xk​)≈0（切线接近水平），迭代会跑到很远；
  • 初值离根太远，可能不收敛或收敛到别的根；
  • 重根处二阶收敛退化为线性收敛。

2.5 割线法#

牛顿法每步要算导数。割线法改用差商代替导数：

xk+1=xk−f(xk)⋅xk−xk−1f(xk)−f(xk−1) x_{k+1} = x_k - f(x_k) \cdot \frac{x_k - x_{k-1}}{f(x_k) - f(x_{k-1})} xk+1​=xk​−f(xk​)⋅f(xk​)−f(xk−1​)xk​−xk−1​​

只需两个初值、每步一次函数求值，收敛阶约为 1.6181.6181.618（黄金比），比二分法快、比牛顿法略慢，但省去了求导。

2.6 方法对比#

方法 收敛阶 每步代价 需要导数 保证收敛
二分法 111（线性） 1 次求值 否 是（需变号区间）

实用策略：先用二分法把区间缩到足够小、保证收敛，再切换到牛顿法或割线法快速收敛到底。

2.7 停机准则#

常用三条，通常合起来用：

  • ∣xk+1−xk∣<ε|x_{k+1} - x_k| < \varepsilon∣xk+1​−xk​∣<ε——相邻两次迭代足够接近；
  • ∣f(xk+1)∣<ε|f(x_{k+1})| < \varepsilon∣f(xk+1​)∣<ε——残差足够小；
  • 迭代次数超过上限——防止死循环。

单看前两条都可能误判（例如函数很平坦时），所以要加次数上限兜底。
