这里记录学习过程中的笔记、做过的东西和踩过的坑。

本站有什么#

  • 课程：成体系的课程笔记，按章组织，每章分「学习笔记」与「作业」两块，讲义和答案可下载
  • 项目：做过的东西，附技术栈与源码地址
  • 文章：零散的技术记录与随想

关于本站#

  • 使用 Hugo 构建，主题为 PaperMod（源码 vendored 进仓库，定制走主题 hook）
  • 部署于 GitHub Pages，push 到 main 由 GitHub Actions 自动构建发布
  • 数学公式用自托管的 KaTeX 渲染，不依赖外部 CDN
  • 仓库结构与全部约定见 my-blog 的 AGENTS.md
