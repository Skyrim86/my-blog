问题二　第二个检测点的选择策略与候选区域#

本章依据赛题正文及其附录 1（干扰源特征）、**附录 2（测向机原理与交会定位法）**建立模型。

为保持正文连贯，本章只写思想、建模过程、算法设计与实验：全部公式与集合定义见《问题二_公式.md》，全部推导与小证明见《问题二_小证明.md》，验证口径、脚本对应与踩坑清单见 main/过程记录/问题二_证明笔记.md。

方法主线。 一次示向度给出的不是源的位置，而是"一条射线 + 一个距离区间"。于是策略分两层：(i) 理想几何——若源距已知，最优是让两条视线正交（β=90∘\beta=90^\circβ=90∘）且第二点尽量靠近源；(ii) 鲁棒化——源距未知时"正交"只是一个族（对每个可能的 rrr 各有一个理想点），必须把第二点限制在保证必然能听到源的候选区域内（透镜），再最小化定位区域直径的期望。本章用 E[D]\mathbb E[D]E[D] 作主指标、tr⁡Σ\operatorname{tr}\SigmatrΣ 作辅指标，给出透镜形候选区域与最优设计，并以解析式 + 精确半平面交 + Monte Carlo 三重验证。

4 问题分析#

选第二点要做三件事，缺一不可：

  1. 把"好"量化。 本问的产物是"定位区域"，故最自然的指标是定位区域直径 DDD（问题一已建立其算法与几何）；同时给出统计指标 tr⁡Σ\operatorname{tr}\SigmatrΣ（GDOP，文献 [8,9]）作为对照。两者一个保证型、一个平均型。
  2. 保证第二点能听到源。 否则测不到示向度，设计落空。由于 Reff≥1000R_{\rm eff}\ge1000Reff​≥1000 m 而具体值未知，唯一可保证的条件是 ∥S2−G∥≤1000\|S_2-G\|\le1000∥S2​−G∥≤1000 m 对所有可能的 GGG 成立。这给出了候选区域的形状。
  3. 在源位置未知下做鲁棒化。 若 r1r_1r1​ 已知，最优 S2S_2S2​ 是"正交且尽量靠近源"（受 r2>5r_2>5r2​>5 m 盲区限制，不能取 S2=GS_2=GS2​=G；见 5.5(3)）；因此本问的全部内容在于"r1r_1r1​ 未知"下的期望化/最坏化与接收保证。

问题一的结论在此处的接口：n=2n=2n=2 时定位区域是两楔形交（四边形或退化为三角形），其直径由问题一的算法给出；且当两示向度夹角 α≤2δ\alpha\le2\deltaα≤2δ 时区域无界（不可定位），这是搜索中必须排除的失败模式。

（1）几何指标（主）。 设两示向度决定定位区域（两楔形之交），其直径记为 DDD，它等于该区域顶点的最大两两距离；由问题一的结论，当交会角 α≤2δ\alpha\le2\deltaα≤2δ 时区域无界、D=+∞D=+\inftyD=+∞，这类构型不可定位、必须排除。

（2）统计指标（辅）。 测向定位的 Fisher 信息与位置协方差取 Torrieri 形式（文献 [8]），其中协方差的两个标量刻画分别为迹 tr⁡Σ\operatorname{tr}\SigmatrΣ 与行列式 det⁡Σ\det\SigmadetΣ（式 (2)，见《问题二_公式.md》§1）：二者均与交会角正弦的平方 sin⁡2α\sin^2\alphasin2α 成反比，但长度依赖不同——tr⁡Σ∝r12+r22\operatorname{tr}\Sigma\propto r_1^2+r_2^2trΣ∝r12​+r22​（两视线长度的平方和），det⁡Σ∝r12r22\det\Sigma\propto r_1^2r_2^2detΣ∝r12​r22​（两视线长度平方之积，不是平方和）。单调性须限定条件：在固定 r1r_1r1​ 与交会角 α\alphaα 时，tr⁡Σ\operatorname{tr}\SigmatrΣ 与 det⁡Σ\det\SigmadetΣ 随 r2r_2r2​ 严格递增（沿固定视线把第二点推远更差）；但作为 S2S_2S2​ 的函数，α\alphaα 也随之变化，故二者整体并非单调——最优设计是"r2r_2r2​ 小"与"α\alphaα 远离 0∘/180∘0^\circ/180^\circ0∘/180∘“的平衡。

5.6 理想构型的思想与结论（正交几何解释层）#

本小节是把"好"的理想形态讲清楚，用于解释最优设计为何落在透镜肩部，而不承担推导（完整推演见《问题二_公式.md》§3）。

思想。 对固定距离的两条视线，方位误差引起的位置误差按交会角正弦的倒数放大（bearings-only 定位的经典结论，文献 [8,9]）：交会角越接近直角越好。因此在源距已知、两视线长度固定的前提下，理想构型是两视线正交，且第二点尽量靠近源。

结论一：正交条件是一族，不是一个点。 在局部坐标下，“两视线正交"对每个可能的源距 rrr 各给出一个不同的理想第二点，它们分别落在过 GGG（即距 S1S_1S1​ 为 rrr 的那一点）且垂直于 S1GS_1GS1​G 的直线上（随 GGG 变）；h=0h=0h=0 的特例 S2=GS_2=GS2​=G 与 r2>5r_2>5r2​>5 m 的盲区相悖，故正交族只作解释层、不作为可达设计。源距未知时"取正交"并不能确定 S2S_2S2​；而且选错源距代价极大——数值上，对 r1=1000r_1=1000r1​=1000 m 正交的点使 E[D]≈167\mathbb E[D]\approx167E[D]≈167 m，而对先验中段 r1≈752r_1\approx752r1​≈752 m 正交的点仅 ≈55.8\approx55.8≈55.8 m，后者已接近期望最优的 55.655.655.6 m。故"正交"是理解最优设计的几何解释，不能替代期望优化。

结论二：正确做法是把正交条件约束到保证域内再取期望。 即在整个透镜可行域上最小化 E[D]\mathbb E[D]E[D]。其解落在透镜肩部，并对先验中段的源近似正交（交会角随 r1r_1r1​ 从约 133∘133^\circ133∘ 变到约 41∘41^\circ41∘，见第 7 节实验 3）；固定在错误的源距上会使 E[D]\mathbb E[D]E[D] 差约 333 倍（第 7 节实验 5′）。

# -*- coding: utf-8 -*-
import math
import numpy as np

D2R = math.pi / 180.0
DELTA = 1.0


def bearing(S, P):
    return math.degrees(math.atan2(P[1] - S[1], P[0] - S[0])) % 360.0


def dcirc(a, b):
    return abs((a - b + 180.0) % 360.0 - 180.0)


def line_inter(h1, h2):
    (q1, n1), (q2, n2) = h1, h2
    det = n1[0] * n2[1] - n1[1] * n2[0]
    if abs(det) < 1e-14:
        return None
    b1 = float(np.dot(n1, q1)); b2 = float(np.dot(n2, q2))
    return np.array([(b1 * n2[1] - b2 * n1[1]) / det, (n1[0] * b2 - n2[0] * b1) / det])


def feasible(p, H, tol=1e-6):
    return all(float(np.dot(n, p - q)) >= -tol for q, n in H)


def exact_diameter(S1, S2, th1, th2, half=DELTA, wedge_halfplanes=None):
    """两楔形交的精确直径（含三角形退化；无界返回 inf）。"""
    if dcirc(th1, th2) <= 2 * half + 1e-12:
        return float("inf")
    H1 = wedge_halfplanes(S1, th1, half)
    H2 = wedge_halfplanes(S2, th2, half)
    H = H1 + H2
    pts = []
    for h1 in H1:
        for h2 in H2:
            p = line_inter(h1, h2)
            if p is not None and feasible(p, H):
                pts.append(p)
    for ap in (S1, S2):
        if feasible(ap, H):
            pts.append(ap)
    uniq = []
    for p in pts:
        if not any(np.linalg.norm(p - u) < 1e-7 for u in uniq):
            uniq.append(p)
    if len(uniq) < 2:
        return 0.0
    P = np.array(uniq)
    return max(float(np.linalg.norm(P[i] - P[j]))
               for i in range(len(P)) for j in range(i + 1, len(P)))


def lens(rho, psi, rmin=5.0, rmax=1500.0, R=1000.0):
    p = np.array([rho * math.cos(psi * D2R), rho * math.sin(psi * D2R)])
    return (np.linalg.norm(p - np.array([rmin, 0.0])) <= R
            and np.linalg.norm(p - np.array([rmax, 0.0])) <= R)


def design_expected_D(prior="u5", rho=1000.0, psi=38.0, exact=True, wedge_halfplanes=None):
    r1s = np.arange(5.0, 1500.0 + 1e-9, 5.0)
    if prior == "u200":
        r1s = r1s[r1s >= 200.0]
    w = r1s.copy() if prior == "r1" else np.ones_like(r1s)
    w = w / w.sum()
    S1 = np.array([0.0, 0.0]); G0 = None
    S2 = np.array([rho * math.cos(psi * D2R), rho * math.sin(psi * D2R)])
    acc = 0.0
    for r1, wi in zip(r1s, w):
        G = np.array([r1, 0.0])
        th1 = bearing(S1, G); th2 = bearing(S2, G)
        if exact:
            d = exact_diameter(S1, S2, th1, th2, wedge_halfplanes=wedge_halfplanes)
        else:
            a = dcirc(th1, th2)
            if a <= 2 * DELTA:
                d = float("inf")
            else:
                r2 = float(np.linalg.norm(S2 - G))
                d = (2 * math.tan(DELTA * D2R) / math.sin(a * D2R)) * \
                    math.sqrt(r1 * r1 + r2 * r2 + 2 * r1 * r2 * abs(math.cos(a * D2R)))
        if not math.isfinite(d):
            return float("inf")
        acc += wi * d
    return acc
