1 问题重述#

在问题三的基础上，源中混入未知数量、未知朝向的定向源：定向源的辐射只覆盖"定向方向两侧各 90∘90^\circ90∘"（含边界），即一个闭半平面。其余条件（源数 10∼1610\sim1610∼16、频道 1∼201\sim201∼20 互不重复、有效接收半径 1000∼15001000\sim15001000∼1500 m、机器狗自原点出发、初始频道 111、确保全部清除）与问题三相同；同样需给出检测与清除策略算法、演练并完成三次正式测试、按表 1 填报。

2 模型假设#

  1. 平面假设（同问题三）。
  2. 有界误差假设：示向度误差 αi∈[θi±1∘]\alpha_i\in[\theta_i\pm1^\circ]αi​∈[θi​±1∘]，δ=1∘\delta=1^\circδ=1∘。

  6. 定向源的示向度仍指向源：附录 2 关于示向度的定义不区分源的类型，故一旦听到，所得方位角即为指向源的真实方位（±1∘\pm1^\circ±1∘）。
  7. 每频道至多一源；同一地点误差固定。

4 问题分析#

定向源带来的变化只在"负信息"的解释上：

  1. no_signal 的强度被削弱。 问题三里一次 no_signal 直接排除一个 100010001000 m 圆盘。定向源下，落在这个圆盘里的源只要"背对"观测点就会给出 no_signal，因此单个 no_signal 不排除任何位置（引理 1 见《问题四_小证明.md》§1）。排除必须靠**多个观测点从不同方向"包围"**该位置（定理 3 见《问题四_小证明.md》§2）。
  2. 采样密度必须提高。 由 §5.4，内层格距需从 3⋅1000\sqrt3\cdot10003​⋅1000 m 收紧到 ≤1000\le1000≤1000 m。
  3. 采样范围必须外扩。 位于圆域边界、朝向域外的源，其覆盖半平面几乎不含域内点，任何域内观测都无法排除它（§5.5 实测域内采样盲区 46.3%46.3\%46.3%）。必须把采样点布置到圆域外，且不是越远越好——外环半径有甜点区 Rout∈[1900,2000]R_{\rm out}\in[1900,2000]Rout​∈[1900,2000] m，本文取其下界 190019001900 m（更远反而重现盲区，更近则稳健角间隙不足）。
  4. 定位与清除不变。 由假设 6 与附录 2，示向度与朝向无关；/clear 只与距离（≤20\le20≤20 m）有关。故一旦听到，问题三的交会定位与清除链（R∗≤16R^*\le16R∗≤16 m 证书直接清除，否则按几何级兜底）完全适用。问题四的额外难度全部在检测与排除，成本增量来自采样密度与范围。

核心主线（三步）：① no_signal 的包围语义（引理 1）⇒\Rightarrow⇒ ② 排除判据与采样构型（定理 3 + 表 2/表 3）⇒\Rightarrow⇒ ③ 定位清除复用问题三的结论。三步的形式化陈述见《问题四_公式.md》，证明见《问题四_小证明.md》与《问题四_证明_下界.md》。

5 模型的建立#

5.1 定向源的接收模型#

由式 (1)（见《问题四_公式.md》），固定频道 kkk、固定观测点 ppp，若得到 no_signal，则必有"源不在 GGG 处，或 ∥p−G∥>Reff\lVert p-G\rVert>R_{\rm eff}∥p−G∥>Reff​，或 ppp 落在源的覆盖半平面外"三者之一成立，即式 (2)。观测点集 SkS_kSk​ 就是所有给出 no_signal 的点。注意 SkS_kSk​ 不含给出 direction 的点——给出示向度的点说明该处能听到源。

5.2 no_signal 的包围语义（引理 1）#

命题（引理 1，陈述见《问题四_公式.md》§3.1）：对任意位置 GGG 与任意单个 no_signal 观测点 ppp，存在某个定向方向 φ\varphiφ 使 ppp 落在 GGG 的覆盖半平面外，从而"源在 GGG 且定向方向为 φ\varphiφ“与"在 ppp 处 no_signal”完全相容。

结论含义：定向源下，对未形成包围的有限观测点集，“某频道在若干点 no_signal”不足以判定该频道为空；单个 no_signal 不排除任何位置，排除必须依赖包围（一旦凸包条件成立即可判空）。这正是问题四与问题三的关键差别（问题三里 no_signal 直接意味着"距离 >1000>1000>1000"）。

完整证明见《问题四_小证明.md》§1（含推论）。

9 理论依据与文献支撑#

（1）分离超平面定理. 定理 3 的核心是"点不属于闭凸集   ⟺  \iff⟺ 存在分离超平面”，这是凸分析的经典结论（文献 [1] 第 11 章）。它把"对所有朝向都存在探测点"这一连续量词的判定，化归为一个凸包/最大角间隙的有限计算。

（2）定向视场下的覆盖与包围. “单点覆盖不足以判定、需要多方向覆盖"在传感器网络与计算几何中有对应命题：定向传感器（摄像机/定向天线）的覆盖判定属"带视场的覆盖/守卫"问题，其保证性判据必须考虑视场方向；本章定理 3 给出的是"闭半平面视场 + 距离截断"下的精确形式（可由分离超平面自证，不依赖文献）。与本问题结构最接近的是限视距 watchman route与"有限视场追逃”（文献 [22]、[24]）：二者都说明"视距有限 ⇒ 保证性巡视必须绕行/多次访问"，这正是本章 §5.5 的采样构型与《问题四_证明_下界.md》引理 3/4 的文献对应物；“最少观察点数"形式的组合下界见 [25]。

（3）搜索论. 把 no_signal 解释为"对（位置, 朝向）联合假设的部分削弱”，与最优搜索论中"负信息即假设剪除"的框架一致（文献 [21]）；本章取最坏朝向（而非边缘化），对应鲁棒/悲观推断（文献 [3]）。注意：通道级的"负信息"不能用分组测试加速——题面 API 一次只能测一个频道（无合并检测），故 [37] 的思路不适用。

（4）问题级下界的文献支撑与后续改进方向. 下界四部分的文献对应物：行程项 = 最短开路精确 DP（[26]）与近似侧 [27]；判空项 = “负信息必须覆盖整个候选域”（[21]）与"外部证据点必须绕边界一圈"（[22]、[25]）；保证性巡视的结构成本 = 限视距巡视/追逃（[22]–[24]）。后续改进方向：① “巡检采样点与源清除点统一开链规划”（TSPN，[29]）——本文的"统一目标集 +++ 在线开路"已是其在线版本，进一步可求已知全部源位置时的离线精确最短开路作为性能参照；② 纯方位定位的最优观测几何（D-最优，交会角 ≈90∘\approx90^\circ≈90∘）用于选第二/第三视线（[30]）；③ “何时中断巡视去清源"的在线决策与竞争比（[31]）；④ 覆盖巡视路线的分解/生成树构造（[32]–[34]）与带界信息路径规划（[35]）。

def ring_points(radius, n, phase=0.0):
    return [(radius * math.cos(phase + 2 * math.pi * i / n),
             radius * math.sin(phase + 2 * math.pi * i / n)) for i in range(n)]


def dist(a, b):
    return math.hypot(a[0] - b[0], a[1] - b[1])


def angdiff(a, b):
    d = abs(a - b) % 360.0
    return min(d, 360.0 - d)


def circ180(a, b):
    """两条视线方向的无向夹角（0..90）。"""
    d = abs(a - b) % 180.0
    return min(d, 180.0 - d)

    return (math.cos(r), math.sin(r))


def perp(deg):
    r = math.radians(deg)
    return (-math.sin(r), math.cos(r))


def bearing(p, q):
    return math.degrees(math.atan2(q[1] - p[1], q[0] - p[0]))


def clamp(p, r=ARENA_R + 120.0):
    d = math.hypot(p[0], p[1])
    return (p[0], p[1]) if d <= r else (p[0] * r / d, p[1] * r / d)


def best_pair_angle(rays):
    best = 0.0
    for i in range(len(rays)):
        for j in range(i + 1, len(rays)):
            best = max(best, circ180(rays[i][2], rays[j][2]))
    return best


def hex_lattice(s, rmax):
    """六边形（三角）晶格，格距 s，取半径 <= rmax 的点（含中心）。"""
    pts = []
    ny = int(rmax / (s * math.sqrt(3) / 2)) + 2
    nx = int(rmax / s) + 2
    for j in range(-ny, ny + 1):
        y = j * s * math.sqrt(3) / 2
        for i in range(-nx, nx + 1):
            x = i * s + (j % 2) * s / 2
            if math.hypot(x, y) <= rmax:
                pts.append((x, y))
    return pts

# ==================== 凸区域：半平面/圆裁剪 + 最小包围圆 ====================
def _wedge_halfplanes(S, theta, half=DELTA):
    a1 = math.radians(theta - half)
    a2 = math.radians(theta + half)
    return [(S, (-math.sin(a1), math.cos(a1))), (S, (math.sin(a2), -math.cos(a2)))]


def _clip_hp(poly, q, n):
    """Sutherland-Hodgman：保留 n*(p-q) >= 0 的一侧。"""
    if not poly:
        return poly
    out = []
    m = len(poly)
    for i in range(m):
        a, b = poly[i], poly[(i + 1) % m]
        da = n[0] * (a[0] - q[0]) + n[1] * (a[1] - q[1])
        db = n[0] * (b[0] - q[0]) + n[1] * (b[1] - q[1])
        if da >= -1e-9:
            out.append(a)
        if (da > 1e-9 > db) or (db > 1e-9 > da):
            t = da / (da - db)
            out.append((a[0] + t * (b[0] - a[0]), a[1] + t * (b[1] - a[1])))
    return out


DISK_N = 120


def _disk_halfplanes(c, r):
    """用外接正 DISK_N 边形（含圆，保守）近似圆盘约束。"""
    R = r / math.cos(math.pi / DISK_N)
    out = []
    for k in range(DISK_N):
        ph = 2.0 * math.pi * k / DISK_N
        nx, ny = math.cos(ph), math.sin(ph)
        out.append(((c[0] + R * nx, c[1] + R * ny), (-nx, -ny)))
    return out


def _circum(a, b, c):
    ax, ay = a
    bx, by = b
    cx, cy = c
    d = 2.0 * (ax * (by - cy) + bx * (cy - ay) + cx * (ay - by))
    if abs(d) < 1e-12:
        best = (a[0], a[1], 0.0)
        for p, q in ((a, b), (b, c), (a, c)):
            r = dist(p, q) / 2.0
            if r > best[2]:
                best = ((p[0] + q[0]) / 2.0, (p[1] + q[1]) / 2.0, r)
        return best
    ux = ((ax * ax + ay * ay) * (by - cy) + (bx * bx + by * by) * (cy - ay)
          + (cx * cx + cy * cy) * (ay - by)) / d
    uy = ((ax * ax + ay * ay) * (cx - bx) + (bx * bx + by * by) * (ax - cx)
          + (cx * cx + cy * cy) * (bx - ax)) / d
    return (ux, uy, math.hypot(ax - ux, ay - uy))


def mec(points, seed=20260912):
    """Welzl 最小包围圆：返回 (cx, cy, R)。"""
    pts = list(points)
    if not pts:
        return None
    if len(pts) == 1:
        return (pts[0][0], pts[0][1], 0.0)
    random.Random(seed).shuffle(pts)

    def inside(p, c):
        return math.hypot(p[0] - c[0], p[1] - c[1]) <= c[2] + 1e-7

    c = None
    for i, p in enumerate(pts):
        if c is not None and inside(p, c):
            continue
        c = (p[0], p[1], 0.0)
        for j in range(i):
            q = pts[j]
            if inside(q, c):
                continue
            c = ((p[0] + q[0]) / 2.0, (p[1] + q[1]) / 2.0, dist(p, q) / 2.0)
            for k in range(j):
                r = pts[k]
                if inside(r, c):
                    continue
                c = _circum(p, q, r)
    return c


def region(rays):
    """由测向约束构造可行域。返回 dict(poly, cons, c, R) 或 None。"""
    if not rays:
        return None
    cons = list(_disk_halfplanes((0.0, 0.0), ARENA_R))
    for (x, y, th) in rays:
        cons.extend(_wedge_halfplanes((x, y), th))
        cons.extend(_disk_halfplanes((x, y), R_MAX + 0.5))
    poly = [(-BOX, -BOX), (BOX, -BOX), (BOX, BOX), (-BOX, BOX)]
    for (q, n) in cons:
        poly = _clip_hp(poly, q, n)
        if len(poly) < 3:
            return None
    c = mec(poly)
    if c is None:
        return None
    return {"poly": poly, "cons": cons, "c": (c[0], c[1]), "R": c[2]}


def _region_after(reg, S, theta):
    poly = reg["poly"]
    for (q, n) in _wedge_halfplanes(S, theta):
        poly = _clip_hp(poly, q, n)
        if len(poly) < 3:
            return None
    cc = mec(poly)
    if cc is None:
        return None
    return ((cc[0], cc[1]), cc[2])


def _spread(reg, k=10):
    poly = reg["poly"]
    pts = list(poly)
    m = len(poly)
    for i in range(m):
        a, b = poly[i], poly[(i + 1) % m]
        pts.append(((a[0] + b[0]) / 2.0, (a[1] + b[1]) / 2.0))
    if len(pts) <= k:
        return pts
    st = len(pts) / float(k)
    return [pts[int(i * st)] for i in range(k)]


def _poly_min_dist(p, poly):
    inside = True
    m = len(poly)
    sgn = 0
    for i in range(m):
        a, b = poly[i], poly[(i + 1) % m]
        cr = (b[0] - a[0]) * (p[1] - a[1]) - (b[1] - a[1]) * (p[0] - a[0])
        if cr > 1e-9:
            if sgn < 0:
                inside = False
                break
            sgn = 1
        elif cr < -1e-9:
            if sgn > 0:
                inside = False
                break
            sgn = -1
    if inside:
        return 0.0
    best = float("inf")
    for i in range(m):
        a, b = poly[i], poly[(i + 1) % m]
        dx, dy = b[0] - a[0], b[1] - a[1]
        L2 = dx * dx + dy * dy
        if L2 < 1e-18:
            d = dist(p, a)
        else:
            t = max(0.0, min(1.0, ((p[0] - a[0]) * dx + (p[1] - a[1]) * dy) / L2))
            d = math.hypot(p[0] - a[0] - t * dx, p[1] - a[1] - t * dy)
        if d < best:
            best = d
    return best


def predicted_R(reg, p):
    cx, cy = reg["c"]
    if math.hypot(p[0] - cx, p[1] - cy) < 1e-9:
        return None
    nr = _region_after(reg, p, bearing(p, (cx, cy)))
    return None if nr is None else nr[1]


def choose_view(reg, pos, avoid=None):
    """谨慎贪心选点：最小化「最坏情形后验 R*」+ λ*移动代价。"""
    cx, cy = reg["c"]
    R = reg["R"]
    samples = _spread(reg, 10)
    reach = max(0.0, SAFE_RANGE ** 2 - R * R) ** 0.5
    cands = []
    for L in (max(45.0, 1.6 * R), R + 200.0, 0.55 * reach, 0.85 * reach):
        L = min(L, reach)
        if L < 45.0:
            continue
        for k in range(12):
            ph = 2.0 * math.pi * k / 12.0
            p = (cx + L * math.cos(ph), cy + L * math.sin(ph))
            if p[0] * p[0] + p[1] * p[1] <= ARENA_R * ARENA_R:
                cands.append(p)
    dp = dist(pos, (cx, cy))
    if dp > 1.0:
        ux, uy = (cx - pos[0]) / dp, (cy - pos[1]) / dp
        for L in (max(60.0, dp - R - 150.0), dp * 0.55):
            p = (cx - L * ux, cy - L * uy)
            if p[0] * p[0] + p[1] * p[1] <= ARENA_R * ARENA_R:
                cands.append(p)
    cands.append((cx, cy))
    uniq = []
    for p in cands:
        p = clamp(p)
        if p[0] * p[0] + p[1] * p[1] > ARENA_R * ARENA_R:
            continue
        if avoid is not None and dist(p, avoid) < 25.0:
            continue
        if any(dist(p, u) < 20.0 for u in uniq):
            continue
        uniq.append(p)
    best = None
    for p in uniq:
        if max(dist(p, q) for q in samples) > SAFE_RANGE:
            continue
        worst = 0.0
        for q in samples:
            nr = _region_after(reg, p, bearing(p, q))
            if nr is None:
                continue
            if nr[1] > worst:
                worst = nr[1]
        travel = dist(pos, p) + dist(p, (cx, cy))
        score = worst + TUNE["LAMBDA"] * travel
        if best is None or score < best[0]:
            best = (score, p, worst)
    return None if best is None else best[1]


# ==================== 开链 TSP：最近邻 + 2-opt + Or-opt ====================
def _path_cost(order, nodes, pos_of, start):
    if not order:
        return 0.0
    c = dist(start, pos_of(nodes[order[0]]))
    for a, b in zip(order, order[1:]):
        c += dist(pos_of(nodes[a]), pos_of(nodes[b]))
    return c


def plan_order(start, nodes, pos_of):
    n = len(nodes)
    if n == 0:
        return []
    if n == 1:
        return [0]
    left = list(range(n))
    order, cur = [], start
    while left:
        k = min(left, key=lambda i: dist(pos_of(nodes[i]), cur))
        order.append(k)
        cur = pos_of(nodes[k])
        left.remove(k)
    best = _path_cost(order, nodes, pos_of, start)
    improved = True
    while improved:
        improved = False
        for i in range(n - 1):
            for j in range(i + 1, n):
                cand = order[:i] + order[i:j + 1][::-1] + order[j + 1:]
                c = _path_cost(cand, nodes, pos_of, start)
                if c < best - 1e-9:
                    order, best, improved = cand, c, True
        for seg_len in (1, 2, 3):
            for i in range(0, n - seg_len + 1):
                seg = order[i:i + seg_len]
                rest = order[:i] + order[i + seg_len:]
                for k in range(len(rest) + 1):
                    if k == i:
                        continue
                    cand = rest[:k] + seg + rest[k:]
                    c = _path_cost(cand, nodes, pos_of, start)
                    if c < best - 1e-9:
                        order, best, improved = cand, c, True
    return order


def tsp_open(targets, start, rounds=4):
    """在线开链规划：起点固定 start，返回 (有序目标点, 总长)。

    用距离矩阵做「最近邻构造 + 开链 2-opt + 单点 Or-opt」，O(n^2) 一轮，便于每一步重算。
    统一目标集（监测点 ∪ 待清源）每步重排，取最近的目标
    前进，使「发现即顺路清除」成为算法的自然结果。
    """
    n = len(targets)
    if n == 0:
        return [], 0.0
    P = [start] + list(targets)
    D = [[math.hypot(P[i][0] - P[j][0], P[i][1] - P[j][1]) for j in range(n + 1)]
         for i in range(n + 1)]
    order, left, cur = [], list(range(n)), 0
    while left:
        nxt = min(left, key=lambda j: D[cur][j + 1])
        order.append(nxt)
        left.remove(nxt)
        cur = nxt + 1

    def total(seq):
        s, prev = 0.0, 0
        for x in seq:
            s += D[prev][x + 1]
            prev = x + 1
        return s

    best = total(order)
    improved = True
    while improved and rounds > 0:
        rounds -= 1
        improved = False
        for i in range(n - 1):
            for j in range(i + 1, n):
                a = order[i - 1] + 1 if i > 0 else 0
                b, cc = order[i] + 1, order[j] + 1
                d = order[j + 1] + 1 if j + 1 < n else -1
                old = D[a][b] + (D[cc][d] if d >= 0 else 0.0)
                new = D[a][cc] + (D[b][d] if d >= 0 else 0.0)
                if new < old - 1e-9:
                    order[i:j + 1] = reversed(order[i:j + 1])
                    best += new - old
                    improved = True
        for i in range(n):                     # 单点 Or-opt
            node = order[i]
            rest = order[:i] + order[i + 1:]
            for j in range(n):
                cand = rest[:j] + [node] + rest[j:]
                v = total(cand)
                if v < best - 1e-9:
                    order, best, improved = cand, v, True
                    break
            if improved:
                break
    return order, best                      # 返回下标序列，避免坐标重复造成歧义


# ==================== DogClient ====================
class DogClient(object):
    """问题4：含定向干扰源的可检性覆盖 + 信念主动定位 + 联合路径规划。"""

    def __init__(self, base_url="http://127.0.0.1:2026", robot_id="2026001",
                 note=None, stop_flag=None, max_attempts=6):
        self.base = base_url.rstrip("/")
        self.robot_id = robot_id
        self.note = note or (lambda *a, **k: None)
        self.stop_flag = stop_flag
        self.max_attempts = max_attempts
        self._counter = 0

        self.t_start = None
        self.remaining_real = None
        self.deadline = None

        self.pos = (0.0, 0.0)
        self.channel = 1
        self.vt = 0.0
        self.entered = False
        self.cleared = set()
        self.results = []

        self.rays = {}            # ch -> [(x, y, svd)]
        self.nosig = {}           # ch -> [(x, y)]
        self.no_source = set()
        self._reg = {}            # ch -> region 缓存
        self._clear_failed = set()
        self._grid_done = set()
        self._acq_n = {}
        self._visited_all = False
        self._conn = None
        # 测量/清除去重缓存：电磁环境对同一 (频道, 位置) 确定性不变（题目明示
        # 「同一地点重复检测误差不变」），故同一 (ch, 四舍五入位置) 的测量结果可直接复用；
        # 同一位置的失败清除同样无需重试。这消除了沿射线推进被 clamp 到同一点时
        # 连续重复 /measure（每次 6 s）的浪费。
        self._meas_cache = {}
        self._clear_cache = set()
        # 每个频道实际测过的巡检点集合：只有测遍全部 25 点才可判定「无源」，
        # 避免因预算中断而在未测点处漏掉朝向刚好避开已测点的定向源。
        self._cover_hits = {}

    # ---------- 通信（长连接复用，失败重连） ----------
    @staticmethod
    def _split(base):
        body = base.split("://", 1)[-1]
        hostport = body.split("/", 1)[0]
        host, _, port = hostport.partition(":")
        return host, int(port or 80)

    def _post(self, path, payload):
        data = json.dumps(payload, ensure_ascii=False).encode("utf-8")
        last = None
        for attempt in range(self.max_attempts):
            if self.stop_flag is not None and self.stop_flag.is_set():
                raise KeyboardInterrupt("stopped")
            try:
                if self._conn is None:
                    host, port = self._split(self.base)
                    self._conn = http.client.HTTPConnection(host, port, timeout=10)
                self._conn.request("POST", path, body=data,
                                   headers={"Content-Type": "application/json"})
                r = self._conn.getresponse()
                raw = r.read()
                body = json.loads(raw.decode("utf-8"))
                if getattr(r, "will_close", False):
                    self._close()
                if r.status != 200 or not body.get("accepted"):
                    last = RuntimeError("HTTP %d: %s" % (r.status, body))
                    self._close()
                else:
                    return body
            except KeyboardInterrupt:
                raise
            except Exception as e:
                last = e
                self._close()
            time.sleep(0.2 * (attempt + 1))
        raise RuntimeError("%s 连续失败: %s" % (path, last))

    def _close(self):
        try:
            if self._conn is not None:
                self._conn.close()
        except Exception:
            pass
        self._conn = None

    def _rid(self, tag):
        self._counter += 1
        return "%s-%d" % (tag, self._counter)

    def _payload(self, rid):
        return {"arena_id": "default", "robot_id": self.robot_id, "request_id": rid}

    def _budget_ok(self):
        if self.vt > MAX_VT - 3000:
            return False
        if self.deadline is not None and time.monotonic() > self.deadline:
            return False
        return True

    # ---------- 动作 ----------
    def enter(self):
        r = self._post("/enter", self._payload(self._rid("enter")))
        self.entered = True
        self.t_start = time.monotonic()
        self.remaining_real = r.get("remaining_real_duration_s", 1200)
        mx = r.get("max_real_duration_s", 1200)
        if self.remaining_real is not None and self.remaining_real < mx - 5:
            self.deadline = self.t_start + max(0, self.remaining_real - 15)
        self.vt = r["virtual_time_s"]
        self.note("进入：remaining_real_duration_s=%s" % self.remaining_real)

    def measure(self, x, y, ch):
        x, y, ch = round(x, 3), round(y, 3), int(ch)
        if ch in self.cleared:               # 已清除频道不可能再现信号
            return "no_signal", None
        key = (ch, x, y)
        if Q4V["DEDUP"] and key in self._meas_cache:   # 同点同频道结果确定 -> 直接复用，省 6 s
            return self._meas_cache[key]
        p = self._payload(self._rid("measure"))
        p["position"] = {"x": x, "y": y}
        p["channel"] = ch
        r = self._post("/measure", p)
        self.pos, self.channel, self.vt = (x, y), ch, r["virtual_time_s"]
        self._reg.pop(ch, None)
        res, svd = r.get("measure_result"), r.get("svd_deg")
        if res == "no_signal":
            self.nosig.setdefault(ch, []).append((x, y))
        elif res == "direction" and svd is not None:
            self.rays.setdefault(ch, []).append((x, y, float(svd)))
        elif res == "near":
            self.note("频道%d 近距离信号 @ (%.1f, %.1f)" % (ch, x, y))
        self._meas_cache[key] = (res, svd)
        return res, svd

    def clear(self, x, y, ch):
        x, y, ch = round(x, 3), round(y, 3), int(ch)
        key = (ch, x, y)
        if Q4V["DEDUP"] and key in self._clear_cache:  # 同点同频道已失败过 -> 不再重试
            return "no_target_in_range"
        p = self._payload(self._rid("clear"))
        p["position"] = {"x": x, "y": y}
        p["channel"] = ch
        r = self._post("/clear", p)
        self.pos, self.vt = (x, y), r["virtual_time_s"]
        res = r.get("clear_result")
        if res == "success":
            self.cleared.add(ch)
            self.results.append((ch, x, y))
            self._reg.pop(ch, None)
            self.note("频道%d 已清除 @ (%.1f, %.1f)" % (ch, x, y))
        else:
            self._clear_cache.add(key)
        return res

    def exit_(self):
        try:
            r = self._post("/exit", self._payload(self._rid("exit")))
            reason = r.get("exit_reason")
        finally:
            self._close()
        self.entered = False
        return reason

    # ==================== 信念 ====================
    def _region(self, ch):
        if ch in self._reg:
            return self._reg[ch]
        reg = region(self.rays.get(ch, []))
        self._reg[ch] = reg
        return reg

    def _routable(self, ch):
        reg = self._region(ch)
        return reg is not None and reg["R"] <= TUNE["STOP_R"]

    def _pending(self):
        out = []
        for ch in range(1, MAX_CH + 1):
            if ch in self.cleared or ch in self.no_source:
                continue
            if not self._routable(ch):
                out.append(ch)
        return out

    def _score(self, ch):
        I = 0.35 if self.rays.get(ch) else 1.0
        C = 0.0 if ch == self.channel else 1.0
        return I / (C + 0.05)

    # ==================== 监测点扫描 ====================
    def _scan_point(self, p, only_unseen=False):
        pend = self._pending()
        if only_unseen:
            pend = [ch for ch in pend if not self.rays.get(ch)]
        if not pend:
            return
        pend.sort(key=self._score, reverse=True)
        self.note("监测点(%.0f,%.0f)：%d 个待定频道%s"
                  % (p[0], p[1], len(pend), "（仅未检出）" if only_unseen else ""))
        for ch in pend:
            if not self._budget_ok():
                return
            if ch in self.cleared:
                continue
            reg = self._region(ch)
            if reg is not None:
                if _poly_min_dist(p, reg["poly"]) > TUNE["SKIP_FAR"]:
                    continue
                pr = predicted_R(reg, p)
                # 只有「最乐观情形下可行域收缩仍不足」才跳过该点测量：
                # predicted_R 假定新视线恰好指向当前可行域中心，是最佳情形；连最佳情形
                # 都缩不动 MIN_SHRINK，实测更不会有用。（旧写法 pr > R 恒不成立，等于没跳。）
                if pr is not None and pr > reg["R"] - TUNE["MIN_SHRINK"]:
                    continue
            res, svd = self.measure(p[0], p[1], ch)
            self._cover_hits.setdefault(ch, set()).add((round(p[0], 1), round(p[1], 1)))
            if res == "near":
                self.clear(p[0], p[1], ch)

    # ==================== 主动定位与保证清除 ====================
    def _perp_ray(self, ch):
        """补第二条视线：从已有视线的**测点**出发，沿「射线前进 a + 侧偏 w」取点。

        理论依据：源必在射线上且距锚点 <= 其有效
        半径 R，取 p = S1 + a*û + w*n̂ 时 |p-G|^2 = (d-a)^2 + w^2，在 d∈[0,R] 上有界
        (R-a)^2+w^2；代入 R 的下界 1000 m，当 a=500、|w|<=250 时 |p-G| <= 587 m <<1000 m，
        即**必在接收半径内**、且交会角良态。候选按「离当前位置由近到远」排序先试近的。
        """
        rays = self.rays.get(ch, [])
        if not rays:
            return False
        # 候选池分两族，各取最近若干再合并--避免"离当前位置最近的全落在盲区一侧"：
        #   锚点族 p = S1 + a*û + w*n̂（u 指向源，保证 |p-G| <= (R-a)^2+w^2 的界，必在接收半径内）
        #   中心族 在可行域中心 c 附近沿射线/横向短距探针（就近、便宜）
        a_cands, c_cands = [], []
        for (x, y, th) in list(rays)[-2:]:
            S = (x, y)
            u = uvec(th)
            n = perp(th)
            for (a, w) in ((500.0, 250.0), (500.0, -250.0), (300.0, 250.0),
                           (300.0, -250.0), (150.0, 150.0), (150.0, -150.0)):
                p = clamp((S[0] + u[0] * a + n[0] * w, S[1] + u[1] * a + n[1] * w))
                a_cands.append((dist(p, self.pos), p))
        reg = self._region(ch)
        # 中心族只在**已有良态双线**（可行域中心才有意义）时使用；单线时可行域是一个大
        # 楔形、中心无信息，用它探针会白跑（实测某些定向源因此在中心族上浪费 ~200 s）。
        if reg is not None and len(rays) >= 2 and best_pair_angle(rays) >= MIN_CROSS:
            cu = uvec(rays[-1][2])
            cn = perp(rays[-1][2])
            cxx, cyy = reg["c"]
            for (a, w) in ((120.0, 0.0), (-80.0, 0.0), (100.0, 150.0), (100.0, -150.0),
                           (200.0, 150.0), (200.0, -150.0), (250.0, 0.0),
                           (0.0, 150.0), (0.0, -150.0)):
                p = clamp((cxx + cu[0] * a + cn[0] * w, cyy + cu[1] * a + cn[1] * w))
                c_cands.append((dist(p, self.pos), p))
        a_cands.sort(key=lambda t: t[0])
        c_cands.sort(key=lambda t: t[0])
        # 中心族（若有，近且便宜）优先；锚点族按离当前位置由近到远试，共上限 6 次。
        cands = c_cands[:4] + a_cands
        tried = 0
        seen = []
        for (_d, p) in cands:
            if tried >= 6:                     # 单次补线上限，避免为顽固源到处跑
                break
            if any(dist(p, q) < 60.0 for q in seen):
                continue
            seen.append(p)
            tried += 1
            if ch in self.cleared or not self._budget_ok():
                return ch in self.cleared
            res, svd2 = self.measure(p[0], p[1], ch)
            if res == "near":
                self.clear(p[0], p[1], ch)
                return ch in self.cleared
            if res == "direction" and svd2 is not None:
                if best_pair_angle(self.rays.get(ch, [])) >= MIN_CROSS:
                    return True
        return False

    def _ray_bracket_clear(self, ch, max_d=1500.0, step=100.0):
        """沿最新视线向源推进，用「有信号->无信号」的翻转点二分定出源距，再清除。

        定向源在覆盖角边界处常只拿到单条视线；沿该视线朝源走，进入覆盖角内即有信号，
        越过源后立即落入盲区变 no_signal，故翻转点就是源的距离。对 R 小于距离的情形
        同样成立（信号只会出现在源附近的一段）。
        """
        rays = self.rays.get(ch, [])
        if not rays:
            return False
        x0, y0, svd = rays[-1]
        ux, uy = uvec(svd)
        first = last_sig = None
        hi = None
        # 采样距离表：近段 40 m 细步（源可能就在锚点附近，避免粗步直接越过盲区），
        # 远段 100 m 粗步。命中速度与稳健性折中。
        ds, d = [], 0.0
        while d < 400.0 - 1e-9:
            d += 40.0
            ds.append(d)
        while d < max_d - 1e-9:
            d = min(max_d, d + step)
            ds.append(d)
        for d in ds:
            if not self._budget_ok():
                return ch in self.cleared
            p = clamp((x0 + d * ux, y0 + d * uy))
            res, _sv = self.measure(p[0], p[1], ch)
            if res == "near":
                self.clear(p[0], p[1], ch)
                return ch in self.cleared
            if res == "direction":
                if first is None:
                    first = d
                last_sig = d
            elif first is not None:
                hi = d
                break
        if first is None:
            return False
        if hi is None:
            hi = max_d
        lo = last_sig if last_sig is not None else first
        for _ in range(7):
            mid = 0.5 * (lo + hi)
            if not self._budget_ok():
                break
            p = clamp((x0 + mid * ux, y0 + mid * uy))
            res, _sv = self.measure(p[0], p[1], ch)
            if res == "near":
                self.clear(p[0], p[1], ch)
                return ch in self.cleared
            if res == "direction":
                lo = mid
            else:
                hi = mid
        for d2 in (lo, 0.5 * (lo + hi), hi):
            p = clamp((x0 + d2 * ux, y0 + d2 * uy))
            if self.clear(p[0], p[1], ch) == "success":
                return True
        return False

    def _resolve(self, ch):
        """主动观测 -> 收缩可行域 -> 保证清除；单线定向源先法向补线、再沿视线二分定位。"""
        if ch in self.cleared or not self._budget_ok():
            return
        for _ in range(VIEW_MAX):
            if ch in self.cleared or not self._budget_ok():
                return
            reg = self._region(ch)
            if reg is None:
                break
            if reg["R"] <= TUNE["TIGHT"]:
                break
            rays = self.rays.get(ch, [])
            if len(rays) >= 2 and best_pair_angle(rays) >= MIN_CROSS:
                # 可行域已很小时直接铺格点清；否则先「到可行域中心量测」--量测便宜且
                # 信息量大，能把 R* 再压小，之后的格点清除点更少（先清后测会多铺很多点）。
                if Q4V["REG"] and reg["R"] <= REG_INLOOP_R and self._region_clear(ch):
                    return
                if reg["R"] <= TUNE["NEAR_FIX"]:
                    p = reg["c"]
                else:
                    p = choose_view(reg, self.pos, avoid=self.pos) or reg["c"]
            else:
                if self._acq_n.get(ch, 0) < 2:      # 每频道最多补线 2 次
                    self._acq_n[ch] = self._acq_n.get(ch, 0) + 1
                    if Q4V["PERP"] and self._perp_ray(ch):
                        continue
                break
            res, svd = self.measure(p[0], p[1], ch)
            if res == "near":
                self.clear(p[0], p[1], ch)
                return
        if ch in self.cleared:
            return
        # 保证清除：R*<=TIGHT 时真值必在可行域内、与 c 距离 <CLEAR_R
        for _ in range(3):
            reg = self._region(ch)
            if reg is None:
                break
            if reg["R"] <= TUNE["TIGHT"]:
                if self.clear(reg["c"][0], reg["c"][1], ch) == "success":
                    return
            if not self._budget_ok():
                break
            c = reg["c"]
            res, svd = self.measure(c[0], c[1], ch)
            if res == "near":
                self.clear(c[0], c[1], ch)
                return
            if res != "direction":
                break
        if ch in self.cleared:
            return
        if Q4V["REG"] and self._region_clear(ch):   # 定向源「近在咫尺却测出 no_signal」的死结：
            return                        # poly 包含 真值 -> 格点覆盖清除必命中
        if Q4V["BRACKET"] and self._ray_bracket_clear(ch):
            return
        if self._cert_clear(ch):          # 补线/二分过程中射线增多，可能已可保证清除
            return
        if ch in self.cleared:
            return
        if self._home_clear(ch):
            return
        if self._cert_clear(ch):
            return
        reg = self._region(ch)
        if reg is not None and ch not in self._grid_done:
            self._grid_done.add(ch)          # 网格兜底每频道只做一次，避免反复烧时间
            self.note("频道%d 转局部网格兜底" % ch)
            if self._grid_clear(ch, reg["c"][0], reg["c"][1], rmax=GRID_RMAX):
                return
        self._clear_failed.add(ch)
        self.note("频道%d 本轮未能清除" % ch)

    def _region_clear(self, ch):
        """可行域格点清除（定向源的关键补强）。

        可行域多边形 poly 由各测向的 +/-1° 楔形与 <=1500 m 距离约束精确裁出，故真值
        必在 poly 内。用间距 REG_SPACING 的方格点阵（覆盖半径 sqrt2/2*间距 <20 m）铺满
        poly，逐点 /clear：/clear 只看距离、与朝向无关，失败仅 3 s，故只要铺满就必命中。
        专治「源就在 4 m 外、但该点落在定向覆盖角外 -> 测出 no_signal」而被迫沿射线
        二分/homing 长距离绕行的情形。
        """
        reg = self._region(ch)
        if reg is None or reg["R"] > REG_CLEAR_R:
            return False
        poly, c = reg["poly"], reg["c"]
        if self.clear(c[0], c[1], ch) == "success":
            return True
        xs = [p[0] for p in poly]
        ys = [p[1] for p in poly]
        x0, y0, x1, y1 = min(xs), min(ys), max(xs), max(ys)
        nx = int((x1 - x0) / REG_SPACING) + 2
        ny = int((y1 - y0) / REG_SPACING) + 2
        cand = []
        for j in range(ny):
            yy = y0 + j * REG_SPACING
            for i in range(nx):
                p = (x0 + i * REG_SPACING, yy)
                if _poly_min_dist(p, poly) <= REG_EDGE:
                    cand.append(p)
        cand.sort(key=lambda p: dist(p, self.pos))   # 近的优先，省移动
        if REG_FULL_ONLY and len(cand) > REG_MAX_PTS:
            return False                             # 铺不满 -> 不做半吊子覆盖
        for p in cand[:REG_MAX_PTS]:
            if ch in self.cleared:
                return True
            if not self._budget_ok():
                return False
            if self.clear(p[0], p[1], ch) == "success":
                return True
        return False

    def _cert_clear(self, ch):
        """证书清除：可行域最小包围圆半径 R* <= TIGHT 时，真值必在区域内、与 c 距离
        <= R* < 20 m，故在 c 处 /clear 必然命中（20 m 清除半径与朝向无关）。"""
        reg = self._region(ch)
        if reg is None or reg["R"] > TUNE["TIGHT"]:
            return False
        return self.clear(reg["c"][0], reg["c"][1], ch) == "success"

    def _home_clear(self, ch):
        """追踪式 homing：用最新视线方向逐步逼近，步骤递减。"""
        ls = self.rays.get(ch, [])
        if not ls:
            return False
        p = self.pos
        last_good = p
        for step in (200.0, 140.0, 90.0, 60.0, 40.0, 25.0, 15.0):
            if ch in self.cleared or not self._budget_ok():
                return ch in self.cleared
            res, svd = self.measure(p[0], p[1], ch)
            if res == "near":
                self.clear(p[0], p[1], ch)
                return ch in self.cleared
            if res != "direction" or svd is None:
                mid = ((p[0] + last_good[0]) / 2.0, (p[1] + last_good[1]) / 2.0)
                for q in (last_good, mid):
                    if self.clear(q[0], q[1], ch) == "success":
                        return True
                return ch in self.cleared
            last_good = p
            p = (p[0] + step * math.cos(math.radians(svd)),
                 p[1] + step * math.sin(math.radians(svd)))
        return self.clear(p[0], p[1], ch) == "success"

    def _grid_clear(self, ch, cx, cy, rmax=GRID_RMAX, spacing=GRID_SPACING):
        if self.clear(cx, cy, ch) == "success":
            return True
        n = int(rmax / spacing)
        for ring in range(1, n + 1):
            r = ring * spacing
            pts = []
            for i in range(-ring, ring + 1):
                pts.append((cx + i * spacing, cy + r))
                pts.append((cx + i * spacing, cy - r))
            for j in range(-ring + 1, ring):
                pts.append((cx + r, cy + j * spacing))
                pts.append((cx - r, cy + j * spacing))
            for (x, y) in pts:
                if ch in self.cleared:
                    return True
                if not self._budget_ok():
                    return False
                if self.clear(x, y, ch) == "success":
                    return True
        return False

    # ==================== 联合路径规划 ====================
    @staticmethod
    def _pos_of(node, est):
        if node[0] == "pt":
            return COVER_POINTS[node[1]]
        return est.get(node[1]) or (0.0, 0.0)

    def _insert(self, route, node, est):
        pos_of = lambda n: self._pos_of(n, est)
        if not route:
            route.append(node)
            return
        base = dist((0.0, 0.0), pos_of(route[0]))
        for a, b in zip(route, route[1:]):
            base += dist(pos_of(a), pos_of(b))
        best_i, best_c = len(route), None
        for i in range(len(route) + 1):
            if i == 0:
                c = (base - dist((0.0, 0.0), pos_of(route[0]))
                     + dist((0.0, 0.0), pos_of(node)) + dist(pos_of(node), pos_of(route[0])))
            elif i == len(route):
                c = base + dist(pos_of(route[-1]), pos_of(node))
            else:
                c = (base - dist(pos_of(route[i - 1]), pos_of(route[i]))
                     + dist(pos_of(route[i - 1]), pos_of(node))
                     + dist(pos_of(node), pos_of(route[i])))
            if best_c is None or c < best_c:
                best_i, best_c = i, c
        route.insert(best_i, node)

    def _bayes_p_remain(self):
        """后验「仍有未检出源」的概率（总数先验 10..16 + 单源检出率 q 的二项似然）。

        D = 已检出（有视线或已清除）的源数；P(S|D) 正比 P(S)*C(S,D)q^D(1-q)^(S-D)。
        返回 (1 - P(S=D|D), D)，即还存在未检出源的估计概率。
        """
        D = len([ch for ch in range(1, MAX_CH + 1)
                 if self.rays.get(ch) or ch in self.cleared])
        q = BAYES_Q
        posts = []
        for S in range(10, 17):
            if S < D:
                continue
            lp = math.log(math.comb(S, D)) + D * math.log(q)
            if S - D > 0:
                lp += (S - D) * math.log(1.0 - q)
            posts.append((S, lp))
        if not posts:
            return 1.0, D
        mx = max(lp for _, lp in posts)
        w = [(S, math.exp(lp - mx)) for S, lp in posts]
        tot = sum(v for _, v in w)
        p0 = sum(v for S, v in w if S == D) / tot
        return 1.0 - p0, D

    def _run_route(self):
        """统一目标集 + 每步在线开路：每步对目标集重排后取最近者前进。

        目标集 = 未访问的监测点 ∪ 已可清除的源（可行域中心）。每一步对目标集做一次
        开链 TSP（最近邻 + 开链 2-opt + Or-opt），取最近的目标前进；于是「发现即顺路
        清除」是算法的自然结果，避免"先跑完巡检再逐个清源"的双程浪费。
        监测点只对仍待定的频道测量；贴边/无信号频道靠监测点路线检出，走完判无源。

        BAYES_STOP=True 时先把内层格走完，再用后验 P(仍有未检出源) 决定是否值得走
        外环（见 `_bayes_p_remain`）--这是"用统计换时间"的档位，默认关闭以保证全清。
        """
        self.note("监测点构型：内层六边格(%.0f,<=%.0f) %d 点 + 外环(%.0f,%d,相位%.0f°)"
                  % (HEX_S, HEX_RMAX, N_INNER, COVER_OUTER_R, COVER_OUTER_K,
                     math.degrees(COVER_OUTER_PHASE)))
        if Q4V["ROUTE"]:
            return self._run_route_insert()
        if USE_OUTER_SWEEP:
            if BAYES_STOP:
                cover_left = list(range(N_INNER))
                outer_left = list(range(N_INNER, len(COVER_POINTS)))
            else:
                cover_left = list(range(len(COVER_POINTS)))
                outer_left = []
        else:
            cover_left = list(range(N_INNER))
            outer_left = []
        guard = 0
        while self._budget_ok() and guard < 1200:
            guard += 1
            if not cover_left and outer_left:          # 内层走完 -> 决定是否走外环
                p_rem, D = self._bayes_p_remain()
                if p_rem <= BAYES_TAU:
                    self.note("贝叶斯停止：已检出 %d 个，P(仍有未检出源)=%.3f <= %.2f，跳过外环"
                              % (D, p_rem, BAYES_TAU))
                    outer_left = []
                else:
                    self.note("贝叶斯续扫：已检出 %d 个，P(仍有未检出源)=%.3f > %.2f"
                              % (D, p_rem, BAYES_TAU))
                    cover_left += outer_left
                    outer_left = []
            targets, kinds = [], []
            for k in cover_left:
                targets.append(COVER_POINTS[k])
                kinds.append(("cover", k))
            for ch in range(1, MAX_CH + 1):
                if (ch in self.cleared or ch in self.no_source
                        or ch in self._clear_failed):
                    continue
                reg = self._region(ch)
                if reg is None or reg["R"] > TUNE["INS_R"]:
                    continue
                rays = self.rays.get(ch, [])
                if not (reg["R"] <= TUNE["NEAR_FIX"]
                        or (len(rays) >= 2 and best_pair_angle(rays) >= MIN_CROSS)):
                    continue          # 单线/近平行：继续在监测点扫描，免费取第二视线
                targets.append(reg["c"])
                kinds.append(("src", ch))
            if not targets:
                break
            ordered, _ = tsp_open(targets, self.pos)
            i = ordered[0]
            kind, val = kinds[i]
            try:
                if kind == "cover":
                    cover_left.remove(val)
                    self._scan_point(COVER_POINTS[val], only_unseen=(val >= N_INNER))
                else:
                    if val in self.cleared:
                        continue
                    self._resolve(val)
            except Exception as e:      # 单步网络/异常不应中断整条巡检
                self.note("步骤异常(ch=%s,%s)：%s" % (val, kind, e))
        self._visited_all = not cover_left

    def _run_route_insert(self):
        """固定覆盖骨架 + 源最小插入代价 + 每步重排（`Q4V_ROUTE=1`）。

        * 覆盖顺序 = 出发点 (0,0) 对全部巡检点**一次性**求开链 TSP（避免逐步重排的抖动）；
        * 频道可行域够小（R* <= INS_R，且 R* <= NEAR_FIX 或已有良态双线）即按**最小插入代价**
          并入**剩余**路线，估计位置随观测更新；
        * 每步用 plan_order 对整条剩余路线做 2-opt/Or-opt 重排，取第一个节点执行；
        * 外环点（下标 >= N_INNER）只测「完全未检出」的频道--内层格已经取到视线的频道
          在边界外环上再测一次几乎无新信息，省下一次测量。
        """
        cover_order = plan_order((0.0, 0.0), list(range(len(COVER_POINTS))),
                                 lambda i: COVER_POINTS[i])
        route = [("pt", i) for i in cover_order]
        est, in_route = {}, set()
        guard = 0
        while route and self._budget_ok() and guard < 1200:
            guard += 1
            for ch in range(1, MAX_CH + 1):
                if (ch in self.cleared or ch in self.no_source
                        or ch in self._clear_failed):
                    continue
                reg = self._region(ch)
                if reg is None or reg["R"] > TUNE["INS_R"]:
                    continue
                rays = self.rays.get(ch, [])
                if not (reg["R"] <= TUNE["NEAR_FIX"]
                        or (len(rays) >= 2 and best_pair_angle(rays) >= MIN_CROSS)):
                    continue          # 单线/近平行：继续在监测点扫描，免费取第二视线
                est[ch] = reg["c"]
                if ch not in in_route:
                    in_route.add(ch)
                    self._insert(route, ("src", ch), est)
            if not route:
                break
            pos_of = lambda n: self._pos_of(n, est)
            route = [route[i] for i in plan_order(self.pos, route, pos_of)]
            node = route.pop(0)
            if node[0] == "pt":
                self._scan_point(COVER_POINTS[node[1]], only_unseen=(node[1] >= N_INNER))
            else:
                ch = node[1]
                in_route.discard(ch)
                if ch in self.cleared:
                    continue
                reg = self._region(ch)
                if reg is not None:
                    est[ch] = reg["c"]      # 用本频道当前的可行域中心（勿用残留值）
                try:
                    self._resolve(ch)
                except Exception as e:
                    self.note("频道%d 清除异常：%s" % (ch, e))
        self._visited_all = all(n[0] != "pt" for n in route)

    # ==================== 主流程 ====================
    def run(self):
        t0 = time.monotonic()
        self.note("问题4策略：内层六边格 + 域外环 可检性覆盖（最坏角间隙 %.1f° <180°）"
                  % COVER_WORST_GAP)
        self.enter()
        try:
            try:
                self._run_route()
            except Exception as e:            # 路线阶段出错也要保证收尾清除不丢
                self.note("路线阶段异常：%s" % e)
            if self._visited_all:
                for ch in range(1, MAX_CH + 1):
                    if (ch not in self.cleared and ch not in self.no_source
                            and not self.rays.get(ch)):
                        # 必须确实测遍全部巡检点才可判无源（保证覆盖定理成立的前提）
                        if (Q4V["GUARD"] and len(self._cover_hits.get(ch, ()))
                                < len(COVER_POINTS)):
                            self.note("频道%d 未测遍全部巡检点，暂不判无源" % ch)
                            continue
                        self.no_source.add(ch)
                        self.note("频道%d 全程无信号，判定无干扰源" % ch)
            # 收尾清除按「就近」顺序（不是频道号顺序）：以可行域中心估计为节点做开链
            # 规划，每清完一个重排一次，避免在场地两端来回空跑。
            tried = {}
            while self._budget_ok():
                pend = []
                for ch in set(self.rays) - self.cleared:
                    reg = self._region(ch)
                    if reg is None or tried.get(ch):
                        continue
                    pend.append((reg["c"], ch))
                if not pend:
                    break
                order, _ = tsp_open([c for c, _ in pend], self.pos)
                ch = pend[order[0]][1]
                tried[ch] = True
                try:
                    self._resolve(ch)
                except Exception as e:
                    self.note("频道%d 清除异常：%s" % (ch, e))
            stuck = [ch for ch in self.rays if ch not in self.cleared]
            if stuck:
                self.note("以下频道未清除: %s" % stuck)
            det = len(set(self.rays) | self.cleared)
            self.note("完备性核验：检出 %d，清除 %d，判无源 %d"
                      % (det, len(self.cleared), len(self.no_source)))
        except KeyboardInterrupt:
            raise
        except Exception as e:
            self.note("运行异常：%s" % e)
        finally:
            det = len(set(self.rays) | self.cleared)
            self.note("完备性核验：检出 %d，清除 %d，判无源 %d"
                      % (det, len(self.cleared), len(self.no_source)))
            try:
                reason = self.exit_()
            except Exception:
                reason = "exit_error"
            dt = time.monotonic() - t0
            n = len(self.cleared)
            self.note("结束(%s)：清除 %d 个，虚拟时间 %.1f s，程序运行 %.1f s，平均 %.1f s"
                      % (reason, n, self.vt, dt, (self.vt / n) if n else 0.0))
        return {"cleared": sorted(self.cleared), "virtual_time": self.vt,
                "program_time": time.monotonic() - t0}
