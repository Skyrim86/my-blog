问题一　交会定位区域直径的计算与圆覆盖性分析#

本章依据赛题正文及其附录 1（干扰源特征）、**附录 2（测向机原理与交会定位法）**建立模型。为控制正文篇幅、便于交叉复核，本章正文只讲思想、建模过程、算法设计与实验：全部符号定义与公式集中在《问题一_公式.md》，全部证明集中在《问题一_小证明.md》，各结论对应的验证脚本、复现命令、数值口径与踩坑记录集中在《问题一_证明笔记.md》（main/过程记录/）。正文中凡需写出公式或定理内容时，一律按上述文件引用其式号或定理名。

1 问题重述#

已知目标区域中某干扰源关于若干检测点的示向度，要求解决两件事：第一，给出采用交会定位法计算该干扰源多边形定位区域直径（即区域内任意两点之间距离的最大值）的算法；第二，回答以该定位区域直径为直径的圆能否覆盖此定位区域。

依附录 2，示向度定义为：在检测点处测得的、使场强最大的接收天线方向的方位角，即 xxx 轴正向逆时针旋转至"检测点指向干扰源"向量方向的角度，取值范围 [0∘,360∘)[0^\circ,360^\circ)[0∘,360∘)。由于环境影响与测向精度所限，示向度与真实方位角之间存在误差；在目标区域全局范围内，误差落在 ±1∘\pm1^\circ±1∘ 内，且同一地点的电磁环境固定，重复检测不改变该误差。附录 2 图 2 给出两检测点交会的情形：两条实线为测得示向度方向，实线与相邻虚线夹角均为 1∘1^\circ1∘，由四条误差边界线围成的四边形即定位区域。

由此可见：一条示向度给出的不是一个点，而是一个角约束；定位区域是这些角约束的公共部分。这正是本问的几何本质。据此，本问的求解不是"求两条射线的交点"这类解方程问题，而是"求一族角度约束的公共位置集合、再在该集合上求最大跨度与其外接圆包含关系"的几何问题。

2 模型假设#

  1. 平面假设：由附录 2(7)，忽略测向机与干扰源的高度差，测向机与所有干扰源位于同一平面，问题为二维几何问题。
  2. 有界误差假设：真实方位角 αi\alpha_iαi​ 与示向度 θi\theta_iθi​ 之差的绝对值不超过楔形半角宽 δ\deltaδ（本题 δ=1∘\delta=1^\circδ=1∘）。本假设不依赖误差的分布形式，也不依赖各检测点误差之间的独立性（题面明确同一地点误差固定、不同地点才呈现统计规律）。这是本问采用"集合隶属"视角的根据。
  3. 同一源假设：所有示向度来自同一个干扰源。
  4. 几何约束仅由方向决定（主模型）：主模型的定位区域仅由示向度方向及其 ±1∘\pm1^\circ±1∘ 误差带决定，即附录 2 图 2 所定义的区域；有效接收半径 [1000,1500][1000,1500][1000,1500] m 与目标圆域半径 180018001800 m 不进入主模型，而是作为物理先验约束单独构造区域 RcR_cRc​ 处理（见 §5.2）。本文的全部定理（有界性、直径、覆盖判据）均针对主模型的 RRR；RcR_cRc​ 需重新计算直径与覆盖性，不能沿用 RRR 的结论。
  5. 忽略数值舍入；算法在实数域上讨论。

4 问题分析#

本问要解决三个层层递进的子问题。

第一，如何把示向度写成几何约束？ 一个检测点的示向度只给出"源在该方向上"的射线，误差带把射线放宽为一个夹角 2∘2^\circ2∘ 的角形区域（楔形）。多个检测点给出多个楔形，它们的交集才是源的可能位置集合，即定位区域。第二，如何由定位区域求直径？ 楔形是两个半平面的交，有限个楔形之交是凸多边形；凸多边形的直径必在其顶点对处取得，故只需在有限个顶点上求最大距离。第三，直径圆能否覆盖定位区域？ 这是"一个由直径决定的圆"与"区域"的包含关系问题。直觉上"直径的两端点决定了区域的最大跨度，所以半径为 D/2D/2D/2 的圆应当够用"是错误的：圆是中心对称的，而区域可以是不对称的（例如钝角或直角三角形），此时区域会从直径圆"鼓"出去。因此需给出严格判据与最坏情况界。

此外必须处理两类退化：观测矛盾（区域为空）与区域无界（无法定位）。二者在数学上是独立的，不能混为一谈——空集判定只能由半平面交本身给出，无界判据不能替代它（§5.3 给出两个方向的算例）。

核心主线（五步）. 本问的解答归结为一条主链：先由误差带写出楔形 WiW_iWi​（式 (1)）；再取诸楔形之交得到定位区域 RRR（凸多边形）；然后做空集、无界、有界的三分判定（定理 1）；再在顶点对上求直径 DDD（定理 2）；最后用 Thales 判据判定直径圆的覆盖性（定理 3）。

这五步全部针对主模型 RRR（严格按题目与附录 2 图 2 定义）。物理约束 RcR_cRc​（目标圆域、有效接收半径）是此主链之外的独立修正层：必须对 RcR_cRc​ 重新求直径、重新判覆盖，不能沿用 RRR 的结论（见 §5.2 与定理 3 之后的覆盖性转移讨论）。

从算法设计角度看，问题一的难点不在优化而在稳健性：区域尺度会随观测几何的退化而无界增长（§5.3 表 1 给出 Δθ\Delta\thetaΔθ 刚超过 2∘2^\circ2∘ 时直径可达万米量级的算例），任何依赖"预先给定一个大框"的实现都会在临界构型上失效。因此本文的算法一律采用无框的区域顶点枚举，其合法性由性质 2 保证。

5.2 定位区域：主模型与物理约束模型#

第一块：主模型 RRR（严格按题目与附录 2 图 2 定义，本文主体）. 主模型只使用示向度方向及其 ±1∘\pm1^\circ±1∘ 误差带，不含任何物理先验；本文的全部定理（有界性、直径、覆盖判据）都针对它。RRR 是 2n2n2n 个半平面之交，由性质 1 为闭凸集，有界非空时是 h≤2nh\le2nh≤2n 的凸多边形——这正是题面所称的"多边形定位区域"。每个楔形的回收锥就是该楔形锥本身（式 (3)），它张角 2δ<180∘2\delta<180^\circ2δ<180∘、不含直线，这正是性质 2 中"尖锥"论断的来源，也是定理 1 中无界判据的出发点。

第二块：物理约束模型 RcR_cRc​（单独定义、独立求解，不继承主模型结论）. 题面另给出两条先验，二者都是凸约束，可把主模型 RRR 进一步缩小为式 (3′) 所示的 RcR_cRc​：目标圆域——源在以原点为心、半径 180018001800 m 的闭圆盘内；有效接收半径——在 SiS_iSi​ 处能测得示向度说明源到 SiS_iSi​ 的距离不超过其有效接收半径，而后者上界为 150015001500 m。二者加入后 Rc⊆RR_c\subseteq RRc​⊆R，故 diam⁡(Rc)≤diam⁡(R)\operatorname{diam}(R_c)\le\operatorname{diam}(R)diam(Rc​)≤diam(R)，即主模型的直径是加约束后直径的保守上界。交后仍是凸紧集。

由此带来两点实现上的注意。其一，直径仍可沿边界求极值（直线段的顶点；以及圆弧段上的极值点，其端点既可能是"圆弧—直线"交点，也可能是两段圆弧的交点）。其二，覆盖判定要注意，定理 3 的"只需在顶点检验"不再直接成立（凸二次函数 ggg 在圆弧边界上可能于内点取极大），需在圆弧段上补求 ggg 的极大值（单变量问题，比较临界点与端点即可）。工程上亦可把圆盘换成内接正 kkk 边形（kkk 足够大），则退化为纯多边形问题，误差可估计。

关于有效接收半径的下界. 题面把有效接收半径写成区间 [1000,1500][1000,1500][1000,1500] m。本节只把上界 150015001500 m 写成凸约束；下界 100010001000 m 的含义是"源不会比 100010001000 m 更近"，对应从 RcR_cRc​ 中挖去各检测点的 100010001000 m 圆盘内部。该约束非凸：取 S1=(0,0)S_1=(0,0)S1​=(0,0)，点 A=(1200,0)A=(1200,0)A=(1200,0) 与点 B=(0,1200)B=(0,1200)B=(0,1200) 都满足到 S1S_1S1​ 的距离不小于 100010001000 m，但其中点 (600,600)(600,600)(600,600) 距 S1S_1S1​ 为 848.5848.5848.5 m，小于 100010001000 m，故可行集对凸组合不封闭。因此：① 若把下界并入，RcR_cRc​ 将失去凸性，定理 2、定理 3 的"极值在顶点取得"不再适用，需改用一般非凸可行性判定；② 本题并不需要这一步——只取上界得到的区域更大，据它作覆盖判定是保守的（若大区域都能被直径圆覆盖，小区域自然也能）。故正文按"只取上界"处理，并把这一保守性作为口径在结论中注明。

题面所问为"多边形定位区域"的直径，故主模型取 RRR（凸多边形，定理 1–4 全程适用）；物理约束 RcR_cRc​ 作为独立的第二块单独求解（见 §6.1 算法第 11–12 步），其直径与覆盖性由 RcR_cRc​ 自身（顶点与圆弧段）重新计算。

覆盖结论不可从主模型直接搬到物理约束模型. “加入约束只会使 RRR 变小、直径是保守上界"这句话对直径成立，但覆盖结论并不随之单调——区域缩小后直径与直径圆同时改变。随机复算（n=2n=2n=2、满足各检测点到源距离不超过 150015001500 m 的物理相容构型 394839483948 组）显示，叠加接收半径约束后约 3.60%3.60\%3.60% 的构型覆盖结论由"覆盖"翻为"不覆盖”。故必须对同一个区域计算直径点对与直径并作覆盖判定，不可把纯角约束下的覆盖结论直接搬到加约束后的区域。

5.3 有界性与空集的判别#

（1）集合隶属（有界误差）估计. 本问把示向度误差视为有界不确定性而非随机变量：真实方位角必落在测得值 ±1∘\pm1^\circ±1∘ 内，故真源必属于所有楔形之交 RRR。“真源属于 RRR“是一个确定性保证，不依赖误差的分布形态，也不依赖各检测点误差的独立性（即使相邻地点误差高度相关仍成立），这正是集合隶属/有界误差估计框架的优点（文献 [3,4]）。由此可得三条直接可用的推论：同一地点重复检测不缩小 RRR（题面明确同点误差固定），故降低不确定域必须改变检测点；两点过近时两楔形几乎重合，RRR 几乎不缩小；保证性与误差相关性无关，故不存在"区域虚假收缩"的风险。基于协方差的 GDOP 与最小二乘（文献 [8,9]）给出的是平均意义下的精度，可作为辅助判据，但不能替代本问的保证性结论。

（2）计算几何. 定位区域是半平面交，其顶点数不超过 2n2n2n；凸多边形直径由顶点对决定，可用枚举或旋转卡壳求解；覆盖问题归结为 Thales 圆与凸集的包含关系，最坏情况由 Jung 定理给出上界，实际最小覆盖圆由 Welzl 算法求得。这些均为计算几何的经典结论（文献 [1,2,5,6,7,10]）。此外，把"回收锥为尖锥的多面体必有顶点"这一多面体基本事实用于无框判空（性质 2），是本问在实现层面避免框依赖的关键（文献 [1]）。

# -*- coding: utf-8 -*-
import math
import numpy as np

EPS = 1e-9
D2R = math.pi / 180.0


def wedge_halfplanes(S, theta_deg, half=1.0):
    """楔形 W = 顶点 S、示向度 theta_deg、左右各 half 度。
    返回两个半平面 (q, n)，含义 n·(p-q) >= 0。"""
    S = np.asarray(S, float)
    a1 = (theta_deg - half) * D2R
    a2 = (theta_deg + half) * D2R
    n1 = np.array([-math.sin(a1), math.cos(a1)])   # 下边界内法向
    n2 = np.array([math.sin(a2), -math.cos(a2)])   # 上边界内法向
    return [(S, n1), (S, n2)]


def clip(poly, q, n):
    """Sutherland-Hodgman: 用半平面 n·(p-q) >= 0 裁剪凸多边形。
    poly 顶点数可为 1 或 2（退化的点/线段），凸裁剪不会使顶点数回升。"""
    if len(poly) == 0:
        return []
    out, m = [], len(poly)
    for i in range(m):
        A, B = poly[i], poly[(i + 1) % m]
        da = float(np.dot(n, A - q)); db = float(np.dot(n, B - q))
        ina, inb = da >= -EPS, db >= -EPS
        if ina:
            out.append(A)
        if ina != inb:
            out.append(A + (da / (da - db)) * (B - A))
    return out


def build_region(dets, box_half=None):
    """dets: [(S, theta_deg), ...] -> 顶点列表（按极角排序）。
    返回 [] 表示**空集**（观测矛盾）；返回 1 或 2 个顶点表示区域退化为点/线段。

    实现（第四次修订：无框化，勘误 C14 由此从结构上消除）
    ---------------------------------------------------
    依据 §5.1 性质 2：每个楔形的回收锥张角 2δ<180°、不含直线，
    故 rec(R)=∩_i C_i 是**尖锥**，非空 R 必有顶点。于是
        R ≠ ∅  ⟺  "边界线两两求交 + 全约束可行性筛选"的候选点集非空。
    该判据**不需要任何裁剪框**，因此不再存在"固定大框在 lmin->2*delta
    附近截断直径或把非空域误判为空"的问题（旧实现 box_half=1e6 的缺陷）。
    空集只能由"半平面交为空"判定，不可由无界判据代替（见 5.3(4)）。
    box_half 仅为兼容旧签名保留，已不再使用。"""
    return region_vertices(dets)


def region_vertices(dets, half=1.0):
    """无框枚举 R 的顶点（性质 2）。返回 [] <=> R 为空集。"""
    hps = []
    for S, th in dets:
        hps.extend(wedge_halfplanes(S, th, half))
    # 相对容差：按坐标尺度缩放，避免绝对容差在 1e6 量级坐标上过紧（见 §6.2）
    scale = max(1.0, max(float(np.max(np.abs(np.asarray(S, float)))) for S, _ in dets))
    tol = 1e-9 * scale
    cand = []
    m = len(hps)
    for i in range(m):
        qi, ni = hps[i]
        for j in range(i + 1, m):
            qj, nj = hps[j]
            den = ni[0] * nj[1] - ni[1] * nj[0]
            if abs(den) <= 1e-12:
                continue                                   # 两边界平行
            bi, bj = float(np.dot(ni, qi)), float(np.dot(nj, qj))
            p = np.array([(bi * nj[1] - bj * ni[1]) / den,
                          (ni[0] * bj - nj[0] * bi) / den])  # Cramer 法则
            if all(float(np.dot(n, p - q)) >= -tol for q, n in hps):
                cand.append(p)                             # 可行 -> 必为顶点
    if not cand:
        return []
    uniq = []
    for p in cand:                                         # 去重（相对容差）
        if not any(float(np.linalg.norm(p - u)) <= 1e-6 * scale for u in uniq):
            uniq.append(p)
    c = np.mean(np.array(uniq), axis=0)                    # 按极角排序成凸多边形顶点序
    uniq.sort(key=lambda p: math.atan2(float(p[1] - c[1]), float(p[0] - c[0])))
    return uniq


def min_arc(thetas):
    """所有示向度在圆周上的最小包含弧长 ℓ_min，式 (5)。

    注意：必须**先去重**再取最大间隙。若不去重，示向度全等（完全共线观测）时
    所有间隙均为 0、max_gap = 0，会返回 360（真值 0），把无界误判为有界。
    """
    ts = sorted(set(t % 360.0 for t in thetas))
    n = len(ts)
    if n <= 1:
        return 0.0
    max_gap = max((ts[(i + 1) % n] - ts[i]) % 360.0 for i in range(n))
    return 360.0 - max_gap


def region_unbounded(thetas, half=1.0):
    """定理 1 的解析判据：方向区间在圆周上有公共点 <=> 无界。"""
    ts = sorted(t % 360.0 for t in thetas)
    if len(ts) <= 1:
        return True
    return min_arc(ts) <= 2 * half + 1e-9


def diameter(V):
    """凸多边形直径 = 顶点对最大距离。"""
    best, pair = 0.0, (0, 0)
    for i in range(len(V)):
        for j in range(i + 1, len(V)):
            d = float(np.linalg.norm(V[i] - V[j]))
            if d > best:
                best, pair = d, (i, j)
    return best, pair


def circum(a, b, c):
    ax, ay = a; bx, by = b; cx, cy = c
    d = 2 * (ax * (by - cy) + bx * (cy - ay) + cx * (ay - by))
    if abs(d) < 1e-14:
        return None, None
    ux = ((ax**2 + ay**2)*(by - cy) + (bx**2 + by**2)*(cy - ay) + (cx**2 + cy**2)*(ay - by)) / d
    uy = ((ax**2 + ay**2)*(cx - bx) + (bx**2 + by**2)*(ax - cx) + (cx**2 + cy**2)*(bx - ax)) / d
    c0 = np.array([ux, uy])
    return c0, float(np.linalg.norm(a - c0))


def mec(V):
    """最小包围圆（暴力：点对 + 点三元组）；单点退化为半径 0。"""
    pts = [np.asarray(p, float) for p in V]
    if len(pts) == 0:
        return None, 0.0
    if len(pts) == 1:
        return pts[0], 0.0
    bestr, bestc = 1e18, None

    def ok(c, r):
        return all(np.linalg.norm(p - c) <= r + 1e-7 for p in pts)

    for i in range(len(pts)):
        for j in range(i + 1, len(pts)):
            c = (pts[i] + pts[j]) / 2
            r = float(np.linalg.norm(pts[i] - pts[j]) / 2)
            if r < bestr and ok(c, r):
                bestr, bestc = r, c
    for i in range(len(pts)):
        for j in range(i + 1, len(pts)):
            for k in range(j + 1, len(pts)):
                c, r = circum(pts[i], pts[j], pts[k])
                if c is not None and r < bestr and ok(c, r):
                    bestr, bestc = r, c
    return bestc, bestr


def solve_question1(dets):
    """主算法 Q1。"""
    V = build_region(dets)
    if len(V) == 0:                                  # 空集优先判定
        return {"status": "inconsistent", "msg": "观测矛盾（非同源/误差超界/误测漏测）",
                "lmin": min_arc([t for _, t in dets])}
    if region_unbounded([t for _, t in dets]):       # 定理 1
        return {"status": "unbounded", "msg": "直径 = +∞，不可定位",
                "lmin": min_arc([t for _, t in dets])}
    D, (ia, ib) = diameter(V)                        # 式 (6)
    a, b = V[ia], V[ib]
    g_all = [float(np.dot(p - a, p - b)) for p in V]
    # g(a) = g(b) = 0 恒成立，不构成覆盖证据；故只报"其余顶点"的最大值
    g_other = max([g for k, g in enumerate(g_all) if k not in (ia, ib)] or [-np.inf])
    c, Rstar = mec(V)
    return {"status": "bounded", "vertices": V, "D": D, "pair": (a, b),
            "covered": g_other <= 1e-9 * max(1.0, D * D),
            "gmax_others": g_other, "gmax": max(g_all),
            "Rstar": Rstar, "MEC_center": c, "Jung": D / math.sqrt(3),
            "degenerate": len(V) < 3}
